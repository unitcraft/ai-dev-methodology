# Шаг агента: код автомата

Стейт-машина одного вызова агента — линзы, запуска сессии цикла, хода чата: типизированный запрос (`ЗапросАгента`), ход к транспорту агента (обращение ХОД_АГЕНТА), повтор временной ошибки, продолжение обрезанного выхода, проверка формы ответа с одним ходом исправления, запросы разрешений (развилка ПОЛИТИКА и ворота РАЗРЕШЕНИЕ), проверка бюджета (БЮДЖЕТ), сбор единой записи расхода (УЧЁТ) и ответ `ОтветАгента` либо отказ с кодом из закрытого списка, — записанная кодом на языке Нова как реализация протокола `Автомат` движка [state-machine-engine-automaton.md](state-machine-engine-automaton.md): данные машины, перечисления `Состояние` и `Событие`, переход `перейти(состояние, событие)` как `match` по состоянию и событию, роли (входы и результаты обращений к транспорту агента и к человеку на воротах), работа операций, ответ по концу по контракту машины. Всё общее — конверт запроса и ответа, исполнитель, снимок и хранилище, общие события «стоп/продолжить/отмена», цикл, фиксации — в движке и здесь не повторяется. Нормы — [task-runner.md](task-runner.md) (словарь, профили запуска, форматы файлов).

**Первоисточник — [state-machine-agent-step-states.md](state-machine-agent-step-states.md)** (машина «Шаг агента»: таблицы состояний, общие события, «Контракт машины», «Решения при переводе»); правила формы — [state-machine-spec.md](state-machine-spec.md). Этот файл — производная запись того же автомата, а не второй источник истины: при любом расхождении верен первоисточник, а этот файл правится вслед за ним. Язык записи — Нова, https://github.com/nv-lang/nova. **Код не компилировался и не проверялся компилятором Нова:** это псевдокод в синтаксисе Нова; соглашения записи, помеченные места (`// псевдокод:`), подтверждённое и неподтверждённое спецификацией — в [state-machine-engine-automaton.md](state-machine-engine-automaton.md), здесь только то, что относится к шагу агента. Опытный статус описан в шапке первоисточника и здесь не повторяется; раннером эта машина не исполняется. Вызывает эту машину запуск сессии — [task-runner-session-automaton.md](task-runner-session-automaton.md) (первоисточник — [task-runner-session-states.md](task-runner-session-states.md); состояние СЕССИЯ) по контракту вызова движка (`Вызываемое`, эффект `Связь`: запрос уходит как `ЗапросРоли`, ответ приходит сообщением), а не прямым вызовом функции; общие типы (`ЗапросАгента`, `ОтветАгента`, `Использование`, `ВидВызывающего`, `ПрофильАгента`, `ПределыАгента`, `МодельАгента`, `Токены`) объявлены в слое методики — [state-machine-methodology-automaton.md](state-machine-methodology-automaton.md). Вызовы ролей совещания на эту машину пока не переведены (первоисточник, решение 13). Имя файла — по `AGENTS.md`, «Вынесенные алгоритмы», форма `automaton` (документ `state-machine`, часть `agent-step`).

## Соглашения записи

1. **Типы и идентификаторы** — по [движку](state-machine-engine-automaton.md), пункты 1–3: русские имена. Общие типы данных (`ВидВызывающего`, `МодельАгента`, `Токены`, `Использование`, `ПрофильАгента`, `ПределыАгента`, `ЗапросАгента`, `ОтветАгента`) объявлены один раз в слое методики [state-machine-methodology-automaton.md](state-machine-methodology-automaton.md) и подключены здесь; их таблица соответствия именам блока «Типы на Нове» — там же. Вход паузы (`ВходПаузы`) — тоже из слоя; вариант `ВходРоли` для входа паузы — `ВходПаузыРоли`. Собственные типы данных этой машины (первоисточник, «Типы»): `РасходТранспорта`, `ВидДействия`, `ЗапросРазрешения`, `ПроверкаОтвета`, `ИтогХода`. Записи автомата, которых в первоисточнике нет: `РезультатРоли`, `ВходРоли`, `Окружение`, `Необратимое`. **Значения перечислений** с совпадающими именами в разных перечнях пишутся с именем типа (`ВидВызывающего.Линза`, `ПроверкаОтвета.Верна`, `ВидДействия.Удаление`).
2. **Данные события.** Поля варианта события берутся образцом в `match`: `Сбой { причина } => …`; при совпадении имени поля с переменной машины поле переименовывается: `Ответ_закончен { текст, артефакт, расход: полученный }`. «Сторона события» и идентификатор события — `событие.сторона`, `событие.идентификатор` (конверт `Входящее` движка, правила 13 и 31). Служебные операции переходу даёт `среда` (журнал, слова человека, сигналы вложенным, данные движка `открытые_запросы`, `предыдущее`, `запрос_вызова`).
3. **Строка таблицы — ветка кода.** Перед каждой строкой первоисточника (условие или событие, «Что меняется», «Куда») стоит комментарий `// <СОСТОЯНИЕ> #<номер строки>: …` с её текстом; у обращения в скобках — данные события; порядок строк как в первоисточнике. «Куда» записано как `Куда(<СОСТОЯНИЕ>)`; «Куда: предыдущее» — у ПАУЗЫ в движке (`Куда(@машина.состояние_по_имени(предыдущее))`). Строка «иначе» развилки — последняя ветка, ведёт в `ОШИБКА` через `среда.ошибка_машины(…)`. Строки «Вход», «Выход», «При входе», «Сторона» и одна строка простыми словами на состояние — комментарии `//` у состояния. Общие события записаны в движке (`общие_события`); `общее` машины сводит к ним её события. Состояние ПАУЗА и его четыре строки подключены фрагментом «Пауза» ([state-machine-pause-states.md](state-machine-pause-states.md)): события паузы разбирает движок, у машины остаются ветка `ПАУЗА => НеЖдёт`, хуки `состояние_паузы`, `причина_остановки_в_паузе`, `состояние_по_имени` и сведение событий паузы в `общее`.
4. **Строки `// псевдокод:`** и перечень подтверждённого спецификацией — в [движке](state-machine-engine-automaton.md), пункт 5. Здесь дополнительно: функции без тела (сигнатуры механики и чтения внешних объектов: `проверка_ответа`, `закрыть_ход_агента`); алиас `type Окружение alias Среда[…]` (как у запуска сессии); импорт `use` общих типов из слоя методики — разрешение вне записи; значения перечислений с именем типа; таблицы параметров проекта (`политика_проекта`, `решает_только_человек`) записаны функциями с `match`. Неподтверждённое спецификацией Нова, используемое здесь (как и в других машинах): объявление `module`, `ro` на уровне модуля (константы), `return` внутри `if` в теле функции, `+=` на целом поле, `Time.now()` как целое число миллисекунд эпохи.
5. **Уточнения записи автомата сверх первоисточника:** (а) метод `событие_ответа` — метод протокола `Автомат`: отображение результата роли в событие; (б) число возвратов ответа не по форме в запросе — поле `возвратов_формы` описания обращения (`Одна`): у ХОД_АГЕНТА `0`, потому что исправление формы идёт не возвратом в том же запросе движка, а ходом «исправить» — новым запросом по строкам ПРОВЕРКИ_ОТВЕТА; вложенных сторон у этой машины нет (`вложенная: false`); метод `при_возобновлении` — заглушка (подготовки при возобновлении нет); (в) `ИтогХода` — результат роли ХОД_АГЕНТА: по варианту на строку «ответ: …» первоисточника; (г) `проверка_ответа` — объект, измеренный исполнителем (функция без тела, как `объём_запуска` у запуска сессии); (д) `запрос_вызова` — всегда `запрос.идентификатор_запроса` (решение о `""` у верхнего уровня открыто, см. движок, пункт 6); (е) `состояние_по_имени` записано полным `match` по именам обращений; (ж) срок бездействия запроса к агенту (`срок_хода`) считает метод `обращение` по данным машины: срок тишины запроса, плюс пауза повтора при ходе «повторить».
6. **Данные машины — поля типа `Машина`**: поля названы как переменные раздела «Данные» первоисточника (правило 25), начальные значения — в `Машина.new()`, по входу шага — `Машина.из_входа` (запрос агента приходит в запросе целиком). Данные движка (конверт, очереди запросов, журнал, слова человека, тексты сбоев) — в `СостояниеДвижка` движка. Внешний объект `проверка_ответа` читается через `Объекты` (`проверка_ответа()`): его измеряет исполнитель перед развилкой ПРОВЕРКА_ОТВЕТА.
7. **`недостижимо(текст)`** (определено в движке, пункт 8): в реализации стоит: у концов КОНЕЦ, ОСТАНОВЛЕНО, ОШИБКА в `перейти` (переходов нет); в `ответ_по_концу` (значение `остановка` вне таблицы; ответ не из конца; использование пусто в КОНЦЕ); в `выполнить_операцию` (состояние без операции); в `вход_запроса` и `следующая_попытка` (состояние не обращение; сторона вне «агент», «человек»); в `состояние_по_имени`, `сторона_обращения` (имя вне перечня); через `обязательное` движка — в `ПОЛИТИКА`, `РАЗРЕШЕНИЕ`, `вход_запроса` (запрос разрешения пуст) и `ответ_по_концу` (использование пусто в КОНЦЕ); `решение_по_политике` и `собрать_использование` `недостижимо` не зовут.

```nova
  | Сеть
  | Мышление
  | СменаРежима
  | Другое

/// ЗапросРазрешения: что агент просит разрешить; описание читает человек на воротах РАЗРЕШЕНИЕ
type ЗапросРазрешения { вид_действия ВидДействия, описание str }

/// ПроверкаОтвета: измерено исполнителем: форма ответа верна, нарушена или ответ пуст (первоисточник, Термины, «Пустой ответ»: у сессии цикла нужен артефакт, у линзы и хода чата — текст)
type ПроверкаОтвета enum
  | Верна
  | Нарушена
  | Пуста

/// ИтогХода: итог одного хода у транспорта; по варианту на строку «ответ: …» первоисточника (раздел «Состояния», ХОД_АГЕНТА)
type ИтогХода enum
  | Закончен { текст Option[str], артефакт Option[str], расход РасходТранспорта }   // конец хода
  | Обрезан { расход РасходТранспорта }                                            // выход остановлен пределом токенов ответа
  | ПределЗапросов { расход РасходТранспорта }                                     // исчерпан предел запросов модели за ход
  | МодельОтказалась { расход РасходТранспорта }                                   // отказ модели
  | Отменён { расход РасходТранспорта }                                            // ход остановлен агентом или транспортом
  | ВременнаяОшибка                                                                // лимит частоты, перегрузка, сбой поставщика: повтор оправдан
  | ПостояннаяОшибка                                                               // повтор не лечит
  | НужноРазрешение { запрос_разрешения ЗапросРазрешения }                         // агент просит разрешение; транспорт держит ход открытым до решения

/// Запись автомата: результат роли — по варианту на обращение первоисточника, где сторона возвращает результат (раздел «Состояния»: Выход);
/// у ворот человека результата роли нет: слово человека приходит событием, а не исходом запроса.
type РезультатРоли enum
  | РезультатХода(ИтогХода)                      // ХОД_АГЕНТА: итог_хода

/// Запись автомата: вход запроса — по варианту на обращение первоисточника; поля — строки таблицы «Вход» состояния, читаемые стороной
/// (у ворот без столбца «Кто читает» — вся таблица); необязательное поле — Option.
type ВходРоли enum
  | ВходХода { запрос_агента ЗапросАгента, ход str, число_повторов int, решение_разрешения Option[str] }   // ХОД_АГЕНТА (агент)
  | ВходРазрешения { запрос_агента ЗапросАгента, запрос_разрешения ЗапросРазрешения }                      // РАЗРЕШЕНИЕ
  | ВходПаузыРоли(ВходПаузы)                                                                               // ПАУЗА

/// Необратимое действие во внешнем мире: последний этап фиксации, повторяемый без вреда (правило 13).
type Необратимое enum
  | ЗакрытьХодАгента        // ОСТАНОВЛЕНО, ОШИБКА: транспорту сообщается об отмене открытого хода, в том числе удержанного до решения о разрешении

/// Окружение перехода шага агента: `Среда` движка с типами шага.
type Окружение alias Среда[Состояние, Событие, Необратимое]
```

## Механика машины

```nova
// Раздел записывает механику шага агента: свободные функции и методы `Машина`; методы `Исполнитель` и общие функции — в движке.
// псевдокод: функции без тела — сигнатуры; тело пишет реализация, в Нове внешняя реализация здесь не показана

// Свободные функции: чтение внешних объектов и операции над ними
// измерено исполнителем перед развилкой ПРОВЕРКА_ОТВЕТА по `текст_ответа` и `артефакт_ответа`: форма верна, нарушена или ответа нет
fn проверка_ответа() Объекты -> ПроверкаОтвета
// транспорту сообщается об отмене открытого хода (в том числе удержанного до решения о разрешении); повторяемо без вреда
fn закрыть_ход_агента() Объекты -> Result[(), ОшибкаОбъекта]

// Свободные функции: термины первоисточника (чистые)
// сумма необязательных целых: нет только если нет обоих
fn сумма_целых(первое Option[int], второе Option[int]) -> Option[int] => match первое {
  Some(значение) => match второе {
    Some(другое) => Some(значение + другое)
    None => Some(значение)
  }
  None => второе
}
// сумма необязательных дробных: нет только если нет обоих
fn сумма_дробных(первое Option[f64], второе Option[f64]) -> Option[f64] => match первое {
  Some(значение) => match второе {
    Some(другое) => Some(значение + другое)
    None => Some(значение)
  }
  None => второе
}
// токены по полям: сумма имеющихся значений
fn сложить_токены(прежние Токены, новые Токены) -> Токены => Токены {
  вход: сумма_целых(прежние.вход, новые.вход), выход: сумма_целых(прежние.выход, новые.выход),
  рассуждение: сумма_целых(прежние.рассуждение, новые.рассуждение),
  кэш_чтение: сумма_целых(прежние.кэш_чтение, новые.кэш_чтение), кэш_запись: сумма_целых(прежние.кэш_запись, новые.кэш_запись) }
// «сложить_расход(a, b)»: нет и b — b; иначе токены и стоимость — суммы, модель и занято_контекста — из b
fn сложить_расход(прежний Option[РасходТранспорта], новый РасходТранспорта) -> РасходТранспорта => match прежний {
  Some(был) => РасходТранспорта {
    модель: новый.модель, токены: сложить_токены(был.токены, новый.токены),
    стоимость: сумма_дробных(был.стоимость, новый.стоимость), занято_контекста: новый.занято_контекста }
  None => новый
}
// «израсходовано_токенов»: вход, выход и рассуждение; кэш в бюджет токенов не входит; нет-расход — 0
fn израсходовано_токенов(расход Option[РасходТранспорта]) -> int => match расход {
  Some(найденный) => (найденный.токены.вход ?? 0) + (найденный.токены.выход ?? 0) + (найденный.токены.рассуждение ?? 0)
  None => 0
}
// «израсходовано_стоимости»: поле стоимость; нет и нет-расход — 0
fn израсходовано_стоимости(расход Option[РасходТранспорта]) -> f64 => match расход {
  Some(найденный) => найденный.стоимость ?? 0.0
  None => 0.0
}
// «предел токенов исчерпан»: бюджет задан и израсходовано не меньше него
fn предел_токенов_исчерпан(запрос ЗапросАгента, расход Option[РасходТранспорта]) -> bool => match запрос.пределы.бюджет_токенов {
  Some(предел) => израсходовано_токенов(расход) >= предел
  None => false
}
// «предел стоимости исчерпан»: бюджет задан и израсходовано не меньше него
fn предел_стоимости_исчерпан(запрос ЗапросАгента, расход Option[РасходТранспорта]) -> bool => match запрос.пределы.бюджет_стоимости {
  Some(предел) => израсходовано_стоимости(расход) >= предел
  None => false
}
// «интерактивный вызов»: у вида «линза» человека нет
fn интерактивный(вид ВидВызывающего) -> bool => match вид {
  ВидВызывающего.Линза => false
  ВидВызывающего.СессияЦикла => true
  ВидВызывающего.ХодЧата => true
}
// закрытый перечень видов действий, на которые автоматически не разрешается никогда (`РЕШАЕТ_ТОЛЬКО_ЧЕЛОВЕК` первоисточника)
fn решает_только_человек(вид_действия ВидДействия) -> bool => match вид_действия {
  ВидДействия.Удаление | ВидДействия.Перенос | ВидДействия.Исполнение | ВидДействия.Сеть | ВидДействия.СменаРежима => true
  _ => false
}
// таблица `ПОЛИТИКА_РАЗРЕШЕНИЙ` первоисточника: параметр проекта; здесь значения по умолчанию методики — «спросить» для всех видов

// «решение_по_политике(вид_действия, вид)»: «спросить», «разрешить» или «отказать»
fn решение_по_политике(вид_действия ВидДействия, вид ВидВызывающего) -> str {
  if решает_только_человек(вид_действия) {
    if интерактивный(вид) { return "спросить" }
    return "отказать"
  }
  ro по_таблице = политика_проекта(вид_действия)
  if по_таблице == "спросить" && !интерактивный(вид) { return "отказать" }
  по_таблице
}
// «пауза_повтора(число_повторов)»: ПАУЗА_ПОВТОРА, умноженная на 2 в степени (число_повторов − 1)
fn пауза_повтора(число_повторов int) -> int {
  mut пауза = ПАУЗА_ПОВТОРА
  mut номер = 1
  while номер < число_повторов {
    пауза = пауза * 2
    номер += 1
  }
  пауза
}
```

```nova
/// Переход по событию. тело_события — событие, которое ждёт состояние `текущее` (у развилки — Сразу без данных);
/// событие — исходное событие шага: его данные (сторона, идентификатор, тело) доступны всей цепочке до ближайшего обращения (правило 13).
/// Состояние пишется при фиксации; в «Что меняется» оно не повторяется.
fn Машина mut @перейти(текущее Состояние, тело_события Событие, событие Входящее[Событие], среда Окружение) Журнал Объекты Time -> Переход[Состояние] {
  match текущее {

  // ===================== СТАРТ — операция =====================
  // Записывает момент начала шага, чтобы запись расхода знала, когда он начался.
  // При входе: исполнитель читает время и записывает его как начало шага.
  // Вход: нет
  // Выход: начато
  СТАРТ => match тело_события {
    // СТАРТ #1: сразу (начато: Число — миллисекунды эпохи)
    Сразу_СТАРТ { начато: момент } => {
      @начато = Some(момент)
      Куда(ХОД_АГЕНТА)
    }
    _ => НеЖдёт
  }

  // ===================== ХОД_АГЕНТА — обращение =====================
  // Просит транспорт агента выполнить один ход в диалоге (первый запрос, повтор, продолжение, исправление формы или продолжение после решения о
  //   разрешении) и возвращает, чем ход кончился.
  // При входе: исполнитель отправляет запрос роли «агент» — транспорту: запрос агента как есть и ход (`ход`), срок бездействия — срок тишины запроса (плюс пауза
  //   повтора, если ход — «повторить»); пока идёт ход, исполнитель следит за тишиной — нет вывода агента дольше срока порождает событие «сбой» с кодом «нет ответа
  //   в срок»; транспорт возвращает итог хода одним из вариантов `ИтогХода`; при ходе «исправить» исполнитель берёт замечания проверки формы из служебной записи
  //   (в данные не входят); при ходе «разрешение» транспорт возобновляет удержанный ход с решением `решение_разрешения`. Подробности — «Реализация на файлах».
  // Сторона: агент.
  // Вход (сторона): запрос_агента (вид, профиль, сессия, контекст, пределы); ход; число_повторов (при ходе «повторить» транспорт ждёт пауза_повтора(число_повторов));
  //   решение_разрешения? (только при ходе «разрешение»)
  // Вход (исполнитель): расход? (накопленный расход прежних ходов: итог хода складывается с ним)
  // Выход: итог_хода (один из восьми вариантов)
  ХОД_АГЕНТА => match тело_события {
    // ХОД_АГЕНТА #1: ответ: закончен (текст: Текст или нет; артефакт: Текст или нет; расход: РасходТранспорта)
    Ответ_закончен { текст, артефакт, расход: полученный } => {
      @расход = Some(сложить_расход(@расход, полученный))
      @текст_ответа = текст
      @артефакт_ответа = артефакт
      Куда(ПРОВЕРКА_ОТВЕТА)
    }
    // ХОД_АГЕНТА #2: ответ: обрезан (расход: РасходТранспорта)
    Ответ_обрезан { расход: полученный } => {
      @расход = Some(сложить_расход(@расход, полученный))
      Куда(ПРОДОЛЖЕНИЕ)
    }
    // ХОД_АГЕНТА #3: ответ: предел_запросов (расход: РасходТранспорта)
    Ответ_предел_запросов { расход: полученный } => {
      @расход = Some(сложить_расход(@расход, полученный))
      @остановка = "предел запросов хода"
      среда.писать_журнал("агент исчерпал предел запросов хода")
      Куда(УЧЁТ)
    }
    // ХОД_АГЕНТА #4: ответ: отказ_модели (расход: РасходТранспорта)
    Ответ_отказ_модели { расход: полученный } => {
      @расход = Some(сложить_расход(@расход, полученный))
      @остановка = "отказ модели"
      среда.писать_журнал("модель отказалась отвечать")
      Куда(УЧЁТ)
    }
    // ХОД_АГЕНТА #5: ответ: отменён (расход: РасходТранспорта)
    Ответ_отменён { расход: полученный } => {
      @расход = Some(сложить_расход(@расход, полученный))
      @остановка = "отменён агентом"
      среда.писать_журнал("ход агента отменён")
      Куда(УЧЁТ)
    }
    // ХОД_АГЕНТА #6: ответ: временная_ошибка
    Ответ_временная_ошибка => Куда(ПОВТОР)
    // ХОД_АГЕНТА #7: ответ: постоянная_ошибка
    Ответ_постоянная_ошибка => {
      @остановка = "нет результата"
      среда.писать_журнал("постоянная ошибка агента")
      Куда(УЧЁТ)
    }
    // ХОД_АГЕНТА #8: ответ: нужно_разрешение (запрос_разрешения: ЗапросРазрешения)
    Ответ_нужно_разрешение { запрос_разрешения: запрос } => {
      @запрос_разрешения = Some(запрос)
      Куда(ПОЛИТИКА)
    }
    // ХОД_АГЕНТА #9: сбой (причина: КодСбоя — у этого обращения: соединение оборвалось, нет ответа в срок или нет результата)
    Сбой { причина } => {
      @остановка = слово_кода(причина)
      среда.писать_журнал("ход агента не состоялся: ${слово_кода(причина)}")
      Куда(УЧЁТ)
    }
    _ => НеЖдёт
  }

  // ===================== ПОВТОР — развилка =====================
  // Решает, повторять ли запрос после временной ошибки: до трёх раз, затем шаг кончается отказом.
  // Вход: число_повторов
  ПОВТОР => {
    // ПОВТОР #1: число_повторов меньше ЧИСЛО_ПОВТОРОВ
    if @число_повторов < ЧИСЛО_ПОВТОРОВ {
      @число_повторов += 1
      @ход = "повторить"
      среда.писать_журнал("временная ошибка агента: повтор ${@число_повторов}")
      return Куда(БЮДЖЕТ)
    }
    // ПОВТОР #2: число_повторов не меньше ЧИСЛО_ПОВТОРОВ
    if @число_повторов >= ЧИСЛО_ПОВТОРОВ {
      @остановка = "нет результата"
      среда.писать_журнал("временная ошибка агента не прошла после ${ЧИСЛО_ПОВТОРОВ} повторов")
      return Куда(УЧЁТ)
    }
    // ПОВТОР #3: иначе
    среда.ошибка_машины("ошибка машины: развилка ПОВТОР, ни одно условие не подошло")
  }

  // ===================== ПРОДОЛЖЕНИЕ — развилка =====================
  // Решает, продолжать ли обрезанный выход: один раз «продолжи с места обрыва», затем шаг кончается отказом.
  // Вход: число_продолжений
  ПРОДОЛЖЕНИЕ => {
    // ПРОДОЛЖЕНИЕ #1: число_продолжений меньше ЧИСЛО_ПРОДОЛЖЕНИЙ
    if @число_продолжений < ЧИСЛО_ПРОДОЛЖЕНИЙ {
      @число_продолжений += 1
      @ход = "продолжить"
      среда.писать_журнал("выход обрезан: ход «продолжи с места обрыва»")
      return Куда(БЮДЖЕТ)
    }
    // ПРОДОЛЖЕНИЕ #2: число_продолжений не меньше ЧИСЛО_ПРОДОЛЖЕНИЙ
    if @число_продолжений >= ЧИСЛО_ПРОДОЛЖЕНИЙ {
      @остановка = "предел токенов"
      среда.писать_журнал("выход обрезан повторно: предел токенов")
      return Куда(УЧЁТ)
    }
    // ПРОДОЛЖЕНИЕ #3: иначе
    среда.ошибка_машины("ошибка машины: развилка ПРОДОЛЖЕНИЕ, ни одно условие не подошло")
  }

  // ===================== ПРОВЕРКА_ОТВЕТА — развилка =====================
  // Проверяет, что ответ агента есть и написан по форме: годный ответ идёт на запись расхода, ответ не по форме один раз возвращается агенту в том же
  //   диалоге, пустой ответ и вторую ошибку формы шаг считает отказом.
  // Вход: проверка_ответа (измерено исполнителем по текст_ответа и артефакт_ответа); число_возвратов
  ПРОВЕРКА_ОТВЕТА => {
    ro проверка = проверка_ответа()
    // ПРОВЕРКА_ОТВЕТА #1: проверка_ответа = «верна»
    if проверка == ПроверкаОтвета.Верна { return Куда(УЧЁТ) }
    // ПРОВЕРКА_ОТВЕТА #2: проверка_ответа = «пуста»
    if проверка == ПроверкаОтвета.Пуста {
      @остановка = "нет результата"
      среда.писать_журнал("агент не дал результата")
      return Куда(УЧЁТ)
    }
    // ПРОВЕРКА_ОТВЕТА #3: проверка_ответа = «нарушена», и число_возвратов меньше ЧИСЛО_ВОЗВРАТОВ_ФОРМЫ
    if проверка == ПроверкаОтвета.Нарушена && @число_возвратов < ЧИСЛО_ВОЗВРАТОВ_ФОРМЫ {
      @число_возвратов += 1
      @ход = "исправить"
      среда.писать_журнал("форма ответа нарушена: ход «исправь форму файла»")
      return Куда(БЮДЖЕТ)
    }
    // ПРОВЕРКА_ОТВЕТА #4: проверка_ответа = «нарушена», и число_возвратов не меньше ЧИСЛО_ВОЗВРАТОВ_ФОРМЫ
    if проверка == ПроверкаОтвета.Нарушена && @число_возвратов >= ЧИСЛО_ВОЗВРАТОВ_ФОРМЫ {
      @остановка = "форма не исправлена"
      среда.писать_журнал("форма ответа не исправлена со второй попытки")
      return Куда(УЧЁТ)
    }
    // ПРОВЕРКА_ОТВЕТА #5: иначе
    среда.ошибка_машины("ошибка машины: развилка ПРОВЕРКА_ОТВЕТА, ни одно условие не подошло")
  }

  // ===================== ПОЛИТИКА — развилка =====================
  // Решает, ответит ли на запрос агента о разрешении автоматическая политика проекта или спросят человека; виды действий, которые решает только человек, и
  //   вызов без человека обработаны отдельно.
  // Вход: запрос_агента (поле вид); запрос_разрешения (поле вид_действия)
  ПОЛИТИКА => {
    ro запрос = обязательное(@запрос_разрешения, "ПОЛИТИКА: запрос разрешения записан в ХОД_АГЕНТЕ")
    ro решение = решение_по_политике(запрос.вид_действия, @запрос_агента.вид)
    // ПОЛИТИКА #1: решение_по_политике(вид_действия, вид) = «разрешить»
    if решение == "разрешить" {
      @решение_разрешения = Some("разрешить")
      @ход = "разрешение"
      среда.писать_журнал("разрешение: ${слово_вида_действия(запрос.вид_действия)} — разрешено политикой автоматически")
      return Куда(БЮДЖЕТ)
    }
    // ПОЛИТИКА #2: решение_по_политике(вид_действия, вид) = «отказать»
    if решение == "отказать" {
      @решение_разрешения = Some("отказать")
      @ход = "разрешение"
      среда.писать_журнал("разрешение: ${слово_вида_действия(запрос.вид_действия)} — отказано политикой автоматически")
      return Куда(БЮДЖЕТ)
    }
    // ПОЛИТИКА #3: решение_по_политике(вид_действия, вид) = «спросить»
    if решение == "спросить" { return Куда(РАЗРЕШЕНИЕ) }
    // ПОЛИТИКА #4: иначе
    среда.ошибка_машины("ошибка машины: развилка ПОЛИТИКА, ни одно условие не подошло")
  }

  // ===================== РАЗРЕШЕНИЕ — обращение =====================
  // Показывает человеку, что агент просит разрешить (вид действия и описание), и спрашивает: разрешить или отказать; агент получит решение и продолжит ход.
  // При входе: ворота РАЗРЕШЕНИЕ: человеку показываются код сессии, вид действия и описание запроса агента; закрытый перечень исходов — «разрешить» и
  //   «отказать»; «стоп человека» и пауза остаются общими событиями.
  // Сторона: человек.
  // Вход: запрос_агента (поле сессия); запрос_разрешения
  // Выход: исход ворот
  РАЗРЕШЕНИЕ => match тело_события {
    // РАЗРЕШЕНИЕ #1: РАЗРЕШЕНИЕ: «разрешить»
    РАЗРЕШЕНИЕ_разрешить => {
      ro запрос = обязательное(@запрос_разрешения, "РАЗРЕШЕНИЕ: запрос разрешения записан в ХОД_АГЕНТЕ")
      @решение_разрешения = Some("разрешить")
      @ход = "разрешение"
      среда.писать_журнал("разрешение: ${слово_вида_действия(запрос.вид_действия)} — человек разрешил")
      Куда(БЮДЖЕТ)
    }
    // РАЗРЕШЕНИЕ #2: РАЗРЕШЕНИЕ: «отказать»
    РАЗРЕШЕНИЕ_отказать => {
      ro запрос = обязательное(@запрос_разрешения, "РАЗРЕШЕНИЕ: запрос разрешения записан в ХОД_АГЕНТЕ")
      @решение_разрешения = Some("отказать")
      @ход = "разрешение"
      среда.писать_журнал("разрешение: ${слово_вида_действия(запрос.вид_действия)} — человек отказал")
      Куда(БЮДЖЕТ)
    }
    _ => НеЖдёт
  }

  // ===================== БЮДЖЕТ — развилка =====================
  // Перед каждым дополнительным ходом (повтором, продолжением, исправлением, продолжением после разрешения) проверяет, не исчерпаны ли пределы токенов
  //   и стоимости: исчерпаны — шаг кончается отказом, нет — ход отправляется.
  // Вход: запрос_агента (поле пределы); расход (нет-расход — израсходовано 0)
  БЮДЖЕТ => {
    // БЮДЖЕТ #1: предел токенов исчерпан
    if предел_токенов_исчерпан(@запрос_агента, @расход) {
      @остановка = "предел токенов"
      среда.писать_журнал("предел токенов исчерпан: израсходовано ${израсходовано_токенов(@расход)}")
      return Куда(УЧЁТ)
    }
    // БЮДЖЕТ #2: предел токенов не исчерпан, и предел стоимости исчерпан
    if !предел_токенов_исчерпан(@запрос_агента, @расход) && предел_стоимости_исчерпан(@запрос_агента, @расход) {
      @остановка = "предел стоимости"
      среда.писать_журнал("предел стоимости исчерпан: израсходовано ${израсходовано_стоимости(@расход)}")
      return Куда(УЧЁТ)
    }
    // БЮДЖЕТ #3: ни один предел не исчерпан
    if !предел_токенов_исчерпан(@запрос_агента, @расход) && !предел_стоимости_исчерпан(@запрос_агента, @расход) { return Куда(ХОД_АГЕНТА) }
    // БЮДЖЕТ #4: иначе
    среда.ошибка_машины("ошибка машины: развилка БЮДЖЕТ, ни одно условие не подошло")
  }

  // ===================== УЧЁТ — операция =====================
  // Собирает единую запись расхода шага из того, что вернул транспорт (поля, которых он не дал, — «нет»), и пишет одну строку журнала.
  // При входе: исполнитель собирает `Использование`: сессия — код сессии запроса; результат — «ответ», если `остановка` пуста, иначе значение `остановка`;
  //   семья — из профиля; модель, токены, стоимость, занято_контекста — из `расход` (без расхода: модель по профилю — идентификатор из профиля, поставщик
  //   `""`, вариант — усилие профиля; токены — все `нет`; стоимость и занято_контекста — `нет`); создано — `начато`; обновлено — время записи; трасса и
  //   номер_шага — вызывающего, из запроса. Запись в служебный учёт токенов (`usage.log`) — механика исполнителя (служебное хранилище).
  // Вход: запрос_агента (поля сессия, профиль, трасса, номер_шага); расход?; остановка; начато
  // Выход: использование
  УЧЁТ => match тело_события {
    // УЧЁТ #1: сразу (использование: Использование)
    Сразу_УЧЁТ { использование: собранное } => {
      @использование = Some(собранное)
      среда.писать_журнал(строка_расхода(собранное))
      Куда(ИТОГ_ШАГА)
    }
    _ => НеЖдёт
  }

  // ===================== ИТОГ_ШАГА — развилка =====================
  // Решает, чем кончается шаг: ответом, если отказа не было, иначе отказом.
  // Вход: остановка
  ИТОГ_ШАГА => {
    // ИТОГ_ШАГА #1: остановка = `""`
    if @остановка == "" { return Куда(КОНЕЦ) }
    // ИТОГ_ШАГА #2: остановка не равна `""`
    if @остановка != "" { return Куда(ОСТАНОВЛЕНО) }
    // ИТОГ_ШАГА #3: иначе
    среда.ошибка_машины("ошибка машины: развилка ИТОГ_ШАГА, ни одно условие не подошло")
  }

  // ===================== ПАУЗА — обращение =====================
  // Подключено фрагментом «Пауза» (state-machine-pause-states.md): события ПАУЗЫ разбирает движок (`общие_события`), строк состояния у машины нет;
  //   остальные события ПАУЗА не ждёт.
  ПАУЗА => НеЖдёт

  // ===================== КОНЕЦ — конец =====================
  // Возвращает вызывающей машине ответ агента с записью расхода: шаг закончен.
  // При входе: ответ `Answer` с `ОтветАгента` (текст, артефакт, использование) уходит вызывающей машине; строка расхода в журнал уже записана состоянием УЧЁТ.
  // Вход: текст_ответа?; артефакт_ответа?; использование
  КОНЕЦ => недостижимо("конец: переходов нет; работа при входе — в «Концы и ответ»")

  // ===================== ОСТАНОВЛЕНО — конец =====================
  // Заканчивает шаг без ответа и записывает, почему; что делать дальше, решает вызывающая машина.
  // При входе: открытый ход агента закрывается — транспорту сообщается об отмене, в том числе ходу, удержанному до решения о разрешении; в журнал —
  //   «шаг агента остановлен: <остановка>»; вызывающая машина получает `Refusal` (таблица «конец → ответ»).
  // Вход: остановка
  ОСТАНОВЛЕНО => недостижимо("конец: переходов нет; работа при входе — в «Концы и ответ»")

  // ===================== ОШИБКА — конец =====================
  // Заканчивает шаг, если сама машина попала в непредусмотренное положение; это дефект машины или реализации, его разбирает человек.
  // При входе: открытый ход агента закрывается; в журнал — запись из перехода и данные машины; вызывающая машина получает `Refusal`; решает человек вне машины.
  // Вход: все данные машины ((в журнал))
  ОШИБКА => недостижимо("конец: переходов нет; работа при входе — в «Концы и ответ»")

  }
}
```

## Работа операций

```nova
/// Работа операций при входе (в одном шаге с переходом; отказа и «нет ответа» у операции нет). Результат — событие: у СТАРТА — `Сразу_СТАРТ`, у УЧЁТА — `Сразу_УЧЁТ` с данными.
fn Машина mut @выполнить_операцию(операция Состояние, среда Окружение) Журнал Объекты Time -> Событие => match операция {
  СТАРТ => Сразу_СТАРТ { начато: Time.now() }
  УЧЁТ => Сразу_УЧЁТ { использование: @собрать_использование(Time.now()) }
  _ => недостижимо("у остальных состояний нет работы операции")
}
```

## Концы и ответ

```nova
/// Работа концов при входе (в последнем, повторяемом без вреда этапе фиксации) и ответ вызвавшей стороне.
/// Вход в любой конец отменяет все открытые запросы (правило 22); машина отвечает ровно один раз (правило 35).
fn Машина mut @при_входе_в_конец(конец Состояние, среда Окружение) Журнал Time -> () => match конец {
  // ОСТАНОВЛЕНО: открытый ход агента закрывается — транспорту сообщается об отмене, в том числе ходу, удержанному до решения о разрешении; если `использование` — `нет` (вход по
  //   общему событию, УЧЁТ не проходился), пишется строка расхода; в журнал — «шаг агента остановлен: <остановка>»; вызывающая машина получает `Refusal` (таблица «конец → ответ»).
  ОСТАНОВЛЕНО => {
    среда.добавить_необратимое(Необратимое.ЗакрытьХодАгента)
    @записать_расход_конца(среда)
    среда.писать_журнал("шаг агента остановлен: ${@остановка}")
  }
  // ОШИБКА: открытый ход агента закрывается; если `использование` — `нет`, пишется строка расхода; в журнал — запись из перехода и данные машины; вызывающая машина
  //   получает `Refusal` с текстом «дефект шага агента: <запись из перехода>»; решает человек вне машины.
  ОШИБКА => {
    среда.добавить_необратимое(Необратимое.ЗакрытьХодАгента)
    @записать_расход_конца(среда)
    среда.писать_журнал(среда.запись_перехода())
    @журнал_данных_машины(среда)
  }
  // КОНЕЦ: ответ `Answer` с `ОтветАгента` уходит вызывающей машине; строка расхода в журнал уже записана состоянием УЧЁТ — своей строки у конца нет.
  КОНЕЦ => ()
  _ => ()
}
// запись для диагностики: все переменные и хранилища (Вход ОШИБКИ) — сигнатура объявлена в разделе «Механика машины»

/// Таблица «конец → ответ» первоисточника (раздел «Контракт машины»): каждый конец и каждое значение остановка — одна строка.
fn Машина @ответ_по_концу(вызов Запрос[ЗапросАгента], конец Состояние, среда Окружение) -> Исход[ОтветАгента] {
  match конец {
    // КОНЕЦ, условие входа: всегда → СРезультатом: текст, артефакт и использование
    КОНЕЦ => СРезультатом(ОтветСРезультатом {
      запрос: вызов.идентификатор_запроса, сторона: вызов.сторона, трасса: вызов.трасса, номер_шага: вызов.номер_шага,
      результат: ОтветАгента {
        текст: @текст_ответа, артефакт: @артефакт_ответа,
        использование: обязательное(@использование, "КОНЕЦ: использование записано в УЧЁТЕ") } })
    // ОШИБКА, условие входа: всегда (дефект машины) → Отказ, НетРезультата; текст — запись из перехода
    ОШИБКА => отказ_по(вызов, НетРезультата, "дефект шага агента: ${среда.запись_перехода()}")
    ОСТАНОВЛЕНО => match @остановка {
      // ОСТАНОВЛЕНО: остановка = «нет результата» → Отказ, НетРезультата
      "нет результата" => отказ_по(вызов, НетРезультата, @остановка)
      // ОСТАНОВЛЕНО: остановка = «отказ модели» → Отказ, ОтказМодели
      "отказ модели" => отказ_по(вызов, ОтказМодели, @остановка)
      // ОСТАНОВЛЕНО: остановка = «соединение оборвалось» → Отказ, СоединениеОборвалось
      "соединение оборвалось" => отказ_по(вызов, СоединениеОборвалось, @остановка)
      // ОСТАНОВЛЕНО: остановка = «форма не исправлена» → Отказ, ФормаНеИсправлена
      "форма не исправлена" => отказ_по(вызов, ФормаНеИсправлена, @остановка)
      // ОСТАНОВЛЕНО: остановка = «нет ответа в срок» → Отказ, НетОтветаВСрок
      "нет ответа в срок" => отказ_по(вызов, НетОтветаВСрок, @остановка)
      // ОСТАНОВЛЕНО: остановка = «предел токенов» → Отказ, ПредельТокенов
      "предел токенов" => отказ_по(вызов, ПредельТокенов, @остановка)
      // ОСТАНОВЛЕНО: остановка = «предел стоимости» → Отказ, ПредельТокенов (отдельного кода для стоимости нет, решение 7 первоисточника)
      "предел стоимости" => отказ_по(вызов, ПредельТокенов, @остановка)
      // ОСТАНОВЛЕНО: остановка = «предел запросов хода» → Отказ, ПредельЗапросовХода
      "предел запросов хода" => отказ_по(вызов, ПредельЗапросовХода, @остановка)
      // ОСТАНОВЛЕНО: остановка = «отменён агентом» → Отказ, ОтмененоРодителем
      "отменён агентом" => отказ_по(вызов, ОтмененоРодителем, @остановка)
      // ОСТАНОВЛЕНО: остановка = «ПАУЗА: остановить» (слово человека; у вызванной машины — сигнал «остановить от родителя» в ПАУЗЕ) → Отказ, ОстановленоЧеловеком
      "ПАУЗА: остановить" => отказ_по(вызов, код_сбоя_общей_остановки(@остановка), @остановка)
      // ОСТАНОВЛЕНО: остановка = «отмена_запроса» → Отказ, ОтмененоРодителем
      "отмена_запроса" => отказ_по(вызов, код_сбоя_общей_остановки(@остановка), @остановка)
      _ => недостижимо("значение остановка вне таблицы «конец → ответ»: новое значение добавляет строку таблицы")
    }
    _ => недостижимо("ответ отдают только концы")
  }
}

/// Точка подстановки эффектов: обработчики выбирает вызывающий код, один раз (`with`), и вне этого файла — любые (`Time` — стандартный, обработчик по умолчанию).
/// Все функции цепочки от `начать`, `возобновить`, `вызвать` объявляют эффекты в своей сигнатуре; здесь они подставлены. Машину по входу запроса создаёт вызывающий код
/// (обработчик `Связь` запуска сессии при запросе `ЗапросРоли` с входом `ЗапросАгента`).
fn шаг_агента(запрос Запрос[ЗапросАгента]) Time -> Исход[ОтветАгента] =>
  with Хранилище = обработчик_хранилища, Журнал = обработчик_журнала, Связь = обработчик_связи, Объекты = обработчик_объектов {   // псевдокод: обработчики (база, файл поверх Fs/Db, очередь сообщений) — любые, вне файла
    mut исполнитель = Исполнитель.new(Машина.из_входа(запрос.вход))
    исполнитель.вызвать(запрос)
  }
```
