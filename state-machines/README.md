# Стейт-машины методики

Файлы описания и кода стейт-машин методики. Правила записи — [state-machine-spec.md](state-machine-spec.md); именование файлов — `AGENTS.md`, правило о вынесенных алгоритмах.

| [state-machine-spec.md](state-machine-spec.md) | спецификация стейт-машин: правила записи, сверки, контракт вызова, подключаемый фрагмент |
| [state-machine-alula-spec.md](state-machine-alula-spec.md) | «Алула» (`Alula`): формат записи машины таблицами с формальными столбцами (типы, выражения, действия, стороны, фрагменты, каталог встроенных функций), версия 2.22 (двуязычный: русский и английский, таблица ключевых слов [alula-keywords.tsv](alula-keywords.tsv), виды параметров фрагмента в ней — своя группа, не типы данных; правило регистра типов; имя скомпилированного дерева `*.alula.json`; JSON-имя строится автоматически — словарь методики, закреплённый хешем, затем транслитерация; другое JSON-имя — только строкой раздела `## Имена`; пространства различимости JSON-имён; слово имени — одной письменности; выражение поля запроса `—` — то же имя; `иначе` развилки обязательна, пока исчерпание не доказано типом; свободный ввод — сторона-человек без счётчика; слова ворот — сигналы сторон; знаки только ASCII; рекомендуемый канонический вид записи для генераторов, раздел 1б); опытный: выразимость проверена пилотами, равенство с автоматом по журналу подтверждено на одной небольшой машине. **Как читать имя:** «Алу́ла», ударение на «у»; женского рода, склоняется как «Луна» (Алулы, на Алуле, Алулой); звезда в лапе Большой Медведицы, араб. *al-qafza al-ūlā* «первый прыжок» (прыжок — переход), и английское *alula* «крылышко» птичьего крыла; история имени — [doc/alula-history.md](../doc/alula-history.md), раздел 10 |

| [check-alula-samples.py](check-alula-samples.py) | сверка двух образцов «Шага агента» на Алуле (русского и английского): разделы, виды и число состояний, строки переходов (метки `№`, «куда», число действий, коды журнала), строки концов, функции, коды журнала, JSON-имена объявлений (у русского образца — автоматические и из `## Имена`); самопроверка мутациями обоих образцов (`--selftest`); запуск `python state-machines/check-alula-samples.py` из корня, код 1 при расхождениях |
