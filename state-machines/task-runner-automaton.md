# Раннер задачи: код автомата

Стейт-машина раннера задачи (фазы РАЗБОР, ПЛАН, РЕАЛИЗАЦИЯ, СДАЧА, ОБРАТНАЯ_СВЯЗЬ и ворота между ними) на языке Нова как реализация протокола `Автомат` движка [state-machine-engine-automaton.md](state-machine-engine-automaton.md): данные машины, перечисления `Состояние` и `Событие`, переход `перейти(состояние, событие)` как `match`, роли (входы и результаты обращений к вложенным машинам запуска сессии и проверки цикла и к человеку на воротах), ответ по концу по контракту машины, работа операций над документами задачи. Общее (конверт запроса и ответа, исполнитель, снимок и хранилище, общие события «стоп/продолжить/отмена», цикл, фиксации) — в движке и здесь не повторяется. Нормы — [task-runner.md](../task-runner.md) (словарь, ворота В1–В15, профили, форматы файлов) и [task-sessions.md](../task-sessions.md) (коды сессий и правила цикла). Идентификаторы кода английские, словарь — [state-machine-glossary.md](state-machine-glossary.md); русские имена — в описаниях и комментариях.

**Первоисточник — [task-runner-states.md](task-runner-states.md)** (машина «Раннер»: таблицы состояний, общие события, «Контракт машины», «Решения при переводе»); правила формы — [state-machine-spec.md](state-machine-spec.md). Этот файл — производная запись того же автомата, не второй источник истины: при расхождении верен первоисточник, этот файл правится вслед за ним. Язык записи — Нова, https://github.com/nv-lang/nova. **Код не компилировался и не проверялся компилятором Нова:** это псевдокод в синтаксисе Нова; соглашения записи, помеченные места (`// псевдокод:`), подтверждённое и неподтверждённое спецификацией — в [state-machine-engine-automaton.md](state-machine-engine-automaton.md), здесь только относящееся к раннеру. Опытный статус и отличия от прежней схемы — в шапке первоисточника; раннер эту машину не исполняет (он исполняет [task-runner-pseudocode.md](task-runner-pseudocode.md), помеченный устаревшим и этим файлом не заменяемый). Вложенные машины: запуск сессии — [task-runner-session-automaton.md](task-runner-session-automaton.md) (первоисточник — [task-runner-session-states.md](task-runner-session-states.md)), проверка цикла — [task-runner-review-automaton.md](task-runner-review-automaton.md) (первоисточник — [task-runner-review-states.md](task-runner-review-states.md)), совещание — [task-runner-meeting-automaton.md](task-runner-meeting-automaton.md). Раннер зовёт запуск сессии и проверку цикла, проверка цикла зовёт запуск сессии и совещание — только по контракту вызова движка (`Вызываемое`, эффект `Связь`: запрос уходит как `ЗапросРоли`, ответ приходит сообщением), а не прямым вызовом функций. Имя файла — по `AGENTS.md`, «Вынесенные алгоритмы», форма `automaton`.

## Соглашения записи

1. **Типы и идентификаторы** — по [движку](state-machine-engine-automaton.md), пункты 1–3: английские имена по [словарю](state-machine-glossary.md), таблица соответствия именам блока «Типы на Нове» первоисточника — ниже. Типы данных первоисточника, общие у раннера и проверки цикла (`Цикл`, `Находка`, `Критичность`, `Уровень`, `ИтогСессии`, `Стадия`, `ВходПроверки`, `ИтогПроверки`, `Вердикт`, `ВходЗапускаСессии`, `ИтогЗапускаСессии`), объявлены один раз в [слое методики](state-machine-methodology-automaton.md) и подключены здесь (`use`); здесь объявлены только типы раннера (`Артефакт`, `Утверждение` и их перечни, `Риск`, `Оценка`, `ПризнакиМаршрута`, `ПорогиМаршрута`, `ПараметрыМаршрута`, `ПараметрыПроекта`, `ВходРаннера`, `ИтогРаннера`). Вход паузы (`ВходПаузы`) тоже в слое; вариант `ВходРоли` для него — `ВходПаузыРоли`. Записи автомата, которых в первоисточнике нет: `РезультатРоли`, `ВходРоли`, `Окружение`, `Необратимое`. **Значения перечислений** с совпадающими именами в разных перечнях (`План`, `Требования`, `Вопрос`, `Готово` и др.) пишутся с именем типа (`ИтогСессии.План`, `Уровень.План`), как в блоке «Типы на Нове» первоисточника (`Level.Plan`, `SessionResult.Plan`).
2. **Данные события.** Поля варианта события берутся образцом в `match`: `Сбой { причина } => …`; при совпадении имени поля с переменной машины поле переименовывается: `Ответ_сессии { итог_сессии: итог }`; остаток непрочитанных полей — `{ цикл, .. }`. «Сторона события» и идентификатор события — `событие.сторона`, `событие.идентификатор` (конверт `Входящее` движка, правила 13 и 31); тело исходного события шага — `событие.тело`. Служебные операции переходу даёт `среда` (журнал, слова человека, сигналы вложенным, данные движка `открытые_запросы`, `предыдущее`, `запрос_вызова`).
3. **Строка таблицы — ветка кода.** Перед каждой строкой первоисточника (условие или событие, «Что меняется», «Куда») стоит комментарий `// <СОСТОЯНИЕ> #<номер строки>: …` с её текстом; у обращения и операции в скобках — данные события; порядок строк как в первоисточнике. «Куда» записано как `Куда(<СОСТОЯНИЕ>)`; «запуск заново» — `Заново(<СОСТОЯНИЕ>)`; «Куда: предыдущее» — у ПАУЗЫ в движке (`Куда(@машина.состояние_по_имени(предыдущее))`). Строка «иначе» каждой развилки — последняя ветка, ведёт в `ОШИБКА` через `среда.ошибка_машины(…)`; той же функцией записана строка, чей первоисточник ведёт в `ОШИБКА` с журналом «ошибка машины: …» (РЕАЛИЗАЦИЯ_ПРОВЕРКА, «ответ: перезапуск»). Строки «Вход», «Выход», «При входе», «Сторона» и строка простыми словами на состояние — комментарии `//` у состояния. Общие события (две строки «стоп» и четыре «отмена_запроса») записаны в движке (`общие_события`); `общее` машины сводит к ним её события. Состояние ПАУЗА и его четыре строки подключены фрагментом «Пауза» ([state-machine-pause-states.md](state-machine-pause-states.md)): события паузы разбирает движок (`общие_события`), у машины остаются ветка `ПАУЗА => НеЖдёт`, хуки `состояние_паузы`, `причина_остановки_в_паузе`, `состояние_по_имени` и сведение событий паузы в `общее`.
4. **Строки `// псевдокод:`** и перечень подтверждённого спецификацией — в [движке](state-machine-engine-automaton.md), пункт 5. Здесь дополнительно: функции без тела (сигнатуры механики и чтения внешних объектов); алиас `type Окружение alias Среда[…]` (как в машине совещания); поле-отображение `HashMap[Стадия, Цикл]` — перечисление как ключ отображения в Нове не подтверждено (запасной вариант — ключ-строка с именем стадии); значения перечислений с именем типа (`ИтогСессии.План`); образец `{ поле, .. }` с остатком и охранное условие в ветке `match` (оба — как в движке и машине совещания). Потолок заходов, число чистых заходов подряд и число проб (бывшие константы `ПОТОЛОК_ЗАХОДОВ`, `ЧИСТЫХ_ПОДРЯД`, `ПРОБ_В_ЧИСТОМ`) — данные задачи (`потолок_заходов`, `чистых_подряд`, `проб_в_чистом`): их пишет МАРШРУТ_ЗАПИСЬ, а во вложенную проверку цикла они уходят полями `ВходПроверки` (решение 36 первоисточника); константы этой машины — только минимумы методики `МИНИМУМ_ЧИСТЫХ_ПОДРЯД` и `МИНИМУМ_ПРОБ_В_ЧИСТОМ`, их читает ПРОВЕРКА_МАРШРУТА. Функции без тела — механика исполнителя и обработчика `Объекты` (в том числе `дописать_как_факт`, читатели документов). Срок бездействия не задан: у обращений раннера `0` (исполнитель «нет ответа» не порождает), для вызова вложенной машины `0` — значение «без срока» (правило 35, пункт 5): родитель ждёт ответа или отмены. Неподтверждённое спецификацией Нова, используемое здесь (как и в машине совещания): объявление `module`, `ro` на уровне модуля (константы), `return` внутри `if` в ветке `match` и в теле функции.
5. **Уточнения записи автомата сверх первоисточника** (каждое — следствие границы с движком, подробности — «Что движок не покрыл»): (а) результат операции ПОДГОТОВКА — запись `ИтогПодготовки` (итог и счётчики цикла каждой стадии): `выполнить_операцию` отдаёт её событием `Сразу_ПОДГОТОВКА`, движок передаёт то же событие следующей развилке цепочки, поэтому развилка ПОДГОТОВКА_ИТОГ читает `итог_подготовки` из тела события, как в первоисточнике («итог_подготовки события»; у развилки «Вход: нет»), и поля-моста в данных машины нет; (б) `событие_ответа` — метод протокола `Автомат`: отображение результата роли в событие с данными; (в) варианты события `Проверка_*` несут `вне_задачи` у всех стадий (так устроен `ИтогПроверки`); переходы стадий, кроме реализации, его не читают; (г) метка инварианта — список номеров заходов по четырём стадиям, движок сравнивает покомпонентно (убыль одного номера при росте другого ловится); (д) `при_возобновлении` — метод протокола: подготовка при каждом старте исполнителя, в том числе при возобновлении (решение 25 первоисточника); метод получает сохранённое состояние и `среду`; исходы те же, что у ПОДГОТОВКА_ИТОГ («готова» — войти в сохранённое состояние; «занята живым процессом» — ОСТАНОВЛЕНО; нерешённые — ворота; «иначе» — ОШИБКА через `среда.ошибка_машины`); перед воротами метод пишет `возврат_подготовки` ← имя сохранённого состояния (если сохранённое состояние — ворота подготовки, подготовка не выполняется, метод даёт `None`), и после ворот ПОДГОТОВКА_ИТОГ ведёт в него, а не в СВЕРКА_СПЕЦИФИКАЦИИ (первоисточник, решение 25); (е) вложенная сторона и число возвратов ответа не по форме — поля `вложенная` и `возвратов_формы` описания обращения (`Одна`): вложенные — «проверка» и «запуск сессии», возвратов формы у раннера нет (ответ не по форме возвращает агенту вложенная машина запуска сессии); (ж) `ВходЗапускаСессии` — вход вложенной машины запуска сессии (один тип у раннера и проверки цикла, слой методики): код сессии — поле `сессия` (Текст); по коду ветвятся запуск сессии, профиль и промпт — механика исполнителя («Реализация на файлах» [task-runner-session-states.md](task-runner-session-states.md)), раннер по нему не ветвится (правило 6), поэтому суммы по видам сессий не заводятся; номер захода раннер не передаёт (`None`); (з) `запрос_вызова` — всегда `запрос.идентификатор_запроса` (решение о `""` у верхнего уровня открыто, см. движок, пункт 6); (и) `состояние_по_имени` записано полным `match` по именам обращений (в машине совещания — сигнатура).
6. **Данные машины — поля типа `Машина`**, а не переменные модуля: поля названы как переменные раздела «Данные» первоисточника (правило 25), начальные значения — в `Машина.new()`, по входу раннера — `Машина.из_входа`. Данные движка (конверт, очереди запросов, журнал, слова человека, тексты сбоев) — в `СостояниеДвижка` движка: `трасса`, `номер_шага`, `счётчик_событий`, `причина_шага`, `запрос_вызова`, `состояние`, `предыдущее`, `открытые_запросы`, `принятые_запросы`. Внешние объекты раздела «Внешние объекты» читаются через эффект `Объекты` читателями `Машина` (документы задачи — `@спецификация()`, `@план_задачи()`, `@отчёт_реализации()`, письма, отчёт по секретам, различия дерева и т. д.): их содержимое вне данных машины; поле — только `утверждения` (запись в данных состояния, `approvals`). **Именование читателей по ключу:** читатель элемента поля называется по полю (`@цикл(стадия)`, `@отложенная_сессия(фаза)`, `@утверждения(документ)`, `@письма_раундов(номер)`) — как в машине совещания. **Поле и метод с одним именем** (`цикл`, `отложенная_сессия`, `источник_отложенной`, `утверждения`) — сознательное решение: в Нове допустимо (`spec/decisions/03-syntax.md`, правило `@name`), правило 25 соблюдено (имя одной сущности одно).
7. **`недостижимо(текст)`** (определено в движке, пункт 8): в реализации стоит: у концов КОНЕЦ, ОСТАНОВЛЕНО, ОШИБКА в `перейти` (переходов нет); в `ответ_по_концу` (значение `остановка` вне таблицы; ответ не из конца); в `выполнить_операцию` (состояние без операции); в `событие_ответа` (вердикт «остановлено»: раннер стадию «совещание» не вызывает); в `вход_запроса` и `следующая_попытка` (обязательное поле входа пусто — `обязательное` движка; состояние не обращение; сторона вне «запуск сессии», «проверка», «вратарь», «усиленный»); в `цикл`, `документ_задачи`, `состояние_по_имени`, `сторона_обращения` (запись стадии не заведена; имя вне перечня).

| КодСбоя: нет результата, отказ модели, соединение оборвалось, форма не исправлена, нет ответа в срок, остановлено человеком, потолок заходов с открытыми находками, отменено родителем, предел токенов, предел запросов хода | `КодСбоя`: `НетРезультата`, `ОтказМодели`, `СоединениеОборвалось`, `ФормаНеИсправлена`, `НетОтветаВСрок`, `ОстановленоЧеловеком`, `ПотолокЗаходов`, `ОтмененоРодителем`, `ПредельТокенов`, `ПредельЗапросовХода` | `FailCode`: `NoResult`, `ModelRefused`, `ConnectionLost`, `FormNotFixed`, `Timeout`, `StoppedByHuman`, `CeilingReached`, `Cancelled`, `MaxTokens`, `MaxTurnRequests` |
| Записи автомата (не из первоисточника): состояние, событие, вид состояния, сообщение, входящее событие, переход | `Состояние`, `Событие`, `Вид`, `Сообщение`, `Входящее`, `РезультатРоли`, `ВходРоли`, `ОшибкаХранилища`, `Переход`: `Куда`, `Заново`, `Остаться`, `НеЖдёт` | `State`, `Event`, `Kind`, `Incoming`, `Transition`: `Go`, `Rerun`, `Stay`, `NotAwaited`; `RoleResult`, `RoleInput` — запись автомата; `Message`, `StoreError` — типы движка; в блоке «Типы на Нове» их нет |
| ВходЗапускаСессии, ИтогЗапускаСессии | те же имена, объявлены в [слое методики](state-machine-methodology-automaton.md) | `SessionLaunchInput`, `SessionLaunchResult` |
| Функции записи автомата: функция переходов, недостижимая ветка | `перейти`, `недостижимо` | `step`, `unreachable` |
| Параметры типов: вход запроса, результат роли | `Вход`, `Результат` | `T`, `R` |

Имена, которых нет в первоисточнике и которые завела запись автомата (не данные машины): `РезультатРоли`, `ВходРоли`, `Окружение`, `Необратимое`, варианты `Событие` с префиксом ворот (`В13_повторить`, …; один вариант на слово ворот строки первоисточника, одно слово у нескольких ворот — один вариант), варианты исходов вложенной проверки (`Проверка_чисто`, …), вариант `Ответ_сессии` (исход вложенного запуска сессии), `Машина.из_входа`, методы машины для протокола `Автомат` (`начальное`, `общее`, `обращение`, `следующая_попытка`, `событие_ответа` и др.), функции раздела «Механика машины» (`назначить_запуск`, `правка_владельца` и др.). Типы и функции движка (`Исполнитель`, `Снимок`, `Хранилище`, `Автомат`, `Среда`, `Входящее`, `Переход`, `Куда`, `Заново`, `Остаться`, `НеЖдёт`, `перейти` и др.) — в [state-machine-engine-automaton.md](state-machine-engine-automaton.md).

```nova
fn MachineData.from_input(input RunnerInput) -> MachineData {
  mut machine = MachineData.new()
  machine.task_dir = input.task_dir
  machine.repo_dir = input.repo_dir
  machine.delivery_mode = input.delivery_mode
  for stage in cycle_stages() {
    machine.cycle.insert(stage, Cycle.new())
  }
  machine
}
```

```nova
// Свободные функции
// статус документа равен заданному; документа нет — нет

// ранг риска для сравнения: низкий < средний < высокий; «не оценён» вне порядка (признаки с ним неполны, до сравнения не доходят)
fn risk_rank(risk Risk) -> int => match risk {
  Risk.Low => 0
  Risk.Medium => 1
  Risk.High => 2
  Risk.Unrated => 3
}

fn risk_higher(risk Risk, allowed Risk) -> bool => risk_rank(risk) > risk_rank(allowed)

fn features_incomplete(features RouteFeatures) -> bool =>
  features.goal == "" || features.sources == None || features.parts == None || features.risk == Risk.Unrated
    || features.irreversible == Rating.Unrated || features.cause_known == Rating.Unrated || features.touches_norm == Rating.Unrated
// «перечень неполных признаков» (термины): имена через запятую в порядке цель, число_источников, число_частей, риск, необратимо, причина_известна, касается_нормы
fn incomplete_features_list(features RouteFeatures) -> str {
  mut names = []str.new()
  if features.goal == "" { names.push("goal") }
  if features.sources == None { names.push("sources") }
  if features.parts == None { names.push("parts") }
  if features.risk == Risk.Unrated { names.push("risk") }
  if features.irreversible == Rating.Unrated { names.push("irreversible") }
  if features.cause_known == Rating.Unrated { names.push("cause_known") }
  if features.touches_norm == Rating.Unrated { names.push("touches_norm") }
  join_with_comma(names)
}
// признаки, вышедшие за порог (у полных признаков): имена в порядке число_источников, число_частей, риск, необратимо, причина_известна, касается_нормы
fn features_over_threshold(features RouteFeatures, thresholds RouteThresholds) -> []str {
  mut names = []str.new()
  if (features.sources ?? 0) > thresholds.max_sources { names.push("sources") }
  if (features.parts ?? 0) > thresholds.max_parts { names.push("parts") }
  if risk_higher(features.risk, thresholds.allowed_risk) { names.push("risk") }
  if features.irreversible == Rating.Yes { names.push("irreversible") }
  if features.cause_known == Rating.No { names.push("cause_known") }
  if features.touches_norm == Rating.Yes { names.push("touches_norm") }
  names
}
// «признак выходит за порог» (термины)
fn feature_over_threshold(features RouteFeatures, thresholds RouteThresholds) -> bool => features_over_threshold(features, thresholds).len() > 0
// «перечень признаков за порогом» (термины)
fn over_threshold_features_list(features RouteFeatures, thresholds RouteThresholds) -> str => join_with_comma(features_over_threshold(features, thresholds))
// «параметры допустимы» (термины): чистых_подряд и проб_в_чистом не меньше минимумов методики, ослаблений нет

// «причина отказа настроек» (термины): первое нарушенное условие допустимости словами

// «профиль вратаря допустим» (термины): класс равен минимуму (минимум — высший класс), размышление включено, усилие не меньше минимума, правило семьи единственно допустимое, ослаблений нет

// подготовка при возобновлении (решение 25 первоисточника): та же подготовка, что операция ПОДГОТОВКА при первом старте, до входа в сохранённое состояние (`сохранённое`); счётчики цикла ставятся по файлам на диске.
// Сохранённое состояние — ворота подготовки: подготовка не выполняется, None — ворота показываются человеку снова (правило 22), «готова» закроет их только по ответу человека.
// Исходы те же, что у ПОДГОТОВКА_ИТОГ: «готова» — None (войти в сохранённое состояние), остальные — переход: «занята живым процессом» — в ОСТАНОВЛЕНО, нерешённые — к воротам,
// и перед воротами `возврат_подготовки` ← имя сохранённого состояния; «иначе» — в ОШИБКУ, как строка «иначе»
fn MachineData mut @on_resume(saved State, environment MachineEnvironment) Journal Objects Time -> Option[Transition[State]] {
  match saved {
    Gate13Preparation | TreeBusy => return None
    _ => ()
  }
  match saved {
    Pause => ()                                 // возврат через ворота подготовки, прерванные паузой, не теряется
    _ => { @preparation_return = "" }           // устаревшее значение не доживает до новой подготовки
  }
  ro outcome = @run_preparation()
  for stage in cycle_stages() { @set_cycle(stage, required(outcome.cycles.get(stage), "Preparation: цикл каждой стадии приходит в итоге подготовки")) }
  match outcome.preparation_outcome {
    "ready" => None
    "busy_by_live_process" => {
      @stop_reason = "task_busy_by_live_process"
      Some(Go(Halted))
    }
    "tree_busy_by_other_task" => {
      @preparation_return = @state_name(saved)
      Some(Go(TreeBusy))
    }
    "группа процессов не остановлена" => {
      @preparation_return = @state_name(saved)
      Some(Go(Gate13Preparation))
    }
    _ => Some(environment.machine_error("ошибка машины: развилка PreparationOutcome, ни одно условие не подошло"))
  }
}

    Verdict.Restart => ReviewRestart { cycle: outcome.cycle, out_of_scope: outcome.out_of_scope }
    Verdict.Stopped => unreachable("вердикт «остановлено» — только у стадии «совещание», раннер её не вызывает")
  }
}

/// Вход вложенной проверки цикла по стадии; «вне_задачи» читается только у стадии «реализация», у остальных — `[]`

  Pause => RolePauseInput(PauseInput { previous: environment.previous(), call_request_id: environment.call_request_id() })

}
```

```nova
/// Переход по событию. тело_события — событие, которое ждёт состояние `текущее` (у операции — результат операции, у развилки — Сразу без данных);
/// событие — исходное событие шага: его данные (сторона, идентификатор, тело) доступны всей цепочке до ближайшего обращения (правило 13).
/// Состояние пишется при фиксации; в «Что меняется» оно не повторяется.
fn MachineData mut @step(current State, event_body Event, event Incoming[Event], environment MachineEnvironment) Journal Objects Time -> Transition[State] {
  match current {

  // ===================== ПОДГОТОВКА — операция =====================
  Preparation => match event_body {
    // ПОДГОТОВКА #1: сразу (итог_подготовки: Текст; цикл[стадия]: Цикл — по каждой стадии)
    ImmediatePreparation { cycles, .. } => {
      for stage in cycle_stages() { @set_cycle(stage, required(cycles.get(stage), "Preparation: цикл каждой стадии приходит в событии")) }
      Go(PreparationOutcome)
    }
    _ => NotAwaited
  }

  // ===================== ПОДГОТОВКА_ИТОГ — развилка =====================
  // Запись автомата: `итог_подготовки` события читается из тела исходного события развилки: движок передаёт развилке результат предыдущей операции
  //   (ПОДГОТОВКА), а не «сразу»; в данных машины поля для него нет.
  PreparationOutcome => match event_body {
    ImmediatePreparation { preparation_outcome: outcome, .. } => {
      // ПОДГОТОВКА_ИТОГ #1: итог_подготовки события = «готова», и возврат_подготовки = ""
      if outcome == "ready" && @preparation_return == "" { return Go(SpecificationReconciliation) }
      // ПОДГОТОВКА_ИТОГ #2: итог_подготовки события = «готова», и возврат_подготовки не ""
      if outcome == "ready" && @preparation_return != "" {
        ro restoration = @state_by_name(@preparation_return)         // «куда» читает прежнее значение
        @preparation_return = ""
        return Go(restoration)
      }
      // ПОДГОТОВКА_ИТОГ #3: итог_подготовки события = «занята живым процессом»
      if outcome == "busy_by_live_process" {
        @stop_reason = "task_busy_by_live_process"
        return Go(Halted)
      }
      // ПОДГОТОВКА_ИТОГ #4: итог_подготовки события = «дерево занято другой задачей»
      if outcome == "tree_busy_by_other_task" { return Go(TreeBusy) }
      // ПОДГОТОВКА_ИТОГ #5: итог_подготовки события = «группа процессов не остановлена»
      if outcome == "группа процессов не остановлена" { return Go(Gate13Preparation) }
      // ПОДГОТОВКА_ИТОГ #6: иначе
      environment.machine_error("ошибка машины: развилка PreparationOutcome, ни одно условие не подошло")
    }
    _ => environment.machine_error("ошибка машины: развилка PreparationOutcome, ни одно условие не подошло")      // события операции ПОДГОТОВКА нет: итога подготовки нет
  }

  // ===================== В13_ПОДГОТОВКА — обращение =====================
  Gate13Preparation => match event_body {
    // В13_ПОДГОТОВКА #1: В13: «повторить»
    Gate13Repeat => Go(Preparation)
    // В13_ПОДГОТОВКА #2: В13: «остановить»
    Gate13Halt => {
      @stop_reason = "gate13_halt"
      Go(Halted)
    }
    _ => NotAwaited
  }

  // ===================== ДЕРЕВО_ЗАНЯТО — обращение =====================
  TreeBusy => match event_body {
    // ДЕРЕВО_ЗАНЯТО #1: ДЕРЕВО_ЗАНЯТО: «повторить»
    TreeBusyRepeat => Go(Preparation)
    // ДЕРЕВО_ЗАНЯТО #2: ДЕРЕВО_ЗАНЯТО: «остановить»
    TreeBusyHalt => {
      @stop_reason = "tree_busy_halt"
      Go(Halted)
    }
    _ => NotAwaited
  }

  // ===================== СВЕРКА_СПЕЦИФИКАЦИИ — развилка =====================
  SpecificationReconciliation => {
    // СВЕРКА_СПЕЦИФИКАЦИИ #1: спецификация есть, и её статус не разобран
    if status_equals(@specification(), ArtifactStatus.Unparsed) { return Go(Gate13Status) }
    // СВЕРКА_СПЕЦИФИКАЦИИ #2: маршрут = «полный», спецификация есть, её статус «утверждено», и утверждение спецификации не действует
    if @route == "full" && status_equals(@specification(), ArtifactStatus.Approved) && !@approval_valid("specification") { return Go(SpecificationSnapshot) }
    // СВЕРКА_СПЕЦИФИКАЦИИ #3: маршрут = `""`, спецификация есть, её статус «утверждено», и утверждение спецификации не действует
    if @route == "" && status_equals(@specification(), ArtifactStatus.Approved) && !@approval_valid("specification") { return Go(SpecificationSnapshot) }
    // СВЕРКА_СПЕЦИФИКАЦИИ #4: маршрут = «быстрый», спецификация есть, её статус «утверждено», и утверждение спецификации не действует
    if @route == "fast" && status_equals(@specification(), ArtifactStatus.Approved) && !@approval_valid("specification") { return Go(CopySnapshot) }
    // СВЕРКА_СПЕЦИФИКАЦИИ #5: спецификации нет
    if @specification() == None { return Go(PlanReconciliation) }
    // СВЕРКА_СПЕЦИФИКАЦИИ #6: спецификация есть, и её статус «черновик»
    if status_equals(@specification(), ArtifactStatus.Draft) { return Go(PlanReconciliation) }
    // СВЕРКА_СПЕЦИФИКАЦИИ #7: спецификация есть, её статус «утверждено», и утверждение спецификации действует
    if status_equals(@specification(), ArtifactStatus.Approved) && @approval_valid("specification") { return Go(PlanReconciliation) }
    // СВЕРКА_СПЕЦИФИКАЦИИ #8: иначе
    environment.machine_error("ошибка машины: развилка SpecificationReconciliation, ни одно условие не подошло")
  }

  // ===================== СНЯТИЕ_СПЕЦИФИКАЦИИ — операция =====================
  SpecificationSnapshot => match event_body {
    // СНЯТИЕ_СПЕЦИФИКАЦИИ #1: сразу
    Immediate => {
      environment.write_journal("правка после утверждения, статус снят: спецификация")
      Go(PlanReconciliation)
    }
    _ => NotAwaited
  }

  // ===================== СНЯТИЕ_КОПИИ — операция =====================
  CopySnapshot => match event_body {
    // СНЯТИЕ_КОПИИ #1: сразу
    Immediate => {
      @phase = "AnalysisPhase"
      @set_cycle(Stage.Implementation, reset_streaks(@cycle(Stage.Implementation)))
      @set_cycle(Stage.Delivery, reset_streaks(@cycle(Stage.Delivery)))
      environment.write_journal("правка копии постановки после утверждения, статус снят: спецификация")
      Go(PlanReconciliation)
    }
    _ => NotAwaited
  }

  // ===================== СВЕРКА_ПЛАНА — развилка =====================
  PlanReconciliation => {
    // СВЕРКА_ПЛАНА #1: план есть, и его статус не разобран
    if status_equals(@task_plan(), ArtifactStatus.Unparsed) { return Go(Gate13Status) }
    // СВЕРКА_ПЛАНА #2: план есть, его статус «утверждено», и утверждение плана не действует
    if status_equals(@task_plan(), ArtifactStatus.Approved) && !@approval_valid("plan") { return Go(PlanSnapshot) }
    // СВЕРКА_ПЛАНА #3: плана нет
    if @task_plan() == None { return Go(PhaseSwitch) }
    // СВЕРКА_ПЛАНА #4: план есть, и его статус «черновик»
    if status_equals(@task_plan(), ArtifactStatus.Draft) { return Go(PhaseSwitch) }
    // СВЕРКА_ПЛАНА #5: план есть, его статус «утверждено», и утверждение плана действует
    if status_equals(@task_plan(), ArtifactStatus.Approved) && @approval_valid("plan") { return Go(PhaseSwitch) }
    // СВЕРКА_ПЛАНА #6: иначе
    environment.machine_error("ошибка машины: развилка PlanReconciliation, ни одно условие не подошло")
  }

  // ===================== СНЯТИЕ_ПЛАНА — операция =====================
  PlanSnapshot => match event_body {
    // СНЯТИЕ_ПЛАНА #1: сразу
    Immediate => {
      environment.write_journal("правка после утверждения, статус снят: план")
      Go(PhaseSwitch)
    }
    _ => NotAwaited
  }

  // ===================== В13_СТАТУС — обращение =====================
  Gate13Status => match event_body {
    // В13_СТАТУС #1: В13: «повторить»
    Gate13Repeat => Go(SpecificationReconciliation)
    // В13_СТАТУС #2: В13: «остановить»
    Gate13Halt => {
      @stop_reason = "gate13_halt"
      Go(Halted)
    }
    _ => NotAwaited
  }

  // ===================== ФАЗА — развилка =====================
  PhaseSwitch => {
    // ФАЗА #1: фаза = «РАЗБОР»
    if @phase == "AnalysisPhase" { return Go(ReviewParsing) }
    // ФАЗА #2: фаза = «ПЛАН»
    if @phase == "PlanPhase" { return Go(PlanPhase) }
    // ФАЗА #3: фаза = «РЕАЛИЗАЦИЯ»
    if @phase == "ImplementationPhase" { return Go(ImplementationPhase) }
    // ФАЗА #4: фаза = «СДАЧА»
    if @phase == "DeliveryPhase" { return Go(DeliveryPhase) }
    // ФАЗА #5: фаза = «ОБРАТНАЯ_СВЯЗЬ»
    if @phase == "FeedbackPhase" { return Go(Gate11) }
    // ФАЗА #6: фаза = «ЗАВЕРШЕНО»
    if @phase == "CompletedPhase" { return Go(End) }
    // ФАЗА #7: иначе
    environment.machine_error("ошибка машины: развилка PhaseSwitch, ни одно условие не подошло")
  }

  // ===================== ЗАПУСК_СЕССИИ — обращение =====================
  SessionLaunch => match event_body {
    // ЗАПУСК_СЕССИИ #1: ответ (итог_сессии: ИтогСессии — готово, ревизия, план, требования или вопрос)
    SessionReplied { result: outcome } => {
      @result = Some(outcome)
      Go(AfterSession)
    }
    // ЗАПУСК_СЕССИИ #2: сбой (причина: КодСбоя)
    Failure { reason } => {
      @failure_reason = fail_code_word(reason)
      environment.write_journal("запуск сессии ${@session} не дал итога: ${fail_code_word(reason)}")
      Go(SessionFailure)
    }
    _ => NotAwaited
  }

  // ===================== ОТКАЗ_СЕССИИ — развилка =====================
  SessionFailure => {
    // ОТКАЗ_СЕССИИ #1: причина_сбоя = «остановлено человеком»
    if @failure_reason == "stopped_by_human" {
      @stop_reason = "session_launch_stopped_by_human"
      return Go(Halted)
    }
    // ОТКАЗ_СЕССИИ #2: причина_сбоя = «нет результата»
    if @failure_reason == "no_result" {
      @stop_reason = "session_launch_no_result"
      return Go(Halted)
    }
    // ОТКАЗ_СЕССИИ #3: иначе
    environment.machine_error("ошибка машины: развилка SessionFailure, ни одно условие не подошло")
  }

  // ===================== ПОСЛЕ_СЕССИИ — развилка =====================
  AfterSession => {
    // ПОСЛЕ_СЕССИИ #1: продолжение = «разбор: очередь», и итог_сессии = «вопрос»
    if @continuation == "analysis_queue" && outcome_equals(@result, SessionResult.Question) { return Go(Gate4Question) }
    // ПОСЛЕ_СЕССИИ #2: продолжение = «разбор: очередь», и итог_сессии отличается от «вопрос»
    if @continuation == "analysis_queue" && !outcome_equals(@result, SessionResult.Question) { return Go(AnalysisReview) }
    // ПОСЛЕ_СЕССИИ #3: продолжение = «разбор: первая сессия»
    if @continuation == "analysis_first_session" { return Go(AnalysisReview) }
    // ПОСЛЕ_СЕССИИ #4: продолжение = «разбор: возврат»
    if @continuation == "analysis_return" { return Go(SpecificationReconciliation) }
    // ПОСЛЕ_СЕССИИ #5: продолжение = «разбор: ответы после вопроса»
    if @continuation == "analysis_answers_after_question" {
      @owner_fix(Stage.Analysis)
      return Go(SpecificationReconciliation)
    }
    // ПОСЛЕ_СЕССИИ #6: продолжение = «разбор: ответы»
    if @continuation == "analysis_answers" {
      @owner_fix(Stage.Analysis)
      @approval_document = "specification"
      return Go(ApprovalCheck)
    }
    // ПОСЛЕ_СЕССИИ #7: продолжение = «разбор: ответы меняют цель»
    if @continuation == "analysis_answers_change_goal" {
      @owner_fix(Stage.Analysis)
      return Go(SpecificationReconciliation)
    }
    // ПОСЛЕ_СЕССИИ #8: продолжение = «план: очередь», и итог_сессии = «требования»
    if @continuation == "plan_queue" && outcome_equals(@result, SessionResult.Requirements) {
      @route_source = "последний абзац плана"
      return Go(ToRequirements)
    }
    // ПОСЛЕ_СЕССИИ #9: продолжение = «план: очередь», и итог_сессии = «вопрос»
    if @continuation == "plan_queue" && outcome_equals(@result, SessionResult.Question) { return Go(Gate7PlanQueue) }
    // ПОСЛЕ_СЕССИИ #10: продолжение = «план: очередь», и итог_сессии отличается от «требования» и от «вопрос»
    if @continuation == "plan_queue" && !outcome_equals(@result, SessionResult.Requirements) && !outcome_equals(@result, SessionResult.Question) { return Go(PlanStopWord) }
    // ПОСЛЕ_СЕССИИ #11: продолжение = «план: первая сессия»
    if @continuation == "plan_first_session" { return Go(PlanStopWord) }
    // ПОСЛЕ_СЕССИИ #12: продолжение = «план: решено»
    if @continuation == "plan_decided" {
      @owner_fix(Stage.Plan)
      return Go(SpecificationReconciliation)
    }
    // ПОСЛЕ_СЕССИИ #13: продолжение = «реализация: очередь»
    if @continuation == "implementation_queue" { return Go(ImplementationOutcome) }
    // ПОСЛЕ_СЕССИИ #14: продолжение = «реализация: первая сессия»
    if @continuation == "implementation_first_session" { return Go(ImplementationOutcome) }
    // ПОСЛЕ_СЕССИИ #15: продолжение = «реализация: продолжение»
    if @continuation == "implementation_continuation" { return Go(ImplementationOutcome) }
    // ПОСЛЕ_СЕССИИ #16: продолжение = «сдача: сдача»
    if @continuation == "delivery_main" { return Go(DeliveryReview) }
    // ПОСЛЕ_СЕССИИ #17: продолжение = «сдача: коммит»
    if @continuation == "delivery_commit" { return Go(DeliveryMessage) }
    // ПОСЛЕ_СЕССИИ #18: продолжение = «сдача: пуш»
    if @continuation == "delivery_push" { return Go(Gate10d) }
    // ПОСЛЕ_СЕССИИ #19: продолжение = «обратная связь: разбор»
    if @continuation == "feedback_analysis" {
      for stage in cycle_stages() { @owner_fix(stage) }
      return Go(FeedbackRoute)
    }
    // ПОСЛЕ_СЕССИИ #20: иначе
    environment.machine_error("ошибка машины: развилка AfterSession, ни одно условие не подошло")
  }

  // ===================== К_ТРЕБОВАНИЯМ — операция =====================
  ToRequirements => match event_body {
    // К_ТРЕБОВАНИЯМ #1: сразу
    Immediate => {
      @set_next_session("AnalysisPhase", "s1_fix")
      @set_next_source("AnalysisPhase", @route_source)
      @set_next_session("PlanPhase", "s3_fix")
      @set_next_source("PlanPhase", @source_with_specification_marks(@route_source))
      @phase = "AnalysisPhase"
      Go(SpecificationReconciliation)
    }
    _ => NotAwaited
  }

  // ===================== К_ПЛАНУ — операция =====================
  ToPlan => match event_body {
    // К_ПЛАНУ #1: сразу
    Immediate => {
      @set_next_session("PlanPhase", "s3_fix")
      @set_next_source("PlanPhase", @route_source)
      @phase = "PlanPhase"
      Go(SpecificationReconciliation)
    }
    _ => NotAwaited
  }

  // ===================== КЛАССИФИКАЦИЯ_МАРШРУТА — развилка =====================
  RouteClassification => {
    ro thresholds = @project_settings().thresholds
    match @route_features() {
      None => {
        // КЛАССИФИКАЦИЯ_МАРШРУТА #1: признаков нет
        @route_proposal = "full"
        @route_basis = "признаки не записаны"
        @route_choice_source = "rule"
        environment.write_journal("маршрут предложен: ${@route_proposal}, ${@route_choice_source}: ${@route_basis}")
        Go(Gate14)
      }
      Some(features) => {
        // КЛАССИФИКАЦИЯ_МАРШРУТА #2: признаки есть, и признаки неполны
        if features_incomplete(features) {
          @route_proposal = "full"
          @route_basis = "признаки неполны: ${incomplete_features_list(features)}"
          @route_choice_source = "rule"
          environment.write_journal("маршрут предложен: ${@route_proposal}, ${@route_choice_source}: ${@route_basis}")
          return Go(Gate14)
        }
        // КЛАССИФИКАЦИЯ_МАРШРУТА #3: признаки есть, они полны, и предложение_помощника = «полный»
        if !features_incomplete(features) && features.helper_proposal == "full" {
          @route_proposal = "full"
          @route_basis = "помощник предложил полный маршрут"
          @route_choice_source = "helper"
          environment.write_journal("маршрут предложен: ${@route_proposal}, ${@route_choice_source}: ${@route_basis}")
          return Go(Gate14)
        }
        // КЛАССИФИКАЦИЯ_МАРШРУТА #4: признаки есть, они полны, предложение_помощника не равно «полный», и признак выходит за порог
        if !features_incomplete(features) && features.helper_proposal != "full" && feature_over_threshold(features, thresholds) {
          @route_proposal = "full"
          @route_basis = "признак выходит за порог: ${over_threshold_features_list(features, thresholds)}"
          @route_choice_source = "rule"
          environment.write_journal("маршрут предложен: ${@route_proposal}, ${@route_choice_source}: ${@route_basis}")
          return Go(Gate14)
        }
        // КЛАССИФИКАЦИЯ_МАРШРУТА #5: признаки есть, они полны, предложение_помощника не равно «полный», и ни один признак не выходит за порог
        if !features_incomplete(features) && features.helper_proposal != "full" && !feature_over_threshold(features, thresholds) {
          @route_proposal = "fast"
          @route_basis = "все признаки в пределах порогов"
          @route_choice_source = "rule"
          environment.write_journal("маршрут предложен: ${@route_proposal}, ${@route_choice_source}: ${@route_basis}")
          return Go(Gate14)
        }
        // КЛАССИФИКАЦИЯ_МАРШРУТА #6: иначе
        environment.machine_error("ошибка машины: развилка RouteClassification, ни одно условие не подошло")
      }
    }
  }

  // ===================== В14 — обращение =====================
  Gate14 => match event_body {
    // В14 #1: В14: «быстрый» (основание: Текст; слово_завода: Текст; дата_слова_завода: Текст)
    Gate14Fast { basis, factory_word: word, factory_word_date: date } => {
      @route = "fast"
      @route_basis = basis
      @route_choice_source = "human"
      @factory_word = word
      @factory_word_date = date
      Go(FactoryWord)
    }
    // В14 #2: В14: «полный» (основание: Текст)
    Gate14Full { basis } => {
      @route = "full"
      @route_basis = basis
      @route_choice_source = "human"
      Go(RouteCheck)
    }
    _ => NotAwaited
  }

  // ===================== В14_ОТКАЗ — обращение =====================
  Gate14Refusal => match event_body {
    // В14_ОТКАЗ #1: В14_ОТКАЗ: «принято»
    Gate14RefusalAccepted => Go(RouteCheck)
    _ => NotAwaited
  }

  // ===================== СЛОВО_ЗАВОДА — развилка =====================
  FactoryWord => {
    // СЛОВО_ЗАВОДА #1: слово_завода не равно `""`, и дата_слова_завода не равна `""`
    if @factory_word != "" && @factory_word_date != "" { return Go(RouteCheck) }
    // СЛОВО_ЗАВОДА #2: слово_завода = `""`
    if @factory_word == "" {
      environment.write_journal("слово завода не названо: быстрый маршрут не принят, ворота Gate14 повторяются")
      @route = ""
      @route_basis = "слово завода не названо: быстрый маршрут не принят"
      @route_choice_source = "rule"
      return Go(Gate14)
    }
    // СЛОВО_ЗАВОДА #3: слово_завода не равно `""`, и дата_слова_завода = `""`
    if @factory_word != "" && @factory_word_date == "" {
      environment.write_journal("дата слова завода не названа: быстрый маршрут не принят, ворота Gate14 повторяются")
      @route = ""
      @route_basis = "дата слова завода не названа: быстрый маршрут не принят"
      @route_choice_source = "rule"
      return Go(Gate14)
    }
    // СЛОВО_ЗАВОДА #4: иначе
    environment.machine_error("ошибка машины: развилка FactoryWord, ни одно условие не подошло")
  }

  // ===================== ПРОВЕРКА_МАРШРУТА — развилка =====================
  RouteCheck => {
    ro settings = @project_settings()
    // ПРОВЕРКА_МАРШРУТА #1: маршрут = «полный», и параметры полного маршрута допустимы
    if @route == "full" && settings_allowed(settings.full) { return Go(RouteRecording) }
    // ПРОВЕРКА_МАРШРУТА #2: маршрут = «полный», и параметры полного маршрута недопустимы
    if @route == "full" && !settings_allowed(settings.full) {
      @stop_reason = "route_settings_violate_invariants"
      environment.write_journal("настройки полного маршрута отклонены: ${settings_refusal_reason(settings.full)}")
      return Go(Halted)
    }
    // ПРОВЕРКА_МАРШРУТА #3: маршрут = «быстрый», и параметры быстрого маршрута допустимы
    if @route == "fast" && settings_allowed(settings.fast) { return Go(RouteRecording) }
    // ПРОВЕРКА_МАРШРУТА #4: маршрут = «быстрый», и параметры быстрого маршрута недопустимы
    if @route == "fast" && !settings_allowed(settings.fast) {
      environment.write_journal("настройки быстрого маршрута отклонены: ${settings_refusal_reason(settings.fast)}, возврат на полный маршрут")
      @route = "full"
      @route_proposal = "full"
      @route_basis = "настройки быстрого маршрута отклонены: ${settings_refusal_reason(settings.fast)}"
      @route_choice_source = "rule"
      return Go(Gate14Refusal)
    }
    // ПРОВЕРКА_МАРШРУТА #5: иначе
    environment.machine_error("ошибка машины: развилка RouteCheck, ни одно условие не подошло")
  }

  // ===================== МАРШРУТ_ЗАПИСЬ — развилка =====================
  RouteRecording => {
    // МАРШРУТ_ЗАПИСЬ #1: маршрут = «полный»
    if @route == "full" {
      ro settings = @project_settings().full
      @clean_needed = settings.clean_needed
      @ceiling = settings.ceiling
      @probes_min = settings.probes_min
      @delivery_short = settings.delivery_short
      environment.write_journal("маршрут записан: ${@route}, ${@route_choice_source}: ${@route_basis}")
      return Go(SpecificationReconciliation)
    }
    // МАРШРУТ_ЗАПИСЬ #2: маршрут = «быстрый»
    if @route == "fast" {
      ro settings = @project_settings().fast
      @clean_needed = settings.clean_needed
      @ceiling = settings.ceiling
      @probes_min = settings.probes_min
      @delivery_short = settings.delivery_short
      environment.write_journal("маршрут записан: ${@route}, ${@route_choice_source}: ${@route_basis}")
      return Go(BriefCheck)
    }
    // МАРШРУТ_ЗАПИСЬ #3: иначе
    environment.machine_error("ошибка машины: развилка RouteRecording, ни одно условие не подошло")
  }

  // ===================== ПРОВЕРКА_ПОСТАНОВКИ — развилка =====================
  BriefCheck => {
    // ПРОВЕРКА_ПОСТАНОВКИ #1: постановка полна
    if brief_complete(@brief()) { return Go(BriefCopy) }
    // ПРОВЕРКА_ПОСТАНОВКИ #2: постановка неполна
    if !brief_complete(@brief()) {
      @route_choice_source = "rule"
      @route_basis = "постановка неполна: нужны критерии `AC-N` и строка `Ветка:`"
      environment.write_journal("быстрый маршрут: постановка неполна, нужны критерии `AC-N` и строка `Ветка:`")
      return Go(FullPathReturn)
    }
    // ПРОВЕРКА_ПОСТАНОВКИ #3: иначе
    environment.machine_error("ошибка машины: развилка BriefCheck, ни одно условие не подошло")
  }

  // ===================== КОПИЯ_ПОСТАНОВКИ — операция =====================
  BriefCopy => match event_body {
    // КОПИЯ_ПОСТАНОВКИ #1: сразу
    Immediate => {
      environment.write_journal("копия постановки создана как спецификация: ${@factory_word}")
      Go(SpecificationReconciliation)
    }
    _ => NotAwaited
  }

  // ===================== ВОЗВРАТ_ПОЛНОГО_ПУТИ — операция =====================
  FullPathReturn => match event_body {
    // ВОЗВРАТ_ПОЛНОГО_ПУТИ #1: сразу
    Immediate => {
      @route = "full"
      @set_next_session("AnalysisPhase", "s1")
      @set_next_source("AnalysisPhase", "")
      @set_next_session("PlanPhase", "")
      @set_next_source("PlanPhase", "")
      @set_cycle(Stage.Implementation, reset_after_return(@cycle(Stage.Implementation)))
      @set_cycle(Stage.Delivery, reset_after_return(@cycle(Stage.Delivery)))
      @phase = "AnalysisPhase"
      environment.write_journal("возврат на полный маршрут: ${@route_choice_source}: ${@route_basis}")
      Go(RouteCheck)
    }
    _ => NotAwaited
  }

  // ===================== УТВЕРЖДЕНИЕ — развилка =====================
  ApprovalCheck => {
    // УТВЕРЖДЕНИЕ #1: у документа на утверждении чужое утверждение
    if @approval_foreign(@approval_document) { return Go(ForeignApproval) }
    // УТВЕРЖДЕНИЕ #2: у документа на утверждении утверждение не чужое
    if !@approval_foreign(@approval_document) { return Go(Gate5) }
    // УТВЕРЖДЕНИЕ #3: иначе
    environment.machine_error("ошибка машины: развилка ApprovalCheck, ни одно условие не подошло")
  }

  // ===================== ЧУЖОЕ_УТВЕРЖДЕНИЕ — обращение =====================
  ForeignApproval => match event_body {
    // ЧУЖОЕ_УТВЕРЖДЕНИЕ #1: ЧУЖОЕ_УТВЕРЖДЕНИЕ: «ваше»
    ForeignApprovalYours => Go(Gate5)
    // ЧУЖОЕ_УТВЕРЖДЕНИЕ #2: ЧУЖОЕ_УТВЕРЖДЕНИЕ: «не ваше»
    ForeignApprovalNotYours => Go(ForeignSnapshot)
    _ => NotAwaited
  }

  // ===================== СНЯТИЕ_ЧУЖОГО — операция =====================
  ForeignSnapshot => match event_body {
    // СНЯТИЕ_ЧУЖОГО #1: сразу
    Immediate => {
      environment.write_journal("чужое утверждение снято: ${@approval_document}")
      Go(Gate5)
    }
    _ => NotAwaited
  }

  // ===================== В5 — обращение =====================
  Gate5 => match event_body {
    // В5 #1: В5: «подтвердил»
    Gate5Confirmed => Go(ApprovalRecording)
    // В5 #2: В5: «полный путь» (основание: Текст)
    FullPath { basis } => {
      @route_choice_source = "human"
      @route_basis = basis
      Go(FullPathReturn)
    }
    _ => NotAwaited
  }

  // ===================== ЗАПИСЬ_УТВЕРЖДЕНИЯ — операция =====================
  ApprovalRecording => match event_body {
    // ЗАПИСЬ_УТВЕРЖДЕНИЯ #1: сразу
    Immediate => Go(AfterApproval)
    _ => NotAwaited
  }

  // ===================== ПОСЛЕ_УТВЕРЖДЕНИЯ — развилка =====================
  AfterApproval => {
    // ПОСЛЕ_УТВЕРЖДЕНИЯ #1: документ_на_утверждении = «спецификация»
    if @approval_document == "specification" {
      @phase = "PlanPhase"
      return Go(SpecificationReconciliation)
    }
    // ПОСЛЕ_УТВЕРЖДЕНИЯ #2: документ_на_утверждении = «план»
    if @approval_document == "plan" {
      @phase = "ImplementationPhase"
      return Go(SpecificationReconciliation)
    }
    // ПОСЛЕ_УТВЕРЖДЕНИЯ #3: иначе
    environment.machine_error("ошибка машины: развилка AfterApproval, ни одно условие не подошло")
  }

  // ===================== РАЗБОР — развилка =====================
  ReviewParsing => {
    // РАЗБОР #1: маршрут = `""`
    if @route == "" { return Go(RouteClassification) }
    // РАЗБОР #2: маршрут = «быстрый», отложенная_сессия[РАЗБОР] = `""`, спецификация есть, её статус «утверждено», и утверждение спецификации действует
    if @route == "fast" && @next_session("AnalysisPhase") == "" && status_equals(@specification(), ArtifactStatus.Approved) && @approval_valid("specification") {
      @approval_document = "specification"
      environment.write_journal("быстрый маршрут: копия постановки утверждена словом завода, С1, С2, Gate4 и Gate5 пропущены")
      return Go(AfterApproval)
    }
    // РАЗБОР #3: маршрут = «быстрый», отложенная_сессия[РАЗБОР] = `""`, спецификация есть, и её статус «черновик»
    if @route == "fast" && @next_session("AnalysisPhase") == "" && status_equals(@specification(), ArtifactStatus.Draft) {
      @approval_document = "specification"
      environment.write_journal("быстрый маршрут: копию правили после утверждения, нужно новое слово человека")
      return Go(ApprovalCheck)
    }
    // РАЗБОР #4: маршрут = «быстрый», отложенная_сессия[РАЗБОР] = `""`, и спецификации нет
    if @route == "fast" && @next_session("AnalysisPhase") == "" && @specification() == None {
      @route_choice_source = "rule"
      @route_basis = "постановки нет: утверждать нечего"
      environment.write_journal("быстрый маршрут: постановки нет")
      return Go(FullPathReturn)
    }
    // РАЗБОР #5: маршрут = «быстрый», и отложенная_сессия[РАЗБОР] не равна `""`
    if @route == "fast" && @next_session("AnalysisPhase") != "" {
      @route_choice_source = "rule"
      @route_basis = "правка меняет требования: задача не мала"
      environment.write_journal("быстрый маршрут: очередь правки требований")
      return Go(FullPathReturn)
    }
    // РАЗБОР #6: маршрут = «полный», и отложенная_сессия[РАЗБОР] не равна `""`
    if @route == "full" && @next_session("AnalysisPhase") != "" {
      @session = @next_session("AnalysisPhase")
      @source = @next_source("AnalysisPhase")
      @set_next_session("AnalysisPhase", "")
      @set_next_source("AnalysisPhase", "")
      @continuation = "analysis_queue"
      return Go(SessionLaunch)
    }
    // РАЗБОР #7: маршрут = «полный», отложенная_сессия[РАЗБОР] = `""`, и спецификации нет
    if @route == "full" && @next_session("AnalysisPhase") == "" && @specification() == None {
      @assign_launch("s1", "", "analysis_first_session")
      return Go(SessionLaunch)
    }
    // РАЗБОР #8: маршрут = «полный», отложенная_сессия[РАЗБОР] = `""`, и спецификация есть
    if @route == "full" && @next_session("AnalysisPhase") == "" && @specification() != None { return Go(AnalysisReview) }
    // РАЗБОР #9: иначе
    environment.machine_error("ошибка машины: развилка ReviewParsing, ни одно условие не подошло")
  }

  // ===================== РАЗБОР_ПРОВЕРКА — обращение =====================
  AnalysisReview => match event_body {
    // РАЗБОР_ПРОВЕРКА #1: ответ: чисто (цикл: Цикл)
    ReviewClean { cycle, .. } => {
      @set_cycle(Stage.Analysis, cycle)
      Go(Gate4)
    }
    // РАЗБОР_ПРОВЕРКА #2: ответ: требования (цикл: Цикл; источник: Текст)
    ReviewRequirements { cycle, source, .. } => {
      @set_cycle(Stage.Analysis, cycle)
      @assign_launch("s1_fix", source, "analysis_return")
      Go(SessionLaunch)
    }
    // РАЗБОР_ПРОВЕРКА #3: ответ: вопрос (цикл: Цикл)
    ReviewQuestion { cycle, .. } => {
      @set_cycle(Stage.Analysis, cycle)
      Go(Gate4Question)
    }
    // РАЗБОР_ПРОВЕРКА #4: ответ: план (цикл: Цикл)
    ReviewPlan { cycle, .. } => {
      @set_cycle(Stage.Analysis, cycle)
      Go(Gate4)
    }
    // РАЗБОР_ПРОВЕРКА #5: сбой (причина: КодСбоя)
    Failure { reason } => {
      @failure_reason = fail_code_word(reason)
      environment.write_journal("проверка разбора не дала итога: ${fail_code_word(reason)}")
      Go(ReviewFailure)
    }
    _ => NotAwaited
  }

  // ===================== В4 — обращение =====================
  Gate4 => match event_body {
    // В4 #1: В4: «ответов нет»
    Gate4NoAnswers => {
      @approval_document = "specification"
      Go(ApprovalCheck)
    }
    // В4 #2: В4: «ответы» (ответы_заказчика: Текст)
    Gate4Answers { customer_answers: answers } => {
      @customer_answers = answers
      @assign_launch("s1_fix", "Ответы", "analysis_answers")
      Go(AnswersRecording)
    }
    // В4 #3: В4: «ответы меняют цель, границы или сценарии» (ответы_заказчика: Текст)
    Gate4AnswersChangeGoal { customer_answers: answers } => {
      @customer_answers = answers
      @assign_launch("s1_fix", "Ответы", "analysis_answers_change_goal")
      Go(AnswersRecording)
    }
    _ => NotAwaited
  }

  // ===================== В4_ВОПРОС — обращение =====================
  Gate4Question => match event_body {
    // В4_ВОПРОС #1: В4: «ответов нет»
    Gate4NoAnswers => {
      @customer_answers = ""
      @assign_launch("s1_fix", "Ответы", "analysis_answers_after_question")
      Go(AnswersRecording)
    }
    // В4_ВОПРОС #2: В4: «ответы» (ответы_заказчика: Текст)
    Gate4Answers { customer_answers: answers } => {
      @customer_answers = answers
      @assign_launch("s1_fix", "Ответы", "analysis_answers_after_question")
      Go(AnswersRecording)
    }
    // В4_ВОПРОС #3: В4: «ответы меняют цель, границы или сценарии» (ответы_заказчика: Текст)
    Gate4AnswersChangeGoal { customer_answers: answers } => {
      @customer_answers = answers
      @assign_launch("s1_fix", "Ответы", "analysis_answers_after_question")
      Go(AnswersRecording)
    }
    _ => NotAwaited
  }

  // ===================== ЗАПИСЬ_ОТВЕТОВ — операция =====================
  AnswersRecording => match event_body {
    // ЗАПИСЬ_ОТВЕТОВ #1: сразу
    Immediate => Go(SessionLaunch)
    _ => NotAwaited
  }

  // ===================== ПЛАН — развилка =====================
  PlanPhase => {
    // ПЛАН #1: маршрут = «быстрый», и отложенная_сессия[ПЛАН] = `""`
    if @route == "fast" && @next_session("PlanPhase") == "" {
      @phase = "ImplementationPhase"
      environment.write_journal("быстрый маршрут: фаза PlanPhase пропущена, план реализации — в начале отчёта реализации")
      return Go(SpecificationReconciliation)
    }
    // ПЛАН #2: маршрут = «быстрый», и отложенная_сессия[ПЛАН] не равна `""`
    if @route == "fast" && @next_session("PlanPhase") != "" {
      @route_choice_source = "rule"
      @route_basis = "правка меняет план: задача не мала"
      environment.write_journal("быстрый маршрут: очередь правки плана")
      return Go(FullPathReturn)
    }
    // ПЛАН #3: маршрут = «полный», и отложенная_сессия[ПЛАН] не равна `""`
    if @route == "full" && @next_session("PlanPhase") != "" {
      @session = @next_session("PlanPhase")
      @source = @next_source("PlanPhase")
      @set_next_session("PlanPhase", "")
      @set_next_source("PlanPhase", "")
      @continuation = "plan_queue"
      return Go(SessionLaunch)
    }
    // ПЛАН #4: маршрут = «полный», отложенная_сессия[ПЛАН] = `""`, и плана нет
    if @route == "full" && @next_session("PlanPhase") == "" && @task_plan() == None {
      @assign_launch("s3", "", "plan_first_session")
      return Go(SessionLaunch)
    }
    // ПЛАН #5: маршрут = «полный», отложенная_сессия[ПЛАН] = `""`, и план есть
    if @route == "full" && @next_session("PlanPhase") == "" && @task_plan() != None { return Go(PlanStopWord) }
    // ПЛАН #6: иначе
    environment.machine_error("ошибка машины: развилка PlanPhase, ни одно условие не подошло")
  }

  // ===================== ПЛАН_СТОП_СЛОВО — развилка =====================
  PlanStopWord => {
    // ПЛАН_СТОП_СЛОВО #1: план есть, и его стоп_слово = «требования»
    if @task_plan() != None && stop_word_equals(@task_plan(), StopWord.Requirements) {
      @route_source = "последний абзац плана"
      return Go(ToRequirements)
    }
    // ПЛАН_СТОП_СЛОВО #2: план есть, и его стоп_слово отличается от «требования»

    // СДАЧА_ДИФФ #2: различия_дерева не равно `""`
    if @tree_diff() != "" { return Go(Gate10a) }
    // СДАЧА_ДИФФ #3: иначе
    environment.machine_error("ошибка машины: развилка DeliveryDiff, ни одно условие не подошло")
  }

  // ===================== В10а — обращение =====================
  Gate10a => match event_body {
    // В10а #1: В10а: «разрешить коммит»
    Gate10aAllowCommit => {
      @assign_launch("commit", "", "delivery_commit")
      Go(SessionLaunch)
    }
    // В10а #2: В10а: «полный путь» (основание: Текст)
    FullPath { basis } => {
      @route_choice_source = "human"
      @route_basis = basis
      Go(FullPathReturn)
    }
    _ => NotAwaited
  }

  // ===================== СДАЧА_СООБЩЕНИЕ — развилка =====================
  DeliveryMessage => {
    // СДАЧА_СООБЩЕНИЕ #1: сообщение_коммита отличается от текста_коммита побайтно
    if @commit_message() != @commit_text() { return Go(Gate10b) }
    // СДАЧА_СООБЩЕНИЕ #2: сообщение_коммита равно тексту_коммита побайтно
    if @commit_message() == @commit_text() { return Go(Gate10c) }
    // СДАЧА_СООБЩЕНИЕ #3: иначе
    environment.machine_error("ошибка машины: развилка DeliveryMessage, ни одно условие не подошло")
  }

  // ===================== В10б — обращение =====================
  Gate10b => match event_body {
    // В10б #1: В10б: «продолжить»
    Gate10bContinue => Go(Gate10c)
    _ => NotAwaited
  }

  // ===================== В10в — обращение =====================
  Gate10c => match event_body {
    // В10в #1: В10в: «разрешить пуш»
    Gate10cAllowPush => {
      @assign_launch("push", "", "delivery_push")
      Go(SessionLaunch)
    }
    _ => NotAwaited
  }

  // ===================== В10г — обращение =====================
  Gate10d => match event_body {
    // В10г #1: В10г: «отправлено»
    Gate10dSent => {
      @phase = "FeedbackPhase"
      Go(SpecificationReconciliation)
    }
    _ => NotAwaited
  }

  // ===================== В11 — обращение =====================
  Gate11 => match event_body {
    // В11 #1: В11: «завершить»
    Gate11Finish => {
      @phase = "CompletedPhase"
      Go(End)
    }
    // В11 #2: В11: «обратная связь» (обратная_связь: Текст)
    Gate11Feedback { feedback: link } => {
      @feedback_round += 1
      @feedback = link
      Go(FeedbackSaving)
    }
    _ => NotAwaited
  }

  // ===================== СОХРАНЕНИЕ_ОБРАТНОЙ_СВЯЗИ — операция =====================
  FeedbackSaving => match event_body {
    // СОХРАНЕНИЕ_ОБРАТНОЙ_СВЯЗИ #1: сразу
    Immediate => {
      @assign_launch("s9", "", "feedback_analysis")
      Go(SessionLaunch)
    }
    _ => NotAwaited
  }

  // ===================== МАРШРУТ_ОБРАТНОЙ_СВЯЗИ — развилка =====================
  FeedbackRoute => {
    // МАРШРУТ_ОБРАТНОЙ_СВЯЗИ #1: маршрут_обратной_связи = «Маршрут: С1 правка»
    if @feedback_route() == Some("route_s1_fix") {
      @set_next_session("ImplementationPhase", "s5_fix")
      @set_next_source("ImplementationPhase", "файл разбора обратной связи раунда ${@feedback_round}")
      @route_source = "файл разбора обратной связи раунда ${@feedback_round}"
      return Go(ToRequirements)
    }
    // МАРШРУТ_ОБРАТНОЙ_СВЯЗИ #2: маршрут_обратной_связи = «Маршрут: С3 правка»
    if @feedback_route() == Some("route_s3_fix") {
      @set_next_session("ImplementationPhase", "s5_fix")
      @set_next_source("ImplementationPhase", "файл разбора обратной связи раунда ${@feedback_round}")
      @route_source = "файл разбора обратной связи раунда ${@feedback_round}"
      return Go(ToPlan)
    }
    // МАРШРУТ_ОБРАТНОЙ_СВЯЗИ #3: маршрут_обратной_связи = «Маршрут: С5 правка»
    if @feedback_route() == Some("route_s5_fix") {
      @set_next_session("ImplementationPhase", "s5_fix")
      @set_next_source("ImplementationPhase", "файл разбора обратной связи раунда ${@feedback_round}")
      @phase = "ImplementationPhase"
      return Go(SpecificationReconciliation)
    }
    // МАРШРУТ_ОБРАТНОЙ_СВЯЗИ #4: маршрут_обратной_связи = «Маршрут: С7»
    if @feedback_route() == Some("route_s7") {
      @phase = "DeliveryPhase"
      return Go(SpecificationReconciliation)
    }
    // МАРШРУТ_ОБРАТНОЙ_СВЯЗИ #5: иначе
    environment.machine_error("ошибка машины: развилка FeedbackRoute, ни одно условие не подошло")
  }

  // ===================== ОТКАЗ_ПРОВЕРКИ — развилка =====================
  ReviewFailure => {
    // ОТКАЗ_ПРОВЕРКИ #1: причина_сбоя = «остановлено человеком»
    if @failure_reason == "stopped_by_human" {
      @stop_reason = "review_stopped_by_human"
      return Go(Halted)
    }
    // ОТКАЗ_ПРОВЕРКИ #2: причина_сбоя = «нет результата»
    if @failure_reason == "no_result" {
      @stop_reason = "review_no_result"
      return Go(Halted)
    }
    // ОТКАЗ_ПРОВЕРКИ #3: иначе
    environment.machine_error("ошибка машины: развилка ReviewFailure, ни одно условие не подошло")
  }

  // ===================== ПАУЗА — обращение =====================
  Pause => NotAwaited

  // ===================== КОНЕЦ — конец =====================
  End => unreachable("конец: переходов нет; работа при входе — в «Концы и ответ»")

  // ===================== ОСТАНОВЛЕНО — конец =====================
  Halted => unreachable("конец: переходов нет; работа при входе — в «Концы и ответ»")

  // ===================== ОШИБКА — конец =====================
  Errored => unreachable("конец: переходов нет; работа при входе — в «Концы и ответ»")

  }
}
```

## Работа операций

```nova
/// Работа операций при входе (в одном шаге с переходом; отказа и «нет ответа» у операции нет).
/// Результат операции — событие: `Сразу`; у ПОДГОТОВКИ — `Сразу_ПОДГОТОВКА` с итогом и счётчиками цикла каждой стадии.
/// Записи в документы идут внутри фиксации; смена статуса, переименование письма — необратимые действия последнего этапа.
fn MachineData mut @run_operation(operation State, environment MachineEnvironment) Journal Objects Time -> Event => match operation {
  Preparation => {
    // при первом старте исполнителя: итог и счётчики цикла каждой стадии — результатом операции; при возобновлении ту же подготовку делает `при_возобновлении`
    ro outcome = @run_preparation()
    ImmediatePreparation { preparation_outcome: outcome.preparation_outcome, cycles: outcome.cycles }
  }
  SpecificationSnapshot => {
    @invalidate("specification", environment)             // invalidate(spec.md); С3 и С5 закрываются, С1 нет; префикс пересобирается — механика исполнителя
    Immediate
  }
  PlanSnapshot => {
    @invalidate("plan", environment)                     // invalidate(plan.md); С5 закрывается, С3 нет; префикс пересобирается
    Immediate
  }
  ToRequirements => {
    @invalidate("specification", environment)             // to_requirements: оба документа — в черновик, записи об утверждении удаляются
    @invalidate("plan", environment)
    Immediate
  }
  ToPlan => {
    @invalidate("plan", environment)                     // to_plan
    Immediate
  }
  ForeignSnapshot => {
    environment.add_irreversible(Irreversible.RevertToDraft(@approval_document))   // без закрытия диалогов: gate_approve не вызывает invalidate
    Immediate
  }
  ApprovalRecording => {
    @approvals.insert(@approval_document, @approval_by_document(@approval_document))   // approvals[файл] ← {дата, кто, hash(файл)}; префикс пересобирается
    Immediate
  }
  AnswersRecording => {
    @write_answers(@customer_answers)    // write_answers: раздел «Ответы» спецификации
    Immediate
  }
  DecisionsRecording => {
    @write_decisions(@plan_decisions)              // write_decisions: раздел «Требует утверждения» плана, пометка «решено:»
    Immediate
  }
  OwnerDecisionsRecording => {
    @write_owner_marks(@owner_decisions)       // write_owner_marks: пометка «решение владельца: …, <дата>»
    Immediate
  }
  LetterRenaming => {
    environment.add_irreversible(Irreversible.RenameLetter(@feedback_round))   // rename(delivery/customer.md → delivery/customer-<номер_раунда>.md)
    Immediate
  }
  FeedbackSaving => {
    @save_round_notes(@feedback_round, @feedback)   // task/feedback-<номер_раунда>/
    Immediate
  }
  BriefCopy => {
    @approvals.insert("specification", @copy_approval(@factory_word, @factory_word_date))   // approvals[spec.md] ← {дата слова, владелец, hash(копия)}: отметка раньше ресурса (правило 13)
    environment.add_irreversible(Irreversible.CreateApprovedCopy(@factory_word, @factory_word_date))   // spec.md ← копия постановки со статусом «утверждено» и словом завода: последний, повторяемый без вреда этап
    Immediate
  }
  CopySnapshot => {
    @invalidate("specification", environment)             // invalidate(spec.md): первая строка ← «Статус: черновик», запись удаляется; С3 и С5 закрываются; префикс пересобирается
    Immediate
  }
  FullPathReturn => {
    if @specification() != None { @invalidate("specification", environment) }   // invalidate(spec.md), если спецификация есть: С3 и С5 закрываются, С1 нет; plan.md у быстрого маршрута нет
    else { @approvals.remove("specification") }               // спецификации нет: удаляется только запись об утверждении (запись без файла недопустима)
    Immediate
  }
  _ => unreachable("у остальных состояний нет работы операции")
}
```

## Концы и ответ

```nova
/// Работа концов при входе (в последнем, повторяемом без вреда этапе фиксации) и ответ вызвавшей стороне.
/// Вход в любой конец отменяет все открытые запросы (правило 22); машина отвечает ровно один раз (правило 35).
fn MachineData mut @on_end_entry(end_state State, environment MachineEnvironment) Journal Time -> () => match end_state {
  // ОСТАНОВЛЕНО: группа процессов агента останавливается целиком и проверяется, что в ней не осталось процессов; в журнал — «раннер остановлен: <остановка>»;
  //   задача не завершена, фаза и все данные сохранены; блокировка остаётся (её держал процесс, который кончил работу).
  Halted => {
    environment.add_irreversible(Irreversible.StopAgentGroup)
    environment.write_journal("раннер остановлен: ${@stop_reason}")
  }
  // ОШИБКА: группа процессов агента останавливается; в журнал — запись из перехода и данные машины; задача не завершена; решает человек вне машины.
  Errored => {
    environment.add_irreversible(Irreversible.StopAgentGroup)
    environment.write_journal(environment.transition_note())
    @journal_machine_data(environment)
  }
  // КОНЕЦ: блокировка снимается; в журнал — «задача завершена, раундов обратной связи: <номер_раунда>»; человеку показывается «задача завершена».
  End => {
    environment.add_irreversible(Irreversible.ReleaseLock)
    environment.write_journal("задача завершена, раундов обратной связи: ${@feedback_round}")
    environment.add_irreversible(Irreversible.ShowHuman("задача завершена"))
  }
  _ => ()
}
// запись для диагностики: все переменные и хранилища (Вход ОШИБКИ)
fn MachineData mut @journal_machine_data(environment MachineEnvironment) Journal Time -> ()

/// Таблица «конец → ответ» первоисточника (раздел «Контракт машины»): каждый конец и каждое значение остановка — одна строка.
fn MachineData @end_response(call_request Request[RunnerInput], end_state State, environment MachineEnvironment) -> Response[RunnerResult] {
  match end_state {
    // КОНЕЦ, условие входа: всегда → СРезультатом: задача завершена, число раундов обратной связи
    End => Answer(Reply {
      request: call_request.id, party: call_request.party, trace: call_request.trace, step: call_request.step,
      result: RunnerResult { feedback_rounds: @feedback_round } })
    // ОШИБКА, условие входа: всегда (дефект машины) → Отказ, НетРезультата; текст — запись из перехода
    Errored => refuse_with(call_request, NoResult, environment.transition_note())
    Halted => match @stop_reason {
      // ОСТАНОВЛЕНО: остановка = «задача занята живым процессом» → Отказ, НетРезультата
      "task_busy_by_live_process" => refuse_with(call_request, NoResult, @stop_reason)
      // ОСТАНОВЛЕНО: остановка = «проверка цикла: нет результата» → Отказ, НетРезультата
      "review_no_result" => refuse_with(call_request, NoResult, @stop_reason)
      // ОСТАНОВЛЕНО: остановка = «запуск сессии: нет результата» → Отказ, НетРезультата
      "session_launch_no_result" => refuse_with(call_request, NoResult, @stop_reason)
      // ОСТАНОВЛЕНО: остановка = «маршрут: настройки нарушают инварианты методики» → Отказ, НетРезультата
      "route_settings_violate_invariants" => refuse_with(call_request, NoResult, @stop_reason)
      // ОСТАНОВЛЕНО: остановка = «В13: остановить», «ДЕРЕВО_ЗАНЯТО: остановить», «проверка цикла: остановлено человеком», «запуск сессии: остановлено человеком» или «ПАУЗА: остановить»
      //   (слово человека; у вызванной машины — сигнал «остановить от родителя» в ПАУЗЕ) → Отказ, ОстановленоЧеловеком
      "gate13_halt" | "tree_busy_halt" | "review_stopped_by_human" | "session_launch_stopped_by_human" => refuse_with(call_request, StoppedByHuman, @stop_reason)
      "pause_halt" => refuse_with(call_request, common_stop_fail_code(@stop_reason), @stop_reason)
      // ОСТАНОВЛЕНО: остановка = «отмена_запроса» → Отказ, ОтмененоРодителем
      "cancel_request" => refuse_with(call_request, common_stop_fail_code(@stop_reason), @stop_reason)
      _ => unreachable("значение остановка вне таблицы «конец → ответ»: новое значение добавляет строку таблицы")
    }
    _ => unreachable("ответ отдают только концы")
  }
}

/// Точка подстановки эффектов: обработчики выбирает вызывающий код, один раз (`with`), и вне этого файла — любые (`Time` — стандартный, обработчик по умолчанию).
/// Все функции цепочки от `начать`, `возобновить`, `вызвать` объявляют эффекты в своей сигнатуре; здесь они подставлены. Машину по входу запроса создаёт вызывающий код.
fn start_runner(request Request[RunnerInput]) Time -> Response[RunnerResult] =>
  with Store = store_handler, Journal = journal_handler, Link = link_handler, Objects = objects_handler {   // псевдокод: обработчики (база, файл поверх Fs/Db, очередь сообщений) — любые, вне файла
    mut engine_instance = Engine.new(MachineData.from_input(request.input))
    engine_instance.call(request)
  }
```
