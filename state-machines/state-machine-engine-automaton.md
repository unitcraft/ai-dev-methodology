# Движок стейт-машины: код исполнителя

Движок любой стейт-машины, записанный кодом на языке Нова: конверт запроса и ответа (`Запрос`, `Исход`, `КодСбоя`), снимок и хранилище, исполнитель (цикл, приём, фиксации, отправка запросов, повтор, журнал и трасса, сигналы вложенным, необратимые действия), общие события «стоп человека», «стоп от родителя», «отмена_запроса», пауза цепочки и протокол `Вызываемое`. Машина подставляется протоколом `Автомат`: движок не знает ни её состояний, ни событий, ни ролей; поэтому он обобщён по `Состояние`, `Событие`, `Вход`, `Выход`, `ВходРоли`, `РезультатРоли`, `Действие`. Машина может быть событием в другой машине (правило 35): исполнитель с машиной реализует `Вызываемое`.

**Нормы — [state-machine-spec.md](state-machine-spec.md)** (правила 12–25, 31, 35). Файл — запись движка, а не вторая спецификация: при расхождении верна спецификация, файл правится вслед за ней. Пример реализации машины, подставляемой в движок, — [task-runner-meeting-automaton.md](task-runner-meeting-automaton.md) (машина совещания; её первоисточник — [task-runner-meeting-states.md](task-runner-meeting-states.md)); имена блока «Типы на Нове» и таблица соответствия — там же. Язык записи — Нова, https://github.com/nv-lang/nova (синтаксис — по `spec/syntax.ru.md`, `spec/effects.md` и `nova.ungrammar` того репозитория). Внешний мир — пять эффектов Нова: `Хранилище`, `Журнал`, `Связь`, `Объекты` и стандартный `Time`; обработчик каждого может быть любым и в файле не записан. Ворота человека не эффект: машина фиксирует состояние, отправляет вопрос через `Связь.отправить` и завершает шаг; слово приходит позже сообщением, а после перезапуска состояние берётся из `Хранилище.загрузить` (ожидание часами, переживающее перезапуск, в Нове не определено). **Код не компилировался и не проверялся компилятором Нова:** это псевдокод в синтаксисе Нова; места, где Нова не выражает записанное или где синтаксис не подтверждён спецификацией, помечены строкой `// псевдокод:` (перечень — в соглашениях, пункт 5). Над движком — слой общих типов и операций машин методики задач [state-machine-methodology-automaton.md](state-machine-methodology-automaton.md); движок о нём не знает. Имя файла — по `AGENTS.md`, «Вынесенные алгоритмы» (документ `state-machine`, часть `engine`, форма `automaton`).

## Соглашения записи

1. **Типы и параметры.** Имена — русские: слово или слитное сочетание с заглавной буквы без подчёркиваний (`КодСбоя`, `СостояниеДвижка`). Параметры типов — осмысленные русские имена: `Состояние`, `Событие` (перечисления машины), `Вход`, `Выход` (вход и итог машины как вызываемой), `ВходРоли`, `РезультатРоли` (вход запроса к стороне и её результат), `Действие` (необратимое действие машины), `ТипМашины` (тип машины с протоколом `Автомат`).
2. **Идентификаторы** все русские: типы и варианты — с заглавной буквы без подчёркиваний, поля, параметры, локальные переменные и функции — змеиный регистр (правило 25 спецификации: имя одной сущности одно). Латиница — только стандартные имена Нова (`fn`, `type`, `match`, `Option`, `Some`, `None`, `Result`, `Ok`, `Err`, `HashMap`, `str`, `int`, `bool`, `never`, `effect`, `with`, `protocol`, `loop` и др.). Нова кириллические идентификаторы не поддерживает (владелец, 2026-10-17); русские имена в псевдокоде — решение этого файла.
3. **Запись Нова.** `ro` — неизменяемая привязка, `mut` — изменяемая переменная; отсутствующее значение — `None`, значение — `Some(x)`; строки — `"… ${выражение} …"`; комментарий — `//`, документирующий — `///` (перед объявлением, пустая строка перед ним). Метод — `fn Тип @имя(…)` читает, `fn Тип mut @имя(…)` меняет; обращение к полю и вызов метода — через `@`. Данные движка у исполнителя — `@состояние_движка.<поле>`, метод машины — `@машина.<метод>`, служебные операции машине — через значение `Среда`. «То же состояние» — `Остаться`, «запуск заново» — `Заново(S)`, «Куда» — `Куда(S)`, «сразу» — событие `событие_сразу()`.
4. **Механика исполнителя.** Раздел «Механика исполнителя» — перечень механики контракта, фиксации и приёма (правила 13–22, 31, 35 спецификации): свободные функции и методы `Исполнитель`; большинство объявлено только сигнатурой, телом записаны те, что выражаются данными. Раздел «Помощники машин» — функции, одинаковые у всех машин (`обязательное`, `объект_ок`, `слово_кода`, `код_сбоя_общей_остановки`, `отказ_по`): машина зовёт их по имени и своих копий не держит.
5. **Строки `// псевдокод:`** стоят там, где записанное — не Нова или не подтверждено его спецификацией: функции без тела (сигнатуры механики); `недостижимо`; кодирование среза исполнителя в строку снимка (`кодировать`, `раскодировать`); ресивер как значение протокола (`среда`). **Подтверждено спецификацией Нова** (проверено оркестратором проекта по чтению репозитория языка, 2026-10-18): `///` — внешний документирующий комментарий (`spec/decisions/03-syntax.md`, D104; привязан к следующему полю записи и варианту суммы); `never` строчная — тип выражения, которое не возвращает значения (`spec/decisions/04-effects.md`, D25), его и берёт `недостижимо`; `Never` заглавная — пустой тип, нужен только как аргумент `E` в `Effect[E, Never]`, здесь не используется; `fn Тип.new()` — статическое объявление (`spec/syntax.ru.md`, `fn Account.new(…)`); `.contains()` на `[]T` (std, `collections/vec/access.nv`); `.len()` на списке (`vec/core.nv`); срез `v[a..]`, `v[a..b]` (`vec/slice.nv`, Plan 284; за границами паника, безопасно `v.get(a..b)`); присваивание как ветка `match` допустимо (`nova.ungrammar`, `MatchArm`), здесь оно записано блоком `=> { x = v }`; длина текста (`.len()` на `str`) нигде не берётся. **Протоколы** (прочитано в `spec/syntax.ru.md`, раздел «Структурные "интерфейсы" — protocol», 2026-10-18): `type Имя protocol { @метод() -> T }`, изменяющий метод — `mut @метод(…)`, обобщённый протокол — `type Next[T] protocol { … }`, соответствие структурное, `impl` не нужен — поэтому `Исполнитель` реализует `Вызываемое` совпадением метода `вызвать`, а машина — `Автомат` совпадением методов. **Эффекты** (прочитано в `spec/effects.md`, 2026-10-18, D61/D142/D434/D456): `type Хранилище effect { fn … -> T }` — операции без `@` и без `mut`, тип возврата обязателен; эффект в сигнатуре между `)` и `->` (`fn … Хранилище -> …`); вызов по имени `Хранилище.сохранить(…)`; обработчик подставляет `with Хранилище = обработчик { … }` один раз у вызывающего кода; прямой эффект объявляется в сигнатуре, транзитивный — предупреждение, при `--strict-effects` ошибка; требование проекта Нова — объявляют все функции цепочки, так в этом файле и записано; единый `with` — на точке запуска. **Записано по выводу, спецификацией не подтверждено:** ошибка операции эффекта через `Result` (форма `Fail[E]` для операции эффекта в спецификации не найдена); форма метода с эффектом `fn Тип @метод(…) Эффект -> Т` (в спецификации — только свободные функции; метод — вывод, не цитата), в том числе у методов протокола; эффекты без параметров типа: обобщённые эффекты в Нове не поддерживаются (`E_EFFECT_GENERIC_UNSUPPORTED`), поэтому через `Связь` ходят конкретные типы `ВходСтороны`, `РезультатСтороны`, `СобытиеСтороны`, а кодирование и раскодирование — методы машины; `Timestamp` и `Time.now()`, `Time.now_monotonic()` (тип результата принят как целое число миллисекунд); подстановка `Time` обработчиком по умолчанию без `with`. **Не подтверждено спецификацией, без пометки в коде:** русские имена параметров типа `[Вход, Выход]`; `return` из `loop` значением функции (`цикл`); `return` в ветке `match` (`=> return None`); протокол с несколькими параметрами типа и параметр типа с границей-протоколом (`ТипМашины Автомат[…]`); охранное условие в ветке `match` (`Some(готовый) if …`); `.insert(0, …)` и `.push(…)` на списке; образец `{ поле, .. }` с остатком (в спецификации — `Occupied { value, .. }`); `.clone()` и `.reverse()` на списке (по образцу std, не проверено); многопривязочный `with Хранилище = …, Журнал = …, …` (в спецификации — одна привязка); оператор `?` для `Option` в теле метода (`общие_события`); обобщённые свободные функции `fn имя[Тип](…)` (в спецификации есть `fn get[K, V, C Index[K, V]]`); параметр типа, который есть только в результате (`отказ_по[Вход, Выход]`: `Выход` выводится из места вызова); **обязательный** метод протокола `при_возобновлении` (необязательный метод, то есть условное соответствие протоколу, в Нове не подтверждено: у машины без подготовки при возобновлении — заглушка `None`); обобщённая запись `ШагЦепочки[Состояние, Событие]` (как `Входящее[Событие]`); поля у вариантов суммы `Набор { …, вложенная bool }`, `Одна { …, возвратов_формы int }` и образец `Одна { сторона, .. }`; список `[]int` в метке инварианта, индексация `после[позиция]`, `.len()` двух списков. **Записано по слову владельца, спецификацией не подтверждено (2026-10-18):** оператор `??` для `Option` — значение либо запасное, правая часть вычисляется только при `None` (`обработать_очередь`). **Тело функции:** блок без стрелки `fn … { … }` (последнее выражение — значение) или `fn … => выражение`; `=> { поле: значение, … }` — литерал записи, так записаны только конструкторы `.new` (спецификация Нова: `FnDecl … (Block | FnExprBody)`, `FnExprBody = "=>" Expr`; проверено оркестратором проекта, 2026-10-18). **Алиасы типов и параметры типов (проверено оркестратором проекта, 2026-10-18):** `type Имя alias Тип` подтверждён (`spec/syntax.md`, `spec/decisions/02-types.md`); алиас с конкретной правой частью пишется без параметров (`type ЗапросРоли alias Запрос[ВходСтороны]`, прецедент `JsonObject` в `std/src/encoding/json.nv`), параметр нужен только у обобщённого алиаса (`type StringMap[V] alias HashMap[str, V]`); имена параметров типов в этом коде — русские слова вместо принятого в Нове одного символа PascalCase (`spec/syntax.md`, таблица соглашений: `T`, `K`, `V`): решение методики, запрета в спецификации нет.
6. **Исполнитель, хранилище, вызываемое.** `Исполнитель` владеет машиной `ТипМашины` и данными движка `СостояниеДвижка`: очередь входящих `очередь`, запрос вызова `вызов`, `готовый_ответ`, `необратимые`, `в_работе`; данные раздела «Данные» первоисточника машины, которые пишет исполнитель (`трасса`, `номер_шага`, `счётчик_событий`, `причина_шага`, `запрос_вызова`, `открытые_запросы`, `принятые_запросы`, `к_отправке`, `ожидание` и др.), лежат в `СостояниеДвижка`, остальное — у машины. `Хранилище` — эффект (`type Хранилище effect`) с операциями `загрузить` и `сохранить`, возвращающими `Result[…, ОшибкаХранилища]`; обработчик — любой, вне файла; так же `Журнал` (`записать`), `Связь` (`отправить`, `принять` без ожидания, отмена, сигналы вложенным, ответ вызвавшему) и `Объекты` (необратимые действия над объектами и чтение для отпечатка); «нет ответа в срок» рождается из сравнения сроков запросов со `Time` (срок — данные запроса, `Ожидание`); после перезапуска `Ожидание` сбрасывается, потому что моменты монотонного времени несравнимы: запросы к ролям без принятого ответа отменяются, повторённые запросы к вложенным получают срок заново при отправке; ответ покидает машину только через `Связь.ответить` (повторяемое необратимое действие последнего этапа фиксации; `вызвать` отдаёт вызвавшему тот же `готовый_ответ` как значение и второй раз не шлёт: поле `ответ_отправлен` в снимке ставится отдельной фиксацией, `возобновить` повторяет отправку, если ответ не ушёл); если `сохранить` не удалось — исполнитель аварийно прерывается (`недостижимо`), шаг не считается зафиксированным, запросы не отправляются. `Снимок` — две строки: данные движка (`СрезИсполнителя`) и данные машины (`снять` машины); `зафиксировать` вызывает `сохранить` в конце шага, ДО отправки запросов (правило 13). Входов два: `начать(запрос)` — состояние движка, фиксация, цикл; `возобновить(идентификатор_запроса)` — загрузка снимка и продолжение с сохранённого `состояние` (запросы без принятого ответа уходят повторно, пауза остаётся до «продолжить»; перед этим метод машины `при_возобновлении` — подготовка при каждом старте, только если сохранённое состояние не конец, до фиксации перезапуска и идемпотентная — может не пустить в сохранённое состояние и дать переход в другое; различие веток: при переходе вложенным идёт сигнал «отмена» и их запросы отменяются, без перехода их запросы повторяются тем же идентификатором (правило 35, п. 4); принятие файла попытки завершается на обеих ветках; правила 12, 14, 22); остановка исполнителя — завершение процесса: состояние уже сохранено. Запрос вызова всегда есть (`запрос_вызова` = `запрос.идентификатор_запроса`): через `Вызываемое` машину вызывают только запросом; решение, оставлять ли `""` у верхнего уровня, открыто (владелец не решил). Событие `ПросроченЗапрос` исполнитель порождает как `Входящее` с `запрос: Some(идентификатор)` и стороной по `сторона_запроса(идентификатор)`. `Вызываемое[Вход, Выход]` с методом `вызвать(запрос) -> Исход[Выход]` реализует `Исполнитель`; повтор запроса с тем же идентификатором возвращает готовый ответ или, если прогон идёт, ждёт его (правило 35, п. 4).
7. **Граница с машиной.** Движок требует от машины протокол `Автомат` (методы `начальное`, `перейти`, `вид`, `общее`, `состояние_по_имени`, `причина_остановки_в_паузе`, `обращение`, `вход_запроса`, `следующая_попытка`, `при_приёме`, `записать_результат`, `событие_ответа`, `выполнить_операцию`, `при_возобновлении`, `при_входе_в_конец`, `ответ_по_концу` и вспомогательные) и даёт ей `Среду` (журнал, слова человека, сигналы вложенным, необратимые действия, данные движка `к_отправке`, `открытые_запросы`, `предыдущее`, `запрос_вызова`, `запись_перехода`). Машина сводит свои события к `ОбщееСобытие` методом `общее`; движок разбирает «стоп человека», «стоп от родителя», «отмена_запроса» и «продолжить вне ПАУЗЫ» до строк состояний. Результат операции — событие (`выполнить_операцию`): его получает переход операции и следующая развилка цепочки (`ШагЦепочки`); событие с данными из результата роли даёт `событие_ответа`; метка инварианта — список чисел, движок сравнивает покомпонентно. Предел одновременных запросов отдаёт машина (`предел_запросов`); срок бездействия роли — данные запроса, задаёт машина (`обращение`).
8. **`недостижимо(текст)`** — тип `never`: ничего не отдаёт и аварийно прерывает исполнителя. Ветка невозможна при соблюдении инвариантов — это ошибка программы. Дефект самой машины (развилка, у которой ни одно условие не подошло) идёт иначе: строка «иначе → ОШИБКА», состояние ошибки, ответ-отказ `НетРезультата`. В движке `недостижимо` стоит: в `получатель` (запрос вызова не принят), в `вызвать` (снимок только что загружен), в `сохранить_снимок` и `загрузить_снимок` (хранилище не ответило); в реализации машины — по её описанию.

```nova
module engine

type NestedSignal { signal str, request str }

/// Запрос

/// Ответ

  | Refusal(Rejection)

/// Ответ (с результатом)

  | Cancelled  // отменено родителем

  | MaxTurnRequests  // исчерпан предел запросов модели за ход (этот код порождает «Шаг агента», остальные машины не порождают)

/// Запись движка: событие с конвертом (правила 13 и 31 спецификации); `Событие` — тип событий машины

  id str,        // «<вид>-<номер по счётчику событий>»
  party str,              // «событие.сторона»; у событий ворот и общих событий не читается
  request Option[str],       // идентификатор запроса, чьим исходом событие пришло (механика закрытия запроса)
  body Event              // вариант события машины и его данные
}

/// Запись движка: вид состояния (четыре вида первоисточника, раздел «Состояния»)
type Kind enum
  | Appeal
  | Operation
  | Fork
  | Final

/// Запись движка: то, что исполнитель обрабатывает при приходе — типизированно, типами машины: ответ или отказ роли, слово человека, сигнал, срок (правила 14, 16, 23)
type Received[Event, RoleResult] enum
  | ResponseReceived(Response[RoleResult])  // результат или отказ открытого запроса
  | WordReceived(Event)              // слово ворот человека или общий сигнал
  | RequestExpired(str)                // «нет ответа в срок»: идентификатор запроса; порождает исполнитель сравнением со сроком

/// Запись движка: куда ведёт строка
type Transition[State] enum
  | Go(State)         // «Куда»: состояние
  | Rerun(State)       // «Куда»: состояние, запуск заново (правило 18)
  | Stay                // «Куда»: то же состояние
  | NotAwaited                  // событие этого состояния не ждёт: остаётся в очереди (правило 13)

/// Запись движка: шаг цепочки — переход, который дал вход в состояние, и событие, которое несёт то, что сделано при входе: результат операции или «сразу» (у развилки);
/// следующая развилка цепочки получает это событие вместо `событие_сразу` (данные операции читает развилка после неё)
type ChainStep[State, Event] { transition Transition[State], body Event }

/// Запись движка: общее событие — то, что разбирается до строк состояний любой машины (правила 17, 23, 35);
/// машина сводит к нему свои события методом `общее`
type CommonEvent enum
  | HumanStop { human_word str, author str, source str }   // «стоп человека»
  | ParentStop { id str }                    // «стоп от родителя»
  | RequestCancelled { id str }                   // «отмена_запроса»
  // события ПАУЗЫ (фрагмент «Пауза», state-machine-pause-states.md): разбирает движок, у машины строк состояния ПАУЗА нет
  | PauseContinue { human_word str, author str, source str }   // ПАУЗА: «продолжить»; вне ПАУЗЫ отбрасывается
  | PauseHalt                                               // ПАУЗА: «остановить» (слово остановки — параметр фрагмента); вне ПАУЗЫ остаётся в очереди
  | PauseContinueFromParent { id str }       // ПАУЗА: «продолжить от родителя»
  | PauseHaltFromParent { id str }       // ПАУЗА: «остановить от родителя»

/// Запись движка: вход запроса к стороне, закодированный машиной (`кодировать_вход`): через эффект `Связь` ходят конкретные типы,
/// обобщённые эффекты в Нове не поддерживаются (`E_EFFECT_GENERIC_UNSUPPORTED`)
type PartyInput { data str }

/// Запись движка: результат стороны, закодированный стороной; машина раскодирует его в `РезультатРоли`
type PartyResult { data str }

/// Запись движка: событие стороны (слово человека, сигнал), закодированное; машина раскодирует его в `Событие`
type PartyEvent { data str }

/// Запись движка: выход машины (её итог как вызываемой), закодированный машиной (`кодировать_выход`)
type PartyOutput { data str }

/// Запись движка: запрос к стороне, как он уходит через `Связь`
type RoleRequest alias Request[PartyInput]

/// Запись движка: то, что приходит через `Связь`: ответ или отказ стороны, слово человека или сигнал «стоп»/«продолжить»/«остановить»/«отмена» (человека и родителя)
type Message enum
  | RoleResponse(Response[PartyResult])
  | Word(PartyEvent)

/// Запись движка: сколько запрос ждёт ответа — для «нет ответа в срок» (срок бездействия — данные запроса, правило 19)
type Waiting { sent int, term int }

/// Запись журнала: конверт трассировки и текст строки (правило 31); `счёт_по_моделям` — буфер строк счёта по моделям, пишется при фиксации
type JournalEntry { trace str, step int, cause str, state str, request str, at Timestamp, text str, model_tally str }

/// Запись движка: как состояние-обращение обращается к сторонам (правила 15, 21, 35).
/// `вложенная` — сторона запроса вложенная машина: ей идут сигналы «стоп», «продолжить», «остановить», «отмена», её запрос после перезапуска повторяется тем же идентификатором;
/// `возвратов_формы` — сколько раз ответ не по форме возвращается стороне в том же запросе, прежде чем это сбой «форма не исправлена» (число — данные описания: возврат и сбой после него — у обработчика роли, движок сбой формы не порождает)
type AppealDescription enum
  | Batch { idle_term int, order []str, nested bool, form_returns int }   // набор сторон из `к_отправке`, запросов одновременно не больше `предел_запросов` машины
  | Single { party str, idle_term int, nested bool, form_returns int }     // одна сторона
```

## Данные

```nova
/// Данные движка любой машины: конверт трассировки, очередь запросов, журнал и хранилища слов; поля названы как переменные раздела «Данные» первоисточника.
/// Сохраняются целиком вместе с состоянием машины, после перезапуска исполнитель входит заново в «состояние» (правило 22).
type EngineState[State] {
  trace str,                                  // назначается при старте, не меняется; конверт трассировки, в Вход не входит
  step int,                              // число фиксаций шагов; растёт на 1 внутри фиксации, откат возвращает; перезапуск и пауза не сбрасывают
  event_counter int,                         // +1 при приходе любого события; перезапуск и пауза не сбрасывают
  cause str,                            // идентификатор события, с которого начался шаг
  call_request_id str,                           // идентификатор запроса вызова; пишет исполнитель при начале (запрос.идентификатор_запроса)
  state State,                         // где машина ждёт (обращение или конец); пишет исполнитель при фиксации шага (правило 13)
  previous str,                              // имя состояния, прерванного «стоп человека» или «стоп от родителя»; пишут только они
  open_requests []str,                      // идентификаторы запросов, не закрытых переходом (правила 16, 21)
  accepted_requests []str,                      // идентификаторы запросов с принятым ответом, ждущим перехода (правило 14)
  to_send []str,                            // стороны набора, которым запрос ещё не отправлен
  nested_signals []NestedSignal,        // сигналы вложенным машинам («стоп», «продолжить», «остановить», «отмена») с идентификаторами их запросов, поставленные шагом; после фиксации их передаёт и очищает исполнитель (правило 35)
  waiting HashMap[str, Waiting],             // открытые запросы и их сроки: «нет ответа в срок» рождается из сравнения с `Time`; в снимок не входит осмысленно: после перезапуска сбрасывается
  model_tally str,                         // буфер строк счёта по моделям: пишется в журнал при фиксации
  transition_note str,                         // текст журнала перехода в ОШИБКУ; пишет ошибка_машины
  human_words str,                          // слово человека с автором и источником, ключ — идентификатор события; никакой шаг не читает
  failure_texts str,                            // свободный текст отказа, ключ — идентификатор события сбоя; никакой шаг не читает, в журнал не идёт
  nested_ids []str,                             // идентификаторы запросов к вложенным машинам (по `вложенная` описания обращения): пишет отправка; открытыми считаются те из них, что лежат в открытые_запросы
}

/// Начальные значения данных движка; состояние — начальное состояние машины.
fn EngineState.new(initial State) -> EngineState[State] => {
  trace: "",
  step: 0,
  event_counter: 0,
  cause: "",
  call_request_id: "",
  state: initial,
  previous: "",
  open_requests: []str.new(),
  accepted_requests: []str.new(),
  to_send: []str.new(),
  nested_signals: []NestedSignal.new(),
  waiting: HashMap[str, Waiting].new(),
  model_tally: "",
  transition_note: "",
  human_words: "",
  failure_texts: "",
  nested_ids: []str.new(),
}
```

## Протоколы и хранилище

```nova
/// Среда: что движок даёт машине внутри перехода — служебные операции и данные движка (правила 8, 13, 14, 17, 18, 19, 21, 35).
/// Машина меняет данные движка только через неё.
type Environment[State, Event, Action] protocol {
  mut @write_journal(text str) Journal Time -> ()                                   // строка журнала с конвертом: трасса, номер_шага, причина_шага, состояние, идентификатор запроса, время (правило 31)
  mut @machine_error(text str) Journal Time -> Transition[State]             // писать_журнал(текст); запись_перехода = текст; Куда(состояние ошибки)
  mut @record_human_word(event Incoming[Event], word str, author str, source str) Journal Time -> ()
  mut @discard(event Incoming[Event]) Journal Time -> ()                       // чужой или поздний сигнал: строка журнала, состояние то же (правило 17)
  mut @pass_to_nested(signal str)
  mut @add_irreversible(action Action)                    // выполняется после сохранения (правило 13)
  @to_send() -> []str
  mut @set_to_send(parties []str)
  mut @return_first_to_send(party str)
  @open_requests() -> []str
  @previous() -> str
  @call_request_id() -> str
  @transition_note() -> str
}

/// Автомат: что движок требует от машины. Любая машина, у которой есть эти методы, подходит (соответствие структурное, `impl` не нужен).
/// Параметры: `Состояние` и `Событие` — перечисления машины, `Вход` и `Выход` — вход и итог машины как вызываемой, `ВходРоли` и `РезультатРоли` — вход запроса к стороне и результат стороны, `Действие` — необратимое действие машины.
type Machine[State, Event, T, U, RoleInput, RoleResult, Action] protocol {
  @initial() -> State
  mut @step(current State, event_body Event, event Incoming[Event], environment Environment[State, Event, Action]) Journal Objects Time -> Transition[State]
  @kind(state State) -> Kind
  @common(current State, event_body Event) -> Option[CommonEvent]
  @pause_state() -> State
  @state_by_name(name str) -> State   // обратная к `имя_состояния`: для «Куда: предыдущее» и «Куда: возврат_подготовки» (правило 24)
  @pause_stop_reason() -> str         // значение «остановка» при «остановить» у ПАУЗЫ: «ПАУЗА: <слово остановки>» (фрагмент «Пауза»)
  @halted_state() -> State
  @error_state() -> State
  @state_name(state State) -> str
  @appeal(current State) -> Option[AppealDescription]
  @request_input(current State, party str, environment Environment[State, Event, Action]) Objects -> RoleInput
  @request_limit() -> int
  @encode_input(input RoleInput) -> PartyInput
  @decode_result(result PartyResult) -> RoleResult
  @decode_event(event PartyEvent) -> Event
  @encode_output(output U) -> PartyOutput
  mut @next_attempt(party str) -> int
  mut @on_accept(current State, response Response[RoleResult])
  mut @record_result(current State, response Response[RoleResult])
  @reply_event(current State, role_result RoleResult) -> Event   // событие с данными из результата роли («ответ: требования» несёт цикл и источник)
  mut @run_operation(operation State, environment Environment[State, Event, Action]) Journal Objects Time -> Event   // результат операции — событие: его принимает переход операции и следующая развилка цепочки
  @immediate_event() -> Event
  @failure_event(reason FailCode) -> Event
  mut @on_end_entry(end_state State, environment Environment[State, Event, Action]) Journal Time -> ()
  @end_response(call_request Request[T], end_state State, environment Environment[State, Event, Action]) -> Response[U]
  mut @record_stop(reason str)
  @invariant_mark() -> []int   // по компоненту на счётчик, который не должен убывать: движок сравнивает покомпонентно
  @object_changed_since_attempt(current State) Objects -> bool
  mut @execute(action Action) Objects -> ()
  mut @accept_attempt_file(id str) Objects -> ()
  @capture() -> str
  mut @restore(data str)
  // подготовка при каждом старте, до входа в сохранённое состояние (`сохранённое`; зовётся, только если оно не конец): None — войти в него, Some — перейти в другое (у машины без подготовки — None).
  // Подготовка выполняется до фиксации перезапуска (до коммита) и обязана быть идемпотентной: при падении до фиксации она выполнится снова
  mut @on_resume(saved State, environment Environment[State, Event, Action]) Journal Objects Time -> Option[Transition[State]]
}

/// Событие: машина как вызываемое событие другой машины (правило 35). Вход и выход — типы запроса и итога.
type Callable[T, U] protocol {
  mut @call(request Request[T]) Store Journal Link Objects Time -> Response[U]
}

/// Снимок: всё состояние движка и машины на конец шага — две строки: данные движка (`СрезИсполнителя`) и данные машины (`снять` машины); кодирует их сторона-владелец.
type Snapshot { engine_data str, machine_data str }

/// Ошибка операции хранилища (запись движка): минимальный текст причины.
type StoreError { text str }

/// Объект хранилища машины (рабочий документ, находки и т. п.): имя, по которому обработчик находит файл (запись движка, конкретный тип)
type Object { name str }

/// Ошибка операции над объектом (запись движка): минимальный текст причины
type ObjectError { text str }

/// Журнал — эффект: куда писать строки журнала с конвертом; обработчик — любой (файл `log.md`, база).
type Journal effect {
  fn write(entry JournalEntry) -> ()
}

/// Связь — эффект: как запрос уходит стороне и как приходят ответы и сигналы; обработчик — любой (файлы и процесс, очередь сообщений, чат).
/// `принять` не ждёт (по образцу `try_recv`): нет сообщения — `None`. Ворота человека — не эффект: машина фиксирует состояние, отправляет вопрос
/// через `отправить`, завершает шаг; слово приходит позже сообщением, после перезапуска состояние берётся из `Хранилище.загрузить`.
type Link effect {
  fn send(request RoleRequest) -> ()                        // запрос стороне (и повтор того же запроса с тем же идентификатором)
  fn receive() -> Option[Message]                            // пришедшее сообщение без ожидания
  fn cancel(id str) -> ()                 // отмена открытого запроса (правило 18)
  fn signal(id str, signal str) -> ()       // «стоп», «продолжить», «остановить», «отмена» вложенной машине (правило 35)
  fn reply(response Response[PartyOutput]) -> ()                 // ответ вызвавшей стороне (правило 35): повторяемо и идемпотентно по запрос_вызова
}

/// Объекты — эффект: доступ к объектам машины, необратимые действия над ними (правило 13) и чтение для отпечатка; обработчик — любой (поверх `Fs`).
type Objects effect {
  fn close_for_writing(object Object) -> Result[(), ObjectError]
  fn open_for_writing(object Object) -> Result[(), ObjectError]
  fn move_to_archive(object Object, suffix int) -> Result[(), ObjectError]
  fn read(object Object) -> Result[[]u8, ObjectError]
  fn accept_attempt_file(object Object, id str) -> Result[(), ObjectError]
}

/// Хранилище снимков по идентификатору запроса — эффект: как сохранять и загружать, выбирает вызывающий код (`with Хранилище = обработчик`).
/// Обработчик — любой (база, файл поверх `Fs`/`Db`, очередь сообщений), вне этого файла. Ошибка операции — через `Result`.
type Store effect {
  fn save(id str, snapshot Snapshot) -> Result[(), StoreError]
  fn load(id str) -> Result[Option[Snapshot], StoreError]
}

/// Срез исполнителя: то, что кроме данных машины входит в снимок (поля `Исполнитель` без машины и флага `в_работе`).
type EngineSlice[State, Event, T, U, Action] {
  engine_state EngineState[State],
  queue []Incoming[Event],
  call_request Option[Request[T]],
  ready_response Option[Response[U]],
  response_sent bool,
  irreversible_actions []Action,
}
```

## Механика исполнителя

```nova
// Раздел записывает механику контракта, фиксации и приёма (правила 13–22, 31, 35 спецификации). Функции делятся по владельцу:
//   свободные — без данных; методы `Исполнитель` — очередь, хранилище, транспорт, журнал и данные движка.
// псевдокод: функции без тела — сигнатуры; тело пишет исполнитель, в Нове внешняя реализация здесь не показана

// Свободные функции
// идентификатор запроса = сторона, «-», номер попытки (правило 15)
fn request_party(id str) -> str
fn response_request[RoleResult](response Response[RoleResult]) -> str
fn form_valid[RoleResult](response Response[RoleResult]) -> bool
fn check_invariant(holds bool)
// метка инварианта не уменьшилась: списки равной длины, каждый компонент после шага не меньше компонента до шага (убыль одного компонента при росте другого ловится)
fn mark_not_decreased(after []int, previous_mark []int) -> bool {
  if after.len() != previous_mark.len() { return false }
  mut position = 0
  while position < previous_mark.len() {
    if after[position] < previous_mark[position] { return false }
    position += 1
  }
  true
}
// псевдокод: недостижимая ветка; в Нове — по выбору исполнителя (прерывание)
fn unreachable(text str) -> never
// псевдокод: кодирование и раскодирование среза исполнителя в строку снимка; формат — за реализацией хранилища
fn encode[Slice](slice Slice) -> str
fn decode[Slice](data str) -> Slice

// Методы Исполнителя: данные движка и механика
// конец ли состояние (вид «конец»)
fn Engine @at_end(state State) -> bool => match @machine.kind(state) {
  Final => true
  _ => false
}
// конец или состояние паузы: «стоп человека» и «стоп от родителя» здесь отбрасываются
fn Engine @at_end_or_pause(state State) -> bool => @at_end(state) || state == @machine.pause_state()
// сам исполнитель как значение `Среда`: его методы машина вызывает из перехода
// псевдокод: ресивер передаётся как значение протокола
fn Engine @environment() -> Environment[State, Event, Action]
// строка журнала с конвертом: трасса, номер_шага, причина_шага, состояние, идентификатор запроса, время (правило 31)
fn Engine mut @write_journal(text str) Journal Time -> () {
  Journal.write(JournalEntry {
    trace: @engine_state.trace, step: @engine_state.step, cause: @engine_state.cause, state: @machine.state_name(@engine_state.state),
    request: @engine_state.call_request_id, at: Time.now(), text: text, model_tally: @engine_state.model_tally })
}
// писать_журнал(текст); запись_перехода = текст; Куда(состояние ошибки)
fn Engine mut @machine_error(text str) Journal Time -> Transition[State] {
  @write_journal(text)
  @engine_state.transition_note = text
  Go(@machine.error_state())
}
// «слова_человека», ключ — событие.идентификатор; ссылка в журнале (правила 19, 31)
fn Engine mut @record_human_word(event Incoming[Event], word str, author str, source str) Journal Time -> ()
// чужой или поздний сигнал: строка журнала, состояние то же (правило 17)
fn Engine mut @discard(event Incoming[Event]) Journal Time -> ()
// правило 18; стороны запросов набора возвращаются в к_отправке перед неотправленными, в прежнем порядке
fn Engine mut @cancel_open_without_accepted(except_nested bool) Link -> () {
  mut returned = []str.new()
  for id in @engine_state.open_requests.clone() {          // копия: `убрать_из_открытых` меняет список

      @remove_from_open(id)
      returned.push(request_party(id))
    }
  }
  @return_to_send(returned)
}

    Some(Batch { order, .. }) => {
      for party in order.reverse() {              // вставка в начало по одной, с конца списка: порядок списка сохраняется

fn Engine mut @pass_accumulated_signals() Journal Link Time -> () {
  for signal in @engine_state.nested_signals {
    // «отмена» доставляется всегда (отмена уже вынула запрос из открытые_запросы); «стоп», «продолжить», «остановить» — только запросам, ещё лежащим в открытые_запросы
    if signal.signal == "cancel" || @engine_state.open_requests.contains(signal.request) {
      Link.signal(signal.request, signal.signal)
      @write_journal("${signal.signal} передан ${signal.request}")   // «стоп передан <идентификатор_запроса>», «продолжить передано <идентификатор_запроса>»
    }
  }
  @engine_state.nested_signals = []NestedSignal.new()
}
fn Engine mut @give_response(response Response[U]) Store Link -> () {
  @ready_response = Some(response)
  @save_snapshot()   // готовый ответ переживает остановку: повтор запроса с тем же идентификатором возвращает его (правило 35, п. 4)
  @send_response()
}
// ответ покидает машину только через `Связь.ответить` — повторяемое необратимое действие последнего этапа фиксации; ушёл — отдельная фиксация с `ответ_отправлен`
fn Engine mut @send_response() Store Link -> () {
  match @ready_response {
    Some(response) => {
      Link.reply(@encode_response(response))        // идемпотентно по запрос_вызова
      @response_sent = true
      @save_snapshot()
    }
    None => ()
  }
}
// ответ машины — в конкретные типы `Связи`
fn Engine @encode_response(response Response[U]) -> Response[PartyOutput] => match response {
  Answer(success) => Answer(Reply {
    request: success.request, party: success.party, result: @machine.encode_output(success.result), trace: success.trace, step: success.step })
  Refusal(refusal) => Refusal(refusal)
}
fn Engine mut @send(request Request[RoleInput]) Link Time -> () {
  @engine_state.waiting.insert(request.id, Waiting { sent: Time.now_monotonic(), term: request.idle_term })
  Link.send(Request {
    id: request.id, attempt: request.attempt, party: request.party,
    input: @machine.encode_input(request.input), idle_term: request.idle_term, trace: request.trace, step: request.step })
}
// принимает пришедшие сообщения без ожидания и обрабатывает их при приходе
fn Engine mut @receive_messages() Store Journal Link Objects Time -> () {
  loop {
    match Link.receive() {
      Some(message) => @on_arrival(@typify(message))
      None => break
    }
  }
}
// сообщение через `Связь` — в типы машины
fn Engine @typify(message Message) -> Received[Event, RoleResult] => match message {
  RoleResponse(Answer(success)) => ResponseReceived(Answer(Reply {
    request: success.request, party: success.party, result: @machine.decode_result(success.result), trace: success.trace, step: success.step }))
  RoleResponse(Refusal(refusal)) => ResponseReceived(Refusal(refusal))
  Word(word) => WordReceived(@machine.decode_event(word))
}
// «нет ответа в срок» (правило 19): запрос ждёт дольше своего срока; у обращения человека срока нет
fn Engine mut @check_idle_terms() Store Journal Link Objects Time -> () {
  ro current_time = Time.now_monotonic()
  for id in @engine_state.open_requests {
    match @engine_state.waiting.get(id) {
      Some(waiting_entry) => {
        if !@engine_state.accepted_requests.contains(id) && waiting_entry.term > 0 && current_time - waiting_entry.sent > waiting_entry.term {
          @engine_state.waiting.remove(id)                // срок наступает один раз
          @on_arrival(RequestExpired(id))
        }
      }
      None => ()
    }
  }
}
// повторяет запрос к вложенной машине с прежним идентификатором (правило 35, п. 4)
fn Engine mut @retry_nested(id str) Link Time -> () {
  @send(@previous_request(id))        // тот же идентификатор: вложенная вернёт готовый ответ или продолжит (правило 35, п. 4); срок ожидания отсчитывается заново
}
// запрос к вложенной машине по идентификатору, восстановленный из снимка (у этой машины вложенных запросов сейчас нет)
fn Engine @previous_request(id str) -> Request[RoleInput]
// снимок всего состояния движка и машины на конец шага
fn Engine @snapshot() -> Snapshot => Snapshot {
  engine_data: encode(EngineSlice { engine_state: @engine_state, queue: @queue, call_request: @call_request, ready_response: @ready_response, response_sent: @response_sent, irreversible_actions: @irreversible_actions }),
  machine_data: @machine.capture() }
// сохраняет снимок в хранилище: прямой вызов операции эффекта, `Хранилище` объявлен в сигнатуре; не удалось — машина не идёт дальше
fn Engine mut @save_snapshot() Store -> () => match Store.save(@recipient().id, @snapshot()) {
  Ok(_) => ()
  Err(failure_error) => unreachable("снимок не сохранён: шаг не зафиксирован, запросы не отправляются, исполнитель остановлен")
}
// загружает снимок; не удалось — исполнитель аварийно прерывается
fn Engine @load_snapshot(id str) Store -> Option[Snapshot] => match Store.load(id) {
  Ok(snapshot) => snapshot
  Err(failure_error) => unreachable("снимок не загружен: исполнитель остановлен")
}
```

## Фрагмент «Пауза»

Состояние ПАУЗА, общие события «стоп человека», «стоп от родителя», «отмена_запроса», события ПАУЗЫ («продолжить», «остановить», «продолжить от родителя», «остановить от родителя») и передача сигналов вложенным записаны один раз — фрагментом «Пауза» ([state-machine-pause-states.md](state-machine-pause-states.md), правило 36 спецификации). Здесь, в разделе «Общие события», движок реализует фрагмент для любой машины; машина даёт только значения параметров фрагмента — хуки `Автомат`:

| Параметр или требование фрагмента | Хук `Автомат` |
|---|---|
| имя состояния ПАУЗА | `состояние_паузы()` |
| требование: концы ОСТАНОВЛЕНО и ОШИБКА (это не параметры; остальные концы — по `вид`: «стоп» в них отбрасывается) | `состояние_остановлено()`, `состояние_ошибки()` |
| слово остановки (значение «остановка») | `причина_остановки_в_паузе()` («ПАУЗА: <слово остановки>») |
| возврат в «предыдущее» (правило 24) | `состояние_по_имени(имя)` — обратная к `имя_состояния` |
| какие события машины — события паузы | `общее(...)`: сводит события машины к `ОбщееСобытие`, включая четыре события ПАУЗЫ |
| вложенные машины, отмена запросов, право записи | `вложенная`, `возвратов_формы` описания обращения; `отменить_открытые_без_принятого`; запись машины (необратимые действия концов) |

«Продолжить», «остановить» и их варианты от родителя вне ПАУЗЫ — лишние сигналы: движок отбрасывает их с записью в журнал (правило 17), очередь они не блокируют. Строк состояния ПАУЗА у машины нет: в `перейти` у неё одна ветка «`НеЖдёт`» (остальные события ПАУЗА не ждёт).

## Общие события

```nova
/// Разбираются до строк состояний (правило 23): сначала общие события, затем машина (`перейти`).
/// «Стоп человека» в ПАУЗЕ и в концах и «продолжить» вне ПАУЗЫ отбрасываются с записью в журнал (правила 17, 23);
/// в таблицах первоисточника для них строки нет, формат строки там не задан.
fn Engine mut @common_events(event Incoming[Event]) Journal Link Time -> Option[Transition[State]] {
  ro common = @machine.common(@engine_state.state, event.body)?       // None — не общее событие: его разбирает машина
  match common {

    HumanStop { human_word, author, source } => {
      // ОБЩ стоп_человека #1: в любом состоянии, кроме ОСТАНОВЛЕНО, ОШИБКА, КОНЕЦ и ПАУЗА
      if @at_end_or_pause(@engine_state.state) { @discard(event); return Some(Stay) }
      @record_human_word(event, human_word, author, source)
      @write_journal("стоп человека: ${author}, ${source}, запись ${event.id}")
      @engine_state.previous = @machine.state_name(@engine_state.state)
      // открытые_запросы без принятого ответа отменены (правило 18), кроме запросов к вложенным машинам
      @cancel_open_without_accepted(true)
      // вложенные получают сигнал «стоп» после фиксации шага; журнал «стоп передан <идентификатор_запроса>» на каждого (правило 35, пункт 8)
      @pass_to_nested("stop")
      Some(Go(@machine.pause_state()))
    }

    ParentStop { id } => {
      // ОБЩ стоп_от_родителя #1: те же состояния, если идентификатор_запроса события = запрос_вызова, иначе сигнал отброшен (правило 17)
      if @at_end_or_pause(@engine_state.state) { @discard(event); return Some(Stay) }
      if id != @engine_state.call_request_id { @discard(event); return Some(Stay) }
      @write_journal("пауза: причина — стоп от родителя, ${id}, запись ${event.id}")
      // слова человека не записываются (""): слов_человека не пишется
      @engine_state.previous = @machine.state_name(@engine_state.state)
      @cancel_open_without_accepted(true)
      @pass_to_nested("stop")
      Some(Go(@machine.pause_state()))
    }

    RequestCancelled { id } => {
      // событие приходит в любом состоянии
      // ОБЩ отмена_запроса #1: идентификатор_запроса события не равен запрос_вызова
      if id != @engine_state.call_request_id {
        @write_journal("отмена отброшена: чужой запрос ${id}, запись ${event.id}")
        return Some(Stay)
      }
      // ОБЩ отмена_запроса #2: = запрос_вызова, и ответ уже отдан (состояние — ОСТАНОВЛЕНО, ОШИБКА или КОНЕЦ)
      if id == @engine_state.call_request_id && @at_end(@engine_state.state) {
        @write_journal("отмена отброшена: ответ уже отдан, ${id}, запись ${event.id}")
        return Some(Stay)
      }
      // ОБЩ отмена_запроса #3: = запрос_вызова, и ответ не отдан
      if id == @engine_state.call_request_id && !@at_end(@engine_state.state) {
        @write_journal("отмена запроса: ${id}, запись ${event.id}")
        @machine.record_stop("cancel_request")
        // сигнал ставится ДО отмены: вложенные ещё лежат в открытые_запросы (правило 35, п. 10)
        @pass_to_nested("cancel")
        @cancel_open_without_accepted(false)    // правило 18
        return Some(Go(@machine.halted_state()))
      }
      // ОБЩ отмена_запроса #4: иначе
      Some(@machine_error("ошибка машины: разбор отмены_запроса, ни одно условие не подошло"))
    }

    // события ПАУЗЫ — фрагмент «Пауза» (state-machine-pause-states.md, состояние ПАУЗА): строк состояния у машины нет, разбирает движок
    PauseContinue { human_word, author, source } => {
      // «продолжить» вне ПАУЗЫ отбрасывается с записью в журнал (правила 17, 23)
      if @engine_state.state != @machine.pause_state() { @discard(event); return Some(Stay) }
      // ПАУЗА #1: «продолжить»
      @record_human_word(event, human_word, author, source)
      @write_journal("продолжение с ${@engine_state.previous}: ${author}, ${source}, запись ${event.id}")
      @pass_to_nested("continue")                // после фиксации шага, журнал «продолжить передано <идентификатор_запроса>»
      Some(Go(@machine.state_by_name(@engine_state.previous)))   // «предыдущее» при этом не пишется (правила 13 и 24)
    }
    PauseHalt => {
      // «остановить» вне ПАУЗЫ — лишний сигнал: отбрасывается с записью в журнал (правило 17), очередь не блокируется
      if @engine_state.state != @machine.pause_state() { @discard(event); return Some(Stay) }
      // ПАУЗА #2: «остановить»
      @machine.record_stop(@machine.pause_stop_reason())
      @pass_to_nested("halt")                // правило 35, пункты 8 и 10
      Some(Go(@machine.halted_state()))
    }
    PauseContinueFromParent { id } => {
      if @engine_state.state != @machine.pause_state() { @discard(event); return Some(Stay) }
      // ПАУЗА #3: «продолжить от родителя» (если идентификатор_запроса события = запрос_вызова, иначе отброшено)
      if id != @engine_state.call_request_id { @discard(event); return Some(Stay) }
      @write_journal("продолжение с ${@engine_state.previous}: от родителя ${id}, запись ${event.id}")
      // слова человека не записываются ("")
      @pass_to_nested("continue")
      Some(Go(@machine.state_by_name(@engine_state.previous)))
    }
    PauseHaltFromParent { id } => {
      if @engine_state.state != @machine.pause_state() { @discard(event); return Some(Stay) }   // лишний сигнал вне ПАУЗЫ: как у ПаузаОстановить
      // ПАУЗА #4: «остановить от родителя» (если идентификатор_запроса события = запрос_вызова, иначе отброшено)
      if id != @engine_state.call_request_id { @discard(event); return Some(Stay) }
      @machine.record_stop(@machine.pause_stop_reason())
      @pass_to_nested("halt")
      Some(Go(@machine.halted_state()))
    }
  }
}
```

## Цикл исполнителя

```nova
/// Исполнитель: ведёт машину `ТипМашины` по правилам 13–24 и 35 спецификации; единственный пишет в хранилище и отправляет запросы.
/// Данные поступают только через события; запросы отправляются только после фиксации шага; снимок сохраняется до открытия ворот.
/// Исполнитель с машиной реализует `Вызываемое[Вход, Выход]` структурно (метод `вызвать`) и подаёт себя машине как `Среда`.
// псевдокод: параметры типа `Исполнитель` перечислены в объявлении и в методах не повторяются
type Engine[State, Event, T, U, RoleInput, RoleResult, Action, M Machine[State, Event, T, U, RoleInput, RoleResult, Action]] {
  machine M,                                  // данные и логика автомата
  engine_state EngineState[State],                // данные движка
  call_request Option[Request[T]],                  // запрос, которым машину вызвали (конверт исполнителя)
  queue []Incoming[Event],                 // входящие события в порядке прихода (правило 13)
  ready_response Option[Response[U]],          // ответ, отданный вызвавшей стороне; машина отвечает один раз; повторная отправка по `Связь` после сбоя допустима, получатель дедуплицирует по `запрос_вызова` (правило 35)
  response_sent bool,                        // ответ ушёл через `Связь.ответить`: ставится после успешной отправки отдельной фиксацией
  irreversible_actions []Action,                      // действия шага, которые выполняются после сохранения; в снимке, чтобы повториться после перезапуска
  running bool,                               // цикл идёт: повтор запроса не запускает вторую машину (исполнитель на запрос один; исключение процессов — вне файла)
}

/// Исполнитель над готовой машиной; хранилище — эффект `Хранилище`, обработчик подставляет вызывающий код.
fn Engine.new(machine M) -> Engine => {
  machine: machine,
  engine_state: EngineState.new(machine.initial()),
  call_request: None,
  queue: []Incoming.new(),
  ready_response: None,
  response_sent: false,
  irreversible_actions: []Action.new(),
  running: false,
}

/// Событие `Вызываемое[Вход, Выход]`: повтор запроса с тем же идентификатором возвращает готовый ответ или продолжает прерванную работу (правило 35, п. 4).
fn Engine mut @call(request Request[T]) Store Journal Link Objects Time -> Response[U] {
  // прогон идёт: повтор не поднимает вторую машину поверх живой, а ждёт готовый ответ идущего прогона
  if @running { return @await_ready_response() }
  match @load_snapshot(request.id) {
    None => @start(request)
    Some(snapshot) => match decode(snapshot.engine_data).ready_response {   // псевдокод: раскодирование среза исполнителя
      Some(ready) if decode(snapshot.engine_data).response_sent => ready   // уже ушёл по `Связь.ответить`: второй раз не шлётся
      _ => match @resume(request.id) {
        Some(response) => response
        None => unreachable("снимок только что загружен: возобновить его находит")
      }
    }
  }
}

/// Новый запрос: входит в начальное состояние машины, фиксирует шаг и входит в цикл. Машину по входу запроса создаёт вызывающий код.
fn Engine mut @start(request Request[T]) Store Journal Link Objects Time -> Response[U] {
  @running = true
  @call_request = Some(request)
  @engine_state = EngineState.new(@machine.initial())
  @queue = []Incoming.new()
  @ready_response = None
  @response_sent = false
  @irreversible_actions = []Action.new()
  @engine_state.call_request_id = request.id
  @engine_state.trace = @new_trace()                  // дочерняя от внешней (запрос.трасса)
  @run_step(@new_event("start"), Go(@machine.initial()))
  @run_loop()
}

/// Продолжение после остановки исполнителя: загружает снимок и продолжает с сохранённого `состояние`; None — снимка нет.
/// Ждавшая обращения машина повторно получает только запросы без принятого ответа; на ПАУЗЕ остаётся, пока человек не скажет «продолжить» (правила 12, 14, 22).
/// Перед этим машина делает подготовку (`при_возобновлении`): она может не пустить в сохранённое состояние и дать переход в другое.
fn Engine mut @resume(id str) Store Journal Link Objects Time -> Option[Response[U]] {
  match @load_snapshot(id) {
    None => None
    Some(snapshot) => {
      ro slice = decode(snapshot.engine_data)      // псевдокод: раскодирование среза исполнителя
      @engine_state = slice.engine_state
      @queue = slice.queue
      @call_request = slice.call_request
      @ready_response = slice.ready_response
      @response_sent = slice.response_sent
      @irreversible_actions = slice.irreversible_actions
      @engine_state.waiting = HashMap[str, Waiting].new()      // моменты `Time.now_monotonic()` после перезапуска несравнимы: сроки открытых запросов отсчитываются заново при повторной отправке
      @machine.restore(snapshot.machine_data)
      match @ready_response {
        Some(ready) => {                           // ответ уже отдан
          if !@response_sent { @send_response() }   // не успел уйти: повторяется, идемпотентно по запрос_вызова; ушёл — ничего не шлётся
          Some(ready)
        }
        None => {
          @running = true
          // подготовка при каждом старте, до входа в сохранённое состояние; Some — в него войти нельзя, шаг ведёт по переходу;
          // у конца (ответ не успел уйти) подготовка не нужна и ответ не подменяет
          ro preparation = if @at_end(@engine_state.state) { None } else { @machine.on_resume(@engine_state.state, @environment()) }
          @after_restart(preparation)
          Some(@run_loop())
        }
      }
    }
  }
}

/// Цикл: берёт события по одному, пока ответ не отдан. Остановка исполнителя — завершение процесса в любой точке цикла:
/// состояние уже сохранено фиксацией шага, дописывать ничего не нужно.
fn Engine mut @run_loop() Store Journal Link Objects Time -> Response[U] {
  loop {
    match @ready_response {
      Some(response) => {
        if !@response_sent { @send_response() }   // повторяемо: идемпотентно по запрос_вызова
        @running = false
        return response
      }
      None => {
        @receive_messages()                   // `Связь.принять` без ожидания
        @check_idle_terms()                     // «нет ответа в срок» — из сравнения со `Time`
        @process_queue()
      }
    }
  }
}

/// Приём при приходе: в порядке прихода и в любом состоянии (правило 14).
fn Engine mut @on_arrival(message Received[Event, RoleResult]) Store Journal Link Objects Time -> () {
  @engine_state.event_counter += 1                               // +1 при приходе любого события
  match message {
    // ответ роли или отказ (Исход от открытой стороны)
    ResponseReceived(response) => {
      ro id = response_request(response)
      // чужой или поздний ответ: неизвестный идентификатор, закрытый или отменённый запрос, повторная доставка (правило 17)
      if !@engine_state.open_requests.contains(id) || @engine_state.accepted_requests.contains(id) {
        // отбрасывание — отдельная фиксация со своей строкой журнала и номером шага (правило 31)
        ro stray = @event_from_message(message)
        @begin_accept_commit(stray)
        @discard(stray)
        @commit()
        return
      }
      // форма: ответ не по форме исполнитель возвращает стороне в том же запросе; число возвратов задаёт состояние
      if !form_valid(response) { @return_to_party(response); return }     // сколько раз и что после — по описанию роли (`возвратов_формы`); счёт и исход — у обработчика роли
      // объект, куда пишется результат (у машины — рабочий документ), изменился с начала попытки — результат не принимается,
      // запрос отменяется и отправляется заново (новая попытка, вход прочитан заново)
      if @machine.object_changed_since_attempt(@engine_state.state) { @retry_request(id); return }
      // приём — одна фиксация: идентификатор в принятые_запросы, «При приёме», запись результата в хранилище, событие в очередь (правила 14, 31)
      ro event = @accept_event(response)
      @begin_accept_commit(event)
      @engine_state.accepted_requests.push(id)
      @machine.on_accept(@engine_state.state, response)
      @machine.record_result(@engine_state.state, response)
      @enqueue(event)
      @commit()
      // последним, повторяемым без вреда этапом — принятие файла попытки (при старте завершается по принятые_запросы)
      @machine.accept_attempt_file(id)
    }
    // слово человека или сигнал
    WordReceived(_) => {
      ro event = @event_from_message(message)
      @begin_accept_commit(event)                // слово человека — своя фиксация: не теряется при сбое (правила 19, 31)
      @record_gate_word(message)                // на воротах (правило 19)
      @enqueue(event)
      @commit()
    }
    // «нет ответа в срок»: порождает исполнитель по таймеру, код НетОтветаВСрок; у обращения человека срока нет (правило 19)
    RequestExpired(id) => {
      // запрос уже закрыт или принят: срок поздний (правило 17) — отдельная фиксация со строкой журнала
      if !@engine_state.open_requests.contains(id) || @engine_state.accepted_requests.contains(id) {
        ro stray = @event_from_message(message)
        @begin_accept_commit(stray)
        @discard(stray)
        @commit()
        return
      }
      ro event = Incoming {
        id: "failure-${@engine_state.event_counter}", party: request_party(id), request: Some(id), body: @machine.failure_event(Timeout) }
      @begin_accept_commit(event)
      @enqueue(event)
      @commit()
    }
  }
}

/// Обработка очереди: первое событие, которое ждёт текущее состояние; остальные остаются в очереди (правило 13).
fn Engine mut @process_queue() Store Journal Link Objects Time -> () {
  match @take_first_awaited() {                   // сигналы ждёт любое состояние, кроме концов
    None => @await_arrival()
    Some(event) => {
      ro transition = @common_events(event) ?? @machine.step(@engine_state.state, event.body, event, @environment())
      @run_step(event, transition)
    }
  }
}

/// Шаг — одна фиксация (правило 13): переходы, записи в хранилище, строки журнала, новые значения «состояние», «открытые_запросы»,
/// «принятые_запросы», «к_отправке» и счётчиков попыток пишутся вместе; незавершённый шаг откатывается.
fn Engine mut @run_step(event Incoming[Event], transition Transition[State]) Store Journal Link Objects Time -> () {
  @begin_commit()
  ro mark_before = @machine.invariant_mark()
  @engine_state.step += 1                                    // растёт внутри фиксации; откат возвращает
  @engine_state.cause = event.id
  mut current_transition = transition
  match current_transition {
    NotAwaited => {                                  // событие остаётся в очереди
      @rollback()
      return
    }
    _ => ()
  }
  // принятый запрос закрывается переходом по своему событию: убирается из открытые_запросы и из принятые_запросы
  match event.request {
    Some(id) => @close_request(id)
    None => ()
  }

  // цепочка операций и развилок и их переходов «сразу» до первого обращения или конца;
  // `тело_цепочки` — событие последнего входа: результат операции или «сразу»; его получает следующая развилка
  mut chain_body = @machine.immediate_event()
  loop {
    match current_transition {
      Stay => break                                  // то же состояние
      NotAwaited => break                            // первое событие проверено выше; в цепочке не встречается
      Go(goal) => match @enter(goal, event, chain_body) {
        Some(step_word) => {
          current_transition = step_word.transition
          chain_body = step_word.body
        }
        None => break                                // ждёт события или конец
      }
      Rerun(goal) => {
        @cancel_open_request_of_appeal(goal)        // «запуск заново» (правило 18): прежний запрос сначала отменяется
        match @enter(goal, event, chain_body) {
          Some(step_word) => {
            current_transition = step_word.transition
            chain_body = step_word.body
          }
          None => break
        }
      }
    }
    // инвариант машины: ни один компонент её метки не уменьшается
    check_invariant(mark_not_decreased(@machine.invariant_mark(), mark_before))
  }
  // последний вход цепочки (обращение или конец) выходит из цикла через `break`: его метка проверяется здесь
  check_invariant(mark_not_decreased(@machine.invariant_mark(), mark_before))
  @commit()                                    // запись шага: снимок сохранён, необратимые действия лежат в нём
  @run_irreversible()                            // последний, повторяемый без вреда этап: переименование в архив, смена права записи
  @after_commit()
}

/// Вход в состояние: запись «состояние» подразумевается у каждого перехода; None — обращение или конец, цепочка заканчивается.
/// Операция выполняется, её результат — событие: оно идёт в переход операции и дальше, следующей развилке цепочки; развилка получает событие предыдущего входа (`тело_цепочки`),
/// а если до неё была не операция — «сразу».
fn Engine mut @enter(destination State, event Incoming[Event], chain_body Event) Journal Objects Time -> Option[ChainStep[State, Event]] {
  @engine_state.state = destination
  match @machine.kind(destination) {
    Appeal | Final => None                        // ждёт события или конец
    Operation => {
      ro exit_event = @machine.run_operation(destination, @environment())
      Some(ChainStep { transition: @machine.step(destination, exit_event, event, @environment()), body: exit_event })
    }
    Fork => Some(ChainStep { transition: @machine.step(destination, chain_body, event, @environment()), body: @machine.immediate_event() })
  }
}

/// После фиксации шага: сначала очередь, потом запросы (правило 13).
fn Engine mut @after_commit() Store Journal Link Objects Time -> () {
  @pass_accumulated_signals()           // «стоп», «продолжить», «остановить», «отмена»; журнал «… передан(о) <идентификатор_запроса>»
  // конец: ответ вызвавшей стороне отдаётся всегда, даже если в очереди сигнал, и один раз (повторная отправка по `Связь` после сбоя допустима, получатель дедуплицирует по `запрос_вызова`; правило 35, «один запрос — один ответ»);
  // сигналы в концах отбрасываются по правилам 17 и 23 уже после ответа
  match @machine.kind(@engine_state.state) {
    Final => match @ready_response {
      None => {
        @cancel_all_open_requests()              // вход в любой конец (правило 22)
        @machine.on_end_entry(@engine_state.state, @environment())
        @run_irreversible()
        @give_response(@machine.end_response(@recipient(), @engine_state.state, @environment()))
      }
      Some(_) => ()                                    // ответ уже отдан
    }
    _ => ()
  }
  // перед отправкой смотрит во входящую очередь: «стоп человека», «стоп от родителя» или «отмена_запроса» — запросы не отправляются,
  // а сигнал разбирается (правила 23, 35)
  if @poll_queue_signal() { return }
  match @machine.kind(@engine_state.state) {
    Appeal => @send_requests(@engine_state.state)
    _ => ()                                          // операции и развилки до сюда не доходят: цепочка идёт до обращения или конца
  }
}

/// Отправка запросов по состоянию. Состояние сохранено до открытия ворот; повторный вход ничего не отправляет стороне,
/// чей запрос открыт или лежит в принятых (правила 12, 14, 21). Как обращается состояние, говорит машина (`обращение`).
fn Engine mut @send_requests(appeal State) Store Link Objects Time -> () => match @machine.appeal(appeal) {
  None => ()
  Some(Batch { idle_term, nested, .. }) => {
    // стороны из к_отправке по порядку, пока открытых запросов меньше предела движка (`предел_запросов` машины, правило 21)
    while @engine_state.to_send.len() > 0 && @engine_state.open_requests.len() < @machine.request_limit() {
      ro party = @engine_state.to_send[0]
      // механика контракта — отдельная фиксация со своим номером шага и сохранением ДО отправки (правила 13, 22):
      // перенос из к_отправке в открытые_запросы и рост счётчика попыток; после падения снимок уже содержит новую попытку и открытый запрос,
      // возобновить отменит его (правило 18), а поздний ответ отбросит (правило 17)
      @begin_request_commit()
      @engine_state.to_send = @engine_state.to_send[1..]
      ro attempt_number = @machine.next_attempt(party)
      @engine_state.open_requests.push("${party}-${attempt_number}")
      if nested { @engine_state.nested_ids.push("${party}-${attempt_number}") }
      @commit()
      @send(Request { id: "${party}-${attempt_number}", attempt: attempt_number, party: party,
        input: @machine.request_input(appeal, party, @environment()), idle_term: idle_term, trace: @engine_state.trace, step: @engine_state.step })
    }
  }
  Some(Single { party, idle_term, nested, .. }) => {
    if @has_open_or_accepted(party) { return }
    // отдельная фиксация со своим номером шага и сохранением ДО отправки, как у набора (правила 13, 22)
    @begin_request_commit()
    ro attempt_number = @machine.next_attempt(party)        // фиксируется до отправки вместе с открытые_запросы
    @engine_state.open_requests.push("${party}-${attempt_number}")
    if nested { @engine_state.nested_ids.push("${party}-${attempt_number}") }
    @commit()
    @send(Request { id: "${party}-${attempt_number}", attempt: attempt_number, party: party,
      input: @machine.request_input(appeal, party, @environment()), idle_term: idle_term, trace: @engine_state.trace, step: @engine_state.step })
  }
}

/// Перезапуск исполнителя: не переход и «состояние» не пишет; шаг со своим номером (правила 22, 31).
/// `подготовка` — ответ `при_возобновлении` машины: `None` — войти в сохранённое состояние; `Some(переход)` — подготовка в него не пустила, шаг ведёт по этому переходу
/// (например, «занята живым процессом» — в ОСТАНОВЛЕНО, нерешённые исходы — к воротам).
fn Engine mut @after_restart(preparation Option[Transition[State]]) Store Journal Link Objects Time -> () {
  @begin_commit()
  @engine_state.step += 1
  ro restart_event = @new_event("restart")
  @engine_state.cause = restart_event.id
  // открытые запросы умершего исполнителя к ролям без принятого ответа отменяются; их поздние ответы отбрасываются (правило 18);
  // ветка `None`: запросы к вложенным машинам не отменяются (кроме_вложенных = true), а повторяются тем же идентификатором — вложенная вернёт готовый ответ
  // или продолжит, заново не запускается (правило 35, п. 4); ветка `Some`: в сохранённое состояние не входят, поэтому вложенным идёт сигнал «отмена»
  // (до отмены, как в «отмена_запроса», правило 35, п. 10) и их запросы отменяются тоже
  ro except_nested = match preparation {
    Some(_) => false
    None => true
  }
  match preparation {
    Some(_) => @pass_to_nested("cancel")
    None => ()
  }
  @cancel_open_without_accepted(except_nested)
  @commit()
  // завершение принятия файла попытки по принятым запросам, не сверяя отпечаток (правило 14): на обеих ветках; повторяется без вреда
  for id in @engine_state.accepted_requests {
    @machine.accept_attempt_file(id)
  }
  match preparation {
    Some(transition) => @run_step(restart_event, transition)      // шаг со своим номером (правила 12, 22); дальше — как после любого шага
    None => {
      // запросы идут только после фиксации (правило 13)
      for id in @nested_requests() {
        @retry_nested(id)
      }
      @run_irreversible()
      // повторный вход в «состояние» (обращение или конец, правило 12); незакрытые ворота показываются человеку снова
      @after_commit()
    }
  }
}
```
