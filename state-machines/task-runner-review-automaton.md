# Проверка цикла: код автомата

Стейт-машина проверки цикла — повтор «проверка → правка» одного артефакта задачи (спецификация, план, реализация, сдача) до серии чистых заходов, а для стадии «совещание» вызов вложенной машины совещания, — записанная кодом на Нове как реализация протокола `Автомат` движка [state-machine-engine-automaton.md](state-machine-engine-automaton.md): данные машины, перечисления `Состояние` и `Событие`, переход `перейти(состояние, событие)` как `match`, роли (входы и результаты обращений к вложенным машинам запуска сессии и совещания и к человеку на воротах), ответ по концу по контракту машины. Всё общее — конверт запроса и ответа, исполнитель, снимок и хранилище, общие события «стоп/продолжить/отмена», цикл, фиксации, передача сигналов вложенным — в движке и здесь не повторяется. Нормы — [task-runner.md](../task-runner.md) (словарь, ворота, форматы файлов проверки) и [task-sessions.md](../task-sessions.md), «Правила» (потолок заходов, чистая серия, пробы). Идентификаторы кода английские, словарь — [state-machine-glossary.md](state-machine-glossary.md); русские имена — в описаниях и комментариях.

**Первоисточник — [task-runner-review-states.md](task-runner-review-states.md)** (машина «Проверка цикла»: таблицы состояний, общие события, «Контракт машины», «Решения при переводе»); правила формы — [state-machine-spec.md](state-machine-spec.md). Этот файл — производная запись того же автомата, не второй источник истины: при расхождении верен первоисточник, этот файл правится вслед за ним. Язык записи — Нова, https://github.com/nv-lang/nova. **Код не компилировался и не проверялся компилятором Нова:** это псевдокод в синтаксисе Нова; соглашения записи, помеченные места (`// псевдокод:`), подтверждённое и неподтверждённое спецификацией — в [state-machine-engine-automaton.md](state-machine-engine-automaton.md), здесь только относящееся к проверке цикла. Опытный статус и отличия от ранее написанной схемы — в шапке первоисточника; раннером эта машина не исполняется (раннер исполняет [task-runner-pseudocode.md](task-runner-pseudocode.md), помеченный устаревшим). Вызывает машину верхняя машина раннера — [task-runner-automaton.md](task-runner-automaton.md) (первоисточник — [task-runner-states.md](task-runner-states.md); состояния `*_ПРОВЕРКА`); для стадии «совещание» она зовёт машину совещания — [task-runner-meeting-automaton.md](task-runner-meeting-automaton.md); каждую сессию проверки и правки запускает вложенной машиной запуска сессии — [task-runner-session-automaton.md](task-runner-session-automaton.md) (первоисточник — [task-runner-session-states.md](task-runner-session-states.md); состояние ЗАПУСК_СЕССИИ). Все вызовы идут по контракту вызова движка (`Вызываемое`, эффект `Связь`: запрос уходит как `ЗапросРоли`, ответ приходит сообщением), не прямым вызовом функций; общие типы (`Цикл`, `Находка`, `Свод`, `Стадия`, `ВходПроверки`, `ИтогПроверки`, `ВходЗапускаСессии`, `ИтогЗапускаСессии` и др.) объявлены в слое методики — [state-machine-methodology-automaton.md](state-machine-methodology-automaton.md), вход и итог совещания — в файле совещания. Имя файла — по `AGENTS.md`, «Вынесенные алгоритмы», форма `automaton`.

## Соглашения записи

1. **Типы и идентификаторы** — по [движку](state-machine-engine-automaton.md), пункты 1–3: английские имена по [словарю](state-machine-glossary.md). Общие типы данных (`Цикл`, `Находка`, `Уровень`, `ИтогСессии`, `Свод`, `Стадия`, `ВходПроверки`, `ИтогПроверки`, `Вердикт`, `ВходЗапускаСессии`, `ИтогЗапускаСессии`) объявлены один раз в слое методики [state-machine-methodology-automaton.md](state-machine-methodology-automaton.md) и подключены здесь; их таблица соответствия именам блока «Типы на Нове» — там же. Вход паузы (`ВходПаузы`) и сигнатуры `объём_запуска`, `остановить_группу_агента` — тоже из слоя; вариант `ВходРоли` для входа паузы — `ВходПаузыРоли`. Собственный тип данных один — `Счётчик` (запись счётчика критерия, блок «Типы»); `Свод` (итог файла проверки захода; в первоисточнике в блоке «Типы на Нове» — `Summary`) вынесен в слой: его возвращает запуск сессии, а читает эта машина. Вход и итог совещания (`ВходСовещания`, `ИтогСовещания`) объявлены в [task-runner-meeting-automaton.md](task-runner-meeting-automaton.md); одноимённые типы того файла (`Находка`, `Критичность`, `Свод`) — другие и сюда не подключаются; вход и итог запуска сессии — в слое методики. **Значения перечислений** с совпадающими именами в разных перечнях (`План`, `Требования`, `Вопрос`, `Готово` и др.) пишутся с именем типа (`ИтогСессии.План`, `Уровень.План`).
2. **Данные события.** Поля варианта события берутся образцом в `match`: `Сбой { причина } => …`; при совпадении имени поля с переменной машины поле переименовывается: `Ответ_сессии { итог_сессии: итог }`; остаток полей, которые переход не читает, — `{ .. }`. «Сторона события» и идентификатор события — `событие.сторона`, `событие.идентификатор` (конверт `Входящее` движка, правила 13 и 31); тело исходного события шага — `событие.тело` (развилка СТАДИЯ_ОСТАНОВКИ читает дату слова «остановиться»). Служебные операции переходу даёт `среда` (журнал, слова человека, сигналы вложенным, данные движка `открытые_запросы`, `предыдущее`, `запрос_вызова`).
3. **Строка таблицы — ветка кода.** Перед каждой строкой первоисточника (условие или событие, «Что меняется», «Куда») стоит комментарий `// <СОСТОЯНИЕ> #<номер строки>: …` с её текстом; у обращения в скобках — данные события; порядок строк как в первоисточнике. «Куда» записано как `Куда(<СОСТОЯНИЕ>)`; «запуск заново» — `Заново(<СОСТОЯНИЕ>)`; «Куда: предыдущее» — у ПАУЗЫ в движке (`Куда(@машина.состояние_по_имени(предыдущее))`). Строка «иначе» каждой развилки — последняя ветка, ведёт в `ОШИБКА` через `среда.ошибка_машины(…)`. Развилка СВОДКА записана `match` по итогу свода (как РАЗБОР в машине совещания), остальные — последовательностью `if`. Строки «Вход», «Выход», «При входе», «Сторона» и одна строка простыми словами на состояние — комментарии `//` у состояния. Общие события (две строки «стоп» и четыре строки «отмена_запроса») записаны в движке (`общие_события`); `общее` машины сводит к ним её события. Состояние ПАУЗА и его четыре строки подключены фрагментом «Пауза» ([state-machine-pause-states.md](state-machine-pause-states.md)): события паузы разбирает движок (`общие_события`), у машины остаются ветка `ПАУЗА => НеЖдёт`, хуки `состояние_паузы`, `причина_остановки_в_паузе`, `состояние_по_имени` и сведение событий паузы в `общее`.
4. **Строки `// псевдокод:`** и перечень подтверждённого спецификацией — в [движке](state-machine-engine-automaton.md), пункт 5. Здесь дополнительно: функции без тела (сигнатуры механики и чтения внешних объектов); алиас `type Окружение alias Среда[…]` (как в машине совещания); импорт `use` общих типов и совпадающие имена модулей (`Находка` слоя методики и `Находка` совещания) — разрешение вне записи; значения перечислений с именем типа; образец `{ .. }` с остатком и охранное условие в ветке `match` (оба — как в движке и машине совещания). Потолок заходов, число чистых заходов подряд и число проб (бывшие константы `ПОТОЛОК_ЗАХОДОВ`, `ЧИСТЫХ_ПОДРЯД`, `ПРОБ_В_ЧИСТОМ`) — данные задачи из `ВходПроверки` (`потолок_заходов`, `чистых_подряд`, `проб_в_чистом`; решение 17 первоисточника): машина получает их в запросе вызова и не меняет; `ro` на уровне модуля в Нове не подтверждено (остался у `ПРЕДЕЛ_ЗАПРОСОВ`). Неподтверждённое спецификацией Нова, используемое здесь (как и в машине совещания): объявление `module`, `return` внутри `if` в ветке `match` и в теле функции, `while`. Срок бездействия не задан: у обращений этой машины `0` (исполнитель «нет ответа» не порождает), для вызова вложенной машины совещания он равен `0` — это значение «без срока» (правило 35, пункт 5): родитель ждёт ответа или отмены.
5. **Уточнения записи автомата сверх первоисточника** (подробности — «Что движок не покрыл»): (а) метод `событие_ответа` — метод протокола `Автомат`: отображение результата роли в событие; (б) вложенная сторона и число возвратов ответа не по форме — поля `вложенная` и `возвратов_формы` описания обращения (`Одна`): вложенные — «совещание» и «запуск сессии», возвратов формы у этой машины нет (ответ не по форме возвращает агенту вложенная машина запуска сессии); метод `при_возобновлении` — заглушка (подготовки при возобновлении нет); (в) `вердикт` — текст, как в данных первоисточника («чисто», «требования», «план», «вопрос», «перезапуск», «остановлено»); в `Вердикт` его переводит `вердикт_из_текста` при ответе (обход, «Что движок не покрыл», п. 12); `стадия` — перечисление `Стадия` блока типов (в таблице данных — Текст: по ней ветвятся развилки); (г) `ВходЗапускаСессии` — вход вложенной машины запуска сессии (слой методики, один тип у раннера и этой машины): код сессии — поле `сессия` (Текст); по коду ветвятся запуск сессии, профиль и промпт — механика исполнителя («Реализация на файлах» [task-runner-session-states.md](task-runner-session-states.md)), машина по нему не ветвится (правило 6), суммы по видам сессий не заводятся; фазу эта машина не передаёт (`None`); (д) `запрос_вызова` — всегда `запрос.идентификатор_запроса` (решение о `""` у верхнего уровня открыто, см. движок, пункт 6); (е) `состояние_по_имени` записано полным `match` по именам обращений.
6. **Данные машины — поля типа `Машина`**: поля названы как переменные раздела «Данные» первоисточника (правило 25), начальные значения — в `Машина.new()`, по входу проверки — `Машина.из_входа` (счётчики цикла, находки «вне задачи», задание и вход совещания приходят в запросе). Данные движка (конверт, очереди запросов, журнал, слова человека, тексты сбоев) — в `СостояниеДвижка` движка. Внешние объекты: `свод` и `находки_проверки` — поля (их пишет исполнитель при приёме ответа сессии проверки, `записать_результат`), читателей через `Объекты` у этой машины нет (объём запуска измеряет вложенная машина запуска сессии). **Именование читателей по ключу:** читатель элемента поля называется по полю (`@свод(номер)`, `@находки_проверки(номер)`). **Поле и метод с одним именем** (`свод`, `находки_проверки`) — сознательное решение: в Нове допустимо (`spec/decisions/03-syntax.md`, правило `@name`), правило 25 соблюдено (имя одной сущности одно).
7. **`недостижимо(текст)`** (определено в движке, пункт 8): в реализации стоит: у концов КОНЕЦ, ОСТАНОВЛЕНО, ОШИБКА в `перейти` (переходов нет); в `ответ_по_концу` (значение `остановка` вне таблицы; ответ не из конца); в `выполнить_операцию` (у этой машины операций нет); в `вход_запроса` и `следующая_попытка` (обязательное поле входа пусто — `обязательное` движка; состояние не обращение; сторона вне «запуск сессии», «совещание», «вратарь», «человек»); в `состояние_по_имени`, `сторона_обращения` (имя вне перечня); в `дата_остановки` (цепочка начата не словом «остановиться»); в `вердикт_из_текста` (вердикт вне перечня).

```nova
fn concat(first_list []Finding, second_list []Finding) -> []Finding {
  mut result = []Finding.new()
  for finding in first_list { result.push(finding) }
  for finding in second_list { result.push(finding) }
  result
}
// счётчик_доказательства(счётчики, доказательство): значение `заходов` записи с этим доказательством; записи нет — 0
fn counter_of(counters []Counter, evidence str) -> int {
  for counter in counters {
    if counter.evidence == evidence { return counter.passes }
  }
  0
}
// обновить_счётчики(счётчики, находки): по записи на каждое непустое доказательство находок (один раз за заход): прежнее значение + 1; записи без находки отбрасываются
fn update_counters(counters []Counter, findings []Finding) -> []Counter {
  mut next_counters = []Counter.new()
  for finding in findings {
    if finding.evidence != "" && counter_of(next_counters, finding.evidence) == 0 {
      next_counters.push(Counter { evidence: finding.evidence, passes: counter_of(counters, finding.evidence) + 1 })
    }
  }
  next_counters
}
// наибольший_счётчик(счётчики): наибольшее `заходов`; у пустого списка 0
fn max_counter(counters []Counter) -> int {
  mut largest = 0
  for counter in counters {
    if counter.passes > largest { largest = counter.passes }
  }
  largest
}
// сбросить_достигших(счётчики): у записей с `заходов` не меньше ПОТОЛОК_ДОКАЗАТЕЛЬСТВА значение 0
fn reset_reached(counters []Counter) -> []Counter {
  mut next_counters = []Counter.new()
  for counter in counters {
    next_counters.push(Counter { evidence: counter.evidence, passes: if counter.passes >= PROOF_CEILING { 0 } else { counter.passes } })
  }
  next_counters
}
// без_достигших_потолка(находки, счётчики): находки, чьё доказательство не достигло потолка; порядок прежний
fn without_reached(findings []Finding, counters []Counter) -> []Finding {
  mut kept = []Finding.new()
  for finding in findings {
    if counter_of(counters, finding.evidence) < PROOF_CEILING { kept.push(finding) }
  }
  kept
}
// записи_сужения(находки, счётчики, что_теряем): запись «сужено: <что_теряем>; доказательство: <доказательство>» на каждую находку с достигшим счётчиком
fn narrowing_notes(findings []Finding, counters []Counter, loss str) -> []str {
  mut notes = []str.new()
  for finding in findings {
    if counter_of(counters, finding.evidence) >= PROOF_CEILING {
      notes.push("сужено: ${loss}; доказательство: ${finding.evidence}")
    }
  }
  notes
}
// добавить_тексты(первые, вторые): элементы первых, затем элементы вторых (правило 30: добавить)
fn concat_texts(first_list []str, second_list []str) -> []str {
  mut result = []str.new()
  for entry in first_list { result.push(entry) }
  for entry in second_list { result.push(entry) }
  result
}
```

```nova
/// Переход по событию. тело_события — событие, которое ждёт состояние `текущее` (у развилки — Сразу без данных);
/// событие — исходное событие шага: его данные (сторона, идентификатор, тело) доступны всей цепочке до ближайшего обращения (правило 13).
/// Состояние пишется при фиксации; в «Что меняется» оно не повторяется.
fn MachineData mut @step(current State, event_body Event, event Incoming[Event], environment MachineEnvironment) Journal Objects Time -> Transition[State] {
  match current {

  // ===================== ВХОД_ПРОВЕРКИ — развилка =====================
  ReviewEntry => {
    // ВХОД_ПРОВЕРКИ #1: стадия = «совещание»
    if @stage == Stage.Meeting { return Go(Pass) }
    // ВХОД_ПРОВЕРКИ #2: стадия отлична от «совещание», и чистых_подряд меньше МИНИМУМ_ЧИСТЫХ_ПОДРЯД
    if @stage != Stage.Meeting && @clean_needed < MIN_CLEAN_NEEDED {
      return environment.machine_error("ошибка машины: чистых_подряд ниже минимума методики")
    }
    // ВХОД_ПРОВЕРКИ #3: стадия отлична от «совещание», чистых_подряд не меньше МИНИМУМ_ЧИСТЫХ_ПОДРЯД, и проб_в_чистом меньше МИНИМУМ_ПРОБ_В_ЧИСТОМ
    if @stage != Stage.Meeting && @clean_needed >= MIN_CLEAN_NEEDED && @probes_min < MIN_PROBES {
      return environment.machine_error("ошибка машины: проб_в_чистом ниже минимума методики")
    }
    // ВХОД_ПРОВЕРКИ #4: стадия отлична от «совещание», чистых_подряд не меньше МИНИМУМ_ЧИСТЫХ_ПОДРЯД, и проб_в_чистом не меньше МИНИМУМ_ПРОБ_В_ЧИСТОМ
    if @stage != Stage.Meeting && @clean_needed >= MIN_CLEAN_NEEDED && @probes_min >= MIN_PROBES { return Go(Pass) }
    // ВХОД_ПРОВЕРКИ #5: иначе
    environment.machine_error("ошибка машины: развилка ReviewEntry, ни одно условие не подошло")
  }

  // ===================== ЗАХОД — развилка =====================
  Pass => {
    // ЗАХОД #1: стадия = «совещание»
    if @stage == Stage.Meeting { return Go(MeetingCall) }
    // ЗАХОД #2: стадия отлична от «совещание», и серия_чистых меньше чистых_подряд
    if @stage != Stage.Meeting && @streak < @clean_needed {
      @assign_launch(checker(@stage), "", @number, "review")
      return Go(SessionLaunch)
    }
    // ЗАХОД #3: стадия отлична от «совещание», и серия_чистых не меньше чистых_подряд
    if @stage != Stage.Meeting && @streak >= @clean_needed {
      @streak = 0
      @verdict = "clean"
      return Go(End)
    }
    // ЗАХОД #4: иначе
    environment.machine_error("ошибка машины: развилка Pass, ни одно условие не подошло")
  }

  // ===================== СОВЕЩАНИЕ — обращение =====================
  MeetingCall => match event_body {
    // СОВЕЩАНИЕ #1: ответ
    MeetingReplied => {
      @verdict = "clean"
      Go(End)
    }
    // СОВЕЩАНИЕ #2: сбой (причина: КодСбоя)
    Failure { reason } => {
      environment.write_journal("совещание остановлено: ${fail_code_word(reason)}")
      @verdict = "stopped"
      Go(End)
    }
    _ => NotAwaited
  }

  // ===================== ЗАПУСК_СЕССИИ — обращение =====================
  // Запись автомата: событие «ответ» несёт итог сессии (`Ответ_сессии`); свод и находки захода сессии проверки исполнитель записывает при приёме
  //   (`записать_результат`).
  SessionLaunch => match event_body {
    // ЗАПУСК_СЕССИИ #1: ответ (итог_сессии: ИтогСессии — готово, ревизия, план, требования или вопрос)
    SessionReplied { result: outcome } => {
      @result = Some(outcome)
      Go(AfterSession)
    }
    // ЗАПУСК_СЕССИИ #2: сбой (причина: КодСбоя)
    Failure { reason } => {
      @failure_reason = fail_code_word(reason)
      environment.write_journal("запуск сессии ${@session} не дал итога: ${fail_code_word(reason)}")
      Go(SessionFailure)
    }
    _ => NotAwaited
  }

  // ===================== ОТКАЗ_СЕССИИ — развилка =====================
  SessionFailure => {
    // ОТКАЗ_СЕССИИ #1: причина_сбоя = «остановлено человеком»
    if @failure_reason == "stopped_by_human" {
      @stop_reason = "session_launch_stopped_by_human"
      return Go(Halted)
    }
    // ОТКАЗ_СЕССИИ #2: причина_сбоя = «нет результата»
    if @failure_reason == "no_result" {
      @stop_reason = "session_launch_no_result"
      return Go(Halted)
    }
    // ОТКАЗ_СЕССИИ #3: иначе
    environment.machine_error("ошибка машины: развилка SessionFailure, ни одно условие не подошло")
  }

  // ===================== ПОСЛЕ_СЕССИИ — развилка =====================
  AfterSession => {
    // ПОСЛЕ_СЕССИИ #1: продолжение = «проверка»
    if @continuation == "review" { return Go(SummaryParsing) }
    // ПОСЛЕ_СЕССИИ #2: продолжение = «правка»
    if @continuation == "fix" { return Go(FixOutcome) }
    // ПОСЛЕ_СЕССИИ #3: продолжение = «не делаю», и стадия = «сдача»
    if @continuation == "not_doing" && @stage == Stage.Delivery {
      @verdict = "restart"
      return Go(End)
    }
    // ПОСЛЕ_СЕССИИ #4: продолжение = «не делаю», и стадия = «реализация»
    if @continuation == "not_doing" && @stage == Stage.Implementation {
      @verdict = "clean"
      return Go(End)
    }
    // ПОСЛЕ_СЕССИИ #5: иначе
    environment.machine_error("ошибка машины: развилка AfterSession, ни одно условие не подошло")
  }

  // ===================== СВОДКА — развилка =====================
  SummaryParsing => match @summary(@number) {
    // СВОДКА #1: итога свода нет
    None => {
      environment.write_journal("итоговой строки нет, все находки считаются существенными")
      @no_probes = 0
      Go(Gate3)
    }
    // СВОДКА #2: итог свода есть, и существенных больше 0
    Some(outcome) if outcome.essential > 0 => {
      @no_probes = 0
      Go(Gate3)
    }
    // СВОДКА #3: итог свода есть, существенных нет, и проб не меньше проб_в_чистом
    Some(outcome) if outcome.essential == 0 && outcome.probes >= @probes_min => {
      @no_probes = 0
      Go(Gate3)
    }
    // СВОДКА #4: итог свода есть, существенных нет, и проб меньше проб_в_чистом
    Some(outcome) if outcome.essential == 0 && outcome.probes < @probes_min => {
      environment.write_journal("заход ${@number}: чистый без проб, не засчитан")
      @number += 1
      @no_probes += 1
      Go(NoProbes)
    }
    // СВОДКА #5: иначе
    _ => environment.machine_error("ошибка машины: развилка SummaryParsing, ни одно условие не подошло")
  }

  // ===================== БЕЗ_ПРОБ — развилка =====================
  NoProbes => {
    match no_probes_step(@cycle()) {
      // БЕЗ_ПРОБ #1: без_проб_подряд = 1
      Some(RepeatReview) => Go(Pass)
      // БЕЗ_ПРОБ #2: без_проб_подряд больше 1
      Some(AskHuman) => Go(Retry)
      // БЕЗ_ПРОБ #3: иначе
      None => environment.machine_error("ошибка машины: развилка NoProbes, ни одно условие не подошло")
    }
  }

  // ===================== ПОВТОР — обращение =====================
  Retry => match event_body {
    // ПОВТОР #1: В13: «повторить»
    Gate13Repeat => Go(Pass)
    // ПОВТОР #2: В13: «остановить»
    Gate13Halt => {
      @stop_reason = "retry_halt"
      Go(Halted)
    }
    _ => NotAwaited
  }

  // ===================== В3 — обращение =====================
  Gate3 => match event_body {
    // В3 #1: В3: «не засчитан»
    Gate3NotCounted => {
      environment.write_journal("заход ${@number}: пробы — не пробы, не засчитан")
      @number += 1
      Go(Pass)
    }
    // В3 #2: В3: «засчитан» (находки_В3: []Находка; вне_задачи_захода: []Находка)
    Gate3Counted { gate3_findings: new_findings, pass_out_of_scope } => {
      @number += 1
      @out_of_scope = concat(@out_of_scope, pass_out_of_scope)
      @gate3_findings = new_findings
      Go(PassOutcome)
    }
    _ => NotAwaited
  }

  // ===================== ИТОГ_ЗАХОДА — развилка =====================
  PassOutcome => {
    // ИТОГ_ЗАХОДА #1: находки_В3 = `[]`
    if @gate3_findings.len() == 0 {
      @streak += 1
      @passes_by_evidence = update_counters(@passes_by_evidence, @gate3_findings)
      return Go(Pass)
    }
    // ИТОГ_ЗАХОДА #2: находки_В3 не равны `[]`
    if @gate3_findings.len() > 0 {
      @streak = 0
      @passes_by_evidence = update_counters(@passes_by_evidence, @gate3_findings)
      return Go(CriterionNotConverging)
    }
    // ИТОГ_ЗАХОДА #3: иначе
    environment.machine_error("ошибка машины: развилка PassOutcome, ни одно условие не подошло")
  }

  // ===================== КРИТЕРИЙ_НЕ_СХОДИТСЯ — развилка =====================
  CriterionNotConverging => {
    // КРИТЕРИЙ_НЕ_СХОДИТСЯ #1: наибольший_счётчик(проходов_по_доказательству) меньше ПОТОЛОК_ДОКАЗАТЕЛЬСТВА
    if max_counter(@passes_by_evidence) < PROOF_CEILING { return Go(Ceiling) }
    // КРИТЕРИЙ_НЕ_СХОДИТСЯ #2: наибольший_счётчик(проходов_по_доказательству) не меньше ПОТОЛОК_ДОКАЗАТЕЛЬСТВА
    if max_counter(@passes_by_evidence) >= PROOF_CEILING { return Go(Gate15) }
    // КРИТЕРИЙ_НЕ_СХОДИТСЯ #3: иначе
    environment.machine_error("ошибка машины: развилка CriterionNotConverging, ни одно условие не подошло")
  }

  // ===================== В15 — обращение =====================
  // Сторона: человек (значение стороны по умолчанию). Слово «сузить» исполнитель ворот принимает только с непустой строкой «что теряем» из одной строки.
  Gate15 => match event_body {
    // В15 #1: В15: «сузить» (что_теряем: Текст)
    Gate15Narrow { loss } => {
      environment.write_journal("решение владельца: сужено: ${loss}")
      @narrowed = concat_texts(@narrowed, narrowing_notes(@gate3_findings, @passes_by_evidence, loss))
      @gate3_findings = without_reached(@gate3_findings, @passes_by_evidence)
      @passes_by_evidence = reset_reached(@passes_by_evidence)
      Go(AfterNarrowing)
    }
    // В15 #2: В15: «ещё заход»
    Gate15AnotherPass => {
      @passes_by_evidence = reset_reached(@passes_by_evidence)
      Go(Ceiling)
    }
    // В15 #3: В15: «остановиться» (дата: Текст)
    Gate15Stop { .. } => {
      @passes_by_evidence = reset_reached(@passes_by_evidence)
      Go(StopStage)
    }
    _ => NotAwaited
  }

  // ===================== ПОСЛЕ_СУЖЕНИЯ — развилка =====================
  AfterNarrowing => {
    // ПОСЛЕ_СУЖЕНИЯ #1: находки_В3 = `[]`
    if @gate3_findings.len() == 0 { return Go(Pass) }
    // ПОСЛЕ_СУЖЕНИЯ #2: находки_В3 не равны `[]`
    if @gate3_findings.len() > 0 { return Go(Ceiling) }
    // ПОСЛЕ_СУЖЕНИЯ #3: иначе
    environment.machine_error("ошибка машины: развилка AfterNarrowing, ни одно условие не подошло")
  }

  // ===================== ПОТОЛОК — развилка =====================
  Ceiling => {
    // ПОТОЛОК #1: (номер_захода − 1) − заход_отсчёта + 1 меньше потолок_заходов
    if !ceiling_reached(@cycle(), @ceiling) { return Go(Levels) }
    // ПОТОЛОК #2: (номер_захода − 1) − заход_отсчёта + 1 не меньше потолок_заходов
    if ceiling_reached(@cycle(), @ceiling) { return Go(Gate9) }
    // ПОТОЛОК #3: иначе
    environment.machine_error("ошибка машины: развилка Ceiling, ни одно условие не подошло")
  }

  // ===================== В9 — обращение =====================
  Gate9 => match event_body {
    // В9 #1: В9: «урезать объём»
    Gate9CutScope => {
      @set_cycle(reset_origin(@cycle()))
      @verdict = "requirements"
      @verdict_source = "файл проверки захода ${@number - 1}"
      Go(End)
    }
    // В9 #2: В9: «разбить»
    Gate9Split => {
      @set_cycle(reset_origin(@cycle()))
      @verdict = "requirements"
      @verdict_source = "файл проверки захода ${@number - 1}"
      Go(End)
    }
    // В9 #3: В9: «спросить заказчика»
    Gate9AskCustomer => {
      @set_cycle(reset_origin(@cycle()))
      @verdict = "question"
      Go(End)
    }
    // В9 #4: В9: «остановиться» (дата: Текст)
    Gate9Stop { .. } => {
      @set_cycle(reset_origin(@cycle()))
      Go(StopStage)
    }
    // В9 #5: В9: «ещё заход»
    Gate9AnotherPass => {
      @set_cycle(reset_origin(@cycle()))
      Go(Levels)
    }
    _ => NotAwaited
  }

  // ===================== СТАДИЯ_ОСТАНОВКИ — развилка =====================
  // Запись автомата: «<дата события>» — дата слова «В9: «остановиться»», тело исходного события шага (`дата_остановки(событие.тело)`).
  StopStage => {
    // СТАДИЯ_ОСТАНОВКИ #1: стадия = «реализация»
    if @stage == Stage.Implementation {
      @assign_launch("s5_fix", "решение владельца: не делаю, ${stop_date(event.body)}", 0, "not_doing")
      return Go(SessionLaunch)
    }
    // СТАДИЯ_ОСТАНОВКИ #2: стадия = «сдача»
    if @stage == Stage.Delivery {
      @assign_launch("s5_fix", "решение владельца: не делаю, ${stop_date(event.body)}", 0, "not_doing")
      return Go(SessionLaunch)
    }
    // СТАДИЯ_ОСТАНОВКИ #3: стадия = «разбор»
    if @stage == Stage.Analysis { return Go(Levels) }
    // СТАДИЯ_ОСТАНОВКИ #4: стадия = «план»
    if @stage == Stage.Plan { return Go(Levels) }
    // СТАДИЯ_ОСТАНОВКИ #5: иначе
    environment.machine_error("ошибка машины: развилка StopStage, ни одно условие не подошло")
  }

  // ===================== УРОВНИ — развилка =====================
  Levels => {
    // УРОВНИ #1: среди находки_В3 есть находка с уровнем «требования»
    if has_finding_of_level(@gate3_findings, Level.Requirements) {
      @verdict = "requirements"
      @verdict_source = "файл проверки захода ${@number - 1}"
      return Go(End)
    }
    // УРОВНИ #2: среди находки_В3 нет находки с уровнем «требования» и нет находки с уровнем «план»
    if !has_finding_of_level(@gate3_findings, Level.Requirements) && !has_finding_of_level(@gate3_findings, Level.Plan) {
      @assign_launch(fixer(@stage), "файл проверки захода ${@number - 1}", @number - 1, "fix")
      return Go(SessionLaunch)
    }
    // УРОВНИ #3: среди находки_В3 нет находки с уровнем «требования», есть находка с уровнем «план», и стадия = «реализация»
    if !has_finding_of_level(@gate3_findings, Level.Requirements) && has_finding_of_level(@gate3_findings, Level.Plan) && @stage == Stage.Implementation {
      @verdict = "plan"
      @verdict_source = "файл проверки захода ${@number - 1}"
      return Go(End)
    }
    // УРОВНИ #4: среди находки_В3 нет находки с уровнем «требования», есть находка с уровнем «план», и стадия = «сдача»
    if !has_finding_of_level(@gate3_findings, Level.Requirements) && has_finding_of_level(@gate3_findings, Level.Plan) && @stage == Stage.Delivery {
      @verdict = "plan"
      @verdict_source = "файл проверки захода ${@number - 1}"
      return Go(End)
    }
    // УРОВНИ #5: среди находки_В3 нет находки с уровнем «требования», есть находка с уровнем «план», и стадия = «разбор»
    if !has_finding_of_level(@gate3_findings, Level.Requirements) && has_finding_of_level(@gate3_findings, Level.Plan) && @stage == Stage.Analysis {
      @assign_launch(fixer(@stage), "файл проверки захода ${@number - 1}", @number - 1, "fix")
      return Go(SessionLaunch)
    }
    // УРОВНИ #6: среди находки_В3 нет находки с уровнем «требования», есть находка с уровнем «план», и стадия = «план»
    if !has_finding_of_level(@gate3_findings, Level.Requirements) && has_finding_of_level(@gate3_findings, Level.Plan) && @stage == Stage.Plan {
      @assign_launch(fixer(@stage), "файл проверки захода ${@number - 1}", @number - 1, "fix")
      return Go(SessionLaunch)
    }
    // УРОВНИ #7: иначе
    environment.machine_error("ошибка машины: развилка Levels, ни одно условие не подошло")
  }

  // ===================== ИТОГ_ПРАВКИ — развилка =====================
  FixOutcome => {
    // ИТОГ_ПРАВКИ #1: итог_сессии = «готово»
    if outcome_equals(@result, SessionResult.Done) { return Go(Pass) }
    // ИТОГ_ПРАВКИ #2: итог_сессии = «вопрос»
    if outcome_equals(@result, SessionResult.Question) {
      @verdict = "question"
      return Go(End)
    }
    // ИТОГ_ПРАВКИ #3: итог_сессии = «ревизия»
    if outcome_equals(@result, SessionResult.Revision) {
      @verdict = "plan"
      @verdict_source = "артефакт автора"
      return Go(End)
    }
    // ИТОГ_ПРАВКИ #4: итог_сессии = «план»
    if outcome_equals(@result, SessionResult.Plan) {
      @verdict = "plan"
      @verdict_source = "артефакт автора"
      return Go(End)
    }
    // ИТОГ_ПРАВКИ #5: итог_сессии = «требования»
    if outcome_equals(@result, SessionResult.Requirements) {
      @verdict = "requirements"
      @verdict_source = "артефакт автора"
      return Go(End)
    }
    // ИТОГ_ПРАВКИ #6: иначе
    environment.machine_error("ошибка машины: развилка FixOutcome, ни одно условие не подошло")
  }

  // ===================== ПАУЗА — обращение =====================
  // Подключено фрагментом «Пауза» (state-machine-pause-states.md): события ПАУЗЫ разбирает движок (`общие_события`), строк состояния у машины нет;
  //   остальные события ПАУЗА не ждёт.
  Pause => NotAwaited

  // ===================== КОНЕЦ — конец =====================
  End => unreachable("конец: переходов нет; работа при входе — в «Концы и ответ»")

  // ===================== ОСТАНОВЛЕНО — конец =====================
  Halted => unreachable("конец: переходов нет; работа при входе — в «Концы и ответ»")

  // ===================== ОШИБКА — конец =====================
  Errored => unreachable("конец: переходов нет; работа при входе — в «Концы и ответ»")

  }
}
```

## Приём ответа и запись результата

```nova
/// При приёме (правило 14): у обращений проверки записи стороны нет (счётчики попыток ведёт механика контракта).
fn MachineData mut @on_accept(current State, response Response[RoleResult]) => ()

/// Запись принятого результата в хранилище (правила 8, 14): роль возвращает результат, в хранилище машины не пишет.
/// Итоговая строка и находки захода пишутся только у сессий проверки (ЗАПУСК_СЕССИИ, свод[номер_захода] и находки_проверки[номер_захода]); у сессий правки
/// и у вложенной машины совещания результат идёт событием; у ворот результата роли нет.
fn MachineData mut @record_result(current State, response Response[RoleResult]) => match response {
  Refusal(_) => ()
  Answer(outcome) => match outcome.result {
    SessionLaunchOutcome(launch_outcome) => {
      match launch_outcome.summary {
        Some(found_item) => { @summary.insert(@number, found_item) }
        None => {}                                        // итога нет: записи в `свод` нет
      }
      match launch_outcome.findings {
        Some(found_items) => { @findings.insert(@number, found_items) }
        None => {}                                        // сессия правки: файла находок нет
      }
    }
    MeetingOutcome(_) => ()
  }
}
```

## Концы и ответ

```nova
/// Работа концов при входе (в последнем, повторяемом без вреда этапе фиксации) и ответ вызвавшей стороне.
/// Вход в любой конец отменяет все открытые запросы (правило 22), в том числе запрос к вложенной машине совещания; машина отвечает ровно один раз (правило 35).
fn MachineData mut @on_end_entry(end_state State, environment MachineEnvironment) Journal Time -> () => match end_state {
  // ОСТАНОВЛЕНО: группа процессов агента останавливается целиком и проверяется, что в ней не осталось процессов; вложенная машина совещания получает отмену, если запрос к ней открыт
  //   (движок: `отменить_все_открытые_запросы`); в журнал — «проверка цикла остановлена: <остановка>»; вызвавшая машина получает `Refusal` (таблица «конец → ответ»).
  Halted => {
    environment.add_irreversible(Irreversible.StopAgentGroup)
    environment.write_journal("проверка цикла остановлена: ${@stop_reason}")
  }
  // ОШИБКА: группа процессов агента останавливается; в журнал — запись из перехода и данные машины; вызвавшая машина получает `Refusal`; решает человек вне машины.
  Errored => {
    environment.add_irreversible(Irreversible.StopAgentGroup)
    environment.write_journal(environment.transition_note())
    @journal_machine_data(environment)
  }
  // КОНЕЦ: в журнал — вердикт, источник маршрута и счётчики цикла; ответ `Answer` с итогом проверки уходит вызвавшей машине.
  End => {
    environment.write_journal("проверка цикла: вердикт ${@verdict}, источник ${@verdict_source}, номер_захода ${@number}, заход_отсчёта ${@origin}, серия_чистых ${@streak}, без_проб_подряд ${@no_probes}, записей сужено ${@narrowed.len()}")
  }
  _ => ()
}

/// Таблица «конец → ответ» первоисточника (раздел «Контракт машины»): каждый конец и каждое значение остановка — одна строка.
/// Вердикты по стадиям (чисто, требования, план, вопрос — у разбора, плана, реализации; перезапуск — только у сдачи; чисто и остановлено — у совещания) задают строки состояний.
fn MachineData @end_response(call_request Request[ReviewInput], end_state State, environment MachineEnvironment) -> Response[ReviewResult] {
  match end_state {
    // КОНЕЦ, условие входа: всегда → СРезультатом: вердикт, источник, счётчики цикла, находки «вне задачи»
    End => Answer(Reply {
      request: call_request.id, party: call_request.party, trace: call_request.trace, step: call_request.step,
      result: ReviewResult {
        verdict: verdict_from_text(@verdict), source: @verdict_source,
        cycle: @cycle(),
        out_of_scope: @out_of_scope } })
    // ОШИБКА, условие входа: всегда (дефект машины) → Отказ, НетРезультата; текст — запись из перехода
    Errored => refuse_with(call_request, NoResult, environment.transition_note())
    Halted => match @stop_reason {
      // ОСТАНОВЛЕНО: остановка = «запуск сессии: нет результата» → Отказ, НетРезультата
      "session_launch_no_result" => refuse_with(call_request, NoResult, @stop_reason)
      // ОСТАНОВЛЕНО: остановка = «ПОВТОР: остановить», «запуск сессии: остановлено человеком» или «ПАУЗА: остановить»
      //   (слово человека; у вызванной машины — сигнал «остановить от родителя» в ПАУЗЕ) → Отказ, ОстановленоЧеловеком
      "retry_halt" | "session_launch_stopped_by_human" => refuse_with(call_request, StoppedByHuman, @stop_reason)
      "pause_halt" => refuse_with(call_request, common_stop_fail_code(@stop_reason), @stop_reason)
      // ОСТАНОВЛЕНО: остановка = «отмена_запроса» → Отказ, ОтмененоРодителем
      "cancel_request" => refuse_with(call_request, common_stop_fail_code(@stop_reason), @stop_reason)
      _ => unreachable("значение остановка вне таблицы «конец → ответ»: новое значение добавляет строку таблицы")
    }
    _ => unreachable("ответ отдают только концы")
  }
}

/// Точка подстановки эффектов: обработчики выбирает вызывающий код, один раз (`with`), и вне этого файла — любые (`Time` — стандартный, обработчик по умолчанию).
/// Все функции цепочки от `начать`, `возобновить`, `вызвать` объявляют эффекты в своей сигнатуре; здесь они подставлены. Машину по входу запроса создаёт вызывающий код
/// (обработчик `Связь` верхней машины при запросе `ЗапросРоли` с входом `ВходПроверкиЦикла`).
fn start_review(request Request[ReviewInput]) Time -> Response[ReviewResult] =>
  with Store = store_handler, Journal = journal_handler, Link = link_handler, Objects = objects_handler {   // псевдокод: обработчики (база, файл поверх Fs/Db, очередь сообщений) — любые, вне файла
    mut engine_instance = Engine.new(MachineData.from_input(request.input))
    engine_instance.call(request)
  }
```
