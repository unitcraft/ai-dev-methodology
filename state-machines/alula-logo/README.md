# Логотип Алулы

Файлы логотипа живут в репозитории языка: [nv-lang/nova-alula, папка `assets/logo/`](https://github.com/nv-lang/nova-alula/tree/main/assets/logo). Там знак, малый знак для значков, перо, слово «Алула» и «alula» (шрифты Manrope 700 и JetBrains Mono 700, слова переведены в кривые) для светлого и тёмного фона и социальная картинка репозитория; описание — в README той папки.

Здесь копий нет: первоисточник один.
