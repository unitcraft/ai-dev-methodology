# Логотип Алулы

Знак: плашка с сеткой 3×3 состояний, диагональ — путь по переходам, конечное состояние в углу нарисовано пером (alula — «крылышко», маленькое перо на крыле птицы). Цвет `#1D9E75`.

| Файл | Где |
|---|---|
| `alula-mark.svg` | основной знак: документация, аватар репозитория (от 48 px) |
| `alula-mark-small.svg` | значки 16–32 px: сетка без пера |
| `alula-feather.svg` | отдельное перо на плашке |
| `alula-wordmark-light.svg`, `alula-wordmark-dark.svg` | знак со словом «Алула» для светлого и тёмного фона |

Слово в файлах со словом пока набрано текстом (шрифт Manrope, как на сайте организации языка Нова; запасные — Segoe UI, Arial); перевод в кривые — следующий шаг. Когда появится репозиторий языка, эта папка переносится туда и становится первоисточником.
