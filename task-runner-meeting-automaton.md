# Совещание агентов: код автомата

Стейт-машина совещания, записанная кодом на языке Нов: объявление данных и типов, перечисления `Состояние` и `Событие`, функция переходов `перейти(состояние, событие)` как `match` по состоянию и событию, концы с ответом по контракту машины, цикл исполнителя. Нормы — [methodology.md](methodology.md), раздел 18, «Согласование решения несколькими агентами».

**Первоисточник — [task-runner-meeting-states.md](task-runner-meeting-states.md)** (таблицы состояний, общие события, «Контракт машины»); правила формы — [state-machine-spec.md](state-machine-spec.md). Этот файл — производная запись того же автомата, а не второй источник истины: при любом расхождении верен первоисточник, а этот файл правится вслед за ним. Язык записи — Нов, https://github.com/nv-lang/nova (синтаксис — по `spec/syntax.ru.md` и `nova.ungrammar` того репозитория). **Код не компилировался и не проверялся компилятором Нова:** это псевдокод в синтаксисе Нова; места, где Нов не выражает записанное или где синтаксис не подтверждён спецификацией, помечены строкой `// псевдокод:` (перечень — в соглашениях, пункт 7). Машина отделена от исполнителя: `Машина` — данные и чистая логика (переходы, общие события, ответ по концу), `Исполнитель` — очередь, фиксация, отправка запросов, журнал, передача сигналов вложенным; снимки состояния лежат в `Хранилище` — эффекте Нова с любым обработчиком (база, диск, очередь сообщений), который выбирает вызывающий код; исполнитель с машиной совещания реализует протокол `Вызываемое[ВходСовещания, ИтогСовещания]`, поэтому машина может быть событием в другой машине (правило 35). Расширения, отличия от псевдокода раннера и опытный статус режима описаны в шапке первоисточника и здесь не повторяются; раннером машина не исполняется. Схема раннера ([task-runner-pseudocode.md](task-runner-pseudocode.md), [task-runner-meeting-pseudocode.md](task-runner-meeting-pseudocode.md)) — другая форма записи, помечена устаревшей и этим файлом не заменяется. Имя файла — по `AGENTS.md`, «Вынесенные алгоритмы», форма `automaton`.

## Соглашения записи

1. **Типы** — русские имена: слово или слитное сочетание с заглавной буквы без подчёркиваний (`КодСбоя`, `ОтветСвидетеля`); имена типов, вариантов и полей блока «Типы на Нове» первоисточника переведены по таблице ниже («русское имя — имя блока на латинице»). Новых типов данных нет; добавлены только типы записи автомата: `Состояние`, `Событие`, `Входящее`, `Переход`, `Вид`, `Сообщение`, `ИтогЛинзы` (то, что возвращает линза: находки и пробы), `РезультатРоли` и `ВходРоли` (суммы результатов и входов ролей по обращениям первоисточника), `Машина` (все данные машины; см. пункт 9), `Исполнитель`, `Снимок`, `Хранилище` (эффект), `ОшибкаХранилища`, `Вызываемое`, `Необратимое`, `СигналВложенному` (см. пункт 10).
2. **Идентификаторы** все русские. Типы и варианты — слова с заглавной буквы без подчёркиваний (`ИтогСовещания`, `НетРезультата`); поля, параметры, локальные переменные и функции — змеиный регистр (правило 25 спецификации: имя одной сущности одно); имена состояний — как есть (`ЗАХОД`), варианты событий с префиксом ворот — как есть (`В13_повторить`). Конфликты имён разрешены различением, а не латиницей: параметр состояния в функции называется по роли — `текущее` (в `перейти`, `при_приёме`), `куда` (`войти_в`), `цель` (цепочка шага), `обращение`, `операция`, `конец`; событие в `перейти` — `тело_события`; тип протокола вызова — `Вызываемое`, чтобы не совпасть с перечислением `Событие`. Латиница остаётся только в стандартных именах Нова (`fn`, `type`, `match`, `if`, `for`, `loop`, `while`, `return`, `break`, `ro`, `mut`, `const`, `enum`, `protocol`, `effect`, `with`, `Result`, `Ok`, `Err`, `never`, `Option`, `Some`, `None`, `HashMap`, `str`, `int`, `bool`, `true`, `false`, `new`, `get`, `insert`, `contains`, `len`, `module`) и в таблице соответствия. Нов кириллические идентификаторы не поддерживает (владелец, 2026-10-17); русские имена в псевдокоде — решение этого файла, при переходе на выполнимый Нов их заменяют латинскими по таблице соответствия.
3. **Данные события.** Поля варианта события берутся образцом в `match`: `Сбой { причина } => …`; при совпадении имени поля с переменной машины поле переименовывается: `В7_ответил { ответ_человека: слово_ответа }`. «Сторона события» и идентификатор события — `событие.сторона`, `событие.идентификатор` (конверт `Входящее`, правила 13 и 31). Шаблон строки журнала «<сторона события>» — `${событие.сторона}`.
4. **Запись Нова.** `ro` — неизменяемая привязка, `mut` — изменяемая переменная; «←» — `=`; «+ 1» — `+= 1`; отсутствующее значение — `None`, значение — `Some(x)`, `Option[T]`; `HashMap[K, V]` — отображение (чтение отсутствующего ключа — функциями `свод`, `аннулирований`: у `аннулирований` — `0`); `да`/`нет` — `true`/`false`; строки — `"… ${выражение} …"`; комментарий — `//`, документирующий — `///` (перед объявлением, пустая строка перед ним); «объединить_без_повторов» — функция правила 30; добавление в список — `.push(x)`, в начало — `.insert(0, x)`, дописывание списка на месте — `.append(другой)` (`std/src/collections/vec/mutate.nv`, проверено оркестратором проекта, 2026-10-18); оператор `+` на списках не пишется (по слову владельца: он копирует весь список, `a += b` — тоже), нужен свежий список из двух — `[]Т.new(cap: первый.len() + второй.len()).append(первый).append(второй)`; «сразу» — событие `Сразу`; «то же состояние» — `Остаться`; «запуск заново» — `Заново(Состояние)`; «Куда» — `Куда(Состояние)`. Имя функции записи в журнал — `писать_журнал`: переменная машины `журнал` занимает имя.
5. **Строка таблицы — ветка кода.** Перед каждой строкой первоисточника (условие или событие, «Что меняется», «Куда») стоит комментарий `// <СОСТОЯНИЕ> #<номер строки>: …` с её текстом; порядок строк как в первоисточнике. Строка «иначе» каждой развилки — последняя ветка, ведёт в `ОШИБКА`. Строки «Вход», «Выход», «При входе», «Сторона» и одна строка простыми словами на состояние — комментарии `//` у состояния.
6. **Механика исполнителя.** Раздел «Механика исполнителя» — перечень механики контракта, фиксации и приёма (правила 13–22 спецификации), разделённый по владельцу: свободные функции, методы `Машина`, методы `Исполнитель`; большинство объявлено только сигнатурой. С телом записаны: свободные — `вид`, `в_конце`, `в_конце_или_паузе`, `правит_автор`, `обязательное`, `инвариант_номер_захода_не_уменьшается`; методы `Машина` — `перейти`, `общие_события`, `отказ_по`, `ответ_по_концу`, `вход_запроса`, `ошибка_машины`, `передать_вложенным`, `свод`, `аннулирований`, `линзы`, `установить_потери`, `установить_пробы`, `установить_попытку`, `счётчик_попыток`, `увеличить_счётчик_попыток`; методы `Исполнитель` — `вызвать`, `начать`, `возобновить`, `цикл`, `при_приходе`, `при_приёме`, `записать_результат`, `обработать_очередь`, `выполнить_шаг`, `войти_в`, `работа_операции`, `после_фиксации`, `отправить_запросы`, `после_перезапуска`, `при_входе_в_конец`, `зафиксировать`, `отдать_ответ`, `получатель`, `снимок`, `новое_событие`, `начать_фиксацию_запроса`, `начать_фиксацию_приёма`, `выполнить_необратимые`, `закрыть_для_записи`, `открыть_для_записи`, `перенести_в_архив`; конструкторы `Машина.new`, `Исполнитель.new`.
7. **Строки `// псевдокод:`** стоят там, где записанное — не Нов или не подтверждено его спецификацией: значения констант (параметры проекта); функции без тела (сигнатуры механики); `недостижимо`; ключ-кортеж `HashMap[(str, int), …]` у `находки_линзы` — в Нове он пока ломает кодогенерацию (запись M-hashmap-tuple-key-mono, открыта), поэтому в Нове пока вложенное отображение `HashMap[str, HashMap[int, V]]` или составной ключ-строка. **Подтверждено спецификацией Нова** (проверено оркестратором проекта по чтению репозитория языка, 2026-10-18; компилятором не проверено): `///` — внешний документирующий комментарий (`spec/decisions/03-syntax.md`, D104; привязан к следующему полю записи и варианту суммы); `never` строчная — тип выражения, которое не возвращает значения (`spec/decisions/04-effects.md`, D25), его и берёт `недостижимо`; `Never` заглавная — пустой тип, нужен только как аргумент `E` в `Effect[E, Never]`, здесь не используется; `fn Машина.new()` — статическое объявление (`spec/syntax.ru.md`, `fn Account.new(…)`); `.contains()` на `[]T` (std, `collections/vec/access.nv`); `.len()` на списке (`vec/core.nv`); срез `v[a..]`, `v[a..b]` (`vec/slice.nv`, Plan 284; за границами паника, безопасно `v.get(a..b)`); присваивание как ветка `match` допустимо (`nova.ungrammar`, `MatchArm`), здесь оно записано блоком `=> { x = v }`. **Отображения.** У `HashMap` нет `[]` и `get_mut`: чтение — `get(ключ) -> Option[V]` (в `линзы`, `свод`, `аннулирований`), запись — `insert(ключ, значение)`; поле записи линзы меняется вставкой изменённой копии (`установить_потери`, `установить_пробы`, `установить_попытку`). Длина текста (`.len()` на `str`) нигде не берётся: `.len()` стоит только на списках. **Записано по слову владельца, спецификацией не подтверждено (2026-10-18):** оператор `??` для `Option` — значение либо запасное, правая часть вычисляется только при `None` (`аннулирований`, цикл исполнителя). **Протоколы** (прочитано в `spec/syntax.ru.md`, раздел «Структурные "интерфейсы" — protocol», 2026-10-18; компилятором не проверено): `type Имя protocol { @метод() -> T }`, изменяющий метод — `mut @метод(…)`, обобщённый протокол — `type Next[T] protocol { … }`, соответствие структурное, `impl` не нужен — поэтому `Исполнитель` реализует `Вызываемое[ВходСовещания, ИтогСовещания]` совпадением метода `вызвать`. **Не подтверждено спецификацией, без пометки в коде:** русские имена параметров типа `[Вход, Выход]`, `return` из `loop` значением функции (`цикл`). **Эффекты** (прочитано в `spec/effects.md`, 2026-10-18, D61/D142/D434/D456; компилятором не проверено): `type Хранилище effect { fn … -> T }` — операции без `@` и без `mut`, тип возврата обязателен; эффект в сигнатуре между `)` и `->` (`fn … Хранилище -> …`); вызов по имени `Хранилище.сохранить(…)`; обработчик подставляет `with Хранилище = обработчик { … }` один раз у вызывающего кода; прямой эффект объявляется, транзитивный — предупреждение (ошибка при `--strict-effects`). **Записано по выводу, спецификацией не подтверждено:** ошибка операции эффекта через `Result` (форма `Fail[E]` для операции эффекта в спецификации не найдена); эффект без параметров типа (`Снимок` конкретный). **Именование читателей по ключу:** читатель элемента поля называется по полю (`@свод(номер)`, `@аннулирований(номер)`, `@линзы(идентификатор)`) — форма чтения свойства по слову владельца, 2026-10-18; поле и метод с одним именем на одном типе в Нове допустимы (`spec/decisions/03-syntax.md`, правило `@name`: «`@name` без `()` — поле, `@name()` — вызов метода»; прецедент — `Vec`, поле `len` и метод `len()` в `std/src/collections/vec/core.nv`; проверено оркестратором проекта, 2026-10-18). **Тело функции:** блок без стрелки `fn … { … }` (последнее выражение — значение) или `fn … => выражение`; `=> { поле: значение, … }` — литерал записи, так записан только `Машина.new` (спецификация Нова: `FnDecl … (Block | FnExprBody)`, `FnExprBody = '=>' Expr`; проверено оркестратором проекта, 2026-10-18).
8. **Уточнения записи автомата сверх первоисточника:** событие `Срок` порождает `Входящее` с `запрос: Some(ид)` и стороной по `сторона_запроса(ид)` (первоисточник даёт только `Сбой { причина: НетОтветаВСрок }`); ветка `None` у `копия` в ВОЗВРАТЕ пишет строку журнала «ВОЗВРАТ: копии нет» (недостижима: копию пишет ЗАМОК); `Сообщение` и методы приёма необобщённые: результаты ролей — сумма `РезультатРоли`, входы запросов — сумма `ВходРоли` (по варианту на обращение первоисточника; у ворот человека результата роли нет — слово приходит событием); обобщены только типы контракта вызова `Запрос[Вход]`, `Исход[Результат]`, `ОтветСРезультатом[Результат]`, `Вызываемое[Вход, Выход]` — параметр там и во входе, и в результате; **`запрос_вызова` — всегда `запрос.идентификатор_запроса`** (решение методики, 2026-10-18; первоисточник приведён к нему): через `Событие` машину вызывают только запросом. Условия не ломаются: отмена и «от родителя» сравнивают идентификатор с `запрос_вызова`; раньше у верхнего уровня сравнение с `""` отбрасывало любой такой сигнал, теперь машина принимает их от вызвавшей стороны по её запросу и по-прежнему отбрасывает чужие; сигналы человека («стоп человека», слова ворот) от `запрос_вызова` не зависят. **Открыто, решение владельца не принято:** оставить `запрос.идентификатор_запроса` или передавать верхнему уровню `""`; до решения в коде `запрос.идентификатор_запроса`.
9. **Данные машины — поля типа `Машина`**, а не переменные модуля: поля названы как переменные раздела «Данных» первоисточника (правило 25), начальные значения — в `Машина.new()`. Функции, читающие или пишущие данные, — методы `Машина`: форма `fn Машина @имя(…)` читает, `fn Машина mut @имя(…)` меняет; обращение к полю и вызов метода — через `@` (спецификация Нова: `fn Account mut @deposit(…) { @_balance += … }`). Функции без данных (`вид`, `в_конце`, списковые помощники, `сторона_запроса`) остаются свободными. Имя `Машина`: `Состояние` занято перечнем состояний; английское имя не взято — имя русское, как имена данных и как у типа записи автомата `ИтогЛинзы`; тип несёт данные машины и чистую логику, а не механику (её несёт `Исполнитель`, пункт 10).
10. **Исполнитель, хранилище, событие.** `Исполнитель` владеет `Машина` и тем, чего в данных первоисточника нет: очередь входящих `очередь`, запрос вызова `вызов`, `готовый_ответ`, `хранилище`. Данные раздела «Данные» первоисточника остаются полями `Машина`, в том числе то, что пишет исполнитель (`трасса`, `номер_шага`, `счётчик_событий`, `причина_шага`, `запрос_вызова`, `открытые_запросы`, `принятые_запросы`, `к_отправке`, счётчики попыток, `журнал`, внешние объекты): исполнитель меняет их через `@машина.поле`, машина — только в строках таблицы. Новое поле `Машина.сигналы_вложенным` — очередь сигналов вложенным: шаг ставит сигнал, исполнитель передаёт его после фиксации (правило 35). `Хранилище` — эффект (`type Хранилище effect`) с операциями `загрузить(идентификатор_запроса) -> Result[Option[Снимок], ОшибкаХранилища]` и `сохранить(идентификатор_запроса, снимок) -> Result[(), ОшибкаХранилища]`; вызов по имени `Хранилище.сохранить(…)`, обработчик подставляет вызывающий код (`with Хранилище = …`) — любой, вне файла; прямые вызовы — только в `сохранить_снимок` и `загрузить_снимок` (с `Хранилище` в сигнатуре); ошибка хранилища: если `сохранить` не удалось — исполнитель аварийно прерывается (`недостижимо`), шаг не считается зафиксированным, запросы не отправляются; `Снимок` — вся `Машина`, `очередь`, `вызов`, `готовый_ответ`, `необратимые`; реализация — любая, вне файла. `зафиксировать` вызывает `сохранить` в конце шага, ДО отправки запросов (правило 13). Входов два: `начать(запрос)` — новая машина, записи линз, ЗАХОД, фиксация, цикл; `возобновить(идентификатор_запроса)` — загрузка снимка и продолжение с сохранённого `состояние` (запросы без принятого ответа уходят повторно, ПАУЗА остаётся до «продолжить»; правила 12, 14, 22). Остановка исполнителя — выход из цикла (завершение процесса): состояние уже сохранено. `запрос_вызова` у машины всегда `запрос.идентификатор_запроса`: через `Событие` машину вызывают всегда запросом. `Вызываемое[Вход, Выход]` с методом `вызвать(запрос) -> Исход[Выход]` реализует `Исполнитель`; повтор запроса с тем же идентификатором возвращает готовый ответ (правило 35, п. 4).
11. **`недостижимо(текст)`** — тип `never`: ничего не отдаёт и аварийно прерывает исполнителя. Ветка невозможна при соблюдении инвариантов — это ошибка программы. Дефект самой машины (развилка, у которой ни одно условие не подошло) идёт иначе: строка «иначе → ОШИБКА», состояние ОШИБКА, ответ-отказ `НетРезультата`. `недостижимо` стоит: у концов ОСТАНОВЛЕНО, ОШИБКА, КОНЕЦ в `перейти` (переходов нет); в `ответ_по_концу` (значение `остановка` вне таблицы; ответ не из конца); в `работа_операции` (состояние без операции); в `при_приёме` и `записать_результат` (вариант результата роли не соответствует состоянию); в `вход_запроса`, `обязательное` (обязательное поле входа пусто; состояние не обращение); в `счётчик_попыток` и `увеличить_счётчик_попыток` (сторона вне «свидетель», «автор», «человек»); в `линзы` (записи линзы нет); в `получатель` (запрос вызова не принят); в `вызвать` (снимок только что загружен).

## Общие события

```nova
/// Разбираются до строк состояний (правило 23): сначала общие события, затем перейти.
/// «Стоп человека» в ПАУЗЕ и в концах и «продолжить» вне ПАУЗЫ отбрасываются с записью в журнал (правила 17, 23);
/// в таблицах первоисточника для них строки нет, формат строки там не задан.
fn Машина mut @общие_события(событие Входящее) -> Option[Переход] {
  ro тело_события = событие.тело
  match тело_события {

    СтопЧеловека { слово_человека, автор, источник } => {
      // ОБЩ стоп_человека #1: в любом состоянии, кроме ОСТАНОВЛЕНО, ОШИБКА, КОНЕЦ и ПАУЗА
      if в_конце_или_паузе(@состояние) { @отбросить(событие); return Some(Остаться) }
      @записать_слово_человека(событие, слово_человека, автор, источник)
      @писать_журнал("стоп человека: ${автор}, ${источник}, запись ${событие.идентификатор}")
      @предыдущее = имя_состояния(@состояние)
      // открытые_запросы без принятого ответа отменены (правило 18), кроме запросов к вложенным машинам
      @отменить_открытые_без_принятого(true)
      // вложенные получают сигнал «стоп» после фиксации шага; журнал «стоп передан <идентификатор_запроса>» на каждого (правило 35, пункт 8)
      @передать_вложенным("стоп")
      Some(Куда(ПАУЗА))
    }

    СтопОтРодителя { идентификатор_запроса } => {
      // ОБЩ стоп_от_родителя #1: те же состояния, если идентификатор_запроса события = запрос_вызова, иначе сигнал отброшен (правило 17)
      if в_конце_или_паузе(@состояние) { @отбросить(событие); return Some(Остаться) }
      if идентификатор_запроса != @запрос_вызова { @отбросить(событие); return Some(Остаться) }
      @писать_журнал("пауза: причина — стоп от родителя, ${идентификатор_запроса}, запись ${событие.идентификатор}")
      // слова человека не записываются (""): слов_человека не пишется
      @предыдущее = имя_состояния(@состояние)
      @отменить_открытые_без_принятого(true)
      @передать_вложенным("стоп")
      Some(Куда(ПАУЗА))
    }

    ОтменаЗапроса { идентификатор_запроса } => {
      // событие приходит в любом состоянии
      // ОБЩ отмена_запроса #1: идентификатор_запроса события не равен запрос_вызова
      if идентификатор_запроса != @запрос_вызова {
        @писать_журнал("отмена отброшена: чужой запрос ${идентификатор_запроса}, запись ${событие.идентификатор}")
        return Some(Остаться)
      }
      // ОБЩ отмена_запроса #2: = запрос_вызова, и ответ уже отдан (состояние — ОСТАНОВЛЕНО, ОШИБКА или КОНЕЦ)
      if идентификатор_запроса == @запрос_вызова && в_конце(@состояние) {
        @писать_журнал("отмена отброшена: ответ уже отдан, ${идентификатор_запроса}, запись ${событие.идентификатор}")
        return Some(Остаться)
      }
      // ОБЩ отмена_запроса #3: = запрос_вызова, и ответ не отдан
      if идентификатор_запроса == @запрос_вызова && !в_конце(@состояние) {
        @писать_журнал("отмена запроса: ${идентификатор_запроса}, запись ${событие.идентификатор}")
        @остановка = "отмена_запроса"
        // сигнал ставится ДО отмены: вложенные ещё лежат в открытые_запросы (правило 35, п. 10)
        @передать_вложенным("отмена")
        @отменить_открытые_без_принятого(false)    // правило 18
        return Some(Куда(ОСТАНОВЛЕНО))
      }
      // ОБЩ отмена_запроса #4: иначе
      Some(@ошибка_машины("ошибка машины: разбор отмены_запроса, ни одно условие не подошло"))
    }

    ПАУЗА_продолжить { .. } | ПАУЗА_продолжить_от_родителя { .. } => {
      // «продолжить» вне ПАУЗЫ отбрасывается с записью в журнал (правила 17, 23); в ПАУЗЕ — строки ПАУЗА #1 и #3
      if @состояние != ПАУЗА { @отбросить(событие); return Some(Остаться) }
      None
    }

    _ => None    // остальные события — строки состояний
  }
}
```

## Переходы

```nova
/// Переход по событию. тело_события — событие, которое ждёт состояние `текущее` (у операции — Сразу, у развилки — Сразу без данных);
/// событие — исходное событие шага: его данные (сторона, идентификатор) доступны всей цепочке до ближайшего обращения (правило 13).
/// Состояние пишется при фиксации; в «Что меняется» оно не повторяется.
fn Машина mut @перейти(текущее Состояние, тело_события Событие, событие Входящее) -> Переход {
  match текущее {

  // ===================== ЗАХОД — развилка =====================
  // Начало очередного захода проверки: смотрит, остались ли вопросы к свидетелю; есть — идёт к свидетелю, нет — сразу к проверке линзами.
  // Вход: вопрос_автора?; номер_захода; порядок_линз; находки_линзы[линза, номер_захода - 1]? (по каждой линзе из порядок_линз, из них вопросы проверяющих, `вопрос` = да)
  ЗАХОД => {
    // ЗАХОД #1: вопрос_автора есть
    if @вопрос_автора != None { return Куда(СВИДЕТЕЛЬ) }
    // ЗАХОД #2: вопрос_автора отсутствует, и в находках любой линзы захода номер_захода - 1 есть вопросы проверяющих (находки с `вопрос` = да)
    if @вопрос_автора == None && @есть_вопросы_проверяющих(@номер_захода - 1) { return Куда(СВИДЕТЕЛЬ) }
    // ЗАХОД #3: вопрос_автора отсутствует, и в находках любой линзы захода номер_захода - 1 вопросов проверяющих (находок с `вопрос` = да) нет
    if @вопрос_автора == None && !@есть_вопросы_проверяющих(@номер_захода - 1) { return Куда(ЗАМОК) }
    // ЗАХОД #4: иначе
    @ошибка_машины("ошибка машины: развилка ЗАХОД, ни одно условие не подошло")
  }

  // ===================== СВИДЕТЕЛЬ — обращение =====================
  // Просит свидетеля ответить на вопросы автора и проверяющих по фактам, чтобы проверка опиралась на сверенные ответы, а не на догадки.
  // При входе: свидетель отвечает на вопросы автора в предложении и проверяющих в находках любой линзы захода номер_захода - 1;
  //   исполнитель сверяет выдержки: несовпадение — один возврат «исправь выдержку» в том же запросе, снова несовпадение — строка «не подтверждено»;
  //   принятые ответы исполнитель записывает в хранилище.
  // Сторона: свидетель.
  // Вход (сторона): вопрос_автора?; находки_линзы[линза, номер_захода - 1]? (по каждой линзе, из них вопросы проверяющих, `вопрос` = да); предложение
  // Вход (исполнитель): номер_захода; порядок_линз (по ним выбирает находки захода номер_захода - 1)
  // Выход: ответы_свидетеля[номер_захода] []ОтветСвидетеля
  СВИДЕТЕЛЬ => match тело_события {
    // СВИДЕТЕЛЬ #1: ответ
    Ответ => {
      @вопрос_автора = None                      // сброс после ответа свидетеля
      Куда(ЗАМОК)
    }
    // СВИДЕТЕЛЬ #2: сбой (причина: КодСбоя)
    Сбой { причина } => {
      @писать_журнал("СВИДЕТЕЛЬ не ответил: ${причина}")
      @сбойное_обращение = "СВИДЕТЕЛЬ"
      Куда(СБОЙ)
    }
    _ => НеЖдёт
  }

  // ===================== ЗАМОК — операция =====================
  // Запоминает текст предложения на начало захода и запрещает его править, чтобы проверяющие читали одно и то же и правку за время проверки можно было заметить.
  // При входе: сохраняется копия предложения с отпечатком; предложение закрывается для записи.
  // Вход: предложение; порядок_линз
  // Выход: копия
  ЗАМОК => match тело_события {
    // ЗАМОК #1: сразу
    Сразу => {
      @к_отправке = @порядок_линз
      @ответившие = 0
      Куда(ЛИНЗЫ)
    }
    _ => НеЖдёт
  }

  // ===================== ЛИНЗЫ — обращение =====================
  // Рассылает предложение проверяющим (у каждого своя точка зрения — линза) и собирает их находки; число одновременных запросов ограничено параметром.
  // При входе: исполнитель отправляет запрос каждой линзе из к_отправке (правило 21); линза проверяет предложение и ответы свидетеля
  //   и возвращает находки; находок других линз этого захода она не видит; форму её находок проверяет исполнитель, возвращая неверную
  //   в том же запросе, и записывает принятые находки в хранилище.
  // Сторона: набор — линзы из порядок_линз; идентификатор линзы — идентификатор стороны; запросов одновременно не больше ПРЕДЕЛ_ЗАПРОСОВ.
  // При приёме (правило 14; запись линзы — событие.сторона): см. при_приёме_ЛИНЗЫ в разделе «Цикл исполнителя».
  // Вход (сторона): предложение; ответы_свидетеля[номер_захода]? (только запрошенной линзе; идентификатор линзы входит в запрос и возвращается с ответом)
  // Вход (исполнитель): номер_захода; к_отправке; линзы (потери_подряд и пробы при приёме); ответившие
  // Выход: находки_линзы[линза, номер_захода]; пробы
  ЛИНЗЫ => match тело_события {
    // ЛИНЗЫ #1: ответ
    Ответ => Куда(ВСЕ_ЗАКРЫТЫ)
    // ЛИНЗЫ #2: сбой (сторона: идентификатор линзы; причина: КодСбоя)
    Сбой { причина } => {
      @писать_журнал("линза ${событие.сторона} не ответила: ${причина}")
      Куда(ОТКАЗ)
    }
    _ => НеЖдёт
  }

  // ===================== ОТКАЗ — развилка =====================
  // Решает, что делать с линзой, которая не ответила: первый раз — отбросить её в этом заходе, второй подряд — спросить человека, не ответила и на повторе — отбросить.
  // Вход: линзы (только запись линзы событие.сторона: потери_подряд); к_отправке; номер_захода
  ОТКАЗ => {
    // ОТКАЗ #1: потери_подряд линзы событие.сторона = 1
    if @линзы(событие.сторона).потери_подряд == 1 {
      @писать_журнал("линза ${событие.сторона} отброшена в заходе ${@номер_захода}")
      return Куда(ВСЕ_ЗАКРЫТЫ)
    }
    // ОТКАЗ #2: потери_подряд линзы событие.сторона = 2
    if @линзы(событие.сторона).потери_подряд == 2 {
      @сбойное_обращение = "ЛИНЗЫ"
      @к_отправке.insert(0, событие.сторона)
      return Куда(СБОЙ)
    }
    // ОТКАЗ #3: потери_подряд линзы событие.сторона = 3
    if @линзы(событие.сторона).потери_подряд == 3 {
      @установить_потери(событие.сторона, 1)
      @писать_журнал("линза ${событие.сторона} отброшена в заходе ${@номер_захода}")
      return Куда(ВСЕ_ЗАКРЫТЫ)
    }
    // ОТКАЗ #4: иначе
    @ошибка_машины("ошибка машины: развилка ОТКАЗ, ни одно условие не подошло")
  }

  // ===================== ВСЕ_ЗАКРЫТЫ — развилка =====================
  // Проверяет, все ли линзы разобраны: остались неотправленные или ждущие ответа — идёт к ним, все закрыты — дальше, а если не ответила ни одна — останавливает совещание.
  // Вход: к_отправке; открытые_запросы; ответившие
  ВСЕ_ЗАКРЫТЫ => {
    // ВСЕ_ЗАКРЫТЫ #1: к_отправке — не пустой список
    if @к_отправке.len() > 0 { return Куда(ЛИНЗЫ) }
    // ВСЕ_ЗАКРЫТЫ #2: к_отправке — пустой список, и открытые_запросы — не пустой список
    if @к_отправке.len() == 0 && @открытые_запросы.len() > 0 { return Куда(ЛИНЗЫ) }
    // ВСЕ_ЗАКРЫТЫ #3: к_отправке — пустой список, открытые_запросы — пустой список, и ответившие больше 0
    if @к_отправке.len() == 0 && @открытые_запросы.len() == 0 && @ответившие > 0 { return Куда(РАЗБЛОК) }
    // ВСЕ_ЗАКРЫТЫ #4: к_отправке — пустой список, открытые_запросы — пустой список, и ответившие = 0
    if @к_отправке.len() == 0 && @открытые_запросы.len() == 0 && @ответившие == 0 {
      @остановка = "ни одна линза не ответила"
      return Куда(ОСТАНОВЛЕНО)
    }
    // ВСЕ_ЗАКРЫТЫ #5: иначе
    @ошибка_машины("ошибка машины: развилка ВСЕ_ЗАКРЫТЫ, ни одно условие не подошло")
  }

  // ===================== СБОЙ — обращение =====================
  // Спрашивает человека, что делать, когда роль не ответила: повторить обращение или остановить совещание.
  // При входе: ворота В13: запрос обращения «сбойное_обращение» закончился сбоем (у ЛИНЗЫ — вторым подряд у линзы, чей идентификатор уже стоит
  //   первым в к_отправке); причина — в журнале. Повтор линзы, не ответившей и на этот раз, ворот не открывает: линза отбрасывается
  //   (ОТКАЗ, потери_подряд = 3), как в `check_meeting`. Это обращение — человеку: срока бездействия и сбоя у него нет (правило 19).
  // Сторона: человек.
  // Вход: сбойное_обращение
  // Выход: исход ворот
  СБОЙ => match тело_события {
    // СБОЙ #1: В13: «повторить»
    В13_повторить => Куда(ПОВТОР_ОБРАЩЕНИЯ)
    // СБОЙ #2: В13: «остановить совещание»
    В13_остановить_совещание => {
      @остановка = "${@сбойное_обращение}: остановить совещание"
      Куда(ОСТАНОВЛЕНО)
    }
    _ => НеЖдёт
  }

  // ===================== ПОВТОР_ОБРАЩЕНИЯ — развилка =====================
  // Возвращает машину к той роли, которая не ответила, чтобы обратиться к ней ещё раз.
  // Вход: сбойное_обращение
  ПОВТОР_ОБРАЩЕНИЯ => {
    // ПОВТОР_ОБРАЩЕНИЯ #1: сбойное_обращение = «СВИДЕТЕЛЬ»
    if @сбойное_обращение == "СВИДЕТЕЛЬ" { return Заново(СВИДЕТЕЛЬ) }
    // ПОВТОР_ОБРАЩЕНИЯ #2: сбойное_обращение = «ЛИНЗЫ»
    if @сбойное_обращение == "ЛИНЗЫ" { return Заново(ЛИНЗЫ) }
    // ПОВТОР_ОБРАЩЕНИЯ #3: сбойное_обращение = «ПРАВКА»
    if @сбойное_обращение == "ПРАВКА" { return Заново(ПРАВКА) }
    // ПОВТОР_ОБРАЩЕНИЯ #4: сбойное_обращение = «ВОПРОС»
    if @сбойное_обращение == "ВОПРОС" { return Заново(ВОПРОС) }
    // ПОВТОР_ОБРАЩЕНИЯ #5: иначе
    @ошибка_машины("ошибка машины: развилка ПОВТОР_ОБРАЩЕНИЯ, ни одно условие не подошло")
  }

  // ===================== РАЗБЛОК — операция =====================
  // Снова разрешает править предложение: линзы закончили чтение.
  // При входе: предложение открывается для записи.
  // Вход: предложение
  // Выход: нет
  РАЗБЛОК => match тело_события {
    // РАЗБЛОК #1: сразу
    Сразу => Куда(СВЕРКА)
    _ => НеЖдёт
  }

  // ===================== СВЕРКА — развилка =====================
  // Проверяет, не изменили ли предложение за время проверки: изменено или нечитаемо — заход недействителен, нужен человек; не изменено — идём дальше.
  // Вход: предложение? (не прочитано); копия
  СВЕРКА => {
    // СВЕРКА #1: предложение прочитано и равно копии
    if @предложение_прочитано() && Some(@предложение) == @копия { return Куда(ФИЛЬТР) }
    // СВЕРКА #2: предложение прочитано и отличается от копии
    if @предложение_прочитано() && Some(@предложение) != @копия { return Куда(ИЗМЕНЁН) }
    // СВЕРКА #3: предложение не прочитано
    if !@предложение_прочитано() { return Куда(ИЗМЕНЁН) }
    // СВЕРКА #4: иначе
    @ошибка_машины("ошибка машины: развилка СВЕРКА, ни одно условие не подошло")
  }

  // ===================== ИЗМЕНЁН — обращение =====================
  // Показывает человеку исходную копию и изменённое предложение и спрашивает: оставить правку, вернуть копию или остановить совещание.
  // При входе: ворота В13 с копией и изменённым предложением.
  // Сторона: человек.
  // Вход (сторона): копия; предложение?
  // Вход (исполнитель): номер_захода; аннулирований[номер_захода]
  // Выход: исход ворот
  ИЗМЕНЁН => match тело_события {
    // ИЗМЕНЁН #1: В13: «оставить правку»
    В13_оставить_правку => {
      @аннулирований.insert(@номер_захода, @аннулирований(@номер_захода) + 1)
      Куда(АННУЛ)
    }
    // ИЗМЕНЁН #2: В13: «вернуть копию»
    В13_вернуть_копию => {
      @аннулирований.insert(@номер_захода, @аннулирований(@номер_захода) + 1)
      Куда(ВОЗВРАТ)
    }
    // ИЗМЕНЁН #3: В13: «остановить совещание»
    В13_остановить_совещание => {
      @остановка = "ИЗМЕНЁН: остановить совещание"
      Куда(ОСТАНОВЛЕНО)
    }
    _ => НеЖдёт
  }

  // ===================== ВОЗВРАТ — операция =====================
  // Заменяет изменённое предложение сохранённой копией.
  // При входе: предложение заменяется копией.
  // Вход: копия
  // Выход: предложение
  ВОЗВРАТ => match тело_события {
    // ВОЗВРАТ #1: сразу
    Сразу => Куда(АННУЛ)
    _ => НеЖдёт
  }

  // ===================== АННУЛ — операция =====================
  // Убирает в архив ответы и находки недействительного захода, чтобы они не попали в счёт и в контекст ролей, и начинает заход заново.
  // При входе: находки_линзы[линза, номер_захода] по каждой линзе и ответы_свидетеля[номер_захода] переносятся в архив недействительных заходов
  //   (суффикс `*.void-<k>.md`, k — аннулирований[номер_захода]).
  // Вход: номер_захода; аннулирований[номер_захода]; порядок_линз; ответы_свидетеля[номер_захода]?; находки_линзы[линза, номер_захода] (по каждой линзе из порядок_линз)
  // Выход: нет
  АННУЛ => match тело_события {
    // АННУЛ #1: сразу
    Сразу => Куда(ЗАХОД)
    _ => НеЖдёт
  }

  // ===================== ФИЛЬТР — операция =====================
  // Убирает из находок несостоятельные мнения (выдуманные цитаты, находки без доказательства) и отмечает линзы, у которых не осталось критических находок.
  // При входе: убираются несостоятельные мнения (четыре признака, `task-runner.md`, «Совещание агентов», «Несостоятельные мнения»; среди них ответ
  //   свидетеля, у которого сверка «не подтверждено»), каждое идёт в счёт по моделям.
  // Вход: номер_захода; порядок_линз; находки_линзы[линза, номер_захода] (по каждой линзе из порядок_линз); ответы_свидетеля[номер_захода]?
  // Выход: находки_линзы[линза, номер_захода] (после фильтра — те же объекты хранилища без несостоятельных мнений, запись на то же место);
  //   линзы_без_критических []str (идентификаторы)
  ФИЛЬТР => match тело_события {
    // ФИЛЬТР #1: сразу (линзы_без_критических: []Текст — идентификаторы)
    Сразу_ФИЛЬТР { линзы_без_критических } => {
      for ид in линзы_без_критических { @установить_пробы(ид, 0) }
      Куда(СВОД)
    }
    _ => НеЖдёт
  }

  // ===================== СВОД — операция =====================
  // Собирает находки всех линз в одну сводку с итоговой строкой: сколько критических, значимых и желательных находок и сколько проб.
  // При входе: записывается свод[номер_захода]: итоговая строка «Заход <номер_захода>: критических K, значимых Z, желательных D, проб P»
  //   (K, Z и D — суммы по линзам, P — наименьшее из проб линз), затем находки с меткой линзы.
  // Вход: номер_захода; находки_линзы[линза, номер_захода] и пробы (по каждой линзе из линзы); пробы (по каждой линзе из линзы)
  // Выход: свод[номер_захода]
  СВОД => match тело_события {
    // СВОД #1: сразу
    Сразу => Куда(РАЗБОР)
    _ => НеЖдёт
  }

  // ===================== РАЗБОР — развилка =====================
  // Читает итоговую строку: чистый заход без проб не засчитывается и идёт заново, в остальных случаях сводка уходит человеку.
  // Вход: свод[номер_захода]; номер_захода; без_проб_подряд
  РАЗБОР => match @свод(@номер_захода) {
    // РАЗБОР #1: итог свода есть, и критических больше 0
    Some(итог) if итог.критических > 0 => {
      @без_проб_подряд = 0
      Куда(В3)
    }
    // РАЗБОР #2: итог свода есть, критических нет, и проб не меньше ПРОБ_В_ЧИСТОМ
    Some(итог) if итог.критических == 0 && итог.проб >= ПРОБ_В_ЧИСТОМ => {
      @без_проб_подряд = 0
      Куда(В3)
    }
    // РАЗБОР #3: итога свода нет
    None => {
      @писать_журнал("итоговой строки нет")
      @без_проб_подряд = 0
      Куда(В3)
    }
    // РАЗБОР #4: итог свода есть, критических нет, и проб меньше ПРОБ_В_ЧИСТОМ
    Some(итог) if итог.критических == 0 && итог.проб < ПРОБ_В_ЧИСТОМ => {
      @писать_журнал("заход ${@номер_захода}: чистый без проб, не засчитан")
      @номер_захода += 1
      @без_проб_подряд += 1
      Куда(БЕЗ_ПРОБ)
    }
    // РАЗБОР #5: иначе
    _ => @ошибка_машины("ошибка машины: развилка РАЗБОР, ни одно условие не подошло")
  }

  // ===================== БЕЗ_ПРОБ — развилка =====================
  // Считает чистые заходы без проб подряд: первый — просто повторить проверку, второй — спросить человека.
  // Вход: без_проб_подряд
  БЕЗ_ПРОБ => {
    // БЕЗ_ПРОБ #1: без_проб_подряд = 1
    if @без_проб_подряд == 1 { return Куда(ЗАХОД) }
    // БЕЗ_ПРОБ #2: без_проб_подряд больше 1
    if @без_проб_подряд > 1 { return Куда(ПОВТОР) }
    // БЕЗ_ПРОБ #3: иначе
    @ошибка_машины("ошибка машины: развилка БЕЗ_ПРОБ, ни одно условие не подошло")
  }

  // ===================== ПОВТОР — обращение =====================
  // Спрашивает человека, что делать после второго подряд чистого захода без проб: повторить проверку или остановить.
  // При входе: ворота В13: проверка второй раз подряд без проб.
  // Сторона: человек.
  // Вход: нет.
  // Выход: исход ворот
  ПОВТОР => match тело_события {
    // ПОВТОР #1: В13: «повторить»
    В13_повторить => Куда(ЗАХОД)
    // ПОВТОР #2: В13: «остановить»
    В13_остановить => {
      @остановка = "ПОВТОР: остановить"
      Куда(ОСТАНОВЛЕНО)
    }
    _ => НеЖдёт
  }

  // ===================== В3 — обращение =====================
  // Показывает человеку находки и пробы захода; он может поднять критичность находок или не засчитать заход, если пробы — не настоящие пробы.
  // При входе: ворота В3: человек читает находки и пробы, может поднять критичность; по его настройке ворота только показывают и идут дальше
  //   как «засчитан» с находками свода без поправки.
  // Сторона: человек.
  // Вход (сторона): свод[номер_захода]; находки_линзы[линза, номер_захода] (по каждой линзе)
  // Вход (исполнитель): номер_захода; порядок_линз
  // Выход: исход ворот; находки_В3 []Находка (после поправки человека)
  В3 => match тело_события {
    // В3 #1: В3: «не засчитан»
    В3_не_засчитан => {
      @писать_журнал("заход ${@номер_захода}: пробы — не пробы, не засчитан")
      @номер_захода += 1
      Куда(ЗАХОД)
    }
    // В3 #2: В3: «засчитан» (находки_В3: []Находка)
    В3_засчитан { находки_В3: новые_находки } => {
      @номер_захода += 1
      @находки_В3 = новые_находки
      Куда(ИТОГ)
    }
    _ => НеЖдёт
  }

  // ===================== ИТОГ — развилка =====================
  // Подводит итог засчитанного захода: есть критические находки — нужна правка, чистых заходов подряд ещё мало — ещё заход, достаточно — итог можно принимать.
  // Вход: находки_В3; серия_чистых; открытые
  ИТОГ => {
    // ИТОГ #1: в находки_В3 есть критические
    if есть_критические(@находки_В3) {
      @серия_чистых = 0
      @открытые = объединить_без_повторов(@открытые, желательные_и_значимые_с_повтором(@находки_В3))
      return Куда(ПОТОЛОК)
    }
    // ИТОГ #2: в находки_В3 критических нет, и серия_чистых + 1 меньше ЧИСТЫХ_ПОДРЯД
    if !есть_критические(@находки_В3) && @серия_чистых + 1 < ЧИСТЫХ_ПОДРЯД {
      @открытые = объединить_без_повторов(@открытые, желательные(@находки_В3))
      @серия_чистых += 1
      return Куда(ЗАХОД)
    }
    // ИТОГ #3: в находки_В3 критических нет, и серия_чистых + 1 не меньше ЧИСТЫХ_ПОДРЯД
    if !есть_критические(@находки_В3) && @серия_чистых + 1 >= ЧИСТЫХ_ПОДРЯД {
      @открытые = объединить_без_повторов(@открытые, желательные_и_значимые(@находки_В3))
      @серия_чистых = 0
      return Куда(ПРИНЯТИЕ)
    }
    // ИТОГ #4: иначе
    @ошибка_машины("ошибка машины: развилка ИТОГ, ни одно условие не подошло")
  }

  // ===================== ПОТОЛОК — развилка =====================
  // Проверяет, не исчерпан ли предел числа заходов: нет — автор правит предложение, исчерпан — решает человек.
  // Вход: номер_захода; заход_отсчёта
  ПОТОЛОК => {
    // ПОТОЛОК #1: (номер_захода - 1) - заход_отсчёта + 1 меньше ПОТОЛОК_ЗАХОДОВ
    if (@номер_захода - 1) - @заход_отсчёта + 1 < ПОТОЛОК_ЗАХОДОВ { return Куда(ПРАВКА) }
    // ПОТОЛОК #2: (номер_захода - 1) - заход_отсчёта + 1 не меньше ПОТОЛОК_ЗАХОДОВ
    if (@номер_захода - 1) - @заход_отсчёта + 1 >= ПОТОЛОК_ЗАХОДОВ { return Куда(В9) }
    // ПОТОЛОК #3: иначе
    @ошибка_машины("ошибка машины: развилка ПОТОЛОК, ни одно условие не подошло")
  }

  // ===================== В9 — обращение =====================
  // Сообщает человеку, что предел заходов исчерпан, и спрашивает: дать ещё заход (с его указанием), остановиться с открытыми находками или остановить совещание.
  // При входе: ворота В9: потолок заходов.
  // Сторона: человек.
  // Вход (сторона): находки_В3; номер_захода; заход_отсчёта
  // Вход (исполнитель): открытые
  // Выход: исход ворот; решение_человека str
  В9 => match тело_события {
    // В9 #1: В9: «ещё заход» (решение_человека: Текст)
    В9_ещё_заход { решение_человека } => {
      @заход_отсчёта = @номер_захода
      @указание_автору = решение_человека        // сузить или разбить
      Куда(ПРАВКА)
    }
    // В9 #2: В9: «остановиться»
    В9_остановиться => {
      @заход_отсчёта = @номер_захода
      @открытые = объединить_без_повторов(@открытые, критические_и_значимые_без_повтора(@находки_В3))
      Куда(ПРИНЯТИЕ)
    }
    // В9 #3: В9: «остановить совещание»
    В9_остановить_совещание => {
      @заход_отсчёта = @номер_захода
      @остановка = "В9: остановить совещание"
      Куда(ОСТАНОВЛЕНО)
    }
    _ => НеЖдёт
  }

  // ===================== ПРАВКА — обращение =====================
  // Просит автора исправить предложение по находкам прошлого захода; автор либо заканчивает, либо останавливается с вопросом к человеку.
  // При входе: автор правит рабочую копию предложения по критическим находкам и значимым находкам без повтора (критические всегда, значимые только без повтора) из находки_В3 (заход
  //   номер_захода - 1) и по указанию человека (указание_автору), дописывает «Изменения захода» и возвращает итог; принятую копию исполнитель
  //   записывает в предложение при приёме ответа, если предложение не менялось с начала попытки (правило 14).
  // Сторона: автор.
  // Вход (сторона): предложение; находки_В3 (из них критические всегда и значимые только без повтора); указание_автору?
  // Вход (исполнитель): номер_захода
  // Выход: итог_правки ИтогПравки
  ПРАВКА => match тело_события {
    // ПРАВКА #1: ответ: закончена
    Ответ_закончена => {
      @указание_автору = ""
      Куда(ЗАХОД)
    }
    // ПРАВКА #2: ответ: вопрос (любое стоп-слово автора читается как вопрос)
    Ответ_вопрос => {
      @указание_автору = ""
      Куда(В7)
    }
    // ПРАВКА #3: сбой (причина: КодСбоя)
    Сбой { причина } => {
      @писать_журнал("ПРАВКА: автор не ответил: ${причина}")
      @сбойное_обращение = "ПРАВКА"
      Куда(СБОЙ)
    }
    _ => НеЖдёт
  }

  // ===================== В7 — обращение =====================
  // Передаёт человеку вопрос автора и получает его ответ.
  // При входе: ворота В7: человек отвечает на вопрос автора.
  // Сторона: человек.
  // Вход: вопрос_автора
  // Выход: ответ_человека str (слово человека; источник записывается вместе с ним)
  В7 => match тело_события {
    // В7 #1: В7: «ответил» (ответ_человека: Текст)
    В7_ответил { ответ_человека: слово_ответа } => {
      @ответ_человека = слово_ответа
      Куда(ВОПРОС)
    }
    _ => НеЖдёт
  }

  // ===================== ВОПРОС — обращение =====================
  // Возвращает автору ответ человека, чтобы он продолжил правку; автор либо заканчивает, либо спрашивает снова.
  // При входе: автор продолжает правку рабочей копии по тем же находкам_В3 и с ответом человека и возвращает итог; принятую копию исполнитель
  //   записывает в предложение при приёме ответа, если предложение не менялось с начала попытки (правило 14).
  // Сторона: автор.
  // Вход: вопрос_автора; предложение; находки_В3 (из них критические всегда и значимые только без повтора); ответ_человека (только автору)
  // Выход: итог_правки ИтогПравки
  ВОПРОС => match тело_события {
    // ВОПРОС #1: ответ: закончена
    Ответ_закончена => Куда(ЗАХОД)
    // ВОПРОС #2: ответ: вопрос
    Ответ_вопрос => Куда(В7)
    // ВОПРОС #3: сбой (причина: КодСбоя)
    Сбой { причина } => {
      @писать_журнал("ВОПРОС: автор не ответил: ${причина}")
      @сбойное_обращение = "ВОПРОС"
      Куда(СБОЙ)
    }
    _ => НеЖдёт
  }

  // ===================== ПРИНЯТИЕ — обращение =====================
  // Просит человека подтвердить итог и записать источник решения.
  // При входе: ворота «принять итог»: человек подтверждает решение и запись источника.
  // Сторона: человек.
  // Вход: предложение; номер_захода; открытые
  // Выход: подтверждение str
  ПРИНЯТИЕ => match тело_события {
    // ПРИНЯТИЕ #1: ПРИНЯТИЕ: «подтвердил» (подтверждение: Текст)
    ПРИНЯТИЕ_подтвердил { подтверждение: слово_подтверждения } => {
      @подтверждение = слово_подтверждения
      Куда(КОНЕЦ)
    }
    _ => НеЖдёт
  }

  // ===================== ПАУЗА — обращение =====================
  // Держит машину остановленной по слову человека, пока он не скажет продолжить (машина вернётся туда, где её остановили) или остановить совещание.
  // При входе: ворота «пауза»: человек остановил машину, открытые_запросы отменены (кроме запросов к вложенным машинам: они получают сигнал «стоп»,
  //   правило 35); человек продолжает с прерванного состояния или останавливает совещание. Право записи на предложение пауза не меняет: закрытое
  //   в окне проверки линз остаётся закрытым, а кто хочет его править, выбирает «остановить совещание» (`doc/open-questions.md`, раздел 9).
  // Сторона: человек — события «продолжить» и «остановить совещание»; родитель — события «продолжить от родителя» и «остановить от родителя».
  // Вход: предыдущее; запрос_вызова (идентификатор запроса вызова)
  // Выход: исход ворот
  // «Продолжить» и «продолжить от родителя» ведут в состояние по имени из «предыдущее» (единственный переход с переменной в «куда», правило 24)
  //   и входят в него заново (повторный вход, правило 12): у ЛИНЗ уходят запросы линзам из к_отправке, у остальных обращений — новый запрос, если
  //   по обращению нет принятого запроса; принятые до стопа ответы остаются. «Предыдущее» при этом не пишется (правила 13 и 24).
  ПАУЗА => match тело_события {
    // ПАУЗА #1: ПАУЗА: «продолжить» (слово_человека; автор; источник)
    ПАУЗА_продолжить { слово_человека, автор, источник } => {
      @записать_слово_человека(событие, слово_человека, автор, источник)
      @писать_журнал("продолжение с ${@предыдущее}: ${автор}, ${источник}, запись ${событие.идентификатор}")
      @передать_вложенным("продолжить")             // после фиксации шага, журнал «продолжить передано <идентификатор_запроса>»
      Куда(состояние_по_имени(@предыдущее))
    }
    // ПАУЗА #2: ПАУЗА: «остановить совещание»
    ПАУЗА_остановить_совещание => {
      @остановка = "ПАУЗА: остановить совещание"
      @передать_вложенным("остановить")             // правило 35, пункты 8 и 10
      Куда(ОСТАНОВЛЕНО)
    }
    // ПАУЗА #3: ПАУЗА: «продолжить от родителя» (если идентификатор_запроса события = запрос_вызова, иначе отброшено)
    ПАУЗА_продолжить_от_родителя { идентификатор_запроса } => {
      if идентификатор_запроса != @запрос_вызова { @отбросить(событие); return Остаться }
      @писать_журнал("продолжение с ${@предыдущее}: от родителя ${идентификатор_запроса}, запись ${событие.идентификатор}")
      // слова человека не записываются ("")
      @передать_вложенным("продолжить")
      Куда(состояние_по_имени(@предыдущее))
    }
    // ПАУЗА #4: ПАУЗА: «остановить от родителя» (если идентификатор_запроса события = запрос_вызова, иначе отброшено)
    ПАУЗА_остановить_от_родителя { идентификатор_запроса } => {
      if идентификатор_запроса != @запрос_вызова { @отбросить(событие); return Остаться }
      @остановка = "ПАУЗА: остановить совещание"
      @передать_вложенным("остановить")
      Куда(ОСТАНОВЛЕНО)
    }
    _ => НеЖдёт
  }

  // ===================== концы: переходов нет =====================
  // ОСТАНОВЛЕНО — конец. Заканчивает совещание без принятого итога и записывает, почему и какие находки остались; решение — за человеком вне машины.
  // Вход: остановка; предложение; открытые; находки_В3
  ОСТАНОВЛЕНО => недостижимо("конец: переходов нет; работа при входе — в «Концы и ответ»")

  // ОШИБКА — конец. Заканчивает совещание, если сама машина попала в непредусмотренное положение; это дефект машины или реализации, его разбирает человек.
  // Вход: предложение; все данные машины (Все переменные и хранилища — в журнал)
  ОШИБКА => недостижимо("конец: переходов нет; работа при входе — в «Концы и ответ»")

  // КОНЕЦ — конец. Записывает принятое решение с источником, числом заходов и открытыми находками: совещание закончено успешно.
  // Вход: предложение; подтверждение; номер_захода; открытые
  КОНЕЦ => недостижимо("конец: переходов нет; работа при входе — в «Концы и ответ»")
  }
}
```

```nova
/// Работа концов при входе (в последнем, повторяемом без вреда этапе фиксации) и ответ вызвавшей стороне.
/// Вход в любой конец отменяет все открытые запросы (правило 22); машина отвечает ровно один раз (правило 35).
fn Исполнитель mut @при_входе_в_конец(конец Состояние) => match конец {
  // ОСТАНОВЛЕНО: предложение открывается для записи; в журнал — «совещание остановлено: <остановка>», затем незакрытые находки:
  //   открытые и находки_В3, не вошедшие в открытые (находки считаются одной по доказательству); итог не принят, программа продолжает остальную работу.
  ОСТАНОВЛЕНО => {
    @открыть_для_записи("предложение")
    @машина.писать_журнал("совещание остановлено: ${@машина.остановка}")
    @журнал_находок(@машина.открытые)
    @журнал_находок(не_вошедшие_в(@машина.находки_В3, @машина.открытые))
  }
  // ОШИБКА: предложение открывается для записи; в журнал — запись из перехода и данные машины; совещание остановлено, итог не принят;
  //   это дефект машины или реализации, решает человек вне машины.
  ОШИБКА => {
    @открыть_для_записи("предложение")
    @машина.писать_журнал(@машина.запись_перехода)
    @журнал_данных_машины()
  }
  // КОНЕЦ: предложение открывается для записи; в журнал — решение (предложение), источник — подтверждение, число заходов номер_захода,
  //   открытые как «открыто»; приписка: «значимые находки прежних заходов, не вошедшие в «открыто», — в файлах заходов»;
  //   тип проверяющего в каждом заходе — по `methodology.md`, раздел 18.
  КОНЕЦ => {
    @открыть_для_записи("предложение")
    @журнал_решения(@машина.предложение, @машина.подтверждение, @машина.номер_захода, @машина.открытые)
    @машина.писать_журнал("значимые находки прежних заходов, не вошедшие в «открыто», — в файлах заходов")
  }
  _ => ()
}

/// Отказ вызвавшей стороне: конверт ответа берётся из запроса вызова.
fn Машина @отказ_по(вызов Запрос[ВходСовещания], причина КодСбоя, текст str) -> Исход[ИтогСовещания] {
  ro в = вызов
  Отказ(ОтветОтказ { запрос: @запрос_вызова, сторона: в.сторона, причина: причина, текст: текст, трасса: в.трасса, номер_шага: в.номер_шага })
}

/// Таблица «конец → ответ» первоисточника (раздел «Контракт машины»): каждый конец и каждое значение остановка — одна строка.
fn Машина @ответ_по_концу(вызов Запрос[ВходСовещания]) -> Исход[ИтогСовещания] {
  ro в = вызов
  match @состояние {
    // КОНЕЦ, условие входа: всегда → СРезультатом: итог с числом заходов и открытыми находками
    КОНЕЦ => СРезультатом(ОтветСРезультатом {
      запрос: @запрос_вызова, сторона: в.сторона, трасса: в.трасса, номер_шага: в.номер_шага,
      результат: ИтогСовещания { решение: @предложение, источник: @подтверждение, число_заходов: @номер_захода, открытые: @открытые } })
    // ОШИБКА, условие входа: всегда (дефект машины) → Отказ, НетРезультата; текст — запись из перехода
    ОШИБКА => @отказ_по(вызов, НетРезультата, @запись_перехода)
    ОСТАНОВЛЕНО => match @остановка {
      // ОСТАНОВЛЕНО: остановка = «ни одна линза не ответила» → Отказ, НетРезультата
      "ни одна линза не ответила" => @отказ_по(вызов, НетРезультата, @остановка)
      // ОСТАНОВЛЕНО: остановка = «В9: остановить совещание» (потолок заходов с открытыми находками) → Отказ, ПотолокЗаходов
      "В9: остановить совещание" => @отказ_по(вызов, ПотолокЗаходов, @остановка)
      // ОСТАНОВЛЕНО: «ПАУЗА: остановить совещание», «<сбойное_обращение>: остановить совещание», «ИЗМЕНЁН: остановить совещание»
      //   или «ПОВТОР: остановить» (слово человека; у вложенной машины — сигнал «остановить от родителя» в ПАУЗЕ) → Отказ, ОстановленоЧеловеком
      "ПАУЗА: остановить совещание" | "ИЗМЕНЁН: остановить совещание" | "ПОВТОР: остановить" => @отказ_по(вызов, ОстановленоЧеловеком, @остановка)
      х if х == "${@сбойное_обращение}: остановить совещание" => @отказ_по(вызов, ОстановленоЧеловеком, @остановка)
      // ОСТАНОВЛЕНО: остановка = «отмена_запроса» → Отказ, ОтмененоРодителем
      "отмена_запроса" => @отказ_по(вызов, ОтмененоРодителем, @остановка)
      _ => недостижимо("значение остановка вне таблицы «конец → ответ»: новое значение добавляет строку таблицы")
    }
    _ => недостижимо("ответ отдают только концы")
  }
}
```

## Цикл исполнителя

```nova
/// Снимок: всё состояние машины и исполнителя на конец шага (поля `Машина`: состояние, предыдущее, открытые и принятые запросы, счётчики, хранилища; очередь входящих событий; запрос вызова; готовый ответ; необратимые действия, ждущие выполнения).
type Снимок {
  машина Машина,
  очередь []Входящее,
  вызов Option[Запрос[ВходСовещания]],
  готовый_ответ Option[Исход[ИтогСовещания]],
  необратимые []Необратимое,
}

/// Необратимое действие во внешнем мире: последний этап фиксации, повторяемый без вреда (правило 13: переименование в архив, смена права записи).
type Необратимое enum
  | ЗакрытьДляЗаписи(str)
  | ОткрытьДляЗаписи(str)
  | ПеренестиВАрхив { номер int, суффикс int }

/// Ошибка операции хранилища (запись автомата): минимальный текст причины.
type ОшибкаХранилища { текст str }

/// Хранилище снимков по идентификатору запроса — эффект: как сохранять и загружать, выбирает вызывающий код (`with Хранилище = обработчик`).
/// Обработчик — любой (база, файл поверх `Fs`/`Db`, очередь сообщений), вне этого файла. Ошибка операции — через `Result`.
type Хранилище effect {
  fn сохранить(идентификатор_запроса str, снимок Снимок) -> Result[(), ОшибкаХранилища]
  fn загрузить(идентификатор_запроса str) -> Result[Option[Снимок], ОшибкаХранилища]
}

/// Событие: машина как вызываемое событие другой машины (правило 35). Вход и выход — типы запроса и итога.
type Вызываемое[Вход, Выход] protocol {
  mut @вызвать(запрос Запрос[Вход]) -> Исход[Выход]
}

/// Исполнитель: ведёт `Машина` по правилам 13–24 и 35 спецификации; единственный пишет в хранилище и отправляет запросы.
/// Данные заходят только через события; запросы отправляются только после фиксации шага; снимок сохраняется до открытия ворот.
/// Исполнитель с машиной совещания реализует `Вызываемое[ВходСовещания, ИтогСовещания]` структурно (метод `вызвать`).
type Исполнитель {
  машина Машина,                               // данные и логика автомата
  вызов Option[Запрос[ВходСовещания]],         // запрос, которым машину вызвали (конверт исполнителя)
  очередь []Входящее,                          // входящие события в порядке прихода (правило 13)
  готовый_ответ Option[Исход[ИтогСовещания]], // ответ, отданный вызвавшей стороне; машина отвечает ровно один раз (правило 35)
  необратимые []Необратимое,                   // действия шага, которые выполняются после сохранения; в снимке, чтобы повториться после перезапуска
  в_работе bool,                               // цикл идёт: повтор запроса не запускает вторую машину (исполнитель на запрос один; исключение процессов — вне файла)
}

/// Исполнитель с пустой машиной; хранилище — эффект `Хранилище`, обработчик подставляет вызывающий код.
fn Исполнитель.new() -> Исполнитель => {
  машина: Машина.new(),
  вызов: None,
  очередь: []Входящее.new(),
  готовый_ответ: None,
  необратимые: []Необратимое.new(),
  в_работе: false,
}

/// Точка подстановки хранилища: обработчик выбирает вызывающий код, один раз (`with`); промежуточные функции эффект не повторяют.
fn запуск_совещания(запрос Запрос[ВходСовещания]) -> Исход[ИтогСовещания] =>
  with Хранилище = обработчик_хранилища {     // псевдокод: обработчик (база, файл поверх Fs/Db) — любой, вне файла
    mut исполнитель = Исполнитель.new()
    исполнитель.вызвать(запрос)
  }

/// Событие `Вызываемое[ВходСовещания, ИтогСовещания]`: повтор запроса с тем же идентификатором возвращает готовый ответ или продолжает прерванную работу (правило 35, п. 4).
fn Исполнитель mut @вызвать(запрос Запрос[ВходСовещания]) -> Исход[ИтогСовещания] {
  // прогон идёт: повтор не поднимает вторую машину поверх живой, а ждёт готовый ответ идущего прогона
  if @в_работе { return @ждать_готовый_ответ() }
  match @загрузить_снимок(запрос.идентификатор_запроса) {
    None => @начать(запрос)
    Some(снимок) => match снимок.готовый_ответ {
      Some(готовый) => готовый
      None => match @возобновить(запрос.идентификатор_запроса) {
        Some(ответ) => ответ
        None => недостижимо("снимок только что загружен: возобновить его находит")
      }
    }
  }
}

/// Новый запрос: создаёт машину, записи линз, входит в ЗАХОД, фиксирует шаг и входит в цикл.
fn Исполнитель mut @начать(запрос Запрос[ВходСовещания]) -> Исход[ИтогСовещания] {
  @в_работе = true
  @вызов = Some(запрос)
  @машина = Машина.new()
  @очередь = []Входящее.new()
  @готовый_ответ = None
  @необратимые = []Необратимое.new()
  // начальные значения — раздел «Данные»
  @машина.запрос_вызова = запрос.идентификатор_запроса
  @машина.трасса = @новая_трасса()                  // дочерняя от внешней (запрос.трасса)
  @машина.предложение = запрос.вход.предложение
  @машина.вопрос_автора = запрос.вход.вопрос_автора
  @машина.порядок_линз = запрос.вход.порядок_линз
  for ид in @машина.порядок_линз {
    @машина.линзы.insert(ид, Линза { идентификатор: ид, потери_подряд: 0, пробы: 0, попытка: 0 })
  }
  @машина.состояние = ЗАХОД
  @выполнить_шаг(@новое_событие("старт"), Куда(ЗАХОД))
  @цикл()
}

/// Продолжение после остановки исполнителя: загружает снимок и продолжает с сохранённого `состояние`; None — снимка нет.
/// Ждавшая обращения машина повторно получает только запросы без принятого ответа; на ПАУЗЕ остаётся, пока человек не скажет «продолжить» (правила 12, 14, 22).
fn Исполнитель mut @возобновить(идентификатор_запроса str) -> Option[Исход[ИтогСовещания]] {
  match @загрузить_снимок(идентификатор_запроса) {
    None => None
    Some(снимок) => {
      @машина = снимок.машина
      @очередь = снимок.очередь
      @вызов = снимок.вызов
      @готовый_ответ = снимок.готовый_ответ
      @необратимые = снимок.необратимые
      match @готовый_ответ {
        Some(готовый) => Some(готовый)               // ответ уже отдан: повторяется без вреда
        None => {
          @в_работе = true
          @после_перезапуска()
          Some(@цикл())
        }
      }
    }
  }
}

/// Цикл: берёт события по одному, пока ответ не отдан. Остановка исполнителя — завершение процесса в любой точке цикла:
/// состояние уже сохранено фиксацией шага, дописывать ничего не нужно.
fn Исполнитель mut @цикл() -> Исход[ИтогСовещания] {
  loop {
    match @готовый_ответ {
      Some(ответ) => {
        @в_работе = false
        return ответ
      }
      None => @обработать_очередь()
    }
  }
}

/// Приём при приходе: в порядке прихода и в любом состоянии (правило 14).
fn Исполнитель mut @при_приходе(сообщение Сообщение) {
  @машина.счётчик_событий += 1                               // +1 при приходе любого события
  match сообщение {
    // ответ роли или отказ (Исход от открытой стороны)
    ОтветРоли(ответ) => {
      ro ид = запрос_ответа(ответ)
      // чужой или поздний ответ: неизвестный идентификатор, закрытый или отменённый запрос, повторная доставка (правило 17)
      if !@машина.открытые_запросы.contains(ид) || @машина.принятые_запросы.contains(ид) {
        // отбрасывание — отдельная фиксация со своей строкой журнала и номером шага (правило 31)
        ro лишнее = @событие_из_сообщения(сообщение)
        @начать_фиксацию_приёма(лишнее)
        @машина.отбросить(лишнее)
        @зафиксировать()
        return
      }
      // форма: ответ не по форме исполнитель возвращает стороне в том же запросе; число возвратов задаёт состояние
      if !форма_верна(ответ) { @вернуть_стороне(ответ); return }
      // объект, куда пишется результат (предложение при правке), изменился с начала попытки — результат не принимается,
      // запрос отменяется и отправляется заново (новая попытка, вход прочитан заново)
      if правит_автор(@машина.состояние) && @предложение_менялось_с_начала_попытки() { @повторить_запрос(ид); return }
      // приём — одна фиксация: идентификатор в принятые_запросы, «При приёме», запись результата в хранилище, событие в очередь (правила 14, 31)
      ro событие = @событие_из_ответа(ответ)
      @начать_фиксацию_приёма(событие)
      @машина.принятые_запросы.push(ид)
      @при_приёме(@машина.состояние, ответ)
      @записать_результат(@машина.состояние, ответ)
      @положить_в_очередь(событие)
      @зафиксировать()
      // последним, повторяемым без вреда этапом — принятие файла попытки (при старте завершается по принятые_запросы)
      @принять_файл_попытки(ид)
    }
    // слово человека или сигнал
    Слово(_) => {
      ro событие = @событие_из_сообщения(сообщение)
      @начать_фиксацию_приёма(событие)                // слово человека — своя фиксация: не теряется при сбое (правила 19, 31)
      @записать_слово_ворот(сообщение)                // на воротах (правило 19)
      @положить_в_очередь(событие)
      @зафиксировать()
    }
    // «нет ответа в срок»: порождает исполнитель по таймеру, код НетОтветаВСрок; у обращения человека срока нет (правило 19)
    Срок(ид) => {
      ro событие = Входящее {
        идентификатор: "сбой-${@машина.счётчик_событий}", сторона: сторона_запроса(ид), запрос: Some(ид), тело: Сбой { причина: НетОтветаВСрок } }
      @начать_фиксацию_приёма(событие)
      @положить_в_очередь(событие)
      @зафиксировать()
    }
  }
}

/// При приёме (правило 14; запись линзы — событие.сторона).
fn Исполнитель mut @при_приёме(текущее Состояние, ответ Исход[РезультатРоли]) => match текущее {
  ЛИНЗЫ => match ответ {
    // ответ: потери_подряд ← 0, пробы ← пробы из ответа (результат ответа, в событии не повторяется), ответившие + 1
    СРезультатом(итог) => match итог.результат {
      РезультатЛинзы(итоги) => {
        @машина.установить_потери(итог.сторона, 0)
        @машина.установить_пробы(итог.сторона, итоги.пробы)
        @машина.ответившие += 1
      }
      _ => недостижимо("результат роли ЛИНЗЫ — ИтогЛинзы")
    }
    // сбой: потери_подряд + 1, пробы ← 0
    Отказ(отказ) => {
      @машина.установить_потери(отказ.сторона, @машина.линзы(отказ.сторона).потери_подряд + 1)
      @машина.установить_пробы(отказ.сторона, 0)
    }
  }
  _ => ()
}

/// Запись принятого результата в хранилище (правила 8, 14): роль возвращает результат, в хранилище машины не пишет.
/// Вариант результата сверяется с состоянием: чужой вариант — ошибка программы; у ворот результата роли нет.
fn Исполнитель mut @записать_результат(текущее Состояние, ответ Исход[РезультатРоли]) => match ответ {
  Отказ(_) => ()
  СРезультатом(итог) => match текущее {
    СВИДЕТЕЛЬ => match итог.результат {
      РезультатСвидетеля(ответы) => { @машина.ответы_свидетеля.insert(@машина.номер_захода, ответы) }
      _ => недостижимо("результат роли СВИДЕТЕЛЬ — []ОтветСвидетеля")
    }
    ЛИНЗЫ => match итог.результат {
      РезультатЛинзы(итоги) => { @машина.находки_линзы.insert((итог.сторона, @машина.номер_захода), итоги.находки) }
      _ => недостижимо("результат роли ЛИНЗЫ — ИтогЛинзы")
    }
    ПРАВКА | ВОПРОС => match итог.результат {
      РезультатПравки(правка) => match правка {            // ИтогПравки: Закончена ведёт в ЗАХОД, Вопрос — в В7
        Закончена(текст) => { @машина.предложение = текст }
        Вопрос(вопрос) => {
          @машина.предложение = вопрос.предложение
          @машина.вопрос_автора = Some(вопрос.вопрос)
        }
      }
      _ => недостижимо("результат роли ПРАВКА и ВОПРОС — ИтогПравки")
    }
    _ => ()                                        // у остальных обращений результат — исход ворот, он идёт событием
  }
}

/// Обработка очереди: первое событие, которое ждёт текущее состояние; остальные остаются в очереди (правило 13).
fn Исполнитель mut @обработать_очередь() {
  match @взять_первое_ожидаемое() {                   // сигналы ждёт любое состояние, кроме концов
    None => @ждать_прихода()
    Some(событие) => {
      ro переход = @машина.общие_события(событие) ?? @машина.перейти(@машина.состояние, событие.тело, событие)
      @выполнить_шаг(событие, переход)
    }
  }
}

/// Шаг — одна фиксация (правило 13): переходы, записи в хранилище, строки журнала, новые значения «состояние», «открытые_запросы»,
/// «принятые_запросы», «к_отправке» и счётчиков попыток пишутся вместе; незавершённый шаг откатывается.
fn Исполнитель mut @выполнить_шаг(событие Входящее, переход Переход) {
  @начать_фиксацию()
  ro номер_захода_до = @машина.номер_захода
  @машина.номер_шага += 1                                    // растёт внутри фиксации; откат возвращает
  @машина.причина_шага = событие.идентификатор
  mut ход = переход
  match ход {
    НеЖдёт => {                                  // событие остаётся в очереди
      @откатить()
      return
    }
    _ => ()
  }
  // принятый запрос закрывается переходом по своему событию: убирается из открытые_запросы и из принятые_запросы
  match событие.запрос {
    Some(ид) => @машина.закрыть_запрос(ид)
    None => ()
  }

  // цепочка операций и развилок и их переходов «сразу» до первого обращения или конца
  loop {
    match ход {
      Остаться => break                                  // то же состояние
      НеЖдёт => break                            // первое событие проверено выше; в цепочке не встречается
      Куда(цель) => match @войти_в(цель, событие) {
        Some(следующий) => { ход = следующий }
        None => break                                // ждёт события или конец
      }
      Заново(цель) => {
        @отменить_открытый_запрос_обращения(цель)        // «запуск заново» (правило 18): прежний запрос сначала отменяется
        match @войти_в(цель, событие) {
          Some(следующий) => { ход = следующий }
          None => break
        }
      }
    }
    проверить_инвариант(инвариант_номер_захода_не_уменьшается(номер_захода_до, @машина.номер_захода))
  }
  @зафиксировать()                                    // запись шага: снимок сохранён, необратимые действия лежат в нём
  @выполнить_необратимые()                            // последний, повторяемый без вреда этап: переименование в `*.void-<k>.md`, смена права записи
  @после_фиксации()
}

/// Вход в состояние: запись «состояние» подразумевается у каждого перехода; None — обращение или конец, цепочка заканчивается.
fn Исполнитель mut @войти_в(куда Состояние, событие Входящее) -> Option[Переход] {
  @машина.состояние = куда
  match вид(куда) {
    Обращение | Конец => None                        // ждёт события или конец
    Операция => {
      ro результат = @работа_операции(куда)
      Some(@машина.перейти(куда, результат_как_событие(куда, результат), событие))
    }
    Развилка => Some(@машина.перейти(куда, Сразу, событие))
  }
}

/// Работа операций при входе (в одном шаге с переходом; отказа и «нет ответа» у операции нет).
fn Исполнитель mut @работа_операции(операция Состояние) -> Option[[]str] => match операция {
  ЗАМОК => {
    @машина.копия = Some(@предложение_с_отпечатком())
    @закрыть_для_записи("предложение")
    None
  }
  РАЗБЛОК => {
    @открыть_для_записи("предложение")
    None
  }
  ВОЗВРАТ => {
    match @машина.копия {
      Some(текст) => { @машина.предложение = текст }
      None => @машина.писать_журнал("ВОЗВРАТ: копии нет")    // псевдокод: недостижимо, копию пишет ЗАМОК
    }
    None
  }
  АННУЛ => {
    @перенести_в_архив(@машина.номер_захода, @машина.аннулирований(@машина.номер_захода))
    None
  }
  ФИЛЬТР => {
    // четыре признака несостоятельных мнения (task-runner.md); каждое идёт в счёт по моделям; запись на то же место
    @убрать_несостоятельные(@машина.номер_захода)
    Some(@линзы_без_критических())                  // идентификаторы
  }
  СВОД => {
    // K, Z, D — суммы по линзам, P — наименьшее из проб
    match @собрать_свод(@машина.номер_захода) {
      Some(итог) => { @машина.свод.insert(@машина.номер_захода, итог) }
      None => {}                                        // итога нет: записи в `свод` нет
    }
    None
  }
  _ => недостижимо("у остальных состояний нет работы операции")
}

/// После фиксации шага: сначала очередь, потом запросы (правило 13).
fn Исполнитель mut @после_фиксации() {
  @передать_вложенным_накопленные_сигналы()           // «стоп», «продолжить», «остановить», «отмена»; журнал «… передан(о) <идентификатор_запроса>»
  // конец: ответ вызвавшей стороне отдаётся всегда, даже если в очереди сигнал, и ровно один раз (правило 35, «один запрос — один ответ»);
  // сигналы в концах отбрасываются по правилам 17 и 23 уже после ответа
  match вид(@машина.состояние) {
    Конец => match @готовый_ответ {
      None => {
        @отменить_все_открытые_запросы()              // вход в любой конец (правило 22)
        @при_входе_в_конец(@машина.состояние)
        @выполнить_необратимые()
        @отдать_ответ(@машина.ответ_по_концу(@получатель()))
      }
      Some(_) => ()                                    // ответ уже отдан
    }
    _ => ()
  }
  // перед отправкой смотрит во входящую очередь: «стоп человека», «стоп от родителя» или «отмена_запроса» — запросы не отправляются,
  // а сигнал разбирается (правила 23, 35)
  if @в_очереди_есть_сигнал() { return }
  match вид(@машина.состояние) {
    Обращение => @отправить_запросы(@машина.состояние)
    _ => ()                                          // операции и развилки до сюда не доходят: цепочка идёт до обращения или конца
  }
}

/// Счётчик попыток одноадресного обращения (правило 15).
fn Машина @счётчик_попыток(сторона str) -> int => match сторона {

/// Перезапуск исполнителя: не переход и «состояние» не пишет; шаг со своим номером (правила 22, 31).
```
