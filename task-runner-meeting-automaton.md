# Совещание агентов: код автомата

Стейт-машина совещания, записанная исполняемым псевдокодом: объявление данных и типов, перечисления `State` и `Event`, функция переходов `step(состояние, событие)` как `match` по состоянию и событию, концы с ответом по контракту машины, цикл исполнителя. Нормы — [methodology.md](methodology.md), раздел 18, «Согласование решения несколькими агентами».

**Первоисточник — [task-runner-meeting-states.md](task-runner-meeting-states.md)** (таблицы состояний, общие события, «Контракт машины»); правила формы — [state-machine-spec.md](state-machine-spec.md). Этот файл — производная запись того же автомата, а не второй источник истины: при любом расхождении верен первоисточник, а этот файл правится вслед за ним. Расширения, отличия от псевдокода раннера и опытный статус режима описаны в шапке первоисточника и здесь не повторяются; раннером машина не исполняется. Схема раннера ([task-runner-pseudocode.md](task-runner-pseudocode.md), [task-runner-meeting-pseudocode.md](task-runner-meeting-pseudocode.md)) — другая форма записи, помечена устаревшей и этим файлом не заменяется. Имя файла — по `AGENTS.md`, «Вынесенные алгоритмы», форма `automaton`.

## Соглашения записи

1. **Типы** — латинские имена и поля блока «Типы на Нове» первоисточника (`Lens`, `Request[T]`, `Finding`, …); соответствие — в таблице ниже. Новых типов данных нет; добавлены только шесть типов записи автомата: `State`, `Event`, `Incoming`, `Transition`, `Kind`, `Message`.
2. **Переменные, состояния, события и их поля** — те же русские имена в змеином регистре, что в первоисточнике (правило 25 спецификации: имя одной сущности одно); имена состояний — как есть. Блок «Типы на Нове» первоисточника русских идентификаторов не содержит, поэтому русские имена в коде — решение этого файла: они ищутся одним поиском по обоим файлам.
3. **Данные события.** «событие.<поле>» первоисточника в коде — `ev.<поле>` (данные события состояния); «сторона события» и идентификатор события — `событие.сторона`, `событие.идентификатор` (конверт `Incoming`, правила 13 и 31). Шаблон строки журнала «<сторона события>» — `{событие.сторона}`.
4. **Запись.** «←» — `=`; «+ 1» — `+= 1`; «добавить», «объединить_без_повторов» — функции правила 30; `нет` — отсутствующее значение внешнего объекта; `Map[K, V]` — отображение, отсутствующий ключ — `нет` (у `аннулирований` — `0`); `Option[T]` — значение или `нет`; «сразу» — событие `Сразу`; «то же состояние» — `Stay`; «запуск заново» — `Rerun(S)`; «Куда» — `Go(S)`.
5. **Строка таблицы — ветка кода.** Перед каждой строкой первоисточника (условие или событие, «Что меняется», «Куда») стоит комментарий `// <СОСТОЯНИЕ> #<номер строки>: …` с её текстом; порядок строк как в первоисточнике. Строка «иначе» каждой развилки — последняя ветка, ведёт в `ОШИБКА`. Строки «Вход», «Выход», «При входе», «Сторона» и одна строка простыми словами на состояние — комментарии `///` и `//` у состояния.
6. **Исполнитель.** Функции раздела «Механика исполнителя» объявлены только сигнатурой: это перечень механики контракта, фиксации и приёма (правила 13–22 спецификации), её записывает исполнитель, а не машина.

Соответствие типов и полей:

| Первоисточник | Код |
|---|---|
| Число, Текст | `int`, `str` |
| Линза: идентификатор, потери_подряд, пробы, попытка | `Lens`: `id`, `lost`, `probes`, `attempt` |
| Запрос: идентификатор_запроса, номер_попытки, сторона, вход, срок_бездействия, трасса, номер_шага | `Request[T]`: `id`, `attempt`, `party`, `input`, `idle_term`, `trace`, `step` |
| Ответ (с результатом): запрос, сторона, результат, трасса, номер_шага | `Reply[R]`: `request`, `party`, `result`, `trace`, `step` |
| Ответ (отказ): запрос, сторона, причина, текст, трасса, номер_шага | `Rejection`: `request`, `party`, `reason`, `text`, `trace`, `step` |
| Ответ: с результатом, отказ | `Response[R]`: `Result(Reply[R])`, `Refusal(Rejection)` |
| КодСбоя: нет результата, отказ модели, соединение оборвалось, форма не исправлена, нет ответа в срок, остановлено человеком, потолок заходов с открытыми находками, отменено родителем | `FailCode`: `NoResult`, `ModelRefused`, `ConnectionLost`, `FormNotFixed`, `Timeout`, `StoppedByHuman`, `CeilingReached`, `Cancelled` |
| ОтветСвидетеля: с утверждением, не измерено | `WitnessAnswer`: `Answered(Claim)`, `NotMeasured(str)` |
| Утверждение: вид, утверждение, источник, выдержка, сверка | `Claim`: `kind`, `statement`, `source`, `excerpt`, `check` |
| Сверка: подтверждено, искажение канала, не подтверждено | `Check`: `Confirmed`, `ChannelDistortion`, `NotConfirmed` |
| ИтогПравки: закончена, вопрос | `EditResult`: `Done(str)`, `Asked(Asking)` |
| ИтогПравки (вопрос): предложение, вопрос | `Asking`: `proposal`, `question` |
| Находка: критичность, доказательство, повтор | `Finding`: `severity`, `evidence`, `repeat` |
| Критичность: критическая, значимая, желательная | `Severity`: `Critical`, `Significant`, `Desirable` |
| Свод: итог (K, P) | `Summary`: `k`, `p` |
| ВходСовещания: предложение, порядок_линз, вопрос_автора | `MeetingInput`: `proposal`, `lens_order`, `author_question` |
| ИтогСовещания: решение, источник, число_заходов, открытые | `MeetingResult`: `decision`, `source`, `passes`, `open` |

Имена, которых нет в первоисточнике и которые завела запись автомата (не данные машины): `State`, `Event`, `Incoming`, `Transition`, `Kind`, `Message`, поле `тело` у `Incoming` (русское имя поля записи автомата; поля типов первоисточника остаются латинскими по блоку «Типы на Нове»), `Stay`/`Go`/`Rerun`/`NotAwaited`, варианты `Event` с префиксом ворот (`В13_повторить`, …; один вариант на слово ворот строки первоисточника), `запись_перехода` (текст журнала перехода в ОШИБКУ) и `вызов` (запрос вызова; конверт исполнителя), функции раздела «Механика исполнителя».

## Типы

```
/// Линза
type Lens { id str, lost int, probes int, attempt int }

/// Запрос
type Request[T] { id str, attempt int, party str, input T, idle_term int, trace str, step int }

/// Ответ
type Response[R] enum
| Result(Reply[R])
| Refusal(Rejection)

/// Ответ (с результатом)
type Reply[R] { request str, party str, result R, trace str, step int }

/// Ответ (отказ)
type Rejection { request str, party str, reason FailCode, text str, trace str, step int }

/// КодСбоя
type FailCode enum
| NoResult
| ModelRefused
| ConnectionLost
| FormNotFixed
| Timeout
| StoppedByHuman  // остановлено человеком
| CeilingReached  // потолок заходов с открытыми находками
| Cancelled  // отменено родителем

/// ОтветСвидетеля
type WitnessAnswer enum
| Answered(Claim)
| NotMeasured(str)

/// ОтветСвидетеля (с утверждением)
type Claim { kind str, statement str, source str, excerpt Option[str], check Check }

/// Сверка
type Check enum
| Confirmed
| ChannelDistortion
| NotConfirmed

/// ИтогПравки
type EditResult enum
| Done(str)
| Asked(Asking)

/// ИтогПравки (вопрос)
type Asking { proposal str, question str }

/// Находка
type Finding { severity Severity, evidence str, repeat bool }

/// Критичность
type Severity enum
| Critical
| Significant
| Desirable

/// Свод
type Summary { k int, p int }

/// ВходСовещания
type MeetingInput { proposal str, lens_order []str, author_question Option[str] }

/// ИтогСовещания
type MeetingResult { decision str, source str, passes int, open []Finding }

/// Запись автомата: событие с конвертом (правила 13 и 31 спецификации)
type Incoming {
  идентификатор str,        // «<вид>-<номер по счётчику событий>»
  сторона str,              // «событие.сторона»; у событий ворот и общих событий не читается
  запрос Option[str],       // идентификатор запроса, чьим исходом событие пришло (механика закрытия запроса)
  тело Event                 // вариант события и его данные (`ev.<поле>`)
}

/// Запись автомата: вид состояния (четыре вида первоисточника, раздел «Состояния»)
type Kind enum
| Обращение
| Операция
| Развилка
| Конец

/// Запись автомата: то, что исполнитель получает при приходе: ответ или отказ роли, слово человека, сигнал, срок (правила 14, 16, 23)
type Message enum
| ОтветРоли(Response[R])   // результат или отказ открытого запроса
| Слово(Event)            // слово ворот человека или общий сигнал
| Срок(str)               // «нет ответа в срок»: идентификатор запроса; порождает исполнитель

/// Запись автомата: куда ведёт строка
type Transition enum
| Go(State)               // «Куда»: состояние
| Rerun(State)            // «Куда»: состояние, запуск заново (правило 18)
| Stay                    // «Куда»: то же состояние
| NotAwaited              // событие этого состояния не ждёт: остаётся в очереди (правило 13)
```

Там, где итога свода может не быть, — `Option[Summary]`.

## Общие события

```
/// Разбираются до строк состояний (правило 23): сначала общие события, затем step.
/// «Стоп человека» в ПАУЗЕ и в концах и «продолжить» вне ПАУЗЫ отбрасываются с записью в журнал (правила 17, 23);
/// в таблицах первоисточника для них строки нет, формат строки там не задан.
fn общие_события(событие Incoming) -> Option[Transition] {
  let ev = событие.тело
  match ev {

    СтопЧеловека => {
      // ОБЩ стоп_человека #1: в любом состоянии, кроме ОСТАНОВ, ОШИБКА, КОНЕЦ и ПАУЗА
      if состояние in [ОСТАНОВ, ОШИБКА, КОНЕЦ, ПАУЗА] { отбросить(событие); return Some(Stay) }
      записать_слово_человека(событие, ev.слово_человека, ev.автор, ev.источник)
      журнал("стоп человека: {ev.автор}, {ev.источник}, запись {событие.идентификатор}")
      предыдущее = состояние.имя
      // открытые_запросы без принятого ответа отменены (правило 18), кроме запросов к вложенным машинам
      отменить_открытые_без_принятого(кроме_вложенных: да)
      // вложенные получают сигнал «стоп» после фиксации шага; журнал «стоп передан <идентификатор_запроса>» на каждого (правило 35, пункт 8)
      передать_вложенным("стоп")
      return Some(Go(ПАУЗА))
    }

    СтопОтРодителя => {
      // ОБЩ стоп_от_родителя #1: те же состояния, если идентификатор_запроса события = запрос_вызова, иначе сигнал отброшен (правило 17)
      if состояние in [ОСТАНОВ, ОШИБКА, КОНЕЦ, ПАУЗА] { отбросить(событие); return Some(Stay) }
      if ev.идентификатор_запроса != запрос_вызова { отбросить(событие); return Some(Stay) }
      журнал("пауза: причина — стоп от родителя, {ev.идентификатор_запроса}, запись {событие.идентификатор}")
      // слова человека не записываются (""): слов_человека не пишется
      предыдущее = состояние.имя
      отменить_открытые_без_принятого(кроме_вложенных: да)
      передать_вложенным("стоп")
      return Some(Go(ПАУЗА))
    }

    ОтменаЗапроса => {
      // событие приходит в любом состоянии
      // ОБЩ отмена_запроса #1: идентификатор_запроса события не равен запрос_вызова
      if ev.идентификатор_запроса != запрос_вызова {
        журнал("отмена отброшена: чужой запрос {ev.идентификатор_запроса}, запись {событие.идентификатор}")
        return Some(Stay)
      }
      // ОБЩ отмена_запроса #2: = запрос_вызова, и ответ уже отдан (состояние — ОСТАНОВ, ОШИБКА или КОНЕЦ)
      if ev.идентификатор_запроса == запрос_вызова && состояние in [ОСТАНОВ, ОШИБКА, КОНЕЦ] {
        журнал("отмена отброшена: ответ уже отдан, {ev.идентификатор_запроса}, запись {событие.идентификатор}")
        return Some(Stay)
      }
      // ОБЩ отмена_запроса #3: = запрос_вызова, и ответ не отдан
      if ev.идентификатор_запроса == запрос_вызова && !(состояние in [ОСТАНОВ, ОШИБКА, КОНЕЦ]) {
        журнал("отмена запроса: {ev.идентификатор_запроса}, запись {событие.идентификатор}")
        остановка = "отмена_запроса"
        отменить_открытые_без_принятого(кроме_вложенных: нет)    // правило 18
        передать_вложенным("отмена")                              // отмена передана вложенным из открытые_запросы
        return Some(Go(ОСТАНОВ))
      }
      // ОБЩ отмена_запроса #4: иначе
      return Some(ошибка_машины("ошибка машины: разбор отмены_запроса, ни одно условие не подошло"))
    }

    ПАУЗА_продолжить | ПАУЗА_продолжить_от_родителя => {
      // «продолжить» вне ПАУЗЫ отбрасывается с записью в журнал (правила 17, 23); в ПАУЗЕ — строки ПАУЗА #1 и #3
      if состояние != ПАУЗА { отбросить(событие); return Some(Stay) }
      return None
    }

    _ => return None    // остальные события — строки состояний
  }
}
```

## Переходы

```
/// Переход по событию. ev — событие, которое ждёт состояние s (у операции — Сразу, у развилки — Сразу без данных);
/// событие — исходное событие шага: его данные (сторона, идентификатор) доступны всей цепочке до ближайшего обращения (правило 13).
/// Состояние пишется при фиксации; в «Что меняется» оно не повторяется.
fn step(s State, ev Event, событие Incoming) -> Transition {
  match s {

  // ===================== ЗАХОД — развилка =====================
  // Начало очередного захода проверки: смотрит, остались ли вопросы к свидетелю; есть — идёт к свидетелю, нет — сразу к проверке линзами.
  // Вход: вопрос_автора?; номер_захода; порядок_линз; находки_линзы[линза, номер_захода - 1]? (по каждой линзе из порядок_линз, из них вопросы проверяющих)
  ЗАХОД => {
    // ЗАХОД #1: вопрос_автора есть
    if вопрос_автора != нет { return Go(СВИДЕТЕЛЬ) }
    // ЗАХОД #2: вопрос_автора отсутствует, и в находках любой линзы захода номер_захода - 1 есть вопросы проверяющих
    if вопрос_автора == нет && есть_вопросы_проверяющих(номер_захода - 1) { return Go(СВИДЕТЕЛЬ) }
    // ЗАХОД #3: вопрос_автора отсутствует, и в находках любой линзы захода номер_захода - 1 вопросов проверяющих нет
    if вопрос_автора == нет && !есть_вопросы_проверяющих(номер_захода - 1) { return Go(ЗАМОК) }
    // ЗАХОД #4: иначе
    return ошибка_машины("ошибка машины: развилка ЗАХОД, ни одно условие не подошло")
  }

  // ===================== СВИДЕТЕЛЬ — обращение =====================
  // Просит свидетеля ответить на вопросы автора и проверяющих по фактам, чтобы проверка опиралась на сверенные ответы, а не на догадки.
  // При входе: свидетель отвечает на вопросы автора в предложении и проверяющих в находках любой линзы захода номер_захода - 1;
  //   исполнитель сверяет выдержки: несовпадение — один возврат «исправь выдержку» в том же запросе, снова несовпадение — строка «не подтверждено»;
  //   принятые ответы исполнитель записывает в хранилище.
  // Сторона: свидетель.
  // Вход (сторона): вопрос_автора?; находки_линзы[линза, номер_захода - 1]? (по каждой линзе, из них вопросы проверяющих); предложение
  // Вход (исполнитель): номер_захода; порядок_линз (по ним выбирает находки захода номер_захода - 1)
  // Выход: ответы_свидетеля[номер_захода] []WitnessAnswer
  СВИДЕТЕЛЬ => match ev {
    // СВИДЕТЕЛЬ #1: ответ
    Ответ => { return Go(ЗАМОК) }
    // СВИДЕТЕЛЬ #2: сбой (причина: КодСбоя)
    Сбой => {
      журнал("СВИДЕТЕЛЬ не ответил: {ev.причина}")
      сбойное_обращение = "СВИДЕТЕЛЬ"
      return Go(СБОЙ)
    }
    _ => return NotAwaited
  }

  // ===================== ЗАМОК — операция =====================
  // Запоминает текст предложения на начало захода и запрещает его править, чтобы проверяющие читали одно и то же и правку за время проверки можно было заметить.
  // При входе: сохраняется копия предложения с отпечатком; предложение закрывается для записи.
  // Вход: предложение; порядок_линз
  // Выход: копия
  ЗАМОК => match ev {
    // ЗАМОК #1: сразу
    Сразу => {
      к_отправке = порядок_линз
      ответившие = 0
      return Go(ЛИНЗЫ)
    }
    _ => return NotAwaited
  }

  // ===================== ЛИНЗЫ — обращение =====================
  // Рассылает предложение проверяющим (у каждого своя точка зрения — линза) и собирает их находки; число одновременных запросов ограничено параметром.
  // При входе: исполнитель отправляет запрос каждой линзе из к_отправке (правило 21); линза проверяет предложение и ответы свидетеля
  //   и возвращает находки; находок других линз этого захода она не видит; форму её находок проверяет исполнитель, возвращая неверную
  //   в том же запросе, и записывает принятые находки в хранилище.
  // Сторона: набор — линзы из порядок_линз; идентификатор линзы — идентификатор стороны; запросов одновременно не больше ПРЕДЕЛ_ЗАПРОСОВ.
  // При приёме (правило 14; запись линзы — событие.сторона): см. при_приёме_ЛИНЗЫ в разделе «Цикл исполнителя».
  // Вход (сторона): предложение; ответы_свидетеля[номер_захода]? (только запрошенной линзе; идентификатор линзы входит в запрос и возвращается с ответом)
  // Вход (исполнитель): номер_захода; к_отправке; линзы (lost и probes при приёме); ответившие
  // Выход: находки_линзы[линза, номер_захода]; пробы
  ЛИНЗЫ => match ev {
    // ЛИНЗЫ #1: ответ
    Ответ => { return Go(ВСЕ_ЗАКРЫТЫ) }
    // ЛИНЗЫ #2: сбой (сторона: идентификатор линзы; причина: КодСбоя)
    Сбой => {
      журнал("линза {событие.сторона} не ответила: {ev.причина}")
      return Go(ОТКАЗ)
    }
    _ => return NotAwaited
  }

  // ===================== ОТКАЗ — развилка =====================
  // Решает, что делать с линзой, которая не ответила: первый раз — отбросить её в этом заходе, второй подряд — спросить человека, не ответила и на повторе — отбросить.
  // Вход: линзы (только запись линзы событие.сторона: lost); к_отправке; номер_захода
  ОТКАЗ => {
    // ОТКАЗ #1: потери_подряд линзы событие.сторона = 1
    if запись_линзы(событие.сторона).lost == 1 {
      журнал("линза {событие.сторона} отброшена в заходе {номер_захода}")
      return Go(ВСЕ_ЗАКРЫТЫ)
    }
    // ОТКАЗ #2: потери_подряд линзы событие.сторона = 2
    if запись_линзы(событие.сторона).lost == 2 {
      сбойное_обращение = "ЛИНЗЫ"
      к_отправке = добавить([событие.сторона], к_отправке)
      return Go(СБОЙ)
    }
    // ОТКАЗ #3: потери_подряд линзы событие.сторона = 3
    if запись_линзы(событие.сторона).lost == 3 {
      запись_линзы(событие.сторона).lost = 1
      журнал("линза {событие.сторона} отброшена в заходе {номер_захода}")
      return Go(ВСЕ_ЗАКРЫТЫ)
    }
    // ОТКАЗ #4: иначе
    return ошибка_машины("ошибка машины: развилка ОТКАЗ, ни одно условие не подошло")
  }

  // ===================== ВСЕ_ЗАКРЫТЫ — развилка =====================
  // Проверяет, все ли линзы разобраны: остались неотправленные или ждущие ответа — идёт к ним, все закрыты — дальше, а если не ответила ни одна — останавливает совещание.
  // Вход: к_отправке; открытые_запросы; ответившие
  ВСЕ_ЗАКРЫТЫ => {
    // ВСЕ_ЗАКРЫТЫ #1: к_отправке — не пустой список
    if к_отправке != [] { return Go(ЛИНЗЫ) }
    // ВСЕ_ЗАКРЫТЫ #2: к_отправке — пустой список, и открытые_запросы — не пустой список
    if к_отправке == [] && открытые_запросы != [] { return Go(ЛИНЗЫ) }
    // ВСЕ_ЗАКРЫТЫ #3: к_отправке — пустой список, открытые_запросы — пустой список, и ответившие больше 0
    if к_отправке == [] && открытые_запросы == [] && ответившие > 0 { return Go(РАЗБЛОК) }
    // ВСЕ_ЗАКРЫТЫ #4: к_отправке — пустой список, открытые_запросы — пустой список, и ответившие = 0
    if к_отправке == [] && открытые_запросы == [] && ответившие == 0 {
      остановка = "ни одна линза не ответила"
      return Go(ОСТАНОВ)
    }
    // ВСЕ_ЗАКРЫТЫ #5: иначе
    return ошибка_машины("ошибка машины: развилка ВСЕ_ЗАКРЫТЫ, ни одно условие не подошло")
  }

  // ===================== СБОЙ — обращение =====================
  // Спрашивает человека, что делать, когда роль не ответила: повторить обращение или остановить совещание.
  // При входе: ворота В13: запрос обращения «сбойное_обращение» закончился сбоем (у ЛИНЗЫ — вторым подряд у линзы, чей идентификатор уже стоит
  //   первым в к_отправке); причина — в журнале. Повтор линзы, не ответившей и на этот раз, ворот не открывает: линза отбрасывается
  //   (ОТКАЗ, потери_подряд = 3), как в `check_meeting`. Это обращение — человеку: срока бездействия и сбоя у него нет (правило 19).
  // Сторона: человек.
  // Вход: сбойное_обращение
  // Выход: исход ворот
  СБОЙ => match ev {
    // СБОЙ #1: В13: «повторить»
    В13_повторить => { return Go(ПОВТОР_ОБРАЩЕНИЯ) }
    // СБОЙ #2: В13: «остановить совещание»
    В13_остановить_совещание => {
      остановка = "{сбойное_обращение}: остановить совещание"
      return Go(ОСТАНОВ)
    }
    _ => return NotAwaited
  }

  // ===================== ПОВТОР_ОБРАЩЕНИЯ — развилка =====================
  // Возвращает машину к той роли, которая не ответила, чтобы обратиться к ней ещё раз.
  // Вход: сбойное_обращение
  ПОВТОР_ОБРАЩЕНИЯ => {
    // ПОВТОР_ОБРАЩЕНИЯ #1: сбойное_обращение = «СВИДЕТЕЛЬ»
    if сбойное_обращение == "СВИДЕТЕЛЬ" { return Rerun(СВИДЕТЕЛЬ) }
    // ПОВТОР_ОБРАЩЕНИЯ #2: сбойное_обращение = «ЛИНЗЫ»

  // ===================== РАЗБЛОК — операция =====================

    // СВЕРКА #4: иначе
    return ошибка_машины("ошибка машины: развилка СВЕРКА, ни одно условие не подошло")
  }

  // ===================== ИЗМЕНЁН — обращение =====================
  // Показывает человеку исходную копию и изменённое предложение и спрашивает: оставить правку, вернуть копию или остановить совещание.
  // При входе: ворота В13 с копией и изменённым предложением.
  // Сторона: человек.
  // Вход (сторона): копия; предложение?

    }

    В13_вернуть_копию => {
      аннулирований[номер_захода] += 1
      return Go(ВОЗВРАТ)
    }
    // ИЗМЕНЁН #3: В13: «остановить совещание»
    В13_остановить_совещание => {

      return Go(ОСТАНОВ)

  // ===================== ВОЗВРАТ — операция =====================
  // Заменяет изменённое предложение сохранённой копией.
  // При входе: предложение заменяется копией.
  // Вход: копия

  // Убирает из находок несостоятельные мнения (выдуманные цитаты, находки без доказательства) и отмечает линзы, у которых не осталось критических находок.
  // При входе: убираются несостоятельные мнения (четыре признака, `task-runner.md`, «Совещание агентов», «Несостоятельные мнения»; среди них ответ

  // Вход: номер_захода; порядок_линз; находки_линзы[линза, номер_захода] (по каждой линзе из порядок_линз); ответы_свидетеля[номер_захода]?

  // Собирает находки всех линз в одну сводку с итоговой строкой: сколько критических, значимых и желательных находок и сколько проб.
  // При входе: записывается свод[номер_захода]: итоговая строка «Заход <номер_захода>: критических K, значимых Z, желательных D, проб P»

  СВОД => match ev {

    Сразу => { return Go(РАЗБОР) }
    _ => return NotAwaited

      return Go(В3)
    }

    if свод[номер_захода] != нет && свод[номер_захода].k == 0 && свод[номер_захода].p >= ПРОБ_В_ЧИСТОМ {

    }

    if свод[номер_захода] == нет {

      без_проб_подряд = 0
      return Go(В3)
    }
    // РАЗБОР #4: итог свода есть, критических нет, и проб меньше ПРОБ_В_ЧИСТОМ
    if свод[номер_захода] != нет && свод[номер_захода].k == 0 && свод[номер_захода].p < ПРОБ_В_ЧИСТОМ {
      журнал("заход {номер_захода}: чистый без проб, не засчитан")
      номер_захода += 1
      без_проб_подряд += 1
      return Go(БЕЗ_ПРОБ)
    }
    // РАЗБОР #5: иначе
    return ошибка_машины("ошибка машины: развилка РАЗБОР, ни одно условие не подошло")
  }

  // Считает чистые заходы без проб подряд: первый — просто повторить проверку, второй — спросить человека.
  // Вход: без_проб_подряд
  БЕЗ_ПРОБ => {

    if без_проб_подряд == 1 { return Go(ЗАХОД) }
    // БЕЗ_ПРОБ #2: без_проб_подряд больше 1
    if без_проб_подряд > 1 { return Go(ПОВТОР) }
    // БЕЗ_ПРОБ #3: иначе
    return ошибка_машины("ошибка машины: развилка БЕЗ_ПРОБ, ни одно условие не подошло")
  }

  // ===================== ПОВТОР — обращение =====================
  // Спрашивает человека, что делать после второго подряд чистого захода без проб: повторить проверку или остановить.
  // При входе: ворота В13: проверка второй раз подряд без проб.
  // Сторона: человек.
  // Вход: нет.
  // Выход: исход ворот
  ПОВТОР => match ev {
    // ПОВТОР #1: В13: «повторить»
    В13_повторить => { return Go(ЗАХОД) }
    // ПОВТОР #2: В13: «остановить»
    В13_остановить => {
      остановка = "ПОВТОР: остановить"
      return Go(ОСТАНОВ)
    }
    _ => return NotAwaited
  }

  // ===================== В3 — обращение =====================
  // Показывает человеку находки и пробы захода; он может поднять критичность находок или не засчитать заход, если пробы — не настоящие пробы.
  // При входе: ворота В3: человек читает находки и пробы, может поднять критичность; по его настройке ворота только показывают и идут дальше
  //   как «засчитан» с находками свода без поправки.
  // Сторона: человек.
  // Вход (сторона): свод[номер_захода]; находки_линзы[линза, номер_захода] (по каждой линзе)
  // Вход (исполнитель): номер_захода; порядок_линз
  // Выход: исход ворот; находки_В3 []Finding (после поправки человека)
  В3 => match ev {
    // В3 #1: В3: «не засчитан»
    В3_не_засчитан => {
      журнал("заход {номер_захода}: пробы — не пробы, не засчитан")
      номер_захода += 1
      return Go(ЗАХОД)
    }
    // В3 #2: В3: «засчитан» (находки_В3: []Находка)
    В3_засчитан => {
      номер_захода += 1
      находки_В3 = ev.находки_В3
      return Go(ИТОГ)
    }
    _ => return NotAwaited
  }

  // ===================== ИТОГ — развилка =====================
  // Подводит итог засчитанного захода: есть критические находки — нужна правка, чистых заходов подряд ещё мало — ещё заход, достаточно — итог можно принимать.
  // Вход: находки_В3; серия_чистых; открытые
  ИТОГ => {
    // ИТОГ #1: в находки_В3 есть критические
    if есть_критические(находки_В3) {
      серия_чистых = 0
      открытые = объединить_без_повторов(открытые, желательные_и_значимые_с_повтором(находки_В3))
      return Go(ПОТОЛОК)
    }
    // ИТОГ #2: в находки_В3 критических нет, и серия_чистых + 1 меньше ЧИСТЫХ_ПОДРЯД
    if !есть_критические(находки_В3) && серия_чистых + 1 < ЧИСТЫХ_ПОДРЯД {
      открытые = объединить_без_повторов(открытые, желательные(находки_В3))
      серия_чистых += 1
      return Go(ЗАХОД)
    }
    // ИТОГ #3: в находки_В3 критических нет, и серия_чистых + 1 не меньше ЧИСТЫХ_ПОДРЯД
    if !есть_критические(находки_В3) && серия_чистых + 1 >= ЧИСТЫХ_ПОДРЯД {
      открытые = объединить_без_повторов(открытые, желательные_и_значимые(находки_В3))
      серия_чистых = 0
      return Go(ПРИНЯТИЕ)
    }
    // ИТОГ #4: иначе
    return ошибка_машины("ошибка машины: развилка ИТОГ, ни одно условие не подошло")
  }

  // ===================== ПОТОЛОК — развилка =====================
  // Проверяет, не исчерпан ли предел числа заходов: нет — автор правит предложение, исчерпан — решает человек.
  // Вход: номер_захода; заход_отсчёта
  ПОТОЛОК => {
    // ПОТОЛОК #1: (номер_захода - 1) - заход_отсчёта + 1 меньше ПОТОЛОК_ЗАХОДОВ
    if (номер_захода - 1) - заход_отсчёта + 1 < ПОТОЛОК_ЗАХОДОВ { return Go(ПРАВКА) }
    // ПОТОЛОК #2: (номер_захода - 1) - заход_отсчёта + 1 не меньше ПОТОЛОК_ЗАХОДОВ
    if (номер_захода - 1) - заход_отсчёта + 1 >= ПОТОЛОК_ЗАХОДОВ { return Go(В9) }
    // ПОТОЛОК #3: иначе
    return ошибка_машины("ошибка машины: развилка ПОТОЛОК, ни одно условие не подошло")
  }

  // Сообщает человеку, что предел заходов исчерпан, и спрашивает: дать ещё заход (с его указанием), остановиться с открытыми находками или остановить совещание.
  // При входе: ворота В9: потолок заходов.

  // Вход (сторона): находки_В3; номер_захода; заход_отсчёта
  // Вход (исполнитель): открытые
  // Выход: исход ворот; решение_человека str
  В9 => match ev {

      return Go(ПРАВКА)

    В9_остановиться => {
      заход_отсчёта = номер_захода
      открытые = объединить_без_повторов(открытые, критические_и_значимые_без_повтора(находки_В3))

    }

    В9_остановить_совещание => {
      заход_отсчёта = номер_захода

  }

  // При входе: автор правит рабочую копию предложения по критическим и значимым находкам, у которых нет повтора из находки_В3 (заход

  //   записывает в предложение при приёме ответа, если предложение не менялось с начала попытки (правило 14).
  // Сторона: автор.
  // Вход (сторона): предложение; находки_В3 (из них критические и значимые, у которых нет повтора); указание_автору?
  // Вход (исполнитель): номер_захода
  // Выход: итог_правки EditResult
  ПРАВКА => match ev {

      return Go(ЗАХОД)
    }

  //   записывает в предложение при приёме ответа, если предложение не менялось с начала попытки (правило 14).
  // Сторона: автор.
  // Вход: вопрос_автора; предложение; находки_В3 (из них критические и значимые, у которых нет повтора); ответ_человека (только автору)
  // Выход: итог_правки EditResult

    // ВОПРОС #3: сбой (причина: КодСбоя)
    Сбой => {
      журнал("ВОПРОС: автор не ответил: {ev.причина}")
      сбойное_обращение = "ВОПРОС"

  }

  // Просит человека подтвердить итог и записать источник решения.

  // Вход: предложение; номер_захода; открытые
  // Выход: подтверждение str
  ПРИНЯТИЕ => match ev {
    // ПРИНЯТИЕ #1: ПРИНЯТИЕ: «подтвердил» (подтверждение: Текст)
    ПРИНЯТИЕ_подтвердил => {
      подтверждение = ev.подтверждение
      return Go(КОНЕЦ)
    }
    _ => return NotAwaited
  }

  // ===================== ПАУЗА — обращение =====================
  // Держит машину остановленной по слову человека, пока он не скажет продолжить (машина вернётся туда, где её остановили) или остановить совещание.
  // При входе: ворота «пауза»: человек остановил машину, открытые_запросы отменены (кроме запросов к вложенным машинам: они получают сигнал «стоп»,
  //   правило 35); человек продолжает с прерванного состояния или останавливает совещание. Право записи на предложение пауза не меняет: закрытое
  //   в окне проверки линз остаётся закрытым, а кто хочет его править, выбирает «остановить совещание» (`doc/open-questions.md`, раздел 9).
  // Сторона: человек — события «продолжить» и «остановить совещание»; родитель — события «продолжить от родителя» и «остановить от родителя».
  // Вход: предыдущее; запрос_вызова (`""` у машины верхнего уровня)
  // Выход: исход ворот
  // «Продолжить» и «продолжить от родителя» ведут в состояние по имени из «предыдущее» (единственный переход с переменной в «куда», правило 24)
  //   и входят в него заново (повторный вход, правило 12): у ЛИНЗ уходят запросы линзам из к_отправке, у остальных обращений — новый запрос, если
  //   по обращению нет принятого запроса; принятые до стопа ответы остаются. «Предыдущее» при этом не пишется (правила 13 и 24).
  ПАУЗА => match ev {
    // ПАУЗА #1: ПАУЗА: «продолжить» (слово_человека; автор; источник)
    ПАУЗА_продолжить => {
      записать_слово_человека(событие, ev.слово_человека, ev.автор, ev.источник)
      журнал("продолжение с {предыдущее}: {ev.автор}, {ev.источник}, запись {событие.идентификатор}")
      передать_вложенным("продолжить")             // после фиксации шага, журнал «продолжить передано <идентификатор_запроса>»
      return Go(состояние_по_имени(предыдущее))
    }
    // ПАУЗА #2: ПАУЗА: «остановить совещание»
    ПАУЗА_остановить_совещание => {
      остановка = "ПАУЗА: остановить совещание"
      передать_вложенным("остановить")             // правило 35, пункты 8 и 10
      return Go(ОСТАНОВ)
    }
    // ПАУЗА #3: ПАУЗА: «продолжить от родителя» (если идентификатор_запроса события = запрос_вызова, иначе отброшено)
    ПАУЗА_продолжить_от_родителя => {
      if ev.идентификатор_запроса != запрос_вызова { отбросить(событие); return Stay }
      журнал("продолжение с {предыдущее}: от родителя {ev.идентификатор_запроса}, запись {событие.идентификатор}")
      // слова человека не записываются ("")
      передать_вложенным("продолжить")
      return Go(состояние_по_имени(предыдущее))
    }
    // ПАУЗА #4: ПАУЗА: «остановить от родителя» (если идентификатор_запроса события = запрос_вызова, иначе отброшено)
    ПАУЗА_остановить_от_родителя => {
      if ev.идентификатор_запроса != запрос_вызова { отбросить(событие); return Stay }
      остановка = "ПАУЗА: остановить совещание"
      передать_вложенным("остановить")
      return Go(ОСТАНОВ)
    }
    _ => return NotAwaited
  }

  // ===================== концы: переходов нет =====================
  // ОСТАНОВ — конец. Заканчивает совещание без принятого итога и записывает, почему и какие находки остались; решение — за человеком вне машины.
  // Вход: остановка; предложение; открытые; находки_В3
  ОСТАНОВ => unreachable("конец: переходов нет; работа при входе — в «Концы и ответ»")

  // ОШИБКА — конец. Заканчивает совещание, если сама машина попала в непредусмотренное положение; это дефект машины или реализации, его разбирает человек.
  // Вход: предложение; все данные машины (Все переменные и хранилища — в журнал)
  ОШИБКА => unreachable("конец: переходов нет; работа при входе — в «Концы и ответ»")

  // КОНЕЦ — конец. Записывает принятое решение с источником, числом заходов и открытыми находками: совещание закончено успешно.
  // Вход: предложение; подтверждение; номер_захода; открытые
  КОНЕЦ => unreachable("конец: переходов нет; работа при входе — в «Концы и ответ»")
  }
}
```

```
/// Работа концов при входе (в последнем, повторяемом без вреда этапе фиксации) и ответ вызвавшей стороне.
/// Вход в любой конец отменяет все открытые запросы (правило 22); машина отвечает ровно один раз (правило 35).

fn при_входе_в_конец(s State) {
  match s {
    // ОСТАНОВ: предложение открывается для записи; в журнал — «совещание остановлено: <остановка>», затем незакрытые находки:
    //   открытые и находки_В3, не вошедшие в открытые; итог не принят, программа продолжает остальную работу.
    ОСТАНОВ => {
      открыть_для_записи(предложение)
      журнал("совещание остановлено: {остановка}")
      журнал_находок(открытые)
      журнал_находок(не_вошедшие_в(находки_В3, открытые))
    }
    // ОШИБКА: предложение открывается для записи; в журнал — запись из перехода и данные машины; совещание остановлено, итог не принят;
    //   это дефект машины или реализации, решает человек вне машины.
    ОШИБКА => {
      открыть_для_записи(предложение)
      журнал(запись_перехода)
      журнал_данных_машины()
    }
    // КОНЕЦ: предложение открывается для записи; в журнал — решение (предложение), источник — подтверждение, число заходов номер_захода,
    //   открытые как «открыто»; приписка: «значимые находки прежних заходов, не вошедшие в «открыто», — в файлах заходов»;
    //   тип проверяющего в каждом заходе — по `methodology.md`, раздел 18.
    КОНЕЦ => {
      открыть_для_записи(предложение)
      журнал_решения(предложение, подтверждение, номер_захода, открытые)
      журнал("значимые находки прежних заходов, не вошедшие в «открыто», — в файлах заходов")
    }
  }
}

/// Таблица «конец → ответ» первоисточника (раздел «Контракт машины»): каждый конец и каждое значение остановка — одна строка.
fn ответ_по_концу(вызов Option[Request[MeetingInput]]) -> Response[MeetingResult] {
  let отказ = |причина FailCode, текст str| Refusal(Rejection {
    request: запрос_вызова, party: вызов.party, reason: причина, text: текст, trace: вызов.trace, step: вызов.step })
  match состояние {
    // КОНЕЦ, условие входа: всегда → Result: итог с числом заходов и открытыми находками
    КОНЕЦ => Result(Reply {
      request: запрос_вызова, party: вызов.party, trace: вызов.trace, step: вызов.step,
      result: MeetingResult { decision: предложение, source: подтверждение, passes: номер_захода, open: открытые } })
    // ОШИБКА, условие входа: всегда (дефект машины) → Refusal, NoResult; текст — запись из перехода
    ОШИБКА => отказ(NoResult, запись_перехода)
    ОСТАНОВ => match остановка {
      // ОСТАНОВ: остановка = «ни одна линза не ответила» → Refusal, NoResult
      "ни одна линза не ответила" => отказ(NoResult, остановка)
      // ОСТАНОВ: остановка = «В9: остановить совещание» (потолок заходов с открытыми находками) → Refusal, CeilingReached
      "В9: остановить совещание" => отказ(CeilingReached, остановка)
      // ОСТАНОВ: «ПАУЗА: остановить совещание», «<сбойное_обращение>: остановить совещание», «ИЗМЕНЁН: остановить совещание»
      //   или «ПОВТОР: остановить» (слово человека; у вложенной машины — сигнал «остановить от родителя» в ПАУЗЕ) → Refusal, StoppedByHuman
      "ПАУЗА: остановить совещание" | "ИЗМЕНЁН: остановить совещание" | "ПОВТОР: остановить" => отказ(StoppedByHuman, остановка)
      х if х == "{сбойное_обращение}: остановить совещание" => отказ(StoppedByHuman, остановка)
      // ОСТАНОВ: остановка = «отмена_запроса» → Refusal, Cancelled
      "отмена_запроса" => отказ(Cancelled, остановка)
      _ => unreachable("значение остановка вне таблицы «конец → ответ»: новое значение добавляет строку таблицы")
    }
  }
}
```

## Цикл исполнителя

```
/// Цикл исполнителя: ведёт автомат по правилам 13–24 и 35 спецификации.
/// Данные заходят только через события; запросы отправляются только после фиксации шага; состояние сохраняется до открытия ворот.
/// `вызов` — запрос, которым машину вызвали из другой машины (конверт исполнителя; у машины верхнего уровня `нет`).

fn запустить(вызов Option[Request[MeetingInput]], вход MeetingInput) {
  // начальные значения — раздел «Данные»
  трасса = новая_трасса(вызов)                       // дочерняя от внешней, если вызов есть
  запрос_вызова = если вызов != нет { вызов.id } иначе { "" }
  предложение = вход.proposal
  вопрос_автора = вход.author_question
  порядок_линз = вход.lens_order
  линзы = порядок_линз.map(id => Lens { id: id, lost: 0, probes: 0, attempt: 0 })
  состояние = ЗАХОД
  выполнить_шаг(новое_событие("старт"), Go(ЗАХОД))
  loop { обработать_очередь() }
}

/// Приём при приходе: в порядке прихода и в любом состоянии (правило 14).
fn при_приходе(сообщение Message) {
  счётчик_событий += 1                               // +1 при приходе любого события
  match сообщение {
    ответ роли, отказ, «нет ответа» (Response от открытой стороны) => {
      // чужой или поздний ответ: неизвестный идентификатор, закрытый или отменённый запрос, повторная доставка (правило 17)
      if ответ.request not in открытые_запросы || ответ.request in принятые_запросы {
        отбросить(событие_из(сообщение)); return
      }
      // форма: ответ не по форме исполнитель возвращает стороне в том же запросе; число возвратов задаёт состояние
      if !форма_верна(ответ) { вернуть_стороне(ответ); return }
      // объект, куда пишется результат (предложение при правке), изменился с начала попытки — результат не принимается,
      // запрос отменяется и отправляется заново (новая попытка, вход прочитан заново)
      if состояние in [ПРАВКА, ВОПРОС] && предложение_менялось_с_начала_попытки() { повторить_запрос(ответ.request); return }
      // одна фиксация: идентификатор в принятые_запросы, «При приёме», запись результата в хранилище, событие в очередь;
      // последним, повторяемым без вреда этапом — принятие файла попытки
      принятые_запросы += ответ.request
      при_приёме(состояние, ответ)
      записать_результат(состояние, ответ)
      положить_в_очередь(событие_из(ответ))
    }
    слово человека или сигнал => { записать_слово_человека(...) на воротах (правило 19); положить_в_очередь(событие) }
    срок => { // «нет ответа в срок»: порождает исполнитель по таймеру, код Timeout; у обращения человека срока нет (правило 19)
      положить_в_очередь(Сбой { причина: Timeout }) }
  }
}

/// При приёме (правило 14; запись линзы — событие.сторона).
fn при_приёме(s State, ответ Response[R]) {
  match s {
    ЛИНЗЫ => match ответ {
      // ответ: потери_подряд ← 0, пробы ← пробы из ответа (результат ответа, в событии не повторяется), ответившие + 1
      Result(r) => { запись_линзы(r.party).lost = 0; запись_линзы(r.party).probes = r.result.пробы; ответившие += 1 }
      // сбой: потери_подряд + 1, пробы ← 0
      Refusal(r) => { запись_линзы(r.party).lost += 1; запись_линзы(r.party).probes = 0 }
    }
    _ => ()
  }
}

/// Запись принятого результата в хранилище (правила 8, 14): роль возвращает результат, в хранилище машины не пишет.
fn записать_результат(s State, ответ Response[R]) {
  match s {
    СВИДЕТЕЛЬ => ответы_свидетеля[номер_захода] = ответ.result
    ЛИНЗЫ     => находки_линзы[(ответ.party, номер_захода)] = ответ.result.находки
    ПРАВКА | ВОПРОС => match ответ.result {      // EditResult: Done ведёт в ЗАХОД, Asked — в В7
      Done(текст)    => предложение = текст
      Asked(вопрос)  => { предложение = вопрос.proposal; вопрос_автора = вопрос.question }
    }
    _ => ()                                      // у остальных обращений результат — исход ворот, он идёт событием
  }
}

/// Обработка очереди: первое событие, которое ждёт текущее состояние; остальные остаются в очереди (правило 13).
fn обработать_очередь() {
  let событие = взять_первое_ожидаемое()          // сигналы ждёт любое состояние, кроме концов
  if событие == нет { ждать_прихода(); return }
  выполнить_шаг(событие, общие_события(событие) ?? step(состояние, событие.тело, событие))
}

/// Шаг — одна фиксация (правило 13): переходы, записи в хранилище, строки журнала, новые значения «состояние», «открытые_запросы»,
/// «принятые_запросы», «к_отправке» и счётчиков попыток пишутся вместе; незавершённый шаг откатывается.
fn выполнить_шаг(событие Incoming, переход Transition) {
  начать_фиксацию()
  номер_шага += 1                                  // растёт внутри фиксации; откат возвращает
  причина_шага = событие.идентификатор
  let t = переход
  if t == NotAwaited { откатить(); return }        // событие остаётся в очереди
  // принятый запрос закрывается переходом по своему событию: убирается из открытые_запросы и из принятые_запросы
  if событие.запрос != нет { закрыть_запрос(событие.запрос) }

  // цепочка операций и развилок и их переходов «сразу» до первого обращения или конца
  loop {
    match t {
      Stay => break                                // то же состояние
      Go(s) | Rerun(s) => {
        if t is Rerun { отменить_открытый_запрос_обращения(s) }      // «запуск заново» (правило 18): прежний запрос сначала отменяется
        состояние = s                              // запись «состояние» подразумевается у каждого перехода
        match вид(s) {
          Обращение | Конец => break               // ждёт события или конец
          Операция => { let результат = работа_операции(s); t = step(s, результат_как_событие(s, результат), событие) }
          Развилка => { t = step(s, Сразу, событие) }
        }
      }
    }
    проверить_инвариант_2()                        // номер_захода не уменьшается
  }
  зафиксировать()                                  // запись шага; затем действия во внешнем мире, повторяемые без вреда:
                                                   // переименование в `*.void-<k>.md`, принятие файла попытки, смена права записи
  после_фиксации()
}

/// Работа операций при входе (в одном шаге с переходом; отказа и «нет ответа» у операции нет).
fn работа_операции(s State) -> Option[[]str] {
  match s {
    ЗАМОК   => { копия = Some(предложение_с_отпечатком()); закрыть_для_записи(предложение); нет }
    РАЗБЛОК => { открыть_для_записи(предложение); нет }
    ВОЗВРАТ => { предложение = копия; нет }
    АННУЛ   => { перенести_в_архив(находки_линзы[(л, номер_захода)] для л в порядок_линз, ответы_свидетеля[номер_захода], суффикс: аннулирований[номер_захода]); нет }
    ФИЛЬТР  => {
      // четыре признака несостоятельных мнения (task-runner.md); каждое идёт в счёт по моделям; запись на то же место
      убрать_несостоятельные(находки_линзы, ответы_свидетеля[номер_захода])
      Some(линзы_без_критических())                // идентификаторы
    }
    СВОД    => { свод[номер_захода] = собрать_свод(номер_захода); нет }    // K, Z, D — суммы по линзам, P — наименьшее из проб
  }
}

/// После фиксации шага: сначала очередь, потом запросы (правило 13).
fn после_фиксации() {
  передать_вложенным_накопленные_сигналы()         // «стоп», «продолжить», «остановить», «отмена»; журнал «… передан(о) <id>»
  // перед отправкой смотрит во входящую очередь: «стоп человека», «стоп от родителя» или «отмена_запроса» — запросы не отправляются,
  // а сигнал разбирается (правила 23, 35)
  if в_очереди_есть([СтопЧеловека, СтопОтРодителя, ОтменаЗапроса]) { return }
  match вид(состояние) {
    Конец => {
      отменить_все_открытые_запросы()              // вход в любой конец (правило 22)
      при_входе_в_конец(состояние)
      отдать_ответ(ответ_по_концу(вызов))          // ровно один раз: из конца переходов нет
    }
    Обращение => отправить_запросы(состояние)
  }
}

/// Отправка запросов по состоянию. Состояние сохранено до открытия ворот; повторный вход ничего не отправляет стороне,
/// чей запрос открыт или лежит в принятых (правила 12, 14, 21).
fn отправить_запросы(s State) {
  match s {
    ЛИНЗЫ => {
      // стороны из к_отправке по порядку, пока открытых запросов меньше ПРЕДЕЛ_ЗАПРОСОВ (правило 21)
      while к_отправке != [] && открытые_запросы.len() < ПРЕДЕЛ_ЗАПРОСОВ {
        let линза = к_отправке.первый()
```
