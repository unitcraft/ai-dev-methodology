# Совещание агентов: код автомата

Стейт-машина совещания, записанная кодом на языке Нов: объявление данных и типов, перечисления `State` и `Event`, функция переходов `step(состояние, событие)` как `match` по состоянию и событию, концы с ответом по контракту машины, цикл исполнителя. Нормы — [methodology.md](methodology.md), раздел 18, «Согласование решения несколькими агентами».

**Первоисточник — [task-runner-meeting-states.md](task-runner-meeting-states.md)** (таблицы состояний, общие события, «Контракт машины»); правила формы — [state-machine-spec.md](state-machine-spec.md). Этот файл — производная запись того же автомата, а не второй источник истины: при любом расхождении верен первоисточник, а этот файл правится вслед за ним. Язык записи — Нов, https://github.com/nv-lang/nova (синтаксис — по `spec/syntax.ru.md` и `nova.ungrammar` того репозитория). **Код не компилировался и не проверялся компилятором Нова:** это псевдокод в синтаксисе Нова; места, где Нов не выражает записанное или где синтаксис не подтверждён спецификацией, помечены строкой `// псевдокод:` (перечень — в соглашениях, пункт 7). Машина отделена от исполнителя: `Машина` — данные и чистая логика (переходы, общие события, ответ по концу), `Исполнитель` — очередь, фиксация, отправка запросов, журнал, передача сигналов вложенным; снимки состояния лежат в `Хранилище` — протоколе с любой реализацией (база, диск, очередь сообщений); исполнитель с машиной совещания реализует протокол `Событие[MeetingInput, MeetingResult]`, поэтому машина может быть событием в другой машине (правило 35). Расширения, отличия от псевдокода раннера и опытный статус режима описаны в шапке первоисточника и здесь не повторяются; раннером машина не исполняется. Схема раннера ([task-runner-pseudocode.md](task-runner-pseudocode.md), [task-runner-meeting-pseudocode.md](task-runner-meeting-pseudocode.md)) — другая форма записи, помечена устаревшей и этим файлом не заменяется. Имя файла — по `AGENTS.md`, «Вынесенные алгоритмы», форма `automaton`.

## Соглашения записи

1. **Типы** — латинские имена и поля блока «Типы на Нове» первоисточника (`Lens`, `Request[T]`, `Finding`, …); соответствие — в таблице ниже. Новых типов данных нет; добавлены только типы записи автомата: `State`, `Event`, `Incoming`, `Transition`, `Kind`, `Message`, `ИтогЛинзы` (то, что возвращает линза: находки и пробы), `Машина` (все данные машины; см. пункт 9), `Исполнитель`, `Снимок`, `Хранилище`, `Событие` (см. пункт 10).
2. **Идентификаторы.** Переменные, состояния, события и их поля — те же русские имена в змеином регистре, что в первоисточнике (правило 25 спецификации: имя одной сущности одно); имена состояний — как есть. Нова кириллические идентификаторы не поддерживает (владелец, 2026-10-17); для псевдокода Нова русские имена оставлены пока — решение этого файла, они ищутся одним поиском по обоим файлам; при переходе на выполнимый Нов их заменяют латинскими по таблице соответствия. Латиница — типы, варианты типов первоисточника и поля его записей.
3. **Данные события.** Поля варианта события берутся образцом в `match`: `Сбой { причина } => …`; при совпадении имени поля с переменной машины поле переименовывается: `В7_ответил { ответ_человека: слово_ответа }`. «Сторона события» и идентификатор события — `событие.сторона`, `событие.идентификатор` (конверт `Incoming`, правила 13 и 31). Шаблон строки журнала «<сторона события>» — `${событие.сторона}`.
4. **Запись Нова.** `ro` — неизменяемая привязка, `mut` — изменяемая переменная; «←» — `=`; «+ 1» — `+= 1`; отсутствующее значение — `None`, значение — `Some(x)`, `Option[T]`; `HashMap[K, V]` — отображение (чтение отсутствующего ключа — функциями `свод`, `аннулирований`: у `аннулирований` — `0`); `да`/`нет` — `true`/`false`; строки — `"… ${выражение} …"`; комментарий — `//`, документирующий — `///` (перед объявлением, пустая строка перед ним); «добавить», «объединить_без_повторов» — функции правила 30; «сразу» — событие `Сразу`; «то же состояние» — `Stay`; «запуск заново» — `Rerun(S)`; «Куда» — `Go(S)`. Имя функции записи в журнал — `писать_журнал`: переменная машины `журнал` занимает имя.
5. **Строка таблицы — ветка кода.** Перед каждой строкой первоисточника (условие или событие, «Что меняется», «Куда») стоит комментарий `// <СОСТОЯНИЕ> #<номер строки>: …` с её текстом; порядок строк как в первоисточнике. Строка «иначе» каждой развилки — последняя ветка, ведёт в `ОШИБКА`. Строки «Вход», «Выход», «При входе», «Сторона» и одна строка простыми словами на состояние — комментарии `//` у состояния.
6. **Механика исполнителя.** Раздел «Механика исполнителя» — перечень механики контракта, фиксации и приёма (правила 13–22 спецификации), разделённый по владельцу: свободные функции, методы `Машина`, методы `Исполнитель`; большинство объявлено только сигнатурой, телом записаны те, что выражаются данными (`ошибка_машины`, `передать_вложенным`, `линзы`, `зафиксировать`, `отдать_ответ`, `получатель`, `снимок`).
7. **Строки `// псевдокод:`** стоят там, где записанное — не Нов или не подтверждено его спецификацией: значения констант (параметры проекта); функции без тела (сигнатуры механики); обобщённый метод `fn Машина mut @имя[R](…)` (форма не подтверждена); доступ к результату роли обобщённого `R` в приёме ответа; `unreachable`; ключ-кортеж `HashMap[(str, int), …]` у `находки_линзы` — в Нове он пока ломает кодогенерацию (запись M-hashmap-tuple-key-mono, открыта), поэтому в Нове пока вложенное отображение `HashMap[str, HashMap[int, V]]` или составной ключ-строка. **Подтверждено спецификацией Нова** (проверено оркестратором проекта по чтению репозитория языка, 2026-10-18; компилятором не проверено): `///` — внешний документирующий комментарий (`spec/decisions/03-syntax.md`, D104; привязан к следующему полю записи и варианту суммы); `never` строчная — тип выражения, которое не возвращает значения (`spec/decisions/04-effects.md`, D25), его и берёт `unreachable`; `Never` заглавная — пустой тип, нужен только как аргумент `E` в `Effect[E, Never]`, здесь не используется; `fn Машина.new()` — статическое объявление (`spec/syntax.ru.md`, `fn Account.new(…)`); `.contains()` на `[]T` (std, `collections/vec/access.nv`); `.len()` на списке (`vec/core.nv`); срез `v[a..]`, `v[a..b]` (`vec/slice.nv`, Plan 284; за границами паника, безопасно `v.get(a..b)`); присваивание как ветка `match` допустимо (`nova.ungrammar`, `MatchArm`), здесь оно записано блоком `=> { x = v }`. **Отображения.** У `HashMap` нет `[]` и `get_mut`: чтение — `get(ключ) -> Option[V]` (в `линзы`, `свод`, `аннулирований`), запись — `insert(ключ, значение)`; поле записи линзы меняется вставкой изменённой копии (`установить_потери`, `установить_пробы`, `установить_попытку`). Длина текста (`.len()` на `str`) нигде не берётся: `.len()` стоит только на списках. **Записано по слову владельца, спецификацией не подтверждено (2026-10-18):** оператор `??` для `Option` — значение либо запасное, правая часть вычисляется только при `None` (`аннулирований`, цикл исполнителя). **Протоколы** (прочитано в `spec/syntax.ru.md`, раздел «Структурные "интерфейсы" — protocol», 2026-10-18; компилятором не проверено): `type Имя protocol { @метод() -> T }`, изменяющий метод — `mut @метод(…)`, обобщённый протокол — `type Next[T] protocol { … }`, соответствие структурное, `impl` не нужен — поэтому `Исполнитель` реализует `Событие[MeetingInput, MeetingResult]` совпадением метода `вызвать`. **Не подтверждено спецификацией, без пометки в коде:** поле записи с типом протокола (`хранилище Хранилище`; в спецификации протокол — тип параметра функции, `fn dump(x Hash)`), русские имена параметров типа `[Вход, Выход]`, `return` из `loop` значением функции (`цикл`). **Именование читателей по ключу:** читатель элемента поля называется по полю (`@свод(номер)`, `@аннулирований(номер)`, `@линзы(id)`) — форма чтения свойства по слову владельца, 2026-10-18; совпадение имени метода и поля в Нове не проверено. **Тело функции:** блок без стрелки `fn … { … }` (последнее выражение — значение) или `fn … => выражение`; `=> { поле: значение, … }` — литерал записи, так записан только `Машина.new` (спецификация Нова: `FnDecl … (Block | FnExprBody)`, `FnExprBody = '=>' Expr`; проверено оркестратором проекта, 2026-10-18).
8. **Уточнения записи автомата сверх первоисточника:** событие `Срок` порождает `Incoming` с `запрос: Some(ид)` и стороной по `сторона_запроса(ид)` (первоисточник даёт только `Сбой { причина: Timeout }`); ветка `None` у `копия` в ВОЗВРАТЕ пишет строку журнала «ВОЗВРАТ: копии нет» (недостижима: копию пишет ЗАМОК); `Message[R]`, `Response[R]` и функции с `R` — обобщённые, `[R]` объявлен у каждой.
9. **Данные машины — поля типа `Машина`**, а не переменные модуля: поля названы как переменные раздела «Данных» первоисточника (правило 25), начальные значения — в `Машина.new()`. Функции, читающие или пишущие данные, — методы `Машина`: форма `fn Машина @имя(…)` читает, `fn Машина mut @имя(…)` меняет; обращение к полю и вызов метода — через `@` (спецификация Нова: `fn Account mut @deposit(…) { @_balance += … }`). Функции без данных (`вид`, `в_конце`, списковые помощники, `сторона_запроса`) остаются свободными. Имя `Машина`: `State` занято перечнем состояний; `Machine` не взято — имя русское, как имена данных и как у типа записи автомата `ИтогЛинзы`; тип несёт данные машины и чистую логику, а не механику (её несёт `Исполнитель`, пункт 10).
10. **Исполнитель, хранилище, событие.** `Исполнитель` владеет `Машина` и тем, чего в данных первоисточника нет: очередь входящих `очередь`, запрос вызова `вызов`, `готовый_ответ`, `хранилище`. Данные раздела «Данные» первоисточника остаются полями `Машина`, в том числе то, что пишет исполнитель (`трасса`, `номер_шага`, `счётчик_событий`, `причина_шага`, `запрос_вызова`, `открытые_запросы`, `принятые_запросы`, `к_отправке`, счётчики попыток, `журнал`, внешние объекты): исполнитель меняет их через `@машина.поле`, машина — только в строках таблицы. Новое поле `Машина.сигналы_вложенным` — очередь сигналов вложенным: шаг ставит сигнал, исполнитель передаёт его после фиксации (правило 35). `Хранилище` — `protocol` с `загрузить(идентификатор_запроса) -> Option[Снимок]` и `сохранить(идентификатор_запроса, снимок)`; `Снимок` — вся `Машина`, `очередь`, `вызов`, `готовый_ответ`; реализация — любая, вне файла. `зафиксировать` вызывает `сохранить` в конце шага, ДО отправки запросов (правило 13). Входов два: `начать(запрос)` — новая машина, записи линз, ЗАХОД, фиксация, цикл; `возобновить(идентификатор_запроса)` — загрузка снимка и продолжение с сохранённого `состояние` (запросы без принятого ответа уходят повторно, ПАУЗА остаётся до «продолжить»; правила 12, 14, 22). Остановка исполнителя — выход из цикла (завершение процесса): состояние уже сохранено. `запрос_вызова` у машины всегда `запрос.id`: через `Событие` машину вызывают всегда запросом. `Событие[Вход, Выход]` с методом `вызвать(запрос) -> Response[Выход]` реализует `Исполнитель`; повтор запроса с тем же идентификатором возвращает готовый ответ (правило 35, п. 4).
11. **`unreachable(текст)`** — тип `never`: ничего не отдаёт и аварийно прерывает исполнителя. Ветка невозможна при соблюдении инвариантов — это ошибка программы. Дефект самой машины (развилка, у которой ни одно условие не подошло) идёт иначе: строка «иначе → ОШИБКА», состояние ОШИБКА, ответ-отказ `NoResult`. `unreachable` стоит: у концов ОСТАНОВЛЕНО, ОШИБКА, КОНЕЦ в `step` (переходов нет); в `ответ_по_концу` (значение `остановка` вне таблицы; ответ не из конца); в `работа_операции` (состояние без операции); в `счётчик_попыток` и `увеличить_счётчик_попыток` (сторона вне «свидетель», «автор», «человек»); в `линзы` (записи линзы нет); в `получатель` (запрос вызова не принят); в `вызвать` (снимок только что загружен).

## Типы

```nova
module meeting_automaton

/// Линза
type Lens { id str, lost int, probes int, attempt int }

/// Запрос
type Request[T] { id str, attempt int, party str, input T, idle_term int, trace str, step int }

/// Ответ
type Response[R] enum
  | Result(Reply[R])
  | Refusal(Rejection)

/// Ответ (с результатом)
type Reply[R] { request str, party str, result R, trace str, step int }

/// Ответ (отказ)
type Rejection { request str, party str, reason FailCode, text str, trace str, step int }

/// КодСбоя
type FailCode enum
  | NoResult
  | ModelRefused
  | ConnectionLost
  | FormNotFixed
  | Timeout
  | StoppedByHuman  // остановлено человеком
  | CeilingReached  // потолок заходов с открытыми находками
  | Cancelled  // отменено родителем

/// ОтветСвидетеля
type WitnessAnswer enum
  | Answered(Claim)
  | NotMeasured(str)

/// ОтветСвидетеля (с утверждением)
type Claim { kind str, statement str, source str, excerpt Option[str], check Check }

/// Сверка
type Check enum
  | Confirmed
  | ChannelDistortion
  | NotConfirmed

/// ИтогПравки
type EditResult enum
  | Done(str)
  | Asked(Asking)

/// ИтогПравки (вопрос)
type Asking { proposal str, question str }

/// Находка
type Finding { severity Severity, evidence str, repeat bool, question bool }

/// Критичность
type Severity enum
  | Critical
  | Significant
  | Desirable

/// Свод
type Summary { k int, p int }

/// ВходСовещания
type MeetingInput { proposal str, lens_order []str, author_question Option[str] }

/// ИтогСовещания; passes = номер_захода при принятии; потолок и passes считаются по номерам заходов, включая не засчитанный как чистый
type MeetingResult { decision str, source str, passes int, open []Finding }

/// Запись автомата: итог линзы (находки и пробы), результат роли ЛИНЗЫ
type ИтогЛинзы { находки []Finding, пробы int }

/// Запись автомата: событие с конвертом (правила 13 и 31 спецификации)
type Incoming {
  идентификатор str,        // «<вид>-<номер по счётчику событий>»

  запрос Option[str],       // идентификатор запроса, чьим исходом событие пришло (механика закрытия запроса)

  | Операция
  | Развилка
  | Конец

/// Запись автомата: то, что исполнитель получает при приходе: ответ или отказ роли, слово человека, сигнал, срок (правила 14, 16, 23)
type Message[R] enum
  | ОтветРоли(Response[R])  // результат или отказ открытого запроса
  | Слово(Event)            // слово ворот человека или общий сигнал
  | Срок(str)               // «нет ответа в срок»: идентификатор запроса; порождает исполнитель

/// Запись автомата: куда ведёт строка
type Transition enum
  | Go(State)               // «Куда»: состояние
  | Rerun(State)            // «Куда»: состояние, запуск заново (правило 18)
  | Stay                    // «Куда»: то же состояние
  | NotAwaited              // событие этого состояния не ждёт: остаётся в очереди (правило 13)
```

```nova
/// Разбираются до строк состояний (правило 23): сначала общие события, затем step.
/// «Стоп человека» в ПАУЗЕ и в концах и «продолжить» вне ПАУЗЫ отбрасываются с записью в журнал (правила 17, 23);
/// в таблицах первоисточника для них строки нет, формат строки там не задан.
fn Машина mut @общие_события(событие Incoming) -> Option[Transition] {
  ro ev = событие.тело
  match ev {

    СтопЧеловека { слово_человека, автор, источник } => {
      // ОБЩ стоп_человека #1: в любом состоянии, кроме ОСТАНОВЛЕНО, ОШИБКА, КОНЕЦ и ПАУЗА
      if в_конце_или_паузе(@состояние) { @отбросить(событие); return Some(Stay) }
      @записать_слово_человека(событие, слово_человека, автор, источник)
      @писать_журнал("стоп человека: ${автор}, ${источник}, запись ${событие.идентификатор}")
      @предыдущее = имя_состояния(@состояние)
      // открытые_запросы без принятого ответа отменены (правило 18), кроме запросов к вложенным машинам
      @отменить_открытые_без_принятого(true)
      // вложенные получают сигнал «стоп» после фиксации шага; журнал «стоп передан <идентификатор_запроса>» на каждого (правило 35, пункт 8)
      @передать_вложенным("стоп")
      Some(Go(ПАУЗА))
    }

    СтопОтРодителя { идентификатор_запроса } => {
      // ОБЩ стоп_от_родителя #1: те же состояния, если идентификатор_запроса события = запрос_вызова, иначе сигнал отброшен (правило 17)
      if в_конце_или_паузе(@состояние) { @отбросить(событие); return Some(Stay) }
      if идентификатор_запроса != @запрос_вызова { @отбросить(событие); return Some(Stay) }
      @писать_журнал("пауза: причина — стоп от родителя, ${идентификатор_запроса}, запись ${событие.идентификатор}")
      // слова человека не записываются (""): слов_человека не пишется
      @предыдущее = имя_состояния(@состояние)
      @отменить_открытые_без_принятого(true)
      @передать_вложенным("стоп")
      Some(Go(ПАУЗА))
    }

    ОтменаЗапроса { идентификатор_запроса } => {
      // событие приходит в любом состоянии
      // ОБЩ отмена_запроса #1: идентификатор_запроса события не равен запрос_вызова
      if идентификатор_запроса != @запрос_вызова {
        @писать_журнал("отмена отброшена: чужой запрос ${идентификатор_запроса}, запись ${событие.идентификатор}")
        return Some(Stay)
      }
      // ОБЩ отмена_запроса #2: = запрос_вызова, и ответ уже отдан (состояние — ОСТАНОВЛЕНО, ОШИБКА или КОНЕЦ)
      if идентификатор_запроса == @запрос_вызова && в_конце(@состояние) {
        @писать_журнал("отмена отброшена: ответ уже отдан, ${идентификатор_запроса}, запись ${событие.идентификатор}")
        return Some(Stay)
      }
      // ОБЩ отмена_запроса #3: = запрос_вызова, и ответ не отдан
      if идентификатор_запроса == @запрос_вызова && !в_конце(@состояние) {
        @писать_журнал("отмена запроса: ${идентификатор_запроса}, запись ${событие.идентификатор}")
        @остановка = "отмена_запроса"
        @отменить_открытые_без_принятого(false)    // правило 18
        @передать_вложенным("отмена")                              // отмена передана вложенным из открытые_запросы
        return Some(Go(ОСТАНОВЛЕНО))
      }
      // ОБЩ отмена_запроса #4: иначе
      Some(@ошибка_машины("ошибка машины: разбор отмены_запроса, ни одно условие не подошло"))
    }

    ПАУЗА_продолжить { .. } | ПАУЗА_продолжить_от_родителя { .. } => {
      // «продолжить» вне ПАУЗЫ отбрасывается с записью в журнал (правила 17, 23); в ПАУЗЕ — строки ПАУЗА #1 и #3
      if @состояние != ПАУЗА { @отбросить(событие); return Some(Stay) }
      None
    }

    _ => None    // остальные события — строки состояний
  }
}
```

## Переходы

```nova
/// Переход по событию. ev — событие, которое ждёт состояние s (у операции — Сразу, у развилки — Сразу без данных);
/// событие — исходное событие шага: его данные (сторона, идентификатор) доступны всей цепочке до ближайшего обращения (правило 13).
/// Состояние пишется при фиксации; в «Что меняется» оно не повторяется.
fn Машина mut @step(s State, ev Event, событие Incoming) -> Transition {
  match s {

  // ===================== ЗАХОД — развилка =====================
  // Начало очередного захода проверки: смотрит, остались ли вопросы к свидетелю; есть — идёт к свидетелю, нет — сразу к проверке линзами.
  // Вход: вопрос_автора?; номер_захода; порядок_линз; находки_линзы[линза, номер_захода - 1]? (по каждой линзе из порядок_линз, из них вопросы проверяющих, `вопрос` = да)
  ЗАХОД => {
    // ЗАХОД #1: вопрос_автора есть
    if @вопрос_автора != None { return Go(СВИДЕТЕЛЬ) }
    // ЗАХОД #2: вопрос_автора отсутствует, и в находках любой линзы захода номер_захода - 1 есть вопросы проверяющих (находки с `вопрос` = да)
    if @вопрос_автора == None && @есть_вопросы_проверяющих(@номер_захода - 1) { return Go(СВИДЕТЕЛЬ) }
    // ЗАХОД #3: вопрос_автора отсутствует, и в находках любой линзы захода номер_захода - 1 вопросов проверяющих (находок с `вопрос` = да) нет
    if @вопрос_автора == None && !@есть_вопросы_проверяющих(@номер_захода - 1) { return Go(ЗАМОК) }
    // ЗАХОД #4: иначе
    @ошибка_машины("ошибка машины: развилка ЗАХОД, ни одно условие не подошло")
  }

  // ===================== СВИДЕТЕЛЬ — обращение =====================
  // Просит свидетеля ответить на вопросы автора и проверяющих по фактам, чтобы проверка опиралась на сверенные ответы, а не на догадки.
  // При входе: свидетель отвечает на вопросы автора в предложении и проверяющих в находках любой линзы захода номер_захода - 1;
  //   исполнитель сверяет выдержки: несовпадение — один возврат «исправь выдержку» в том же запросе, снова несовпадение — строка «не подтверждено»;
  //   принятые ответы исполнитель записывает в хранилище.
  // Сторона: свидетель.
  // Вход (сторона): вопрос_автора?; находки_линзы[линза, номер_захода - 1]? (по каждой линзе, из них вопросы проверяющих, `вопрос` = да); предложение
  // Вход (исполнитель): номер_захода; порядок_линз (по ним выбирает находки захода номер_захода - 1)
  // Выход: ответы_свидетеля[номер_захода] []WitnessAnswer
  СВИДЕТЕЛЬ => match ev {
    // СВИДЕТЕЛЬ #1: ответ
    Ответ => {
      @вопрос_автора = None                      // сброс после ответа свидетеля
      Go(ЗАМОК)
    }
    // СВИДЕТЕЛЬ #2: сбой (причина: КодСбоя)
    Сбой { причина } => {
      @писать_журнал("СВИДЕТЕЛЬ не ответил: ${причина}")
      @сбойное_обращение = "СВИДЕТЕЛЬ"
      Go(СБОЙ)
    }
    _ => NotAwaited
  }

  // ===================== ЗАМОК — операция =====================
  // Запоминает текст предложения на начало захода и запрещает его править, чтобы проверяющие читали одно и то же и правку за время проверки можно было заметить.
  // При входе: сохраняется копия предложения с отпечатком; предложение закрывается для записи.
  // Вход: предложение; порядок_линз
  // Выход: копия
  ЗАМОК => match ev {
    // ЗАМОК #1: сразу
    Сразу => {
      @к_отправке = @порядок_линз
      @ответившие = 0
      Go(ЛИНЗЫ)
    }
    _ => NotAwaited
  }

  // ===================== ЛИНЗЫ — обращение =====================
  // Рассылает предложение проверяющим (у каждого своя точка зрения — линза) и собирает их находки; число одновременных запросов ограничено параметром.
  // При входе: исполнитель отправляет запрос каждой линзе из к_отправке (правило 21); линза проверяет предложение и ответы свидетеля
  //   и возвращает находки; находок других линз этого захода она не видит; форму её находок проверяет исполнитель, возвращая неверную
  //   в том же запросе, и записывает принятые находки в хранилище.
  // Сторона: набор — линзы из порядок_линз; идентификатор линзы — идентификатор стороны; запросов одновременно не больше ПРЕДЕЛ_ЗАПРОСОВ.
  // При приёме (правило 14; запись линзы — событие.сторона): см. при_приёме_ЛИНЗЫ в разделе «Цикл исполнителя».
  // Вход (сторона): предложение; ответы_свидетеля[номер_захода]? (только запрошенной линзе; идентификатор линзы входит в запрос и возвращается с ответом)
  // Вход (исполнитель): номер_захода; к_отправке; линзы (lost и probes при приёме); ответившие
  // Выход: находки_линзы[линза, номер_захода]; пробы
  ЛИНЗЫ => match ev {
    // ЛИНЗЫ #1: ответ
    Ответ => Go(ВСЕ_ЗАКРЫТЫ)
    // ЛИНЗЫ #2: сбой (сторона: идентификатор линзы; причина: КодСбоя)
    Сбой { причина } => {
      @писать_журнал("линза ${событие.сторона} не ответила: ${причина}")
      Go(ОТКАЗ)
    }
    _ => NotAwaited
  }

  // ===================== ОТКАЗ — развилка =====================
  // Решает, что делать с линзой, которая не ответила: первый раз — отбросить её в этом заходе, второй подряд — спросить человека, не ответила и на повторе — отбросить.
  // Вход: линзы (только запись линзы событие.сторона: lost); к_отправке; номер_захода
  ОТКАЗ => {
    // ОТКАЗ #1: потери_подряд линзы событие.сторона = 1
    if @линзы(событие.сторона).lost == 1 {
      @писать_журнал("линза ${событие.сторона} отброшена в заходе ${@номер_захода}")
      return Go(ВСЕ_ЗАКРЫТЫ)
    }
    // ОТКАЗ #2: потери_подряд линзы событие.сторона = 2
    if @линзы(событие.сторона).lost == 2 {
      @сбойное_обращение = "ЛИНЗЫ"
      @к_отправке = добавить([событие.сторона], @к_отправке)
      return Go(СБОЙ)
    }
    // ОТКАЗ #3: потери_подряд линзы событие.сторона = 3
    if @линзы(событие.сторона).lost == 3 {
      @установить_потери(событие.сторона, 1)
      @писать_журнал("линза ${событие.сторона} отброшена в заходе ${@номер_захода}")
      return Go(ВСЕ_ЗАКРЫТЫ)
    }
    // ОТКАЗ #4: иначе
    @ошибка_машины("ошибка машины: развилка ОТКАЗ, ни одно условие не подошло")
  }

  // ===================== ВСЕ_ЗАКРЫТЫ — развилка =====================
  // Проверяет, все ли линзы разобраны: остались неотправленные или ждущие ответа — идёт к ним, все закрыты — дальше, а если не ответила ни одна — останавливает совещание.
  // Вход: к_отправке; открытые_запросы; ответившие
  ВСЕ_ЗАКРЫТЫ => {
    // ВСЕ_ЗАКРЫТЫ #1: к_отправке — не пустой список
    if @к_отправке.len() > 0 { return Go(ЛИНЗЫ) }
    // ВСЕ_ЗАКРЫТЫ #2: к_отправке — пустой список, и открытые_запросы — не пустой список
    if @к_отправке.len() == 0 && @открытые_запросы.len() > 0 { return Go(ЛИНЗЫ) }
    // ВСЕ_ЗАКРЫТЫ #3: к_отправке — пустой список, открытые_запросы — пустой список, и ответившие больше 0
    if @к_отправке.len() == 0 && @открытые_запросы.len() == 0 && @ответившие > 0 { return Go(РАЗБЛОК) }
    // ВСЕ_ЗАКРЫТЫ #4: к_отправке — пустой список, открытые_запросы — пустой список, и ответившие = 0
    if @к_отправке.len() == 0 && @открытые_запросы.len() == 0 && @ответившие == 0 {
      @остановка = "ни одна линза не ответила"
      return Go(ОСТАНОВЛЕНО)
    }
    // ВСЕ_ЗАКРЫТЫ #5: иначе
    @ошибка_машины("ошибка машины: развилка ВСЕ_ЗАКРЫТЫ, ни одно условие не подошло")
  }

  // ===================== СБОЙ — обращение =====================
  // Спрашивает человека, что делать, когда роль не ответила: повторить обращение или остановить совещание.
  // При входе: ворота В13: запрос обращения «сбойное_обращение» закончился сбоем (у ЛИНЗЫ — вторым подряд у линзы, чей идентификатор уже стоит
  //   первым в к_отправке); причина — в журнале. Повтор линзы, не ответившей и на этот раз, ворот не открывает: линза отбрасывается
  //   (ОТКАЗ, потери_подряд = 3), как в `check_meeting`. Это обращение — человеку: срока бездействия и сбоя у него нет (правило 19).
  // Сторона: человек.
  // Вход: сбойное_обращение
  // Выход: исход ворот
  СБОЙ => match ev {
    // СБОЙ #1: В13: «повторить»
    В13_повторить => Go(ПОВТОР_ОБРАЩЕНИЯ)
    // СБОЙ #2: В13: «остановить совещание»
    В13_остановить_совещание => {
      @остановка = "${@сбойное_обращение}: остановить совещание"
      Go(ОСТАНОВЛЕНО)
    }
    _ => NotAwaited
  }

  // ===================== ПОВТОР_ОБРАЩЕНИЯ — развилка =====================
  // Возвращает машину к той роли, которая не ответила, чтобы обратиться к ней ещё раз.
  // Вход: сбойное_обращение
  ПОВТОР_ОБРАЩЕНИЯ => {
    // ПОВТОР_ОБРАЩЕНИЯ #1: сбойное_обращение = «СВИДЕТЕЛЬ»
    if @сбойное_обращение == "СВИДЕТЕЛЬ" { return Rerun(СВИДЕТЕЛЬ) }

    if @сбойное_обращение == "ЛИНЗЫ" { return Rerun(ЛИНЗЫ) }

    if @сбойное_обращение == "ПРАВКА" { return Rerun(ПРАВКА) }
    // ПОВТОР_ОБРАЩЕНИЯ #4: сбойное_обращение = «ВОПРОС»
    if @сбойное_обращение == "ВОПРОС" { return Rerun(ВОПРОС) }
    // ПОВТОР_ОБРАЩЕНИЯ #5: иначе

  }

  // ===================== РАЗБЛОК — операция =====================
  // Снова разрешает править предложение: линзы закончили чтение.
  // При входе: предложение открывается для записи.
  // Вход: предложение
  // Выход: нет
  РАЗБЛОК => match ev {
    // РАЗБЛОК #1: сразу
    Сразу => Go(СВЕРКА)
    _ => NotAwaited
  }

  // ===================== СВЕРКА — развилка =====================
  // Проверяет, не изменили ли предложение за время проверки: изменено или нечитаемо — заход недействителен, нужен человек; не изменено — идём дальше.
  // Вход: предложение? (не прочитано); копия
  СВЕРКА => {
    // СВЕРКА #1: предложение прочитано и равно копии

    if !@предложение_прочитано() { return Go(ИЗМЕНЁН) }
    // СВЕРКА #4: иначе
    @ошибка_машины("ошибка машины: развилка СВЕРКА, ни одно условие не подошло")
  }

  // ===================== ИЗМЕНЁН — обращение =====================
  // Показывает человеку исходную копию и изменённое предложение и спрашивает: оставить правку, вернуть копию или остановить совещание.
  // При входе: ворота В13 с копией и изменённым предложением.
  // Сторона: человек.
  // Вход (сторона): копия; предложение?
  // Вход (исполнитель): номер_захода; аннулирований[номер_захода]
  // Выход: исход ворот
  ИЗМЕНЁН => match ev {
    // ИЗМЕНЁН #1: В13: «оставить правку»
    В13_оставить_правку => {
      @аннулирований.insert(@номер_захода, @аннулирований(@номер_захода) + 1)
      Go(АННУЛ)
    }
    // ИЗМЕНЁН #2: В13: «вернуть копию»
    В13_вернуть_копию => {
      @аннулирований.insert(@номер_захода, @аннулирований(@номер_захода) + 1)
      Go(ВОЗВРАТ)
    }
    // ИЗМЕНЁН #3: В13: «остановить совещание»
    В13_остановить_совещание => {
      @остановка = "ИЗМЕНЁН: остановить совещание"
      Go(ОСТАНОВЛЕНО)
    }
    _ => NotAwaited
  }

  // ===================== ВОЗВРАТ — операция =====================
  // Заменяет изменённое предложение сохранённой копией.
  // При входе: предложение заменяется копией.
  // Вход: копия
  // Выход: предложение
  ВОЗВРАТ => match ev {

    Сразу => Go(АННУЛ)
    _ => NotAwaited

  // При входе: находки_линзы[линза, номер_захода] по каждой линзе и ответы_свидетеля[номер_захода] переносятся в архив недействительных заходов

  АННУЛ => match ev {

    Сразу => Go(ЗАХОД)
    _ => NotAwaited
  }

  // Убирает из находок несостоятельные мнения (выдуманные цитаты, находки без доказательства) и отмечает линзы, у которых не осталось критических находок.
  // При входе: убираются несостоятельные мнения (четыре признака, `task-runner.md`, «Совещание агентов», «Несостоятельные мнения»; среди них ответ

  // Вход: номер_захода; порядок_линз; находки_линзы[линза, номер_захода] (по каждой линзе из порядок_линз); ответы_свидетеля[номер_захода]?
  // Выход: находки_линзы[линза, номер_захода] (после фильтра — те же объекты хранилища без несостоятельных мнений, запись на то же место);

    Сразу_ФИЛЬТР { линзы_без_критических } => {

  // При входе: записывается свод[номер_захода]: итоговая строка «Заход <номер_захода>: критических K, значимых Z, желательных D, проб P»
  //   (K, Z и D — суммы по линзам, P — наименьшее из проб линз), затем находки с меткой линзы.
  // Вход: номер_захода; находки_линзы[линза, номер_захода] и пробы (по каждой линзе из линзы); пробы (по каждой линзе из линзы)
  // Выход: свод[номер_захода]
  СВОД => match ev {
    // СВОД #1: сразу
    Сразу => Go(РАЗБОР)
    _ => NotAwaited
  }

  // ===================== РАЗБОР — развилка =====================
  // Читает итоговую строку: чистый заход без проб не засчитывается и идёт заново, в остальных случаях сводка уходит человеку.
  // Вход: свод[номер_захода]; номер_захода; без_проб_подряд
  РАЗБОР => match @свод(@номер_захода) {
    // РАЗБОР #1: итог свода есть, и критических больше 0
    Some(итог) if итог.k > 0 => {
      @без_проб_подряд = 0
      Go(В3)
    }
    // РАЗБОР #2: итог свода есть, критических нет, и проб не меньше ПРОБ_В_ЧИСТОМ
    Some(итог) if итог.k == 0 && итог.p >= ПРОБ_В_ЧИСТОМ => {
      @без_проб_подряд = 0
      Go(В3)
    }
    // РАЗБОР #3: итога свода нет
    None => {
      @писать_журнал("итоговой строки нет")
      @без_проб_подряд = 0
      Go(В3)
    }
    // РАЗБОР #4: итог свода есть, критических нет, и проб меньше ПРОБ_В_ЧИСТОМ
    Some(итог) if итог.k == 0 && итог.p < ПРОБ_В_ЧИСТОМ => {
      @писать_журнал("заход ${@номер_захода}: чистый без проб, не засчитан")
      @номер_захода += 1
      @без_проб_подряд += 1
      Go(БЕЗ_ПРОБ)
    }
    // РАЗБОР #5: иначе
    _ => @ошибка_машины("ошибка машины: развилка РАЗБОР, ни одно условие не подошло")
  }

  // ===================== БЕЗ_ПРОБ — развилка =====================
  // Считает чистые заходы без проб подряд: первый — просто повторить проверку, второй — спросить человека.
  // Вход: без_проб_подряд
  БЕЗ_ПРОБ => {
    // БЕЗ_ПРОБ #1: без_проб_подряд = 1
    if @без_проб_подряд == 1 { return Go(ЗАХОД) }
    // БЕЗ_ПРОБ #2: без_проб_подряд больше 1
    if @без_проб_подряд > 1 { return Go(ПОВТОР) }
    // БЕЗ_ПРОБ #3: иначе
    @ошибка_машины("ошибка машины: развилка БЕЗ_ПРОБ, ни одно условие не подошло")
  }

  // ===================== ПОВТОР — обращение =====================
  // Спрашивает человека, что делать после второго подряд чистого захода без проб: повторить проверку или остановить.
  // При входе: ворота В13: проверка второй раз подряд без проб.
  // Сторона: человек.
  // Вход: нет.
  // Выход: исход ворот
  ПОВТОР => match ev {
    // ПОВТОР #1: В13: «повторить»
    В13_повторить => Go(ЗАХОД)
    // ПОВТОР #2: В13: «остановить»
    В13_остановить => {
      @остановка = "ПОВТОР: остановить"
      Go(ОСТАНОВЛЕНО)
    }
    _ => NotAwaited
  }

  // ===================== В3 — обращение =====================
  // Показывает человеку находки и пробы захода; он может поднять критичность находок или не засчитать заход, если пробы — не настоящие пробы.
  // При входе: ворота В3: человек читает находки и пробы, может поднять критичность; по его настройке ворота только показывают и идут дальше
  //   как «засчитан» с находками свода без поправки.
  // Сторона: человек.
  // Вход (сторона): свод[номер_захода]; находки_линзы[линза, номер_захода] (по каждой линзе)
  // Вход (исполнитель): номер_захода; порядок_линз
  // Выход: исход ворот; находки_В3 []Finding (после поправки человека)
  В3 => match ev {
    // В3 #1: В3: «не засчитан»
    В3_не_засчитан => {
      @писать_журнал("заход ${@номер_захода}: пробы — не пробы, не засчитан")
      @номер_захода += 1
      Go(ЗАХОД)
    }
    // В3 #2: В3: «засчитан» (находки_В3: []Находка)
    В3_засчитан { находки_В3: новые_находки } => {
      @номер_захода += 1
      @находки_В3 = новые_находки
      Go(ИТОГ)
    }
    _ => NotAwaited
  }

  // ===================== ИТОГ — развилка =====================
  // Подводит итог засчитанного захода: есть критические находки — нужна правка, чистых заходов подряд ещё мало — ещё заход, достаточно — итог можно принимать.
  // Вход: находки_В3; серия_чистых; открытые
  ИТОГ => {
    // ИТОГ #1: в находки_В3 есть критические
    if есть_критические(@находки_В3) {
      @серия_чистых = 0
      @открытые = объединить_без_повторов(@открытые, желательные_и_значимые_с_повтором(@находки_В3))
      return Go(ПОТОЛОК)
    }
    // ИТОГ #2: в находки_В3 критических нет, и серия_чистых + 1 меньше ЧИСТЫХ_ПОДРЯД
    if !есть_критические(@находки_В3) && @серия_чистых + 1 < ЧИСТЫХ_ПОДРЯД {
      @открытые = объединить_без_повторов(@открытые, желательные(@находки_В3))
      @серия_чистых += 1
      return Go(ЗАХОД)
    }
    // ИТОГ #3: в находки_В3 критических нет, и серия_чистых + 1 не меньше ЧИСТЫХ_ПОДРЯД
    if !есть_критические(@находки_В3) && @серия_чистых + 1 >= ЧИСТЫХ_ПОДРЯД {
      @открытые = объединить_без_повторов(@открытые, желательные_и_значимые(@находки_В3))
      @серия_чистых = 0
      return Go(ПРИНЯТИЕ)
    }
    // ИТОГ #4: иначе
    @ошибка_машины("ошибка машины: развилка ИТОГ, ни одно условие не подошло")
  }

  // ===================== ПОТОЛОК — развилка =====================
  // Проверяет, не исчерпан ли предел числа заходов: нет — автор правит предложение, исчерпан — решает человек.
  // Вход: номер_захода; заход_отсчёта
  ПОТОЛОК => {
    // ПОТОЛОК #1: (номер_захода - 1) - заход_отсчёта + 1 меньше ПОТОЛОК_ЗАХОДОВ
    if (@номер_захода - 1) - @заход_отсчёта + 1 < ПОТОЛОК_ЗАХОДОВ { return Go(ПРАВКА) }

    if (@номер_захода - 1) - @заход_отсчёта + 1 >= ПОТОЛОК_ЗАХОДОВ { return Go(В9) }
    // ПОТОЛОК #3: иначе
    @ошибка_машины("ошибка машины: развилка ПОТОЛОК, ни одно условие не подошло")
  }

  // ===================== В9 — обращение =====================
  // Сообщает человеку, что предел заходов исчерпан, и спрашивает: дать ещё заход (с его указанием), остановиться с открытыми находками или остановить совещание.
  // При входе: ворота В9: потолок заходов.
  // Сторона: человек.
  // Вход (сторона): находки_В3; номер_захода; заход_отсчёта
  // Вход (исполнитель): открытые
  // Выход: исход ворот; решение_человека str
  В9 => match ev {

    В9_ещё_заход { решение_человека } => {
      @заход_отсчёта = @номер_захода
      @указание_автору = решение_человека        // сузить или разбить
      Go(ПРАВКА)
    }
    // В9 #2: В9: «остановиться»
    В9_остановиться => {
      @заход_отсчёта = @номер_захода
      @открытые = объединить_без_повторов(@открытые, критические_и_значимые_без_повтора(@находки_В3))
      Go(ПРИНЯТИЕ)
    }

    В9_остановить_совещание => {
      @заход_отсчёта = @номер_захода
      @остановка = "В9: остановить совещание"
      Go(ОСТАНОВЛЕНО)

  }

  // Сторона: автор.

  // Вход (исполнитель): номер_захода
  // Выход: итог_правки EditResult
  ПРАВКА => match ev {

    Ответ_закончена => {
      @указание_автору = ""
      Go(ЗАХОД)
    }
    // ПРАВКА #2: ответ: вопрос (любое стоп-слово автора читается как вопрос)
    Ответ_вопрос => {
      @указание_автору = ""
      Go(В7)
    }
    // ПРАВКА #3: сбой (причина: КодСбоя)
    Сбой { причина } => {
      @писать_журнал("ПРАВКА: автор не ответил: ${причина}")
      @сбойное_обращение = "ПРАВКА"
      Go(СБОЙ)
    }
    _ => NotAwaited
  }

  // ===================== В7 — обращение =====================
  // Передаёт человеку вопрос автора и получает его ответ.
  // При входе: ворота В7: человек отвечает на вопрос автора.
  // Сторона: человек.
  // Вход: вопрос_автора
  // Выход: ответ_человека str (слово человека; источник записывается вместе с ним)
  В7 => match ev {
    // В7 #1: В7: «ответил» (ответ_человека: Текст)
    В7_ответил { ответ_человека: слово_ответа } => {
      @ответ_человека = слово_ответа
      Go(ВОПРОС)
    }
    _ => NotAwaited
  }

  // ===================== ВОПРОС — обращение =====================
  // Возвращает автору ответ человека, чтобы он продолжил правку; автор либо заканчивает, либо спрашивает снова.
  // При входе: автор продолжает правку рабочей копии по тем же находкам_В3 и с ответом человека и возвращает итог; принятую копию исполнитель
  //   записывает в предложение при приёме ответа, если предложение не менялось с начала попытки (правило 14).
  // Сторона: автор.
  // Вход: вопрос_автора; предложение; находки_В3 (из них критические всегда и значимые только без повтора); ответ_человека (только автору)
  // Выход: итог_правки EditResult
  ВОПРОС => match ev {
    // ВОПРОС #1: ответ: закончена
    Ответ_закончена => Go(ЗАХОД)
    // ВОПРОС #2: ответ: вопрос
    Ответ_вопрос => Go(В7)
    // ВОПРОС #3: сбой (причина: КодСбоя)
    Сбой { причина } => {
      @писать_журнал("ВОПРОС: автор не ответил: ${причина}")
      @сбойное_обращение = "ВОПРОС"
      Go(СБОЙ)
    }
    _ => NotAwaited
  }

  // ===================== ПРИНЯТИЕ — обращение =====================
  // Просит человека подтвердить итог и записать источник решения.
  // При входе: ворота «принять итог»: человек подтверждает решение и запись источника.
  // Сторона: человек.
  // Вход: предложение; номер_захода; открытые
  // Выход: подтверждение str
  ПРИНЯТИЕ => match ev {
    // ПРИНЯТИЕ #1: ПРИНЯТИЕ: «подтвердил» (подтверждение: Текст)
    ПРИНЯТИЕ_подтвердил { подтверждение: слово_подтверждения } => {
      @подтверждение = слово_подтверждения
      Go(КОНЕЦ)
    }
    _ => NotAwaited
  }

  // ===================== ПАУЗА — обращение =====================
  // Держит машину остановленной по слову человека, пока он не скажет продолжить (машина вернётся туда, где её остановили) или остановить совещание.
  // При входе: ворота «пауза»: человек остановил машину, открытые_запросы отменены (кроме запросов к вложенным машинам: они получают сигнал «стоп»,
  //   правило 35); человек продолжает с прерванного состояния или останавливает совещание. Право записи на предложение пауза не меняет: закрытое
  //   в окне проверки линз остаётся закрытым, а кто хочет его править, выбирает «остановить совещание» (`doc/open-questions.md`, раздел 9).
  // Сторона: человек — события «продолжить» и «остановить совещание»; родитель — события «продолжить от родителя» и «остановить от родителя».
  // Вход: предыдущее; запрос_вызова (`""` у машины верхнего уровня)
  // Выход: исход ворот
  // «Продолжить» и «продолжить от родителя» ведут в состояние по имени из «предыдущее» (единственный переход с переменной в «куда», правило 24)
  //   и входят в него заново (повторный вход, правило 12): у ЛИНЗ уходят запросы линзам из к_отправке, у остальных обращений — новый запрос, если
  //   по обращению нет принятого запроса; принятые до стопа ответы остаются. «Предыдущее» при этом не пишется (правила 13 и 24).
  ПАУЗА => match ev {
    // ПАУЗА #1: ПАУЗА: «продолжить» (слово_человека; автор; источник)
    ПАУЗА_продолжить { слово_человека, автор, источник } => {
      @записать_слово_человека(событие, слово_человека, автор, источник)
      @писать_журнал("продолжение с ${@предыдущее}: ${автор}, ${источник}, запись ${событие.идентификатор}")
      @передать_вложенным("продолжить")             // после фиксации шага, журнал «продолжить передано <идентификатор_запроса>»
      Go(состояние_по_имени(@предыдущее))
    }
    // ПАУЗА #2: ПАУЗА: «остановить совещание»
    ПАУЗА_остановить_совещание => {
      @остановка = "ПАУЗА: остановить совещание"
      @передать_вложенным("остановить")             // правило 35, пункты 8 и 10
      Go(ОСТАНОВЛЕНО)
    }
    // ПАУЗА #3: ПАУЗА: «продолжить от родителя» (если идентификатор_запроса события = запрос_вызова, иначе отброшено)
    ПАУЗА_продолжить_от_родителя { идентификатор_запроса } => {
      if идентификатор_запроса != @запрос_вызова { @отбросить(событие); return Stay }
      @писать_журнал("продолжение с ${@предыдущее}: от родителя ${идентификатор_запроса}, запись ${событие.идентификатор}")
      // слова человека не записываются ("")
      @передать_вложенным("продолжить")
      Go(состояние_по_имени(@предыдущее))
    }
    // ПАУЗА #4: ПАУЗА: «остановить от родителя» (если идентификатор_запроса события = запрос_вызова, иначе отброшено)
    ПАУЗА_остановить_от_родителя { идентификатор_запроса } => {
      if идентификатор_запроса != @запрос_вызова { @отбросить(событие); return Stay }
      @остановка = "ПАУЗА: остановить совещание"
      @передать_вложенным("остановить")
      Go(ОСТАНОВЛЕНО)
    }
    _ => NotAwaited
  }

  // ===================== концы: переходов нет =====================
  // ОСТАНОВЛЕНО — конец. Заканчивает совещание без принятого итога и записывает, почему и какие находки остались; решение — за человеком вне машины.
  // Вход: остановка; предложение; открытые; находки_В3
  ОСТАНОВЛЕНО => unreachable("конец: переходов нет; работа при входе — в «Концы и ответ»")

  // ОШИБКА — конец. Заканчивает совещание, если сама машина попала в непредусмотренное положение; это дефект машины или реализации, его разбирает человек.
  // Вход: предложение; все данные машины (Все переменные и хранилища — в журнал)
  ОШИБКА => unreachable("конец: переходов нет; работа при входе — в «Концы и ответ»")

  // КОНЕЦ — конец. Записывает принятое решение с источником, числом заходов и открытыми находками: совещание закончено успешно.
  // Вход: предложение; подтверждение; номер_захода; открытые
  КОНЕЦ => unreachable("конец: переходов нет; работа при входе — в «Концы и ответ»")
  }
}
```

```nova
/// Работа концов при входе (в последнем, повторяемом без вреда этапе фиксации) и ответ вызвавшей стороне.
/// Вход в любой конец отменяет все открытые запросы (правило 22); машина отвечает ровно один раз (правило 35).
fn Исполнитель mut @при_входе_в_конец(s State) => match s {
  // ОСТАНОВЛЕНО: предложение открывается для записи; в журнал — «совещание остановлено: <остановка>», затем незакрытые находки:
  //   открытые и находки_В3, не вошедшие в открытые (находки считаются одной по доказательству); итог не принят, программа продолжает остальную работу.
  ОСТАНОВЛЕНО => {
    @открыть_для_записи("предложение")
    @машина.писать_журнал("совещание остановлено: ${@машина.остановка}")
    @журнал_находок(@машина.открытые)
    @журнал_находок(не_вошедшие_в(@машина.находки_В3, @машина.открытые))
  }
  // ОШИБКА: предложение открывается для записи; в журнал — запись из перехода и данные машины; совещание остановлено, итог не принят;
  //   это дефект машины или реализации, решает человек вне машины.
  ОШИБКА => {
    @открыть_для_записи("предложение")
    @машина.писать_журнал(@машина.запись_перехода)
    @журнал_данных_машины()
  }
  // КОНЕЦ: предложение открывается для записи; в журнал — решение (предложение), источник — подтверждение, число заходов номер_захода,
  //   открытые как «открыто»; приписка: «значимые находки прежних заходов, не вошедшие в «открыто», — в файлах заходов»;
  //   тип проверяющего в каждом заходе — по `methodology.md`, раздел 18.
  КОНЕЦ => {
    @открыть_для_записи("предложение")
    @журнал_решения(@машина.предложение, @машина.подтверждение, @машина.номер_захода, @машина.открытые)
    @машина.писать_журнал("значимые находки прежних заходов, не вошедшие в «открыто», — в файлах заходов")
  }
  _ => ()
}

/// Отказ вызвавшей стороне: конверт ответа берётся из запроса вызова.
fn Машина @отказ_по(вызов Request[MeetingInput], причина FailCode, текст str) -> Response[MeetingResult] {
  ro в = вызов
  Refusal(Rejection { request: @запрос_вызова, party: в.party, reason: причина, text: текст, trace: в.trace, step: в.step })
}

/// Таблица «конец → ответ» первоисточника (раздел «Контракт машины»): каждый конец и каждое значение остановка — одна строка.
fn Машина @ответ_по_концу(вызов Request[MeetingInput]) -> Response[MeetingResult] {
  ro в = вызов
  match @состояние {
    // КОНЕЦ, условие входа: всегда → Result: итог с числом заходов и открытыми находками
    КОНЕЦ => Result(Reply {
      request: @запрос_вызова, party: в.party, trace: в.trace, step: в.step,
      result: MeetingResult { decision: @предложение, source: @подтверждение, passes: @номер_захода, open: @открытые } })
    // ОШИБКА, условие входа: всегда (дефект машины) → Refusal, NoResult; текст — запись из перехода
    ОШИБКА => @отказ_по(вызов, NoResult, @запись_перехода)
    ОСТАНОВЛЕНО => match @остановка {
      // ОСТАНОВЛЕНО: остановка = «ни одна линза не ответила» → Refusal, NoResult
      "ни одна линза не ответила" => @отказ_по(вызов, NoResult, @остановка)
      // ОСТАНОВЛЕНО: остановка = «В9: остановить совещание» (потолок заходов с открытыми находками) → Refusal, CeilingReached
      "В9: остановить совещание" => @отказ_по(вызов, CeilingReached, @остановка)
      // ОСТАНОВЛЕНО: «ПАУЗА: остановить совещание», «<сбойное_обращение>: остановить совещание», «ИЗМЕНЁН: остановить совещание»
      //   или «ПОВТОР: остановить» (слово человека; у вложенной машины — сигнал «остановить от родителя» в ПАУЗЕ) → Refusal, StoppedByHuman
      "ПАУЗА: остановить совещание" | "ИЗМЕНЁН: остановить совещание" | "ПОВТОР: остановить" => @отказ_по(вызов, StoppedByHuman, @остановка)
      х if х == "${@сбойное_обращение}: остановить совещание" => @отказ_по(вызов, StoppedByHuman, @остановка)
      // ОСТАНОВЛЕНО: остановка = «отмена_запроса» → Refusal, Cancelled
      "отмена_запроса" => @отказ_по(вызов, Cancelled, @остановка)
      _ => unreachable("значение остановка вне таблицы «конец → ответ»: новое значение добавляет строку таблицы")
    }
    _ => unreachable("ответ отдают только концы")
  }
}
```

## Цикл исполнителя

```nova
/// Снимок: всё состояние машины и исполнителя на конец шага (поля `Машина`: состояние, предыдущее, открытые и принятые запросы, счётчики, хранилища; очередь входящих событий; запрос вызова; готовый ответ).
type Снимок { машина Машина, очередь []Incoming, вызов Option[Request[MeetingInput]], готовый_ответ Option[Response[MeetingResult]] }

/// Хранилище снимков по идентификатору запроса. Реализация — любая (база, диск, очередь сообщений) и вне этого файла.
type Хранилище protocol {
  @загрузить(идентификатор_запроса str) -> Option[Снимок]
  mut @сохранить(идентификатор_запроса str, снимок Снимок)
}

/// Событие: машина как вызываемое событие другой машины (правило 35). Вход и выход — типы запроса и итога.
type Событие[Вход, Выход] protocol {
  mut @вызвать(запрос Request[Вход]) -> Response[Выход]
}

/// Исполнитель: ведёт `Машина` по правилам 13–24 и 35 спецификации; единственный пишет в хранилище и отправляет запросы.
/// Данные заходят только через события; запросы отправляются только после фиксации шага; снимок сохраняется до открытия ворот.
/// Исполнитель с машиной совещания реализует `Событие[MeetingInput, MeetingResult]` структурно (метод `вызвать`).
type Исполнитель {
  машина Машина,                               // данные и логика автомата
  хранилище Хранилище,                         // снимки по идентификатору запроса
  вызов Option[Request[MeetingInput]],         // запрос, которым машину вызвали (конверт исполнителя)
  очередь []Incoming,                          // входящие события в порядке прихода (правило 13)
  готовый_ответ Option[Response[MeetingResult]], // ответ, отданный вызвавшей стороне; машина отвечает ровно один раз (правило 35)
}

/// Исполнитель с пустой машиной над данным хранилищем.
fn Исполнитель.new(хранилище Хранилище) -> Исполнитель => {
  машина: Машина.new(),
  хранилище: хранилище,
  вызов: None,
  очередь: []Incoming.new(),
  готовый_ответ: None,
}

/// Событие `Событие[MeetingInput, MeetingResult]`: повтор запроса с тем же идентификатором возвращает готовый ответ или продолжает прерванную работу (правило 35, п. 4).
fn Исполнитель mut @вызвать(запрос Request[MeetingInput]) -> Response[MeetingResult] {
  match @хранилище.загрузить(запрос.id) {
    None => @начать(запрос)
    Some(снимок) => match снимок.готовый_ответ {
      Some(готовый) => готовый
      None => match @возобновить(запрос.id) {
        Some(ответ) => ответ
        None => unreachable("снимок только что загружен: возобновить его находит")
      }
    }
  }
}

/// Новый запрос: создаёт машину, записи линз, входит в ЗАХОД, фиксирует шаг и входит в цикл.
fn Исполнитель mut @начать(запрос Request[MeetingInput]) -> Response[MeetingResult] {
  @вызов = Some(запрос)
  @машина = Машина.new()
  @очередь = []Incoming.new()
  @готовый_ответ = None
  // начальные значения — раздел «Данные»
  @машина.запрос_вызова = запрос.id
  @машина.трасса = @новая_трасса()                  // дочерняя от внешней (запрос.trace)
  @машина.предложение = запрос.input.proposal
  @машина.вопрос_автора = запрос.input.author_question
  @машина.порядок_линз = запрос.input.lens_order
  for id in @машина.порядок_линз {
    @машина.линзы.insert(id, Lens { id: id, lost: 0, probes: 0, attempt: 0 })
  }
  @машина.состояние = ЗАХОД
  @выполнить_шаг(@новое_событие("старт"), Go(ЗАХОД))
  @цикл()
}

/// Продолжение после остановки исполнителя: загружает снимок и продолжает с сохранённого `состояние`; None — снимка нет.
/// Ждавшая обращения машина повторно получает только запросы без принятого ответа; на ПАУЗЕ остаётся, пока человек не скажет «продолжить» (правила 12, 14, 22).
fn Исполнитель mut @возобновить(идентификатор_запроса str) -> Option[Response[MeetingResult]] {
  match @хранилище.загрузить(идентификатор_запроса) {
    None => None
    Some(снимок) => {
      @машина = снимок.машина
      @очередь = снимок.очередь
      @вызов = снимок.вызов
      @готовый_ответ = снимок.готовый_ответ
      match @готовый_ответ {
        Some(готовый) => Some(готовый)               // ответ уже отдан: повторяется без вреда
        None => {
          @после_перезапуска()
          Some(@цикл())
        }
      }
    }
  }
}

/// Цикл: берёт события по одному, пока ответ не отдан. Остановка исполнителя — завершение процесса в любой точке цикла:
/// состояние уже сохранено фиксацией шага, дописывать ничего не нужно.
fn Исполнитель mut @цикл() -> Response[MeetingResult] {
  loop {
    match @готовый_ответ {
      Some(ответ) => return ответ
      None => @обработать_очередь()
    }
  }
}

/// Приём при приходе: в порядке прихода и в любом состоянии (правило 14).
// псевдокод: обобщённый метод (форма не подтверждена)
fn Исполнитель mut @при_приходе[R](сообщение Message[R]) {
  @машина.счётчик_событий += 1                               // +1 при приходе любого события
  match сообщение {
    // ответ роли или отказ (Response от открытой стороны)
    ОтветРоли(ответ) => {
      ro ид = запрос_ответа(ответ)
      // чужой или поздний ответ: неизвестный идентификатор, закрытый или отменённый запрос, повторная доставка (правило 17)
      if !@машина.открытые_запросы.contains(ид) || @машина.принятые_запросы.contains(ид) {
        @машина.отбросить(@событие_из_сообщения(сообщение))
        return
      }
      // форма: ответ не по форме исполнитель возвращает стороне в том же запросе; число возвратов задаёт состояние
      if !форма_верна(ответ) { @вернуть_стороне(ответ); return }
      // объект, куда пишется результат (предложение при правке), изменился с начала попытки — результат не принимается,
      // запрос отменяется и отправляется заново (новая попытка, вход прочитан заново)
      if правит_автор(@машина.состояние) && @предложение_менялось_с_начала_попытки() { @повторить_запрос(ид); return }
      // одна фиксация: идентификатор в принятые_запросы, «При приёме», запись результата в хранилище, событие в очередь;
      // последним, повторяемым без вреда этапом — принятие файла попытки
      @машина.принятые_запросы = добавить(@машина.принятые_запросы, [ид])
      @при_приёме(@машина.состояние, ответ)
      @записать_результат(@машина.состояние, ответ)
      @положить_в_очередь(@событие_из_ответа(ответ))
    }
    // слово человека или сигнал
    Слово(_) => {
      @записать_слово_ворот(сообщение)                // на воротах (правило 19)
      @положить_в_очередь(@событие_из_сообщения(сообщение))
    }
    // «нет ответа в срок»: порождает исполнитель по таймеру, код Timeout; у обращения человека срока нет (правило 19)
    Срок(ид) => {
      @положить_в_очередь(Incoming {
        идентификатор: "сбой-${@машина.счётчик_событий}", сторона: сторона_запроса(ид), запрос: Some(ид), тело: Сбой { причина: Timeout } })
    }
  }
}

/// При приёме (правило 14; запись линзы — событие.сторона).
// псевдокод: обобщённый метод (форма не подтверждена)
fn Исполнитель mut @при_приёме[R](s State, ответ Response[R]) => match s {
  ЛИНЗЫ => match ответ {
    // ответ: потери_подряд ← 0, пробы ← пробы из ответа (результат ответа, в событии не повторяется), ответившие + 1
    // псевдокод: r.result — результат роли ЛИНЗЫ, ИтогЛинзы; для обобщённого R поле недоступно
    Result(r) => {
      @машина.установить_потери(r.party, 0)
      @машина.установить_пробы(r.party, r.result.пробы)
      @машина.ответившие += 1
    }
    // сбой: потери_подряд + 1, пробы ← 0
    Refusal(r) => {
      @машина.установить_потери(r.party, @машина.линзы(r.party).lost + 1)
      @машина.установить_пробы(r.party, 0)
    }
  }
  _ => ()
}

/// Запись принятого результата в хранилище (правила 8, 14): роль возвращает результат, в хранилище машины не пишет.
// псевдокод: обобщённый метод (форма не подтверждена)
fn Исполнитель mut @записать_результат[R](s State, ответ Response[R]) => match ответ {
  Refusal(_) => ()
  Result(r) => match s {
    // псевдокод: r.result — результат роли состояния s: []WitnessAnswer, ИтогЛинзы или EditResult; для обобщённого R не выражается
    СВИДЕТЕЛЬ => @машина.ответы_свидетеля.insert(@машина.номер_захода, r.result)
    ЛИНЗЫ => @машина.находки_линзы.insert((r.party, @машина.номер_захода), r.result.находки)
    ПРАВКА | ВОПРОС => match r.result {            // EditResult: Done ведёт в ЗАХОД, Asked — в В7
      Done(текст) => { @машина.предложение = текст }
      Asked(вопрос) => {
        @машина.предложение = вопрос.proposal
        @машина.вопрос_автора = Some(вопрос.question)
      }
    }
    _ => ()                                        // у остальных обращений результат — исход ворот, он идёт событием
  }
}

/// Обработка очереди: первое событие, которое ждёт текущее состояние; остальные остаются в очереди (правило 13).
fn Исполнитель mut @обработать_очередь() {
  match @взять_первое_ожидаемое() {                   // сигналы ждёт любое состояние, кроме концов
    None => @ждать_прихода()
    Some(событие) => {
      ro переход = @машина.общие_события(событие) ?? @машина.step(@машина.состояние, событие.тело, событие)
      @выполнить_шаг(событие, переход)
    }
  }
}

/// Шаг — одна фиксация (правило 13): переходы, записи в хранилище, строки журнала, новые значения «состояние», «открытые_запросы»,
/// «принятые_запросы», «к_отправке» и счётчиков попыток пишутся вместе; незавершённый шаг откатывается.
fn Исполнитель mut @выполнить_шаг(событие Incoming, переход Transition) {
  @начать_фиксацию()
  ro номер_захода_до = @машина.номер_захода
  @машина.номер_шага += 1                                    // растёт внутри фиксации; откат возвращает
  @машина.причина_шага = событие.идентификатор
  mut t = переход
  match t {
    NotAwaited => {                                  // событие остаётся в очереди
      @откатить()
      return
    }
    _ => ()
  }
  // принятый запрос закрывается переходом по своему событию: убирается из открытые_запросы и из принятые_запросы
  match событие.запрос {
    Some(ид) => @машина.закрыть_запрос(ид)
    None => ()
  }

  // цепочка операций и развилок и их переходов «сразу» до первого обращения или конца
  loop {
    match t {
      Stay => break                                  // то же состояние
      NotAwaited => break                            // первое событие проверено выше; в цепочке не встречается
      Go(s) => match @войти_в(s, событие) {
        Some(следующий) => { t = следующий }
        None => break                                // ждёт события или конец
      }
      Rerun(s) => {
        @отменить_открытый_запрос_обращения(s)        // «запуск заново» (правило 18): прежний запрос сначала отменяется
        match @войти_в(s, событие) {
          Some(следующий) => { t = следующий }
          None => break
        }
      }
    }
    проверить_инвариант(инвариант_номер_захода_не_уменьшается(номер_захода_до, @машина.номер_захода))
  }
  @зафиксировать()                                    // запись шага; затем действия во внешнем мире, повторяемые без вреда:
                                                     // переименование в `*.void-<k>.md`, принятие файла попытки, смена права записи
  @после_фиксации()
}

/// Вход в состояние: запись «состояние» подразумевается у каждого перехода; None — обращение или конец, цепочка заканчивается.
fn Исполнитель mut @войти_в(s State, событие Incoming) -> Option[Transition] {
  @машина.состояние = s
  match вид(s) {
    Обращение | Конец => None                        // ждёт события или конец
    Операция => {
      ro результат = @работа_операции(s)
      Some(@машина.step(s, @результат_как_событие(s, результат), событие))
    }
    Развилка => Some(@машина.step(s, Сразу, событие))
  }
}

/// Работа операций при входе (в одном шаге с переходом; отказа и «нет ответа» у операции нет).
fn Исполнитель mut @работа_операции(s State) -> Option[[]str] => match s {
  ЗАМОК => {
    @машина.копия = Some(@предложение_с_отпечатком())
    @закрыть_для_записи("предложение")
    None
  }
  РАЗБЛОК => {
    @открыть_для_записи("предложение")
    None
  }
  ВОЗВРАТ => {
    match @машина.копия {
      Some(текст) => { @машина.предложение = текст }
      None => @машина.писать_журнал("ВОЗВРАТ: копии нет")    // псевдокод: недостижимо, копию пишет ЗАМОК
    }
    None
  }
  АННУЛ => {
    @перенести_в_архив(@машина.номер_захода, @машина.аннулирований(@машина.номер_захода))
    None
  }
  ФИЛЬТР => {
    // четыре признака несостоятельных мнения (task-runner.md); каждое идёт в счёт по моделям; запись на то же место
    @убрать_несостоятельные(@машина.номер_захода)
    Some(@линзы_без_критических())                  // идентификаторы
  }
  СВОД => {
    // K, Z, D — суммы по линзам, P — наименьшее из проб
    match @собрать_свод(@машина.номер_захода) {
      Some(итог) => { @машина.свод.insert(@машина.номер_захода, итог) }
      None => {}                                        // итога нет: записи в `свод` нет
    }
    None
  }
  _ => unreachable("у остальных состояний нет работы операции")
}

/// После фиксации шага: сначала очередь, потом запросы (правило 13).
fn Исполнитель mut @после_фиксации() {
  @передать_вложенным_накопленные_сигналы()           // «стоп», «продолжить», «остановить», «отмена»; журнал «… передан(о) <id>»
  // перед отправкой смотрит во входящую очередь: «стоп человека», «стоп от родителя» или «отмена_запроса» — запросы не отправляются,
  // а сигнал разбирается (правила 23, 35)
  if @в_очереди_есть_сигнал() { return }
  match вид(@машина.состояние) {
    Конец => {
      @отменить_все_открытые_запросы()                // вход в любой конец (правило 22)
      @при_входе_в_конец(@машина.состояние)
      @отдать_ответ(@машина.ответ_по_концу(@получатель()))            // ровно один раз: из конца переходов нет
    }
    Обращение => @отправить_запросы(@машина.состояние)
    _ => ()                                          // операции и развилки до сюда не доходят: цепочка идёт до обращения или конца
  }
}

/// Счётчик попыток одноадресного обращения (правило 15).
fn Машина @счётчик_попыток(сторона str) -> int => match сторона {
  "свидетель" => @попытка_свидетеля
  "автор" => @попытка_автора
  "человек" => @попытка_человека
  _ => unreachable("сторона вне «свидетель», «автор», «человек»")
}

fn Машина mut @увеличить_счётчик_попыток(сторона str) => match сторона {
  "свидетель" => { @попытка_свидетеля += 1 }
  "автор" => { @попытка_автора += 1 }
  "человек" => { @попытка_человека += 1 }
  _ => unreachable("сторона вне «свидетель», «автор», «человек»")
}

/// Отправка запросов по состоянию. Состояние сохранено до открытия ворот; повторный вход ничего не отправляет стороне,
/// чей запрос открыт или лежит в принятых (правила 12, 14, 21).
fn Исполнитель mut @отправить_запросы(s State) => match s {
  ЛИНЗЫ => {
    // стороны из к_отправке по порядку, пока открытых запросов меньше ПРЕДЕЛ_ЗАПРОСОВ (правило 21)
    while @машина.к_отправке.len() > 0 && @машина.открытые_запросы.len() < ПРЕДЕЛ_ЗАПРОСОВ {
      ro линза = @машина.к_отправке[0]
      // механика контракта, фиксируется до отправки: перенос из к_отправке в открытые_запросы и рост счётчика попыток
      @машина.к_отправке = @машина.к_отправке[1..]
      @машина.установить_попытку(линза, @машина.линзы(линза).attempt + 1)
      @машина.открытые_запросы = добавить(@машина.открытые_запросы, ["${линза}-${@машина.линзы(линза).attempt}"])
      @отправить(Request { id: "${линза}-${@машина.линзы(линза).attempt}", attempt: @машина.линзы(линза).attempt, party: линза,
        input: @машина.вход_запроса(ЛИНЗЫ, линза), idle_term: СРОК_БЕЗДЕЙСТВИЯ, trace: @машина.трасса, step: @машина.номер_шага })
    }
  }
  СВИДЕТЕЛЬ | ПРАВКА | ВОПРОС | В3 | В9 | В7 | ПРИНЯТИЕ | СБОЙ | ИЗМЕНЁН | ПОВТОР | ПАУЗА => {
    ro сторона = сторона_обращения(s)              // «свидетель», «автор» или «человек»
    if @машина.есть_открытый_или_принятый(сторона) { return }
    @машина.увеличить_счётчик_попыток(сторона)             // фиксируется до отправки вместе с открытые_запросы
    @машина.открытые_запросы = добавить(@машина.открытые_запросы, ["${сторона}-${@машина.счётчик_попыток(сторона)}"])
    @отправить(Request { id: "${сторона}-${@машина.счётчик_попыток(сторона)}", attempt: @машина.счётчик_попыток(сторона), party: сторона,
      input: @машина.вход_запроса(s, сторона), idle_term: срок_если_не_человек(сторона), trace: @машина.трасса, step: @машина.номер_шага })
  }
  _ => ()
}

/// Перезапуск исполнителя: не переход и «состояние» не пишет; шаг со своим номером (правила 22, 31).
fn Исполнитель mut @после_перезапуска() {
  @начать_фиксацию()
  @машина.номер_шага += 1
  @машина.причина_шага = @новое_событие("перезапуск").идентификатор
  // открытые запросы умершего исполнителя без принятого ответа отменяются; их поздние ответы отбрасываются
  @машина.отменить_открытые_без_принятого(false)             // кроме_вложенных
  @зафиксировать()
  // повторный вход в «состояние» (обращение или конец, правило 12); незакрытые ворота показываются человеку снова
  @после_фиксации()
}
```
