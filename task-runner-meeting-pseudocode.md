# Совещание агентов: псевдокод

Вынесено из [task-runner.md](task-runner.md), «Совещание агентов»: там правила режима, здесь `meeting` и `check_meeting`; `loop_review` — [task-runner-pseudocode.md](task-runner-pseudocode.md). Схема опытного режима, раннером не выполняется. Та же схема состояниями — [task-runner-meeting-states.md](task-runner-meeting-states.md).

```text
алгоритм meeting(proposal, lenses, facts_holder):
    пока истина:
        verdict ← loop_review(meeting)               # checker(meeting) — check_meeting, fixer(meeting) — автор
        выбор verdict:
            halt:               log(«совещание остановлено: <причина>, незакрытые находки»); вернуть     # итог не принимается
            stopped(«вопрос»):  fixed ← stopped(«вопрос»)                          # любое стоп-слово автора совещания читается как «вопрос»
                                пока fixed = stopped(_):                          # автор может спросить ещё раз — снова В7
                                    answer ← gate(В7, вопрос автора)
                                    fixed ← run(автор, source=answer, pass=state.pass[meeting] − 1)   # номер захода с находками (state.pass уже увеличен); ответ сразу идёт автору; новая версия proposal.md — вход следующего захода
                                если fixed = halt: log(«совещание остановлено: <причина>, незакрытые находки»); вернуть
                                continue
            clean:              выйти
    gate(«принять итог»)                             # решения закрытого списка и потолок — только человек
    записать решение с источником, числом заходов и незакрытыми находками в log.md

алгоритм check_meeting(n):                           # вместо run(checker(stage), pass=n) в loop_review, когда stage = meeting
    если есть вопросы автора (proposal.md) и проверяющих (файлы захода N−1): facts-n.md ← run(держатель_фактов, source=вопросы, pass=n); если halt: вернуть halt
    если facts-n.md есть: проверка выдержек (поиск строки); несовпадение → один ход держателю «исправь выдержку»; снова несовпадение → строка помечена «не подтверждено»   # до того, как линзы читают файл
    копия ← копия proposal.md с хешем                 # в начале захода
    proposal.md ← только чтение                       # на время проверок линз; запись возвращается в finally
    для каждой линзы: файл линзы ← run(проверка_линзы, source=proposal, pass=n)    # линзы читают proposal.md и facts-n.md, но не файлы других линз этого захода; verify_formats внутри run
        если run вернул failed: lost[линза] += 1
            если lost[линза] ≥ 2: choice ← gate(В13, «линза потеряна второй раз подряд»)
                «остановить совещание»: вернуть halt
                «повторить»:            перезапустить линзу в этом же заходе (lost не обнуляется); получила ответ — lost ← 0, дальше следующая линза
            если линза так и не ответила: она отброшена (log; в счёт по моделям, если причина «модель»); P линзы ← 0; если линз не осталось: вернуть halt   # halt означает, что решает человек
        иначе: lost[линза] ← 0
        если run вернул halt (В13 для автора или держателя фактов: «остановить»): вернуть halt
    если proposal.md ≠ копия: choice ← gate(В13, «proposal.md изменён за время проверок», показать копию и изменённый файл)   # заход недействителен; его находки в счёт и в потолок не идут
        «оставить правку» | «вернуть копию»: (копию вернуть, если выбрана); файлы линз и фактов этого захода переименовать в `*.void-<k>.md`, k — номер недействительного прохода в этом заходе (в контекст не входят); повторить check_meeting(n) с начала на выбранной версии
        «остановить совещание»: вернуть halt
    для каждой линзы: признаки несостоятельного мнения → убрать из файла, записать в счёт по моделям; если у линзы отброшены все существенные находки, её P ← 0   # такой заход не считается чистым
    proposal-review-N.md ← первая строка «Заход N: существенных K, поверхностных M, проб P» (K, M — суммы, P — наименьшее по линзам),
                           затем находки с меткой линзы
    вернуть proposal-review-N.md                      # дальше loop_review как обычно: parse_summary, В3, В9
```
