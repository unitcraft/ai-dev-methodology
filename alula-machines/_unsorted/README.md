# Несортированные сценарии

Шесть сценариев `nested-steps-*` относятся к машине `dialog_steps` (продукт потребителя), а не к трём машинам методики и не к `agent_step`. Положены сюда без изменений, не удалены; судьбу решает методика вместе с переносом `agent_step`. Раскладка — [../README.md](../README.md).
