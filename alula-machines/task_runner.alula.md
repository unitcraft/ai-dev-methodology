# Машина: Раннер задачи

- machine: task_runner
- revision: 2
- alula_version: 0.28

Машина «Раннер задачи»: фазы РАЗБОР, ПЛАН, РЕАЛИЗАЦИЯ, СДАЧА, ОБРАТНАЯ_СВЯЗЬ и ворота между ними;
маршруты `full`, `fast`, `small`. Норма и контракт хозяина — [task-runner.md](../task-runner.md),
«Смена маршрута»; реестр и журнал — соседние файлы. Машина вызывает «Запуск сессии» (`session_start`)
и «Проверку цикла» (`cycle_check`); запуск сессии вызывает «Шаг агента». Остановка и отмена —
вложенный фрагмент «Пауза»; продолжение требует связанного решения ворот. Чтение и запись документов,
подготовка и блокировки — примитивы хозяина. `ScriptedHost` — тестовый исполнитель заданных ответов,
не реализация проверки личности; боевого хозяина этот репозиторий не содержит.

**Что записано иначе, чем в первоисточнике, и почему** (полный перечень — в разборе задачи). Статус документа, стоп-слово и признаки документа читают примитивы `specification`, `task_plan` и `implementation_report` в «При входе» развилки (по правилу AL-29 чтение — только через `пусть`), а не условие. Внешний объект «утверждения[документ]» — словарь данных: его пишут ЗАПИСЬ_УТВЕРЖДЕНИЯ и КОПИЯ_ПОСТАНОВКИ, снимают операции «снятие»; «утверждение действует» — хеш записи равен хешу документа сейчас. Коды сессий — латинские коды рукописного автомата (`s1`, `s1_fix`, …), метки продолжения и слова остановки — наборы литералов его слов. Слова ворот, у которых в первоисточнике разный состав данных при одном имени («продолжить», «реализация»), записаны с одним составом: слово человека — с автором и источником. Подготовка при возобновлении (`возврат_подготовки`) — действие исполнителя до входа в сохранённое состояние: данное пишет только оно.

## Данные

Данные фрагмента «Пауза» (`предыдущее`, `запрос_вызова`, `открытые_запросы`) входят из фрагмента и здесь не повторяются; в `все_данные` они идут первыми. Данные исполнителя (`состояние`, `трасса`, `номер_шага`, `счётчик_событий`, `причина_шага`, `принятые_запросы`, журнал) и хранилища (`слова_человека`, `тексты_сбоев`) в таблицу не вносятся. Внешние объекты методики (спецификация, план, отчёт реализации, письма, постановка, различия дерева, сообщения коммита) читают примитивы хозяина; в данных — только `утверждения`.

### КОНЕЦ — конец
- При входе:
  - журнал("task_completed", feedback_rounds: строка(номер_раунда));
  - release_lock();
  - show_human("задача завершена")

### ОСТАНОВЛЕНО — конец
- При входе:
  - пусть остановка_или_отмена = если Пауза.причина == ПричинаПаузы.Отменена то { "cancel_request" } иначе { остановка };
  - пусть остановка_с_паузой = если Пауза.причина == ПричинаПаузы.Остановлена то { "pause_halt" } иначе { остановка_или_отмена };
  - stop_agent_group();
  - журнал("runner_stopped", reason: остановка_с_паузой)
- Кроме: остановка в ["", "pause_halt", "cancel_request"]

### ОШИБКА — конец
- При входе:
  - stop_agent_group();
  - журнал(запись_перехода);
  - журнал(все_данные)

Состояние ПАУЗА приносит подключение «Пауза» (раздел «Подключения»); здесь оно не объявляется.
