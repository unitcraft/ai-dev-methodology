# Совещание агентов: стейт-машина

Та же схема, что в [task-runner.md](task-runner.md), «Совещание агентов», и в псевдокоде ([task-runner-meeting-pseudocode.md](task-runner-meeting-pseudocode.md): `meeting`, `check_meeting`; [task-runner-pseudocode.md](task-runner-pseudocode.md): `loop_review(meeting)`), записанная состояниями и переходами. Нормы — [methodology.md](methodology.md), раздел 18, «Согласование решения несколькими агентами»; при расхождении верны `task-runner.md` и псевдокод. Опытный режим: раннером не выполняется.

## Данные

| Имя | Что это | Где хранится |
|---|---|---|
| n | номер текущего захода | `state.pass[meeting]` |
| origin | заход, от которого считается потолок | `state.pass_origin[meeting]` |
| streak | чистых заходов подряд | `state.clean_streak[meeting]` |
| unaccounted | чистых заходов без проб подряд | `state.unaccounted[meeting]` |
| lost[л] | потерянных заходов линзы л подряд | `state.lost[линза]` |
| extra | решение человека у В9 для правки автора | в памяти до ПРАВКИ |
| копия | `proposal.md` с хешем на начало захода | файл рядом с `proposal.md` |

Константы — ПОТОЛОК_ЗАХОДОВ, ЧИСТЫХ_ПОДРЯД, ПРОБ_В_ЧИСТОМ (`task-runner.md`, начало).

## Инварианты

1. **Решает только человек** — на воротах В3, В7, В9, В13 и «принять итог»; секретарь считает, переключает состояния и пишет журнал. Исключение — В3 в режиме «показать и продолжить», если человек так настроил.
2. **Предложение неизменно, пока работают линзы**: в состояниях ЛИНЗА `proposal.md` только для чтения, и любой выход из них возвращает запись; при старте секретаря, если проверка не идёт, запись тоже возвращается; изменение, найденное в СВЕРКЕ, делает заход недействительным.
3. **n не уменьшается**; недействительный заход повторяется под тем же n, его файлы переименованы в `*.void-<k>.md` и в счёт не идут.

## Состояния

| Состояние | Что делается при входе |
|---|---|
| ФАКТЫ | если автор в `proposal.md` или проверяющие в файлах захода n − 1 оставили вопросы, держатель фактов отвечает в `facts-n.md`; секретарь сверяет выдержки: несовпадение — один ход «исправь выдержку», снова несовпадение — строка помечается «не подтверждено». Вопросов нет — ничего не делается |
| ЗАМОК | копия `proposal.md` с хешем; `proposal.md` — только для чтения |
| ЛИНЗА(i) | линза номер i проверяет `proposal.md` и `facts-n.md`; файлов других линз этого захода она не видит; форму её файла проверяет запуск |
| СВЕРКА | запись в `proposal.md` возвращается; файл сравнивается с копией |
| ФИЛЬТР | убираются несостоятельные мнения (четыре признака, `task-runner.md`), каждое идёт в счёт по моделям; у линзы, потерявшей все существенные находки, P = 0 |
| СВОД | `proposal-review-n.md`: первая строка «Заход n: существенных K, поверхностных M, проб P» (K и M — суммы по линзам, P — наименьшее), затем находки с меткой линзы |
| РАЗБОР | читается первая строка свода; если её нет — все находки существенные, в журнал «итоговой строки нет» |
| В3 | человек читает находки и пробы, может поднять критичность и засчитывает заход или нет; по его настройке ворота только показывают и идут дальше |
| ПОТОЛОК | считается, сколько заходов прошло с последней правки по решению человека: (n − 1) − origin + 1 |
| ПРАВКА | автор правит `proposal.md` по находкам захода n − 1 и по extra, дописывает «Изменения захода» |
| ВОПРОС | ворота В7: человек отвечает на вопрос автора; автор продолжает правку с этим ответом |
| ПРИНЯТИЕ | ворота «принять итог»: человек подтверждает решение и запись источника |
| ОСТАНОВ | в `log.md` — «совещание остановлено: <причина>» и незакрытые находки; итог не принят, программа продолжает остальную работу |
| КОНЕЦ | в `log.md` — решение с источником, числом заходов и незакрытыми находками; тип проверяющего в каждом заходе — по `methodology.md`, раздел 18 |

## Переходы

Одна строка — один переход. «Сразу» — переход без события, как только сделано действие при входе. «Запуск заново» повторяет только запуск роли с теми же входами, действие при входе не повторяется.

| Из | Когда | Что меняется | Куда |
|---|---|---|---|
| ФАКТЫ | держатель ответил или вопросов не было | — | ЗАМОК |
| ФАКТЫ | держатель не ответил (в том числе на ходе «исправь выдержку») — ворота В13, человек: «повторить» | — | ФАКТЫ, запуск заново |
| ФАКТЫ | то же, человек: «остановить совещание» | — | ОСТАНОВ |
| ЗАМОК | сразу | i ← 1 | ЛИНЗА(1) |
| ЛИНЗА(i) | линза ответила, и есть следующая | lost[i] ← 0; i ← i + 1 | ЛИНЗА(i) |
| ЛИНЗА(i) | линза ответила, и она последняя | lost[i] ← 0 | СВЕРКА |
| ЛИНЗА(i) | линза не ответила, lost[i] был 0 | lost[i] ← 1; линза отброшена в этом заходе, её P = 0, запись в журнал | следующая линза; если линз больше нет — СВЕРКА, а если в этом заходе не ответила ни одна линза — ОСТАНОВ |
| ЛИНЗА(i) | линза не ответила, lost[i] был 1 или больше: lost[i] + 1, ворота В13, человек: «повторить» | lost[i] не сбрасывается | ЛИНЗА(i), запуск заново |
| ЛИНЗА(i) | то же, человек: «остановить совещание» | — | ОСТАНОВ |
| СВЕРКА | файл равен копии | — | ФИЛЬТР |
| СВЕРКА | файл изменён — ворота В13 с копией и изменённым файлом, человек: «оставить правку» или «вернуть копию» | при «вернуть копию» копия возвращается; файлы линз и фактов захода переименованы в `*.void-<k>.md`; n не меняется | ФАКТЫ |
| СВЕРКА | то же, человек: «остановить совещание» | — | ОСТАНОВ |
| ФИЛЬТР | сразу | — | СВОД |
| СВОД | сразу | — | РАЗБОР |
| РАЗБОР | есть существенные находки или проб не меньше ПРОБ_В_ЧИСТОМ | unaccounted ← 0 | В3 |
| РАЗБОР | существенных нет и проб меньше ПРОБ_В_ЧИСТОМ, первый раз подряд | журнал «заход n: чистый без проб, не засчитан»; n + 1; unaccounted ← 1 | ФАКТЫ |
| РАЗБОР | то же второй раз подряд — ворота В13, человек: «повторить» | журнал; n + 1; unaccounted + 1 | ФАКТЫ |
| РАЗБОР | то же, человек: «остановить» | журнал; n + 1; unaccounted + 1 | ОСТАНОВ |
| В3 | человек: «не засчитан» | журнал «заход n: пробы — не пробы, не засчитан»; n + 1 | ФАКТЫ |
| В3 | засчитан, существенных нет, серия ещё не набрана | n + 1; streak + 1 | ФАКТЫ |
| В3 | засчитан, существенных нет, и streak + 1 = ЧИСТЫХ_ПОДРЯД | n + 1; streak ← 0 | ПРИНЯТИЕ |
| В3 | засчитан, существенные есть | n + 1; streak ← 0 | ПОТОЛОК |
| ПОТОЛОК | заходов меньше ПОТОЛОК_ЗАХОДОВ | — | ПРАВКА |
| ПОТОЛОК | заходов не меньше ПОТОЛОК_ЗАХОДОВ — ворота В9, человек: «ещё заход» | origin ← n; extra ← решение человека (сузить или разбить) | ПРАВКА |
| ПОТОЛОК | то же, человек: «остановиться» | origin ← n | ПРИНЯТИЕ, с незакрытыми находками |
| ПОТОЛОК | то же, человек: «остановить совещание» | origin ← n | ОСТАНОВ |
| ПРАВКА | автор закончил | extra ← ∅ | ФАКТЫ |
| ПРАВКА | автор остановился (любое его стоп-слово читается как вопрос) | — | ВОПРОС |
| ПРАВКА | автор не ответил — ворота В13, человек: «повторить» | extra сохраняется | ПРАВКА, запуск заново |
| ПРАВКА | то же, человек: «остановить совещание» | — | ОСТАНОВ |
| ВОПРОС | автор закончил | — | ФАКТЫ |
| ВОПРОС | автор снова спросил | — | ВОПРОС, новые ворота В7 |
| ВОПРОС | автор не ответил — ворота В13, человек: «повторить» | ответ сохраняется, В7 не открывается | ВОПРОС, запуск заново |
| ВОПРОС | то же, человек: «остановить совещание» | — | ОСТАНОВ |
| ПРИНЯТИЕ | человек подтвердил | — | КОНЕЦ |

«Не ответил» — нет артефакта, отказ модели, форма не исправлена или бездействие дольше срока («Срок бездействия роли», `task-runner.md`).

```
ФАКТЫ → ЗАМОК → ЛИНЗА(1…L) → СВЕРКА → ФИЛЬТР → СВОД → РАЗБОР → В3 ─┬→ ПРИНЯТИЕ → КОНЕЦ
  ↑                            │ изменён                  │ без проб  ├→ ФАКТЫ  (чистый, серия не набрана; не засчитан)
  ├────────────────────────────┘                          │           └→ ПОТОЛОК ─┬→ ПРАВКА → ВОПРОС ↺
  ├───────────────────────────────────────────────────────┘                       └→ В9 → ПРАВКА | ПРИНЯТИЕ | ОСТАНОВ
  └──────────────────────────────────── ПРАВКА / ВОПРОС: готово
ОСТАНОВ — из любого состояния с запуском роли или воротами В13.
```
