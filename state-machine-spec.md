# Спецификация стейт-машин

Правила для файлов, где алгоритм этого репозитория записан состояниями и переходами. Образец — [task-runner-meeting-states.md](task-runner-meeting-states.md).

## Файл

1. **Имя** — по `AGENTS.md`, «Вынесенные алгоритмы», форма `states`.
2. **Шапка** называет, откуда схема, и ровно один первоисточник: при расхождении верен первоисточник, а стейт-машина правится вслед за ним. Опытный режим так и помечается.
3. **Разделы по порядку**: «Данные», «Инварианты», «Состояния», «Переходы», схема.

## Данные и инварианты

4. **Данные** — таблица «имя, что это, где хранится»; константы — строкой со ссылкой на их источник. Состояние читает и меняет только названные здесь данные.
5. **Инварианты** — только то, что из переходов не видно: кто решает, что неизменно между состояниями, что не уменьшается. Правило, которое видно из строк переходов, инвариантом не повторяется.

## Состояния

6. **Таблица** «состояние, вид, что делается при входе».
7. **Вид** — один из трёх:
   - **действие** — делает работу или открывает ворота и ждёт события; событий у действия может быть несколько, в том числе исходы ворот, которые оно открыло (например, В13 при отказе роли);
   - **выбор** — ничего не делает и не ждёт, только проверяет данные; в столбце «что делается при входе» у него «—» без пояснений; изменения данных у выбора — только в строках его переходов;
   - **конец** — последнее состояние, переходов из него нет; при входе только запись итога.
8. **Повторный вход в действие** повторяет действие при входе целиком. Чтобы повторить только запуск роли с теми же входами, переход пишет «запуск заново».

## Переходы

9. **Одна строка — один переход**: откуда, когда, что меняется, куда. В «куда» — только состояние, при повторе запуска роли — с пометкой «запуск заново» (правило 8). Одна величина — одно имя: если значение меняется по ходу (до ворот и после), у каждого варианта своё имя в «Данных».
10. **«Когда» у действия** — одно событие: роль закончила, остановилась или не ответила, исход ворот, человек выбрал вариант; или «сразу» — переход без события, как только сделано действие при входе.
11. **«Когда» у выбора** — одно условие над данными. Условия одного выбора взаимоисключающие, последнее — «иначе»; порядок строк ничего не решает, и двух подходящих строк быть не может. Условие может состоять из частей через «и» — это части одного правила; «или» в условиях и событиях строк не допускается (определения терминов, правило 16, — не условия): независимые условия — разные строки, даже с одним и тем же переходом. Событие в строке тоже одно: «роль ответила или вопросов не было» — два правила, и второе — условие отдельного выбора.
12. **Событие и условие в одной строке не смешиваются.** Что делается по событию, пишется в его переходе; развилка по данным после события — отдельным выбором. Неверно: «линза ответила, и есть следующая → …»; верно: «линза ответила → ДАЛЬШЕ», затем выбор ДАЛЬШЕ по «i меньше числа линз».
13. **Ворота** — по строке на каждый исход; исход пишется словами ворот («В13: «повторить»»).
14. **Что меняется** — все изменения данных и записи в журнал этого перехода, в порядке выполнения; нет изменений — «—». Пояснения о том, что не меняется, сюда не пишутся. Изменение данных, которое не в этом столбце и не в действии при входе, не происходит.
15. **Пустое «когда» не допускается**: переход без события пишет «сразу», последнее условие выбора — «иначе».
16. **Термины перехода**, которыми пользуется вся машина («не ответил», «запуск заново»), определяются одной строкой перед таблицей.

## Схема

17. **Схема** — текстом, для обзора основного пути; полнота — у таблицы, и при расхождении верна таблица. Каждая стрелка схемы есть в таблице переходов, но не каждый переход обязан быть на схеме.

## Проверка

18. **Сверка с первоисточником** — по каждой ветке первоисточника есть строка перехода с тем же действием и тем же порядком изменения данных, и у каждой строки есть ветка в первоисточнике.
19. **Сверка с этой спецификацией** — каждая строка соблюдает правила 10–15; у каждого выбора условия покрывают все случаи и не пересекаются.
