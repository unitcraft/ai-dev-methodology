# Проверка цикла: код автомата

Стейт-машина проверки цикла — повтор «проверка → правка» одного артефакта задачи (спецификация, план, реализация, сдача) до серии чистых заходов, а для стадии «совещание» вызов вложенной машины совещания, — записанная кодом на языке Нова как реализация протокола `Автомат` движка [state-machine-engine-automaton.md](state-machine-engine-automaton.md): данные машины, перечисления `Состояние` и `Событие`, переход `перейти(состояние, событие)` как `match` по состоянию и событию, роли (входы и результаты обращений к вложенным машинам запуска сессии и совещания и к человеку на воротах), ответ по концу по контракту машины. Всё общее — конверт запроса и ответа, исполнитель, снимок и хранилище, общие события «стоп/продолжить/отмена», цикл, фиксации, передача сигналов вложенным — в движке и здесь не повторяется. Нормы — [task-runner.md](task-runner.md) (словарь, ворота, форматы файлов проверки) и [task-sessions.md](task-sessions.md), «Правила» (потолок заходов, чистая серия, пробы).

**Первоисточник — [task-runner-review-states.md](task-runner-review-states.md)** (машина «Проверка цикла»: таблицы состояний, общие события, «Контракт машины», «Решения при переводе»); правила формы — [state-machine-spec.md](state-machine-spec.md). Этот файл — производная запись того же автомата, а не второй источник истины: при любом расхождении верен первоисточник, а этот файл правится вслед за ним. Язык записи — Нова, https://github.com/nv-lang/nova. **Код не компилировался и не проверялся компилятором Нова:** это псевдокод в синтаксисе Нова; соглашения записи, помеченные места (`// псевдокод:`), подтверждённое и неподтверждённое спецификацией — в [state-machine-engine-automaton.md](state-machine-engine-automaton.md), здесь только то, что относится к проверке цикла. Опытный статус и отличия от ранее написанной схемы описаны в шапке первоисточника и здесь не повторяются; раннером эта машина не исполняется (раннер исполняет [task-runner-pseudocode.md](task-runner-pseudocode.md), помеченный устаревшим). Вызывает эту машину верхняя машина раннера — [task-runner-automaton.md](task-runner-automaton.md) (первоисточник — [task-runner-states.md](task-runner-states.md); состояния `*_ПРОВЕРКА`); для стадии «совещание» эта машина зовёт машину совещания — [task-runner-meeting-automaton.md](task-runner-meeting-automaton.md); каждую сессию проверки и правки она запускает вложенной машиной запуска сессии — [task-runner-session-automaton.md](task-runner-session-automaton.md) (первоисточник — [task-runner-session-states.md](task-runner-session-states.md); состояние ЗАПУСК_СЕССИИ). Все вызовы идут по контракту вызова движка (`Вызываемое`, эффект `Связь`: запрос уходит как `ЗапросРоли`, ответ приходит сообщением), а не прямым вызовом функций; общие типы (`Цикл`, `Находка`, `Свод`, `Стадия`, `ВходПроверки`, `ИтогПроверки`, `ВходЗапускаСессии`, `ИтогЗапускаСессии` и др.) объявлены в слое методики — [state-machine-methodology-automaton.md](state-machine-methodology-automaton.md), вход и итог совещания — в файле совещания. Имя файла — по `AGENTS.md`, «Вынесенные алгоритмы», форма `automaton`.

## Соглашения записи

1. **Типы и идентификаторы** — по [движку](state-machine-engine-automaton.md), пункты 1–3: русские имена. Общие типы данных (`Цикл`, `Находка`, `Уровень`, `ИтогСессии`, `Свод`, `Стадия`, `ВходПроверки`, `ИтогПроверки`, `Вердикт`, `ВходЗапускаСессии`, `ИтогЗапускаСессии`) объявлены один раз в слое методики [state-machine-methodology-automaton.md](state-machine-methodology-automaton.md) и подключены здесь; их таблица соответствия именам блока «Типы на Нове» — там же. Вход паузы (`ВходПаузы`) и сигнатуры `объём_запуска`, `остановить_группу_агента` — тоже из слоя; вариант `ВходРоли` для входа паузы — `ВходПаузыРоли`. Собственных типов данных у этой машины нет: `Свод` (итог файла проверки захода; в первоисточнике в блоке «Типы на Нове» — `Summary`) вынесен в слой, потому что его возвращает запуск сессии, а читает эта машина. Вход и итог совещания (`ВходСовещания`, `ИтогСовещания`) объявлены в [task-runner-meeting-automaton.md](task-runner-meeting-automaton.md); одноимённые типы того файла (`Находка`, `Критичность`, `Свод`) — другие и сюда не подключаются; вход и итог запуска сессии — в слое методики. Записи автомата, которых в первоисточнике нет: `РезультатРоли`, `ВходРоли`, `Окружение`, `Необратимое`. **Значения перечислений** с совпадающими именами в разных перечнях (`План`, `Требования`, `Вопрос`, `Готово` и др.) пишутся с именем типа (`ИтогСессии.План`, `Уровень.План`).
2. **Данные события.** Поля варианта события берутся образцом в `match`: `Сбой { причина } => …`; при совпадении имени поля с переменной машины поле переименовывается: `Ответ_сессии { итог_сессии: итог }`; остаток полей, которые переход не читает, — `{ .. }`. «Сторона события» и идентификатор события — `событие.сторона`, `событие.идентификатор` (конверт `Входящее` движка, правила 13 и 31); тело исходного события шага — `событие.тело` (развилка СТАДИЯ_ОСТАНОВКИ читает дату слова «остановиться»). Служебные операции переходу даёт `среда` (журнал, слова человека, сигналы вложенным, данные движка `открытые_запросы`, `предыдущее`, `запрос_вызова`).
3. **Строка таблицы — ветка кода.** Перед каждой строкой первоисточника (условие или событие, «Что меняется», «Куда») стоит комментарий `// <СОСТОЯНИЕ> #<номер строки>: …` с её текстом; у обращения в скобках — данные события; порядок строк как в первоисточнике. «Куда» записано как `Куда(<СОСТОЯНИЕ>)`; «запуск заново» — `Заново(<СОСТОЯНИЕ>)`; «Куда: предыдущее» — у ПАУЗЫ в движке (`Куда(@машина.состояние_по_имени(предыдущее))`). Строка «иначе» каждой развилки — последняя ветка, ведёт в `ОШИБКА` через `среда.ошибка_машины(…)`. Развилка СВОДКА записана `match` по итогу свода (как РАЗБОР в машине совещания), остальные — последовательностью `if`. Строки «Вход», «Выход», «При входе», «Сторона» и одна строка простыми словами на состояние — комментарии `//` у состояния. Общие события (две строки «стоп» и четыре строки «отмена_запроса») записаны в движке (`общие_события`); `общее` машины сводит к ним её события. Состояние ПАУЗА и его четыре строки подключены фрагментом «Пауза» ([state-machine-pause-states.md](state-machine-pause-states.md)): события паузы разбирает движок (`общие_события`), у машины остаются ветка `ПАУЗА => НеЖдёт`, хуки `состояние_паузы`, `причина_остановки_в_паузе`, `состояние_по_имени` и сведение событий паузы в `общее`.
4. **Строки `// псевдокод:`** и перечень подтверждённого спецификацией — в [движке](state-machine-engine-automaton.md), пункт 5. Здесь дополнительно: функции без тела (сигнатуры механики и чтения внешних объектов); алиас `type Окружение alias Среда[…]` (как в машине совещания); импорт `use` общих типов и совпадающие имена модулей (`Находка` слоя методики и `Находка` совещания) — разрешение вне записи; значения перечислений с именем типа; образец `{ .. }` с остатком и охранное условие в ветке `match` (оба — как в движке и машине совещания). Значения констант `ПОТОЛОК_ЗАХОДОВ` (4), `ЧИСТЫХ_ПОДРЯД` (2), `ПРОБ_В_ЧИСТОМ` (3) — из первоисточника (`task-sessions.md`, «Правила»; числа — параметры проекта); `ro` на уровне модуля в Нове не подтверждено. Неподтверждённое спецификацией Нова, используемое здесь (как и в машине совещания): объявление `module`, `return` внутри `if` в ветке `match` и в теле функции, `while`. Срок бездействия не задан: у обращений этой машины `0` (исполнитель «нет ответа» не порождает), для вызова вложенной машины совещания он равен `0` — это значение «без срока» (правило 35, пункт 5): родитель ждёт ответа или отмены.
5. **Уточнения записи автомата сверх первоисточника** (подробности — «Что движок не покрыл»): (а) метод `событие_ответа` — метод протокола `Автомат`: отображение результата роли в событие; (б) вложенная сторона и число возвратов ответа не по форме — поля `вложенная` и `возвратов_формы` описания обращения (`Одна`): вложенные — «совещание» и «запуск сессии», возвратов формы у этой машины нет (ответ не по форме возвращает агенту вложенная машина запуска сессии); метод `при_возобновлении` — заглушка (подготовки при возобновлении нет); (в) `вердикт` — текст (`вердикт_из_текста` — обход, «Что движок не покрыл», п. 12) (как в данных первоисточника: «чисто», «требования», «план», «вопрос», «перезапуск», «остановлено»), в `Вердикт` его переводит `вердикт_из_текста` при ответе; `стадия` — перечисление `Стадия` блока типов (в таблице данных — Текст: по ней ветвятся развилки); (г) `ВходЗапускаСессии` — вход вложенной машины запуска сессии (слой методики, один тип у раннера и этой машины): код сессии — поле `сессия` (Текст); по коду ветвятся запуск сессии, профиль и промпт — механика исполнителя («Реализация на файлах» [task-runner-session-states.md](task-runner-session-states.md)), машина по нему не ветвится (правило 6), суммы по видам сессий не заводятся; фазу эта машина не передаёт (`None`); (д) `запрос_вызова` — всегда `запрос.идентификатор_запроса` (решение о `""` у верхнего уровня открыто, см. движок, пункт 6); (е) `состояние_по_имени` записано полным `match` по именам обращений.
6. **Данные машины — поля типа `Машина`**: поля названы как переменные раздела «Данные» первоисточника (правило 25), начальные значения — в `Машина.new()`, по входу проверки — `Машина.из_входа` (счётчики цикла, находки «вне задачи», задание и вход совещания приходят в запросе). Данные движка (конверт, очереди запросов, журнал, слова человека, тексты сбоев) — в `СостояниеДвижка` движка. Внешние объекты: `свод` и `находки_проверки` — поля (их пишет исполнитель при приёме ответа сессии проверки, `записать_результат`), читателей через `Объекты` у этой машины нет (объём запуска измеряет вложенная машина запуска сессии). **Именование читателей по ключу:** читатель элемента поля называется по полю (`@свод(номер)`, `@находки_проверки(номер)`). **Поле и метод с одним именем** (`свод`, `находки_проверки`) — сознательное решение: в Нове допустимо (`spec/decisions/03-syntax.md`, правило `@name`), правило 25 соблюдено (имя одной сущности одно).
7. **`недостижимо(текст)`** (определено в движке, пункт 8): в реализации стоит: у концов КОНЕЦ, ОСТАНОВЛЕНО, ОШИБКА в `перейти` (переходов нет); в `ответ_по_концу` (значение `остановка` вне таблицы; ответ не из конца); в `выполнить_операцию` (у этой машины операций нет); в `вход_запроса` и `следующая_попытка` (обязательное поле входа пусто — `обязательное` движка; состояние не обращение; сторона вне «запуск сессии», «совещание», «человек»); в `состояние_по_имени`, `сторона_обращения` (имя вне перечня); в `дата_остановки` (цепочка начата не словом «остановиться»); в `вердикт_из_текста` (вердикт вне перечня).

```nova
/// у ворот человека результата роли нет: слово человека приходит событием, а не исходом запроса.
type РезультатРоли enum
  | РезультатЗапускаСессии(ИтогЗапускаСессии)                                                         // ЗАПУСК_СЕССИИ: итог_сессии; свод и находки_проверки — только у сессий проверки
  | РезультатСовещания(ИтогСовещания)                                                                  // СОВЕЩАНИЕ: итог_совещания (эта машина полей не читает)

/// Запись автомата: вход запроса — по варианту на обращение первоисточника; поля — строки таблицы «Вход» состояния, читаемые стороной
/// (у ворот без столбца «Кто читает» — вся таблица); необязательное поле — Option. Режим «показывать и продолжать» (исход по умолчанию даёт исполнитель) — на стороне исполнителя.
type ВходРоли enum
  | ВходЗапускаСессииРоли(ВходЗапускаСессии)                                                                      // ЗАПУСК_СЕССИИ (вложенная машина «Запуск сессии»); план_задачи читает та машина
  | ВходСовещанияРоли(ВходСовещания)                                                                              // СОВЕЩАНИЕ (вложенная машина совещания)
  | ВходПовтора                                                                                                    // ПОВТОР: входа нет
  | ВходВ3 { свод Option[Свод], находки_проверки []Находка }                                                       // В3: свод (объект) есть всегда, итог внутри может отсутствовать
  | ВходВ9 { находки_проверки []Находка, номер_захода int, заход_отсчёта int, стадия Стадия }                      // В9: все находки цикла от заход_отсчёта до номер_захода − 1
  | ВходПаузыРоли(ВходПаузы)                                                                // ПАУЗА

/// Необратимое действие во внешнем мире: последний этап фиксации, повторяемый без вреда (правило 13).
type Необратимое enum
  | ОстановитьГруппуАгента        // ОСТАНОВЛЕНО, ОШИБКА: группа процессов агента останавливается целиком, проверяется, что в ней не осталось процессов
```

```nova
  находки_В3 []Находка,                        // существенные находки последнего засчитанного захода после поправки человека у В3, без «вне задачи»
  вердикт str,                                 // что вернуть вызвавшей машине: чисто, требования, план, вопрос, перезапуск или остановлено
  источник_вердикта str,                       // файл, на который опирается маршрут «требования» или «план»
  сессия str,                                  // код запускаемой сессии: проверка (С2, С4, С6, С8), правка (С1п, С3п, С5п, С7п)
  источник_запуска str,                        // источник правок для запускаемой сессии; `""` — источника нет
  заход_запуска int,                           // номер захода, с которым запускается сессия

  остановка str,                               // почему проверка останавливается: исход ворот или причина вложенной машины запуска сессии
  попытка_сессии int,                          // счётчики попыток одноадресных обращений (правило 15): к вложенной машине запуска сессии, к вложенной машине совещания, к человеку
  попытка_совещания int,
  попытка_человека int,

  свод HashMap[int, Свод],                     // [номер_захода]; итоговая строка файла проверки захода; в заходе без неё итога нет (записи нет)

  рабочее_дерево str,
  режим_сдачи str,
  предложение Option[str],                     // только у стадии «совещание»
  порядок_линз []str,                          // только у стадии «совещание»
  вопрос_автора Option[str],                   // только у стадии «совещание»; может отсутствовать
```

```nova
// Раздел записывает механику проверки цикла: свободные функции и методы `Машина`; методы `Исполнитель` и общие функции — в движке.
// псевдокод: функции без тела — сигнатуры; тело пишет реализация, в Нове внешняя реализация здесь не показана

// Свободные функции
// итог последней сессии равен заданному; сессия ещё не кончалась — нет
fn итог_равен(итог Option[ИтогСессии], значение ИтогСессии) -> bool => match итог {
  Some(найденный) => найденный == значение
  None => false
}
// среди находок есть находка заданного уровня
fn есть_находка_уровня(находки []Находка, уровень Уровень) -> bool {
  for находка in находки {
    if находка.уровень == уровень { return true }
  }
  false
}
// элементы первых, затем элементы вторых (правило 30: добавить)
fn добавить(первые []Находка, вторые []Находка) -> []Находка {
  mut результат = []Находка.new()
  for находка in первые { результат.push(находка) }
  for находка in вторые { результат.push(находка) }
  результат
}
// проверяющий(стадия): С2, С4, С6, С8 (термины); у «совещания» проверяющего нет — его ведёт вложенная машина
fn проверяющий(стадия Стадия) -> str => match стадия {
  Стадия.Разбор => "С2"
  Стадия.План => "С4"
  Стадия.Реализация => "С6"
  Стадия.Сдача => "С8"
  Стадия.Совещание => недостижимо("проверяющего у стадии «совещание» нет: ЗАХОД ведёт её в СОВЕЩАНИЕ")
}
// правщик(стадия): С1п, С3п, С5п, С7п (термины)
fn правщик(стадия Стадия) -> str => match стадия {
  Стадия.Разбор => "С1п"
  Стадия.План => "С3п"
  Стадия.Реализация => "С5п"
  Стадия.Сдача => "С7п"
  Стадия.Совещание => недостижимо("правщика у стадии «совещание» нет: правку ведёт вложенная машина")
}
// дата слова «остановиться» у В9: данные исходного события шага, которые читает СТАДИЯ_ОСТАНОВКИ
fn дата_остановки(тело Событие) -> str => match тело {
```

## Переходы

```nova
/// Переход по событию. тело_события — событие, которое ждёт состояние `текущее` (у развилки — Сразу без данных);
/// событие — исходное событие шага: его данные (сторона, идентификатор, тело) доступны всей цепочке до ближайшего обращения (правило 13).
/// Состояние пишется при фиксации; в «Что меняется» оно не повторяется.
fn Машина mut @перейти(текущее Состояние, тело_события Событие, событие Входящее[Событие], среда Окружение) Журнал Объекты Time -> Переход[Состояние] {
  match текущее {

  // ===================== ЗАХОД — развилка =====================
  // Начало очередного захода: для совещания зовёт машину совещания; для остальных стадий серия чистых заходов набрана — возвращает «чисто», иначе
  //   просит проверяющего проверить артефакт.
  // Вход: стадия; серия_чистых; номер_захода
  ЗАХОД => {
    // ЗАХОД #1: стадия = «совещание»
    if @стадия == Стадия.Совещание { return Куда(СОВЕЩАНИЕ) }
    // ЗАХОД #2: стадия отлична от «совещание», и серия_чистых меньше ЧИСТЫХ_ПОДРЯД
    if @стадия != Стадия.Совещание && @серия_чистых < ЧИСТЫХ_ПОДРЯД {
      @назначить_запуск(проверяющий(@стадия), "", @номер_захода, "проверка")
      return Куда(ЗАПУСК_СЕССИИ)
    }
    // ЗАХОД #3: стадия отлична от «совещание», и серия_чистых не меньше ЧИСТЫХ_ПОДРЯД
    if @стадия != Стадия.Совещание && @серия_чистых >= ЧИСТЫХ_ПОДРЯД {
      @серия_чистых = 0
      @вердикт = "чисто"
      return Куда(КОНЕЦ)
    }
    // ЗАХОД #4: иначе
    среда.ошибка_машины("ошибка машины: развилка ЗАХОД, ни одно условие не подошло")
  }

  // ===================== СОВЕЩАНИЕ — обращение =====================
  // Просит вложенную машину совещания провести согласование предложения до принятого итога; вернёт «чисто», если итог принят, и «остановлено», если
  //   человек остановил совещание.
  // При входе: исполнитель отправляет запрос вложенной машине совещания ([task-runner-meeting-states.md](task-runner-meeting-states.md)):
  //   предложение, порядок линз, вопрос автора; весь цикл `loop_review(meeting)` — заходы, чистые серии, В3, В7, В9, правку автора, «принять итог» —
  //   ведёт та машина.
  // Сторона: совещание (вложенная машина).
  // Вход (сторона): предложение; порядок_линз; вопрос_автора?
  // Выход: итог_совещания (эта машина полей не читает)
  СОВЕЩАНИЕ => match тело_события {
    // СОВЕЩАНИЕ #1: ответ
    Ответ_совещания => {
      @вердикт = "чисто"
      Куда(КОНЕЦ)
    }
    // СОВЕЩАНИЕ #2: сбой (причина: КодСбоя)
    Сбой { причина } => {
      среда.писать_журнал("совещание остановлено: ${слово_кода(причина)}")
      @вердикт = "остановлено"
      Куда(КОНЕЦ)
    }
    _ => НеЖдёт
  }

  // ===================== ЗАПУСК_СЕССИИ — обращение =====================
  // Просит вложенную машину запуска сессии выполнить одну сессию агента (проверки или правки) и возвращает, чем она кончилась; профиль и цена,
  //   объём, повтор при сбое — дело той машины.
  // Запись автомата: событие «ответ» несёт итог сессии (`Ответ_сессии`); свод и находки захода сессии проверки исполнитель записывает при приёме
  //   (`записать_результат`).
  // При входе: исполнитель отправляет запрос вложенной машине запуска сессии ([task-runner-session-states.md](task-runner-session-states.md)): код сессии,
  //   источник правок, номер захода и задание; ворота В2, В1, В13 и обращение к агенту ведёт та машина. Место, откуда сессию запустили, называет
  //   `продолжение`: оно остаётся здесь и запросом не передаётся — по нему ПОСЛЕ_СЕССИИ решает, куда идти дальше.
  // Сторона: запуск сессии (вложенная машина, [task-runner-session-states.md](task-runner-session-states.md)).
  // Вход (сторона): сессия; источник_запуска?; заход_запуска (номер захода файла проверки: у проверяющего — номер файла, который он напишет, у
  //   правщика — номер файла с находками); режим_сдачи (подставляется в промпты сдачи (С7п)); папка_задачи (агент запускается из неё); рабочее_дерево
  // Выход: итог_сессии; свод[номер_захода]? (только у сессий проверки: итоговая строка файла захода); находки_проверки[номер_захода]? (только у
  //   сессий проверки)
  ЗАПУСК_СЕССИИ => match тело_события {
    // ЗАПУСК_СЕССИИ #1: ответ (итог_сессии: ИтогСессии — готово, ревизия, план, требования или вопрос)
    Ответ_сессии { итог_сессии: итог } => {
      @итог_сессии = Some(итог)
      Куда(ПОСЛЕ_СЕССИИ)
    }
    // ЗАПУСК_СЕССИИ #2: сбой (причина: КодСбоя)
    Сбой { причина } => {
      @причина_сбоя = слово_кода(причина)
      среда.писать_журнал("запуск сессии ${@сессия} не дал итога: ${слово_кода(причина)}")
      Куда(ОТКАЗ_СЕССИИ)
    }
    _ => НеЖдёт
  }

  // ===================== ОТКАЗ_СЕССИИ — развилка =====================
  // Решает, как проверка остановится, если вложенный запуск сессии не вернул итог: по человеку (он остановил на воротах) или по отсутствию результата.
  // Вход: причина_сбоя
  ОТКАЗ_СЕССИИ => {
    // ОТКАЗ_СЕССИИ #1: причина_сбоя = «остановлено человеком»
    if @причина_сбоя == "остановлено человеком" {
      @остановка = "запуск сессии: остановлено человеком"
      return Куда(ОСТАНОВЛЕНО)
    }
    // ОТКАЗ_СЕССИИ #2: причина_сбоя = «нет результата»
    if @причина_сбоя == "нет результата" {
      @остановка = "запуск сессии: нет результата"
      return Куда(ОСТАНОВЛЕНО)
    }
    // ОТКАЗ_СЕССИИ #3: иначе
    среда.ошибка_машины("ошибка машины: развилка ОТКАЗ_СЕССИИ, ни одно условие не подошло")
  }

  // ===================== ПОСЛЕ_СЕССИИ — развилка =====================
  // Решает, куда идти после сессии: сессия проверки ведёт к разбору итоговой строки, сессия правки — к разбору её исхода, сессия «не делаю» — к
  //   возврату вердикта.
  // Вход: продолжение; стадия
  ПОСЛЕ_СЕССИИ => {
    // ПОСЛЕ_СЕССИИ #1: продолжение = «проверка»
    if @продолжение == "проверка" { return Куда(СВОДКА) }
    // ПОСЛЕ_СЕССИИ #2: продолжение = «правка»
    if @продолжение == "правка" { return Куда(ИТОГ_ПРАВКИ) }
    // ПОСЛЕ_СЕССИИ #3: продолжение = «не делаю», и стадия = «сдача»
    if @продолжение == "не делаю" && @стадия == Стадия.Сдача {
      @вердикт = "перезапуск"
      return Куда(КОНЕЦ)
    }
    // ПОСЛЕ_СЕССИИ #4: продолжение = «не делаю», и стадия = «реализация»
    if @продолжение == "не делаю" && @стадия == Стадия.Реализация {
      @вердикт = "чисто"
      return Куда(КОНЕЦ)
    }
    // ПОСЛЕ_СЕССИИ #5: иначе
    среда.ошибка_машины("ошибка машины: развилка ПОСЛЕ_СЕССИИ, ни одно условие не подошло")
  }

  // ===================== СВОДКА — развилка =====================
  // Читает итоговую строку файла проверки: чистый заход без проб не засчитывается и идёт заново, в остальных случаях находки уходят человеку.
  // Вход: свод[номер_захода]? (объект есть всегда, итог внутри может отсутствовать); номер_захода; без_проб_подряд
  СВОДКА => match @свод(@номер_захода) {
    // СВОДКА #1: итога свода нет
    None => {
      среда.писать_журнал("итоговой строки нет, все находки считаются существенными")
      @без_проб_подряд = 0
      Куда(В3)
    }
    // СВОДКА #2: итог свода есть, и существенных больше 0
    Some(итог) if итог.существенных > 0 => {
      @без_проб_подряд = 0
      Куда(В3)
    }
    // СВОДКА #3: итог свода есть, существенных нет, и проб не меньше ПРОБ_В_ЧИСТОМ
    Some(итог) if итог.существенных == 0 && итог.проб >= ПРОБ_В_ЧИСТОМ => {
      @без_проб_подряд = 0
      Куда(В3)
    }
    // СВОДКА #4: итог свода есть, существенных нет, и проб меньше ПРОБ_В_ЧИСТОМ
    Some(итог) if итог.существенных == 0 && итог.проб < ПРОБ_В_ЧИСТОМ => {
      среда.писать_журнал("заход ${@номер_захода}: чистый без проб, не засчитан")
      @номер_захода += 1
      @без_проб_подряд += 1
      Куда(БЕЗ_ПРОБ)
    }
    // СВОДКА #5: иначе
    _ => среда.ошибка_машины("ошибка машины: развилка СВОДКА, ни одно условие не подошло")
  }

  // ===================== БЕЗ_ПРОБ — развилка =====================
  // Считает чистые заходы без проб подряд: первый — просто повторить проверку, второй — спросить человека.
  // Вход: без_проб_подряд
  БЕЗ_ПРОБ => {
    match шаг_без_проб(@цикл()) {
      // БЕЗ_ПРОБ #1: без_проб_подряд = 1
      Some(ПовторитьПроверку) => Куда(ЗАХОД)
      // БЕЗ_ПРОБ #2: без_проб_подряд больше 1
      Some(СпроситьЧеловека) => Куда(ПОВТОР)
      // БЕЗ_ПРОБ #3: иначе
      None => среда.ошибка_машины("ошибка машины: развилка БЕЗ_ПРОБ, ни одно условие не подошло")
    }
  }

  // ===================== ПОВТОР — обращение =====================
  // Спрашивает человека, что делать после второго подряд чистого захода без проб: повторить проверку или остановить раннер.
  // При входе: ворота В13: проверка второй раз подряд без проб.
  // Сторона: человек.
  // Вход: нет.
  // Выход: исход ворот
  ПОВТОР => match тело_события {
    // ПОВТОР #1: В13: «повторить»
    В13_повторить => Куда(ЗАХОД)
    // ПОВТОР #2: В13: «остановить»
    В13_остановить => {
      @остановка = "ПОВТОР: остановить"
      Куда(ОСТАНОВЛЕНО)
    }
    _ => НеЖдёт
  }

  // ===================== В3 — обращение =====================
  // Показывает человеку находки и пробы захода; он может поднять критичность находок или не засчитать заход, если пробы — не настоящие пробы; находки
  //   «вне задачи» он отделяет.
  // При входе: ворота В3: человек читает находки и пробы (а не итог), может поднять критичность, не засчитать чистый заход, если пробы — не пробы, и
  //   называет существенные находки с уровнями (без уровня «вне задачи»: их он отделяет в `вне_задачи_захода`); в режиме «показывать и продолжать»
  //   ворота только показывают и идут дальше как «засчитан» с находками свода без поправки.
  // Сторона: человек.
  // Вход (сторона): свод[номер_захода]? (объект есть всегда, итог внутри может отсутствовать); находки_проверки[номер_захода]
  // Вход (исполнитель): номер_захода; вне_задачи (к ним добавятся находки «вне задачи» этого захода)
  // Выход: исход ворот; находки_В3 (существенные находки после поправки человека, без «вне задачи»); вне_задачи_захода (находки уровня «вне задачи»
  //   этого захода)
  В3 => match тело_события {
    // В3 #1: В3: «не засчитан»
    В3_не_засчитан => {
      среда.писать_журнал("заход ${@номер_захода}: пробы — не пробы, не засчитан")
      @номер_захода += 1
      Куда(ЗАХОД)
    }
    // В3 #2: В3: «засчитан» (находки_В3: []Находка; вне_задачи_захода: []Находка)
    В3_засчитан { находки_В3: новые_находки, вне_задачи_захода } => {
      @номер_захода += 1
      @вне_задачи = добавить(@вне_задачи, вне_задачи_захода)
      @находки_В3 = новые_находки
      Куда(ИТОГ_ЗАХОДА)
    }
    _ => НеЖдёт
  }

  // ===================== ИТОГ_ЗАХОДА — развилка =====================
  // Подводит итог засчитанного захода: существенных находок нет — ещё один чистый заход в серии; есть — серия обрывается и надо смотреть потолок.
  // Вход: находки_В3; серия_чистых
  ИТОГ_ЗАХОДА => {
    // ИТОГ_ЗАХОДА #1: находки_В3 = `[]`
    if @находки_В3.len() == 0 {
      @серия_чистых += 1
      return Куда(ЗАХОД)
    }
    // ИТОГ_ЗАХОДА #2: находки_В3 не равны `[]`
    if @находки_В3.len() > 0 {
      @серия_чистых = 0
      return Куда(ПОТОЛОК)
    }
    // ИТОГ_ЗАХОДА #3: иначе
    среда.ошибка_машины("ошибка машины: развилка ИТОГ_ЗАХОДА, ни одно условие не подошло")
  }

  // ===================== ПОТОЛОК — развилка =====================
  // Проверяет, не исчерпан ли предел числа заходов: нет — идти к правке, исчерпан — решает человек.
  // Вход: номер_захода; заход_отсчёта
  ПОТОЛОК => {
    // ПОТОЛОК #1: (номер_захода − 1) − заход_отсчёта + 1 меньше ПОТОЛОК_ЗАХОДОВ
    if !потолок_исчерпан(@цикл(), ПОТОЛОК_ЗАХОДОВ) { return Куда(УРОВНИ) }
    // ПОТОЛОК #2: (номер_захода − 1) − заход_отсчёта + 1 не меньше ПОТОЛОК_ЗАХОДОВ
    if потолок_исчерпан(@цикл(), ПОТОЛОК_ЗАХОДОВ) { return Куда(В9) }
    // ПОТОЛОК #3: иначе
    среда.ошибка_машины("ошибка машины: развилка ПОТОЛОК, ни одно условие не подошло")
  }

  // ===================== В9 — обращение =====================
  // Сообщает человеку, что предел заходов исчерпан и существенные находки остались, и спрашивает: урезать объём, разбить, спросить заказчика, ещё
  //   заход или остановиться (у реализации и сдачи — не делать; у разбора и плана — править дальше по находкам).
  // При входе: ворота В9: потолок заходов, человек видит все находки цикла (от `заход_отсчёта`); исход «остановиться» у разбора и плана ведёт к
  //   правке по находкам, как «ещё заход» (СТАДИЯ_ОСТАНОВКИ; «Решения при переводе», решение 9); решение владельца всегда сдвигает отсчёт потолка
  //   (правка владельца).
  // Сторона: человек.
  // Вход (сторона): находки_проверки[номер_захода] (все находки цикла: заходы от заход_отсчёта до номер_захода − 1); номер_захода; заход_отсчёта;
  //   стадия (по ней ворота решают, предлагать ли «остановиться»)
  // Выход: исход ворот
  В9 => match тело_события {
    // В9 #1: В9: «урезать объём»
    В9_урезать_объём => {
      @установить_цикл(сброс_отсчёта(@цикл()))
      @вердикт = "требования"
      @источник_вердикта = "файл проверки захода ${@номер_захода - 1}"
      Куда(КОНЕЦ)
    }
    // В9 #2: В9: «разбить»
    В9_разбить => {
      @установить_цикл(сброс_отсчёта(@цикл()))
      @вердикт = "требования"
      @источник_вердикта = "файл проверки захода ${@номер_захода - 1}"
      Куда(КОНЕЦ)
    }
    // В9 #3: В9: «спросить заказчика»
    В9_спросить_заказчика => {
      @установить_цикл(сброс_отсчёта(@цикл()))
      @вердикт = "вопрос"
      Куда(КОНЕЦ)
    }
    // В9 #4: В9: «остановиться» (дата: Текст)
    В9_остановиться { .. } => {
      @установить_цикл(сброс_отсчёта(@цикл()))
      Куда(СТАДИЯ_ОСТАНОВКИ)
    }
    // В9 #5: В9: «ещё заход»
    В9_ещё_заход => {
      @установить_цикл(сброс_отсчёта(@цикл()))
      Куда(УРОВНИ)
    }
    _ => НеЖдёт
  }

  // ===================== СТАДИЯ_ОСТАНОВКИ — развилка =====================
  // Решает, что значит «остановиться» у этой стадии: у реализации и сдачи — правка С5п «не делаю»; у разбора и плана такого решения нет, и дальше
  //   идёт правка по находкам этого захода, как после «ещё заход».
  // Запись автомата: «<дата события>» — дата слова «В9: «остановиться»», тело исходного события шага (`дата_остановки(событие.тело)`).
  // Вход: стадия
  СТАДИЯ_ОСТАНОВКИ => {
    // СТАДИЯ_ОСТАНОВКИ #1: стадия = «реализация»
    if @стадия == Стадия.Реализация {
      @назначить_запуск("С5п", "решение владельца: не делаю, ${дата_остановки(событие.тело)}", 0, "не делаю")
      return Куда(ЗАПУСК_СЕССИИ)
    }
    // СТАДИЯ_ОСТАНОВКИ #2: стадия = «сдача»
    if @стадия == Стадия.Сдача {
      @назначить_запуск("С5п", "решение владельца: не делаю, ${дата_остановки(событие.тело)}", 0, "не делаю")
      return Куда(ЗАПУСК_СЕССИИ)
    }
    // СТАДИЯ_ОСТАНОВКИ #3: стадия = «разбор»
    if @стадия == Стадия.Разбор { return Куда(УРОВНИ) }
    // СТАДИЯ_ОСТАНОВКИ #4: стадия = «план»
    if @стадия == Стадия.План { return Куда(УРОВНИ) }
    // СТАДИЯ_ОСТАНОВКИ #5: иначе
    среда.ошибка_машины("ошибка машины: развилка СТАДИЯ_ОСТАНОВКИ, ни одно условие не подошло")
  }

  // ===================== УРОВНИ — развилка =====================
  // Смотрит уровни существенных находок: требования — вернуть работу в требования; план — вернуть в план (для реализации и сдачи); иначе находки
  //   правит автор.
  // Вход: находки_В3; стадия; номер_захода
  УРОВНИ => {
    // УРОВНИ #1: среди находки_В3 есть находка с уровнем «требования»
    if есть_находка_уровня(@находки_В3, Уровень.Требования) {
      @вердикт = "требования"
      @источник_вердикта = "файл проверки захода ${@номер_захода - 1}"
      return Куда(КОНЕЦ)
    }
    // УРОВНИ #2: среди находки_В3 нет находки с уровнем «требования» и нет находки с уровнем «план»
    if !есть_находка_уровня(@находки_В3, Уровень.Требования) && !есть_находка_уровня(@находки_В3, Уровень.План) {
      @назначить_запуск(правщик(@стадия), "файл проверки захода ${@номер_захода - 1}", @номер_захода - 1, "правка")
      return Куда(ЗАПУСК_СЕССИИ)
    }
    // УРОВНИ #3: среди находки_В3 нет находки с уровнем «требования», есть находка с уровнем «план», и стадия = «реализация»
    if !есть_находка_уровня(@находки_В3, Уровень.Требования) && есть_находка_уровня(@находки_В3, Уровень.План) && @стадия == Стадия.Реализация {
      @вердикт = "план"
      @источник_вердикта = "файл проверки захода ${@номер_захода - 1}"
      return Куда(КОНЕЦ)
    }
    // УРОВНИ #4: среди находки_В3 нет находки с уровнем «требования», есть находка с уровнем «план», и стадия = «сдача»
    if !есть_находка_уровня(@находки_В3, Уровень.Требования) && есть_находка_уровня(@находки_В3, Уровень.План) && @стадия == Стадия.Сдача {
      @вердикт = "план"
      @источник_вердикта = "файл проверки захода ${@номер_захода - 1}"
      return Куда(КОНЕЦ)
    }
    // УРОВНИ #5: среди находки_В3 нет находки с уровнем «требования», есть находка с уровнем «план», и стадия = «разбор»
    if !есть_находка_уровня(@находки_В3, Уровень.Требования) && есть_находка_уровня(@находки_В3, Уровень.План) && @стадия == Стадия.Разбор {
      @назначить_запуск(правщик(@стадия), "файл проверки захода ${@номер_захода - 1}", @номер_захода - 1, "правка")
      return Куда(ЗАПУСК_СЕССИИ)
    }
    // УРОВНИ #6: среди находки_В3 нет находки с уровнем «требования», есть находка с уровнем «план», и стадия = «план»
    if !есть_находка_уровня(@находки_В3, Уровень.Требования) && есть_находка_уровня(@находки_В3, Уровень.План) && @стадия == Стадия.План {
      @назначить_запуск(правщик(@стадия), "файл проверки захода ${@номер_захода - 1}", @номер_захода - 1, "правка")
      return Куда(ЗАПУСК_СЕССИИ)
    }
    // УРОВНИ #7: иначе
    среда.ошибка_машины("ошибка машины: развилка УРОВНИ, ни одно условие не подошло")
  }

  // ===================== ИТОГ_ПРАВКИ — развилка =====================
  // Разбирает, чем кончилась правка автора: закончена — проверка заново; остановилась с вопросом или с вынесением работы на другой уровень — вернуть
  //   это вызвавшей машине.
  // Вход: итог_сессии
  ИТОГ_ПРАВКИ => {
    // ИТОГ_ПРАВКИ #1: итог_сессии = «готово»
    if итог_равен(@итог_сессии, ИтогСессии.Готово) { return Куда(ЗАХОД) }
    // ИТОГ_ПРАВКИ #2: итог_сессии = «вопрос»
    if итог_равен(@итог_сессии, ИтогСессии.Вопрос) {
      @вердикт = "вопрос"
      return Куда(КОНЕЦ)
    }
    // ИТОГ_ПРАВКИ #3: итог_сессии = «ревизия»
    if итог_равен(@итог_сессии, ИтогСессии.Ревизия) {
      @вердикт = "план"
      @источник_вердикта = "артефакт автора"
      return Куда(КОНЕЦ)
    }
    // ИТОГ_ПРАВКИ #4: итог_сессии = «план»
    if итог_равен(@итог_сессии, ИтогСессии.План) {
      @вердикт = "план"
      @источник_вердикта = "артефакт автора"
      return Куда(КОНЕЦ)
    }
    // ИТОГ_ПРАВКИ #5: итог_сессии = «требования»
    if итог_равен(@итог_сессии, ИтогСессии.Требования) {
      @вердикт = "требования"
      @источник_вердикта = "артефакт автора"
      return Куда(КОНЕЦ)
    }
    // ИТОГ_ПРАВКИ #6: иначе
    среда.ошибка_машины("ошибка машины: развилка ИТОГ_ПРАВКИ, ни одно условие не подошло")
  }

  // ===================== ПАУЗА — обращение =====================
  // Подключено фрагментом «Пауза» (state-machine-pause-states.md): события ПАУЗЫ разбирает движок (`общие_события`), строк состояния у машины нет;
  //   остальные события ПАУЗА не ждёт.
  ПАУЗА => НеЖдёт

  // ===================== КОНЕЦ — конец =====================
  // Возвращает вызвавшей машине вердикт проверки с источником маршрута, счётчиками цикла и находками «вне задачи»: проверка закончена.
  // При входе: в журнал — вердикт, источник маршрута и счётчики цикла; ответ `Answer` с итогом проверки уходит вызвавшей машине.
  // Вход: вердикт; источник_вердикта? (у вердиктов «требования» и «план»); номер_захода; заход_отсчёта; серия_чистых; без_проб_подряд; вне_задачи
  КОНЕЦ => недостижимо("конец: переходов нет; работа при входе — в «Концы и ответ»")

  // ===================== ОСТАНОВЛЕНО — конец =====================
  // Заканчивает проверку без вердикта и записывает, почему; решение, что делать дальше, — за человеком вне машины.
  // При входе: группа процессов агента останавливается целиком и проверяется, что в ней не осталось процессов; вложенная машина совещания получает
  //   отмену, если запрос к ней открыт; в журнал — «проверка цикла остановлена: <остановка>»; вызвавшая машина получает `Refusal` (таблица «конец →
  //   ответ»).
  // Вход: остановка
  ОСТАНОВЛЕНО => недостижимо("конец: переходов нет; работа при входе — в «Концы и ответ»")

  // ===================== ОШИБКА — конец =====================
  // Заканчивает проверку, если сама машина попала в непредусмотренное положение; это дефект машины или реализации, его разбирает человек.
  // При входе: группа процессов агента останавливается; в журнал — запись из перехода и данные машины; вызвавшая машина получает `Refusal`; решает
  //   человек вне машины.
  // Вход: все данные машины ((в журнал))
  ОШИБКА => недостижимо("конец: переходов нет; работа при входе — в «Концы и ответ»")

  }
}
```

## Приём ответа и запись результата

```nova
/// При приёме (правило 14): у обращений проверки записи стороны нет (счётчики попыток ведёт механика контракта).
fn Машина mut @при_приёме(текущее Состояние, ответ Исход[РезультатРоли]) => ()

/// Запись принятого результата в хранилище (правила 8, 14): роль возвращает результат, в хранилище машины не пишет.
/// Итоговая строка и находки захода пишутся только у сессий проверки (ЗАПУСК_СЕССИИ, свод[номер_захода] и находки_проверки[номер_захода]); у сессий правки
/// и у вложенной машины совещания результат идёт событием; у ворот результата роли нет.
fn Машина mut @записать_результат(текущее Состояние, ответ Исход[РезультатРоли]) => match ответ {
  Отказ(_) => ()
  СРезультатом(итог) => match итог.результат {
    РезультатЗапускаСессии(итог_запуска) => {
      match итог_запуска.свод {
        Some(найденный) => { @свод.insert(@номер_захода, найденный) }
        None => {}                                        // итога нет: записи в `свод` нет
      }
      match итог_запуска.находки_проверки {
        Some(найденные) => { @находки_проверки.insert(@номер_захода, найденные) }
        None => {}                                        // сессия правки: файла находок нет
      }
    }
    РезультатСовещания(_) => ()
  }
}
```

## Концы и ответ

```nova
/// Работа концов при входе (в последнем, повторяемом без вреда этапе фиксации) и ответ вызвавшей стороне.
/// Вход в любой конец отменяет все открытые запросы (правило 22), в том числе запрос к вложенной машине совещания; машина отвечает ровно один раз (правило 35).
fn Машина mut @при_входе_в_конец(конец Состояние, среда Окружение) Журнал Time -> () => match конец {
  // ОСТАНОВЛЕНО: группа процессов агента останавливается целиком и проверяется, что в ней не осталось процессов; вложенная машина совещания получает отмену, если запрос к ней открыт
  //   (движок: `отменить_все_открытые_запросы`); в журнал — «проверка цикла остановлена: <остановка>»; вызвавшая машина получает `Refusal` (таблица «конец → ответ»).
  ОСТАНОВЛЕНО => {
    среда.добавить_необратимое(Необратимое.ОстановитьГруппуАгента)
    среда.писать_журнал("проверка цикла остановлена: ${@остановка}")
  }
  // ОШИБКА: группа процессов агента останавливается; в журнал — запись из перехода и данные машины; вызвавшая машина получает `Refusal`; решает человек вне машины.
  ОШИБКА => {
    среда.добавить_необратимое(Необратимое.ОстановитьГруппуАгента)
    среда.писать_журнал(среда.запись_перехода())
    @журнал_данных_машины(среда)
  }
  // КОНЕЦ: в журнал — вердикт, источник маршрута и счётчики цикла; ответ `Answer` с итогом проверки уходит вызвавшей машине.
  КОНЕЦ => {
    среда.писать_журнал("проверка цикла: вердикт ${@вердикт}, источник ${@источник_вердикта}, номер_захода ${@номер_захода}, заход_отсчёта ${@заход_отсчёта}, серия_чистых ${@серия_чистых}, без_проб_подряд ${@без_проб_подряд}")
  }
  _ => ()
}

/// Таблица «конец → ответ» первоисточника (раздел «Контракт машины»): каждый конец и каждое значение остановка — одна строка.
/// Вердикты по стадиям (чисто, требования, план, вопрос — у разбора, плана, реализации; перезапуск — только у сдачи; чисто и остановлено — у совещания) задают строки состояний.
fn Машина @ответ_по_концу(вызов Запрос[ВходПроверки], конец Состояние, среда Окружение) -> Исход[ИтогПроверки] {
  match конец {
    // КОНЕЦ, условие входа: всегда → СРезультатом: вердикт, источник, счётчики цикла, находки «вне задачи»
    КОНЕЦ => СРезультатом(ОтветСРезультатом {
      запрос: вызов.идентификатор_запроса, сторона: вызов.сторона, трасса: вызов.трасса, номер_шага: вызов.номер_шага,
      результат: ИтогПроверки {
        вердикт: вердикт_из_текста(@вердикт), источник: @источник_вердикта,
        цикл: @цикл(),
        вне_задачи: @вне_задачи } })
    // ОШИБКА, условие входа: всегда (дефект машины) → Отказ, НетРезультата; текст — запись из перехода
    ОШИБКА => отказ_по(вызов, НетРезультата, среда.запись_перехода())
    ОСТАНОВЛЕНО => match @остановка {
      // ОСТАНОВЛЕНО: остановка = «запуск сессии: нет результата» → Отказ, НетРезультата
      "запуск сессии: нет результата" => отказ_по(вызов, НетРезультата, @остановка)
      // ОСТАНОВЛЕНО: остановка = «ПОВТОР: остановить», «запуск сессии: остановлено человеком» или «ПАУЗА: остановить»
      //   (слово человека; у вызванной машины — сигнал «остановить от родителя» в ПАУЗЕ) → Отказ, ОстановленоЧеловеком
      "ПОВТОР: остановить" | "запуск сессии: остановлено человеком" => отказ_по(вызов, ОстановленоЧеловеком, @остановка)
      "ПАУЗА: остановить" => отказ_по(вызов, код_сбоя_общей_остановки(@остановка), @остановка)
      // ОСТАНОВЛЕНО: остановка = «отмена_запроса» → Отказ, ОтмененоРодителем
      "отмена_запроса" => отказ_по(вызов, код_сбоя_общей_остановки(@остановка), @остановка)
      _ => недостижимо("значение остановка вне таблицы «конец → ответ»: новое значение добавляет строку таблицы")
    }
    _ => недостижимо("ответ отдают только концы")
  }
}

/// Точка подстановки эффектов: обработчики выбирает вызывающий код, один раз (`with`), и вне этого файла — любые (`Time` — стандартный, обработчик по умолчанию).
/// Все функции цепочки от `начать`, `возобновить`, `вызвать` объявляют эффекты в своей сигнатуре; здесь они подставлены. Машину по входу запроса создаёт вызывающий код
/// (обработчик `Связь` верхней машины при запросе `ЗапросРоли` с входом `ВходПроверкиЦикла`).
fn запуск_проверки(запрос Запрос[ВходПроверки]) Time -> Исход[ИтогПроверки] =>
  with Хранилище = обработчик_хранилища, Журнал = обработчик_журнала, Связь = обработчик_связи, Объекты = обработчик_объектов {   // псевдокод: обработчики (база, файл поверх Fs/Db, очередь сообщений) — любые, вне файла
    mut исполнитель = Исполнитель.new(Машина.из_входа(запрос.вход))
    исполнитель.вызвать(запрос)
  }
```
