# WC-6: Реальные агентные интеграции

Эпик: `doc/tasks/work-coordinator-epic`

## Результат и границы

Подключить согласованные исполнительные/проверочные интеграции к стабильному контракту; журналировать неизвестные исходы и обеспечивать идемпотентность эффектов. Контракт не менять под конкретного поставщика.

## REQ/AC эпика

REQ-3, REQ-6–9; AC-3, AC-6–9.

## Зависимости

Зависит от: `doc/tasks/work-coordinator-epic/wc-5-end-to-end`.

Блокирует: общую приёмку эпика.

Пересекается (файлы): определить при постановке после WC-5.

Начинается после: WC-5 принята; приняты host и контракт; решения о границе продукта/backend и полномочиях интеграций приняты.

## Приёмка

Контрактные проверки каждого адаптера покрывают повтор, таймаут, неизвестный эффект, отсутствие автоматической приёмки/публикации и общую приёмку. Exactly-once не обещается. До выполнения предшественников не запускать.
