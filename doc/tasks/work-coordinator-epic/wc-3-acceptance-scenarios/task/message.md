# WC-3: Сценарии и примеры приёмки

Эпик: `doc/tasks/work-coordinator-epic`

## Результат и границы

Исполнимо сформулированные сценарии для всех REQ/AC и трассировка требований к проверкам. Это спецификация поведения, не реализация тестового стенда.

## REQ/AC эпика

REQ-1–10; AC-1–12.

## Зависимости

Зависит от: `doc/tasks/work-coordinator-epic/wc-1-rules`, `doc/tasks/work-coordinator-epic/wc-2-common-contract`.

Блокирует: `doc/tasks/work-coordinator-epic/wc-4-minimal-host` и `doc/tasks/work-coordinator-epic/wc-5-end-to-end`.

Пересекается (файлы): определить при постановке после предшественников.

Начинается после: WC-1 и WC-2 приняты.

## Приёмка

Каждый AC имеет вход, ожидаемую запись/исход и способ проверки; отрицательные пробы из принятого плана присутствуют; трассировка полна, непроверяемые требования объяснены. До выполнения предшественников не запускать.
