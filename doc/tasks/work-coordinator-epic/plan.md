# План эпика: переносимый координатор выполнения работ

**Тип:** эпик. **Статус:** регистрация выполнена; дочерние задачи-кандидаты WC-1—WC-6 не созданы и не запущены.

**Источник плана:** [doc/work-coordinator-epic-plan.md](../../../doc/work-coordinator-epic-plan.md). Это единственный первоисточник состава, зависимостей, проверок, оценок и распределения REQ/AC; здесь они не дублируются.

Порядок постановки и зависимости кандидатов, покрытие требований и примеры общей приёмки определены в первоисточнике плана. До отдельного решения о постановке кандидаты не являются активными задачами. Вопросы, блокирующие реализацию, остаются открытыми в первоисточнике спецификации.

Эпик принимается не по созданию карточки и не по готовности дочерних по отдельности, а по критериям в [spec.md](spec.md) и правилам методики.
