# WC-5: Сквозной сценарий

Эпик: `doc/tasks/work-coordinator-epic`

## Результат и границы

Исполняемый сквозной тест объединённого результата: вложенный эпик, параллельные задачи, изменение в середине работы, рестарт, доставка решения владельца и общая приёмка. Новые продуктовые интеграции не добавлять.

## REQ/AC эпика

REQ-1–9; AC-9, AC-10.

## Зависимости

Зависит от: `doc/tasks/work-coordinator-epic/wc-3-acceptance-scenarios`, `doc/tasks/work-coordinator-epic/wc-4-minimal-host`.

Блокирует: `doc/tasks/work-coordinator-epic/wc-6-agent-integrations`.

Пересекается (файлы): сквозной тест и общий host — согласовать владельцев до запуска.

Начинается после: WC-3 и WC-4 приняты.

## Приёмка

Тест красный при отключении пересверки затронутой ветви, восстановления доставки или общей приёмки; зелёный на принятой реализации; незатронутая ветвь не перезапущена. До выполнения предшественников не запускать.
