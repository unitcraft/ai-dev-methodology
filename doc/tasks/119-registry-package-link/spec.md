# Спецификация: М-1 — связь реестров методики и пакета

**Тип: задача (дитя эпика 118, REQ-3 → AC-2/AC-3). Статус: постановка из слов владельца (быстрый маршрут).** Вход — [task/message.md](task/message.md); нормативная основа — [spec.md эпика](../118-tonkiy-hozyain-v-pakete-epic/spec.md) REQ-3.

## AC

- **AC-M1-1.** Страж задачи 103 сверки: 13 универсальных строк таблицы «Primitives» реестра методики равны строкам реестра пакета (`nova-alula/src/thin_host/registry.md`, дерево e92b966) построчно и байт-в-байт (все шесть ячеек); ядро-4 (`issue_token`, `verify_token`, `journal_write`, `release_lock`) в реестре пакета отсутствует; расхождение любой ячейки, отсутствие строки, лишняя универсальная строка или утечка ядра-4 — красный с именем строки и колонкой. Путь к реестру пакета задаётся аргументом `--package-registry <путь>` (или переменной среды `ALULA_PACKAGE_REGISTRY`; аргумент сильнее); без пути проверка связи пропускается с явным сообщением — репозиторий методики чужих путей не хранит (образец — `--glossary` проверок пакета).
- **AC-M1-2.** Шапка `alula-machines/registry.md` — помеченный абзац-указатель: канонический источник 13 универсальных строк — реестр пакета; строки таблицы методики — действующие данные машин и сверяются стражем; перенос датирован и назван решением владельца (эпик 118). Строки таблиц «Primitives»/«Reasons» не меняются.
- **AC-M1-3.** Прогоны: страж зелёный в обе стороны (базовая проверка + сверка с пакетом); самотест стража зелёный с новыми случаями; `alula test alula-machines` (595 тестов) зелёный БЕЗ изменения фикстур; саботаж-проба — правка одной ячейки в копии реестра пакета → страж красный с именем строки (копия во временной папке, рабочие реестры не правятся).

## Границы

Только М-1: расширение стража 103, шапка реестра, карточка. Не входит: миграция машин (G), правка строк реестра, правки репозитория пакета, заводы П-2. Публикация (коммит методики) — по слову владельца.
