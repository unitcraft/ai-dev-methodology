## Сделано

1. Реестр: 16 строк каркаса (ФС 6, процессы 4, замок `acquire_lock`, `parse_agent`,
   `sha256`, ядро 3) + типы `ExecResult`, `Opening`; шапка — 87 инструментов,
   назначение каркаса и стадии. Сверка с планом v3.1 — совпадение имён, классов,
   сигнатур; 17-й примитив `release_lock` в реестре действующий (замена на версию
   с токеном — стадия 4, чтобы не ломать контракт с 595 тестами раннера).
2. Страж 103: закрытый список универсальных примитивов расширен словом владельца
   (план v3.1): ФС, процессы, замки, `parse_agent`, `sha256`; документация стража
   обновлена; прогон по действующему реестру зелёный (0 без причины).
3. ScriptedHost-эталон (`scripted_host.py`): реально исполняет ФС, замки
   (атомарное O_EXCL, повтор со своим токеном — истина), `sha256` (hashlib —
   стандартная библиотека Python, поверх системной криптобиблиотеки ОС; 64 hex),
   журнал; скриптует процессы, разбор агента, токены. Общие правила: пути только
   внутри дерева хозяина, недоступность — сбой шага (`StepFailure`).
4. Спецификация `host-spec.md`: состав, поведение каждого примитива, общие
   правила, связь с реестром и стадией 4.
5. Машины `task_runner`/`session_start` не менялись: новые примитивы не зовут
   (стадии 2–6).
