Их основание — ожидаемые ошибки при отсутствии указанного следа; если сверка покажет, что пробел уже закрыт, соответствующее уточнение удаляется.

## Предполагаемая граница правила

Умолчание может разрешать только действие, уже входящее в выданную работу. Наступивший срок сам по себе не открывает owner gate и не снимает HOLD, live/safety-ограничения, решения о деньгах, новой работе или публикации. Вопрос и ответ сохраняют ссылку на исходный контекст и источник; при конфликте приоритет имеет более позднее подтверждённое слово владельца, а повторный ответ не создаёт нового решения и не закрывает уже решённый вопрос. Формулировки остаются переносимыми: без идентификаторов сообщений конкретного инструмента и названий продуктов.

Неблокирующая находка не останавливает уже разрешённую работу. Блокер называет конкретное невыполнимое требование и следующий разрешённый шаг. Отложенный результат остаётся в предусмотренной записи с причиной, ответственным и условием возврата. При повторе известного класса фиксируется конкретная регрессионная проба; если её нельзя добавить, указывается доказанная причина невозможности. Исправление подтверждается повторным выполнением исходной пробы.

## Текстовые пробы для независимой сверки

| Пара пробы | Положительный вход → исход | Отрицательный вход → исход |
|---|---|---|
| Срок и полномочия | Срок истёк; уже выданное безопасное действие в рамках задачи имеет умолчание → действие разрешено, независимые разрешённые шаги продолжаются | То же умолчание пытаются применить для владельческих ворот, остановки, денег, действующей системы, новой работы или публикации → действие запрещено без отдельного полномочного решения |
| Связь вопроса и ответа | Открытый вопрос получает ответ, относящийся к его контексту и источнику → решается только эта развилка | Вопрос уже решён; приходит повторный/устаревший ответ → исход не переоткрывается; затем приходит новое подтверждённое слово владельца → допускается смена решения с записью даты и источника |
| Неблокирующая находка | Несвязанная неблокирующая находка внесена в существующий дом → фиксируется, разрешённая независимая работа идёт дальше | Та же находка используется, чтобы остановить всю задачу → недопустимо |
| Блокер | Запись называет требование постановки, которое нельзя выполнить, и следующий разрешённый шаг → блокируются только зависимые действия, шаг понятен | Требование или следующий шаг не названы → по этой записи нельзя объявить работу заблокированной |
| Отложенный результат | В существующей записи есть причина, ответственный и условие возврата → отложение проверяемо | Любое из трёх полей отсутствует → отложение неполно, результат не объявляется закрытым |
| Доказательство исправления | Исходная воспроизводимая проба до исправления отрицательна, после — даёт ожидаемый результат → исправление подтверждено | Есть только письмо «исправлено», исходная проба не повторена → исправление не подтверждено |

Проверяющий сверяет обе стороны каждой пробы по нормативному diff и точному SHA. Проверка формулировок на базе `d7b7afc3e3f71d88ba8c7a4f2ad3f34c5f97a9d0` до правки дала красный результат для шести критериев; на текущем кандидате — зелёный для всех шести. Это текстовая проба наличия нового правила, не машинное доказательство его исполнения. Таблица задаёт положительный и отрицательный сценарии для независимого смыслового чтения.
