## Честная оговорка

- Scripted-ответы движка матчатся только по имени примитива (проверено по
  коду движка, `machine_run/machine.nv`): после слияния четырёх git-чтений
  в один `run_command` значения для разных чтений разведены по шагам
  фикстур; это механика тестов, не логика машины.
- Пути `delivery/commit.txt` и `delivery/customer.md` взяты из прозы
  `task-sessions.md` (С7); в письме интегратора путь был короче
  (`папка_задачи/commit.txt`) — проза методики честнее и детальнее.
- Реестр не менялся: предметные инструменты остаются со своими причинами
  до поздних стадий (решение интегратора).
