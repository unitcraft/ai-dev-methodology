# Результат задачи 103

## Артефакт

Страж универсальности внешних функций хозяина (правило 14б `state-machine-spec.md`):
`check_host_universality.py` и его пробы `test_check_host_universality.py`. Запускается
стандартной библиотекой Python. Страж читает реестр хозяина (`alula-machines/registry.md`,
раздел «## Primitives») и ничего в нём не меняет.

## Сделано

1. Сбор: разбор таблицы «## Primitives» реестра — все объявленные внешние функции
   (`parse_primitives`; без раздела, таблицы или столбца `name` страж красный, а не молчит).
2. Проверка каждой функции: имя в закрытом списке универсальных примитивов
   (`read_file`, `write_file`, `run_command` — примеры правила 14б; `time_now`, `new_id` —
   примитивы языка по шапке реестра, раздел 7а, AL-113) — зелёная; иначе предметная и
   зелёная только с непустой причиной в столбце `reason` таблицы (пустая ячейка и `—` —
   причины нет). Список универсальных — параметр стража; его расширение — решение методики.
3. Красный: на каждую предметную функцию без записанной причины выводится строка
   «КРАСНЫЙ: <имя> — предметная функция без записанной причины нераскладываемости
   (правило 14б)», код возврата 1.
4. Уточнение критерия (письмо интегратора, 2026-11-06): каждая внешняя функция —
   примитив, не раскладывающийся на другие внешние функции без потери смысла; у каждой
   функции есть записанное доказательство, что она не реализуется через существующие
   примитивы. Страж проверяет и это: если записанная причина сама называет другие
   функции реестра (слово целиком), декларация признаёт разложение — красный
   «раскладывается на примитивы: <имена>» с перечнем этих примитивов. Ссылка функции
   на саму себя и имена вне реестра разложением не считаются.

Прочитано перед реализацией: `state-machine-spec.md` правила 14а (коммит 8af7d78) и 14б
(коммит 9e88481; влит в целевую ветку задачей 102 до публикации этой — страж реализует
его проверку), реестр хозяина `alula-machines/registry.md` (шапка — формат объявления:
раздел 7 спецификации Алулы, столбцы name/parameters/result/class/reads/writes).
