01 / Карта сессий

План утверждён — только потом начинается реализация

Промпты работают по файлам, поэтому планирование и код могут разделять время и разные исполнители. Проверяющая сессия не пишет код, который проверяет.

Основной маршрут

ЧЕРНОВИК → ПРОВЕРКА → РЕШЕНИЕ
С1 → С2Разобрать

Источники → spec.md → проверка → вопросы.

ВОРОТА 1Утвердить требования

Ответы и подтверждение сценариев владельцем.

С3 → С4Спланировать

Шаги → plan.md → независимая проверка.

ВОРОТА 2Утвердить план

План зафиксирован; реализация может начаться.

С5 → С8Сделать и сдать

Реализация → проверка → сдача → проверка.

После передачи: С9 разбирает обратную связь и направляет следующий раунд к требованиям, плану или реализации.
02 / Повтор проверки

Чистый итог — это подтверждённая серия

Один красивый отчёт не останавливает этап. Человек читает находки, проверяет пробы и засчитывает каждый заход.

Петля одного этапа

АВТОР · ПРОВЕРКА · ПРАВКА
01Автор

Создаёт или обновляет артефакт.

02Проверяющий

Свежая сессия ищет пропуски и ошибки.

03Владелец

Читает все находки, решает и фиксирует.

04Повтор

Правка → новая проверка → следующий заход.

05Выход

Два чистых захода подряд с нужными пробами.

Ограничители цикла

ПРАВИЛА ИЗ ДОКУМЕНТА
2×

Чистая серия

Остановка после двух проверок подряд без существенных находок.

3×

Проба обязательна

Чистый заход засчитывается только с тремя проверяемыми пробами.

4×

Потолок этапа

Если существенные находки остались, решение принимает владелец.

03 / Возврат по уровню

Замечание ведёт к тому документу, который нужно менять

После правки не перезапускается вся задача. Возврат сохраняет готовые срезы и продолжает с нужной проверки.

Требования изменились

С1 правка → С2 → повторное утверждение spec.md → план.

Нужна правка плана

С3 правка → С4 → утверждение plan.md → продолжение реализации.

Замечание по коду

С5 правка → С6; результат снова проходит нужные проверки.

Сессия не опирается на историю чата: источники, решения, статусы и номера заходов находятся в файлах задачи.
04 / Перед первым запуском

Подготовить папку задачи — и сессии станут взаимозаменяемыми

Минимальный цикл рассчитан на человека, задание и ИИ-агента без трекера и команды. Каждый запуск получает полный промпт и читает актуальное состояние из файлов.

02 / ИЗОЛЯЦИЯ

Не смешивать незакоммиченные изменения разных задач.
